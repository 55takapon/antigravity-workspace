## やるべきことを、チェックリストにまとめました

「検索対策をやらなきゃいけないのはわかっている。でも何からやればいいのかわからない。」

そんなふうに悩んでいませんか？

「専門用語が多くて難しい」「業者に頼まないと無理なのかな」と感じるかもしれません。でも大丈夫です。

自分でできる検索対策（検索結果で上のほうに表示されるための対策）を、分かりやすい言葉でチェックリスト形式にまとめました。

業者に頼まなくても、ここに書かれていることを1つずつ実行するだけで、あなたのホームページは検索で見つけてもらいやすくなります。

上から順にチェックしていってください。完了したら次の項目へ進む。それだけです。

---

## チェックリスト1：基本設定（最初に1回やるだけ）

まずは土台を整えます。これは最初に1回やれば完了する作業です。

- [ ] ホームページのタイトルタグを「サービス名＋エリア名｜お店の名前」の形に設定した
- [ ] 各ページにメタディスクリプション（80〜120文字の説明文）を設定した
- [ ] トップページに「誰のためのお店か」「何ができるか」「どこにあるか」が文章として書かれている
- [ ] お店の住所・電話番号がホームページ内に明記されている（フッターがベスト）
- [ ] ホームページがスマホで見やすく表示されている（文字が小さすぎないか、ボタンが押しやすいか）
- [ ] ホームページの表示速度が遅くないか確認した（Googleの「PageSpeed Insights」で無料チェックできます）
- [ ] SSL（https）対応済みか確認した（URLが「https://」で始まっているか）

ここまでができていれば、検索対策の土台は整っています。

土台ができたら、次はGoogleマップとの連携です。

---

## チェックリスト2：マップ集客との連携

ホームページの検索対策とマップ集客は、セットで取り組むと相乗効果が生まれます。

- [ ] Googleビジネスプロフィール（マップ情報）に登録済み
- [ ] マップ情報の全項目（営業時間・住所・電話番号・説明文・カテゴリ・属性）が入力済み
- [ ] マップ情報とホームページの住所・電話番号・営業時間が完全に一致している
- [ ] マップ情報にホームページのURLを設定している
- [ ] 写真を10枚以上登録している
- [ ] 口コミに返信している

マップ情報の設定がまだの方は、先にこちらの記事をご覧ください。
→ [Googleビジネスプロフィールの始め方｜最初にやるべき5つの設定](./A-01_gbp-setup-guide.md)（A-01）

マップの連携が終わったら、いよいよコンテンツを増やしていきます。

---

## チェックリスト3：ブログ運用（継続して取り組む）

土台が整ったら、ブログで検索の「入口」を増やしていきます。

- [ ] 記事を書く前に「お客さんが検索しそうな言葉（キーワード）」を決めている
- [ ] タイトルにキーワードが含まれている
- [ ] タイトルが30〜35文字に収まっている
- [ ] 記事の冒頭に結論が書かれている
- [ ] 見出し（大見出し・小見出し）で記事の構成が整理されている
- [ ] 見出しだけ読んでも記事の流れがわかる
- [ ] 文字数が3,000〜5,000文字になっている
- [ ] 記事の最後に「次にやるべきこと」と案内が書かれている
- [ ] 関連する記事へのリンクが2〜3本入っている
- [ ] 週1〜2本のペースで更新している（またはそのペースを目指している）

ブログの書き方の詳細はこちら。
→ [検索順位を上げるブログの書き方｜店舗オーナー向けSEOライティング](./B-02_seo-writing-guide.md)（B-02）

ブログを書き始めたら、外部のサイトとの連携も確認しましょう。

---

## チェックリスト4：外部対策

ホームページの外側でできる対策もあります。

- [ ] 業種に合ったポータルサイト（食べログ、ホットペッパー、エキテン等）にお店の情報を登録している
- [ ] 各ポータルサイトのお店の名前・住所・電話番号がホームページと完全に一致している
- [ ] SNS（Instagram、LINE公式等）のプロフィールにホームページのURLを載せている
- [ ] ブログ記事をSNSでシェアしている

すべての対策が終わったら、あとは定期的な確認だけです。

---

## チェックリスト5：効果確認（月に1回）

やりっぱなしにせず、月に1回は状況を確認しましょう。

- [ ] Google Search Console にホームページを登録している
- [ ] Search Console で「どんな言葉で検索されているか」を確認した
- [ ] 狙っているキーワードで実際に検索して、自分のページが何番目に表示されるか確認した
- [ ] マップ情報の管理画面で閲覧数・アクション数の推移を確認した
- [ ] 数字が伸びている施策は続け、伸びていない施策は見直した

## よくある質問

### Q. 全部やらないとダメですか？

全部を一度にやる必要はありません。チェックリスト1（基本設定）とチェックリスト2（マップ連携）を先に済ませてから、チェックリスト3（ブログ運用）に取り組んでください。焦らず、1つずつ進めていくことが大切です。

### Q. WordPressじゃないとできませんか？

WordPressでなくても可能です。ただし、タイトルタグやメタディスクリプションを自由に編集できるCMS（ホームページ管理システム）を使っていることが前提です。無料ブログサービス（アメブロ等）では一部の設定ができない場合があります。

### Q. 効果が出ているかどうか、どう判断しますか？

Google Search Console の「検索パフォーマンス」で、表示回数とクリック数の推移を確認してください。これが右肩上がりになっていれば、対策は効いています。3か月を目安に判断しましょう。

## まとめ｜まずはチェックリスト1から始めてください

自分でできる検索対策の全体像をまとめます。

1. 基本設定を整える（1回だけ）
2. マップ集客と連携させる
3. ブログで検索の入口を増やす
4. 外部サイトにお店情報を統一する
5. 月1回、効果を確認する

まずはチェックリスト1を上から順に確認してください。タイトルタグとメタディスクリプションの設定だけでも、検索結果での見え方が変わります。
