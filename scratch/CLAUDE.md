# プロジェクト概要

このワークスペースは `C:\Users\hangy\.gemini\antigravity\scratch` にある Antigravity の作業ディレクトリです。
Web開発、自動化スクリプト、データ処理など多目的に使用します。

## 基本ルール

- 日本語で応答すること
- コードのコメントは日本語で記述すること
- コミットメッセージは日本語で記述すること

## コーディング規約

- ファイル名はスネークケース（例: `my_script.py`）またはケバブケース（例: `my-component.js`）を使用
- インデントは2スペース（HTML/CSS/JS）または4スペース（Python）
- 文字エンコーディングは UTF-8 を使用

## ワークフロー

- 変更を行う前に、既存のコードベースを確認すること
- 変更後は動作確認を行うこと
- 大きな変更は段階的に実施すること

## ディレクトリ構成

- `company_search/` — 企業検索ツール
- `form_automation/` — フォーム自動化ツール
- `website_production/` — Webサイト制作
- `chatgpt_automation/` — ChatGPT連携ツール
