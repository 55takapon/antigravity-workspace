# contact-auto テストフォーム 10パターン

各パターンのCF7ショートコードを自社サイトに実装し、
contact-autoの自動送信精度を検証する。

| # | パターン名 | テスト対象 |
|---|-----------|-----------|
| 1 | 基本4項目 | 氏名・メール・件名・本文（標準） |
| 2 | 会社名＋部署 | company / department 認識 |
| 3 | 電話＋FAX | phone / fax 認識 |
| 4 | ラジオボタン（お問い合わせ種別） | radio 自動選択 |
| 5 | プルダウン（予算・プラン） | select 自動選択 |
| 6 | ラジオ（連絡方法希望） | preferred_contact radio |
| 7 | URL＋制作時期 | url / deadline 認識 |
| 8 | 非標準フィールド名 | name属性がテキトーな場合 |
| 9 | チェックボックス（同意）＋複合 | checkbox + 複数select |
| 10 | フルコンボ（全部入り） | 全カテゴリ同時テスト |
