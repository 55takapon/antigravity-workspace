# 業種別拡張の設計ルール

## 目的

このスキルはGBP投稿文作成のコアとして使う。医療、飲食、美容、士業、不動産、金融などの業種固有ルールは、必要になった時に追加ファイルとして拡張する。

## 拡張ファイルに入れるもの

| 項目 | 書く内容 |
|:---|:---|
| 業種固有の規制 | 医療広告、景品表示、士業広告、食品表示など |
| 投稿テーマ | 季節、悩み、来店動機、予約動機 |
| 禁止表現 | 効能断言、比較優良、過度な割引訴求など |
| 推奨素材 | 写真、メニュー、症例ではなく設備説明、スタッフ紹介など |
| 品質チェック | コアの品質チェックへ追加する項目 |

## 作業手順

1. 業種別拡張が存在する場合だけ、そのファイルを該当工程で読む。
2. 業種別拡張が存在しない場合は、このコアスキルの安全側ルールを優先する。
3. 医療や金融など高リスク業種では、効果・成果・比較優良・体験談を本文の中心にしない。
4. 飲食など写真と季節性が強い業種では、メニュー、利用シーン、予約動機、写真案を中心に設計する。
5. 拡張ファイルを追加する時は、SKILL.mdを肥大化させず、referencesの1階層に置く。

## 出力形式

業種別拡張を使った場合は、最終出力に次を短く添える。

| 項目 | 内容 |
|:---|:---|
| 使用した業種別拡張 | 実行時に読んだ拡張名 |
| 追加チェック | コアに追加した確認項目 |
| 除外した表現 | 規制または根拠不足で入れなかった内容 |

## 確認方法

- 業種別の詳細ルールをSKILL.mdへ直接増やしていない。
- 拡張ファイルがない業種で、危ない断言をしていない。
- 業種別拡張の内容が、コアの材料確認と品質チェックに接続されている。

## 不合格時の対応

- 業種固有の規制を確認できない場合は、低リスクな事実告知に寄せる。
- 高リスク表現が必要な依頼は、完成文を出さず確認質問に戻す。
- 拡張すべき内容が増えた場合は、コアではなく新しい業種別referenceとして追加する。
