# 投稿方針の決め方

## 目的

確認済み材料を、Googleビジネスプロフィールで使える投稿方針へ変換する。順位上昇を保証する文章ではなく、顧客が来店・予約・問い合わせを判断しやすい文章にする。

## 投稿タイプの選び方

| 投稿タイプ | 使う場面 | 注意点 |
|:---|:---|:---|
| 最新情報 | お知らせ、季節情報、サービス紹介、FAQ | 迷ったらこれを使う |
| 特典 | 割引、クーポン、期間限定キャンペーン | 期間、条件、対象者を必ず確認する |
| イベント | セミナー、相談会、店内イベント | 開催日、時間、場所、申込方法を必ず確認する |

商品・メニュー紹介をしたい場合も、投稿として出すなら原則「最新情報」を使う。プロフィールの「商品」や「メニュー」機能そのものを更新する作業とは分ける。

## 見る観点

- 誰に向けた投稿か。
- 何を知ってもらう投稿か。
- 投稿後にどんな行動を促すか。
- 地域名、サービス名、悩み語が自然に入るか。
- 過去投稿と同じ切り口になっていないか。
- 写真や動画で補うべき情報があるか。

## 作業手順

1. 投稿目的を「認知」「比較検討」「予約・問い合わせ」「来店前の不安解消」のどれかに寄せる。
2. 最初の一文で、地域、対象顧客、投稿テーマが分かる切り口を決める。
3. 投稿タイプとCTAを決める。電話は本文に書かず、必要なら「今すぐ電話」ボタンで扱う。
4. 使うキーワードを3から6語に絞り、文脈の中で自然に使う。
5. 固定フッターを使う場合は、地域、業種、主力サービスを120から200字程度でまとめる。

## 出力形式

| 項目 | 内容 |
|:---|:---|
| 投稿タイプ | 最新情報、特典、イベントのいずれか |
| 投稿目的 | 認知、比較検討、予約・問い合わせ、来店前の不安解消 |
| 対象顧客 | 投稿を読む人 |
| 中心メッセージ | 一番伝えること |
| CTA | 詳細、予約、注文、電話など |
| 写真案 | 投稿に合う写真または動画 |
| 採用しない主張 | 根拠不足、規制リスク、重複テーマ |

## 確認方法

- 投稿タイプとCTAが矛盾していない。
- 地域名やサービス名が、文章の意味を壊さず入る。
- 未確認の実績や効果を中心メッセージにしていない。

## 不合格時の対応

- 目的が曖昧なら「最新情報」で安全に設計する。
- 特典やイベントの条件が足りない場合は、完成文にせず質問する。
- 重複テーマしか作れない場合は、対象顧客、季節性、利用シーンのいずれかを変える。
