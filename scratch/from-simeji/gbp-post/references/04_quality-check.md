# 品質チェック

## 目的

投稿前に、Googleビジネスプロフィールのポリシー、事実確認、業種規制、読みやすさを確認する。

## 公式確認先

- Googleビジネスプロフィールヘルプ: 写真・動画ポリシーと投稿コンテンツポリシー  
  https://support.google.com/business/answer/7213077
- Googleビジネスプロフィールヘルプ: ビジネスプロフィール投稿の作成と管理  
  https://support.google.com/business/answer/7342169
- Googleビジネスプロフィールヘルプ: ビジネスプロフィールポリシーの概要  
  https://support.google.com/business/answer/13762416

公式情報では、投稿説明文に電話番号を含めると拒否される可能性がある。投稿は公開前にGoogleのポリシー確認を受けるため、迷う表現は安全側へ修正する。

## チェック項目

| 軸 | 判定すること | 不合格例 | 修正方針 |
|:---|:---|:---|:---|
| 事実確認 | 材料カードにない事実がないか | 未確認の設備、価格、営業時間 | 削除または質問 |
| Googleポリシー | 電話番号、低品質リンク、不適切表現がないか | 投稿本文の電話番号 | CTAボタンやプロフィール情報へ分ける |
| 誇大表現 | 効果、順位、人気、実績を保証していないか | 必ず集客、地域一番 | 傾向表現または削除 |
| 規制業種 | 医療、金融、アルコール等の制限に触れないか | 効果効能の断言 | 業種別拡張または公式資料へ戻る |
| 読みやすさ | スマートフォンで読みやすいか | 長い一段落、記号過多 | 段落分け、短文化 |
| 重複回避 | 過去投稿と同じタイトルや切り口でないか | 先月と同じ訴求 | 季節、対象、利用シーンを変える |

## 作業手順

1. 投稿文の各文を材料カードへ照合する。
2. 電話番号、過剰なURL、キーワード羅列、記号過多を確認する。
3. 誇大表現と広告規制リスクのある語を弱めるか削除する。
4. 過去投稿がある場合は、タイトルと訴求の重複を確認する。
5. 修正版とチェック結果を一緒に出す。

## 出力形式

| チェック軸 | 判定 | 修正内容 |
|:---|:---|:---|
| 事実確認 | 合格または要修正 | 実行時の修正内容を書く |
| Googleポリシー | 合格または要修正 | 実行時の修正内容を書く |
| 誇大表現 | 合格または要修正 | 実行時の修正内容を書く |
| 規制業種 | 合格、要修正、対象外 | 実行時の修正内容を書く |
| 読みやすさ | 合格または要修正 | 実行時の修正内容を書く |
| 重複回避 | 合格、要修正、未確認 | 実行時の修正内容を書く |

## 確認方法

- 要修正が残っている場合、最終投稿案として出していない。
- 修正理由が品質チェック結果に残っている。
- 規制業種の判断を対象外にする場合、理由が説明できる。

## 不合格時の対応

- 事実確認で不合格なら、該当文を削除する。
- 規制リスクで不合格なら、業種別拡張または公式資料確認へ戻る。
- 投稿目的が崩れるほど削除が多い場合は、完成文ではなく素材不足質問を出す。
