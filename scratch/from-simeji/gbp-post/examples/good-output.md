# 出力の型

このファイルは、実データがない時の入力と出力の型を示す。コピー用の完成投稿文ではない。

## 正常系: 材料が足りている場合

### 入力

| 項目 | 内容 |
|:---|:---|
| 業種 | 地域店舗または来店型サービス |
| 地域 | 店舗が主に集客したい市区町村または駅名 |
| 投稿テーマ | 季節のお知らせ、サービス紹介、イベント、キャンペーンのいずれか |
| 確認済み材料 | 店舗名、主力サービス、対象顧客、期間、条件、公式情報 |
| 希望CTA | 予約、詳細確認、問い合わせ、来店のいずれか |

### 出力

```markdown
## 投稿タイプ
最新情報、特典、イベントのいずれか

## タイトル案
確認済み材料だけで作った短いタイトル

## 投稿文
冒頭で地域・対象・テーマが分かり、本文で確認済みの特徴や利用シーンを説明し、最後に自然な行動促進で終える投稿文

## CTA
Googleビジネスプロフィール上で選ぶボタン案

## 写真案
投稿内容と一致する写真または動画の案

## 使った材料
投稿文に反映した確認済み材料の一覧

## 未確認のため入れなかった内容
出典不足、条件不明、規制リスクで除外した内容

## 品質チェック結果
事実確認、Googleポリシー、誇大表現、規制業種、読みやすさ、重複回避の判定
```

## 異常系: 材料不足で完成文を出せない場合

### 入力

| 項目 | 内容 |
|:---|:---|
| 業種 | 医療、金融、士業、健康美容など規制リスクがある業種 |
| 投稿テーマ | 効果、成果、割引、症状改善、法律効果など確認が必要な内容 |
| 確認済み材料 | 店舗名と大まかなサービス名のみ |
| 不足情報 | 期間、条件、公式記載、広告規制上の確認材料 |

### 出力

```markdown
## 作成を止める理由
確認済み材料だけでは、事実確認または広告規制の面で安全な投稿文にできない理由

## 追加で必要な情報
- 公式サイトまたはパンフレットに記載されたサービス内容
- キャンペーン期間、対象者、条件
- 効果や実績を示す場合の根拠
- 業種別広告規制で確認すべき項目

## 今回入れない内容
未確認の効果、成果、価格、期間、比較優良、体験談

## 安全に作れる代替案
営業時間案内、予約枠案内、設備紹介、アクセス案内など、確認済み事実だけで作れる投稿テーマ
```
