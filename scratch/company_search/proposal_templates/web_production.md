# Web制作・HP制作会社向け 協業提案文テンプレート

---

## このカテゴリの特徴

- HP制作後の「その先」（集客）に課題を抱えるクライアントが多い
- GBP運用はHP公開と同時に開始するのが効果的 → 制作時の同時提案が最強
- 小規模Web制作会社ほど付加価値サービスへの関心が高い

---

## 提案文テンプレート

```
件名: 【Web制作 × MEO】貴社クライアント様の集客を強化する協業のご提案

{company_name}
{representative}様

突然のご連絡失礼いたします。
Googleビジネスプロフィール（MEO）の運用支援を専門に行っております、
[あなたの会社名] の [あなたの名前] と申します。

貴社のWebサイトおよび制作実績を拝見し、
{region}エリアで高品質なWeb制作をされていることに大変感銘を受けました。

■ ご提案の背景

Web制作会社様とお話しする中で、よくお聞きする課題があります。

「HPを納品した後、クライアント様から
 "ホームページ作ったけど、お客さん来ないんだけど…" と言われてしまう」

これ、実はGoogleビジネスプロフィール（GBP）の運用で
大きく改善できるケースが非常に多いのをご存知でしょうか？

特に実店舗をお持ちのクライアント様の場合：
・「{region} + 業種名」で検索した際にGoogleマップに表示される
・口コミや写真でお客様の来店判断に直接影響する
・HPとGBPの相乗効果で検索順位が上がる

■ 具体的な協業モデル

【モデルA: 紹介フィー型】
 貴社がクライアント様にGBP運用をご紹介 → 当社が運用 → 紹介手数料をお支払い

【モデルB: OEM/ホワイトラベル型】
 貴社のサービスメニューに「MEO対策」を追加 → 実務は当社が裏方として対応

【モデルC: 共同提案型】
 HP制作の見積もりに「GBP運用プラン」をセットで提案 → 受注率UPに貢献

■ 貴社のメリット

✅ 既存の制作案件にGBP運用をアドオンするだけで客単価UP
✅ クライアント様の「HPの効果が見えない」問題を解決 → 継続率UP
✅ GBP運用の実務は当社が行うため、貴社の工数はゼロ
✅ 月額ストック収入で安定した売上基盤を構築
```
