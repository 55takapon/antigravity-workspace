## 1. 飲食店のMEO市場環境（2025-2026）

### 1.1 飲食店×ローカル検索の現状

- **グルメポータル→Googleマップへのシフト加速**: 食べログ・ぐるなびの利用率が漸減する一方、Googleマップでの飲食店検索が急増。特に20〜30代はGoogleマップを第一選択肢に
- **「今すぐ行きたい」検索の主戦場**: 「近くの居酒屋」「○○駅 個室 居酒屋」等のリアルタイム検索では、MEO上位表示が直接来店に直結
- **AI検索の影響**: 「渋谷で3人以上の個室がある日本酒が美味しい居酒屋」のような複合検索にGemini/AI Overviewsが対応。属性・メニュー・口コミの充実度が引用される鍵
- **ゼロクリック検索の増加**: GBP上で営業時間・メニュー・価格帯が確認でき、電話予約やルート検索まで完結。自社サイトへのクリックなしで来店に至るケースが増加

### 1.2 飲食店MEOの難易度と特徴

| 項目 | 飲食店の特徴 |
|------|------------|
| 競合密度 | **非常に高い**（都市部では半径500m内に30〜100店舗） |
| 口コミ数の重要度 | **最重要**（上位3位入りに80〜150件必要） |
| 写真の影響度 | **極めて大きい**（料理写真がCTR・来店意思決定に直結） |
| 更新頻度の重要度 | **高い**（メニュー変更・季節限定・日替わりの反映） |
| 予約連携 | **必須級**（Google経由の予約がアクション数に直結） |
| 季節変動 | **大きい**（忘年会・歓送迎会・ビアガーデン等で来店数が2〜3倍変動） |

### 2.2 属性設定チェックリスト（飲食店固有）

飲食店はGBP属性が最も多い業種の1つ。すべての該当属性を設定する。

#### 必須属性
- [ ] **サービス形態**: イートイン / テイクアウト / デリバリー
- [ ] **支払い方法**: 現金 / クレジットカード / PayPay / 交通系IC / QRコード決済
- [ ] **座席数**: 設定可能な場合は記載
- [ ] **駐車場**: あり/なし/近隣コインパーキング
- [ ] **予約**: 予約可 / 予約推奨 / 予約不要

#### 飲食店重要属性
- [ ] **個室**: あり/なし（「個室 居酒屋」の検索で最重要フィルター）
- [ ] **喫煙**: 全席禁煙 / 分煙 / 喫煙可
- [ ] **Wi-Fi**: あり/なし
- [ ] **バリアフリー**: 車椅子対応入口 / 車椅子対応トイレ / 車椅子対応座席
- [ ] **お子様連れ**: お子様連れ歓迎 / キッズメニューあり / お子様用椅子
- [ ] **ペット**: テラスのみ可 / 店内OK / 不可
- [ ] **飲み放題**: あり/なし
- [ ] **コース料理**: あり/なし
- [ ] **深夜営業**: 該当する場合は設定
- [ ] **ハッピーアワー**: 該当する場合は設定

> **「個室」属性は必ず設定**: 「個室 居酒屋 ○○駅」は高CVRキーワード。個室がある場合のCTRは無い場合の**1.4〜1.8倍**に達する。

### 2.3 メニュー・商品機能の活用

GBPの「メニュー」セクションは飲食店にとって最重要機能。

#### メニュー登録のベストプラクティス
1. **全カテゴリを網羅**: お通し・前菜・刺身・焼物・揚物・〆・ドリンク等のカテゴリ別に登録
2. **価格を必ず記載**: 価格帯がわかることでユーザーの安心感が向上
3. **写真を添付**: 主要メニュー（10品以上）には写真を添付
4. **看板メニューを先頭に配置**: 「おすすめ」「人気メニュー」カテゴリを最上部に
5. **季節メニューの更新**: 季節限定メニューは追加・終了を都度反映
6. **コース料理の詳細**: 品数・制限時間・飲み放題の有無・金額を明記

> **AIメニューデジタル化機能（2025年〜）**: メニュー画像/PDFをアップロードするとAIが自動でデジタルメニューに変換。高品質なメニュー画像の用意が重要。

## 3. 写真・動画コンテンツ戦略

### 3.1 飲食店の必須写真カテゴリ

飲食店は**写真の品質と量がCTR・来店決定に最も影響する業種**。最低50枚、理想100枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **料理写真（看板メニュー）** | 15〜30枚 | 45度俯瞰・自然光・湯気が出ているタイミング |
| **料理写真（ドリンク）** | 5〜10枚 | 日本酒/ビール/カクテルのグラス映え |
| **店内（客席）** | 5〜8枚 | 照明ON・テーブルセッティング済の状態 |
| **個室** | 3〜5枚 | 個室の雰囲気・収容人数がわかるカット |
| **カウンター** | 2〜3枚 | 大将/マスターとの距離感がわかるカット |
| **外観** | 3〜5枚 | 昼/夜・看板・入口（初来店でも迷わない角度） |
| **スタッフ** | 2〜3枚 | 笑顔の接客シーン・調理風景 |
| **宴会風景** | 3〜5枚 | 賑わいの雰囲気（顔は加工/許可取得） |
| **メニュー表** | 2〜3枚 | 高解像度で読み取れるメニュー画像 |

### 3.2 料理写真の撮影テクニック（プロ品質）

```
【照明】
  ✓ 自然光がベスト（窓際・昼間に撮影）
  ✓ 暖色系のライティング（居酒屋の雰囲気再現）
  ✗ フラッシュ直焚きは厳禁（平面的になる）

【アングル】
  ✓ 45度俯瞰: 最も料理映えする万能アングル
  ✓ 真俯瞰: 皿数が多い宴会コース・お通し盛り合わせ
  ✓ 横アングル: ドリンク・層のあるパフェ・高さのある料理
  ✗ 下から煽り: 非推奨（料理が不味そうに見える）

【スタイリング】
  ✓ 箸を添える/取り分けシーンで「食べたい」を喚起
  ✓ 日本酒は升枠注ぎの瞬間を撮る（シズル感）
  ✓ 七輪・網・鍋は火がついている状態で撮影
  ✓ 背景に店内の雰囲気が映るように（ボケ味活用）

【ファイル最適化】
  ✓ ファイル名: 「渋谷_居酒屋_刺身盛り合わせ.jpg」（地域名+業種+料理名）
  ✓ 解像度: 1200x900px以上（4:3推奨）
  ✓ ジオタグ: 店舗内で位置情報ONにして撮影
```

### 3.3 動画コンテンツ案（75秒フル活用）

| 動画テーマ | 尺 | 内容 |
|-----------|-----|------|
| **店舗紹介ツアー** | 60〜75秒 | 外観→入口→カウンター→個室→テーブル席の一連 |
| **看板料理の調理工程** | 30〜45秒 | 大将の包丁さばき・炭火焼きの臨場感 |
| **コース料理紹介** | 60〜75秒 | 前菜から〆まで一品ずつスライドショー風 |
| **アクセス案内** | 30〜45秒 | 最寄り駅出口→店舗入口までの道順 |
| **宴会の雰囲気** | 15〜30秒 | 乾杯シーン・賑わいの雰囲気（BGM付き） |

> **Google Vision AI**: Googleは写真・動画をAIで解析し、料理の種類・雰囲気を自動タグ付けする。「刺身」「個室」「宴会」等のシーンが含まれる写真は、関連検索での表示に有利。

## 4. 口コミ獲得・管理（飲食店特化）

### 4.1 飲食店の口コミ獲得タイミング

飲食店は**「食後の満足度が最高の瞬間」**に依頼するのが鉄則。

#### 最適タイミング
1. **会計時**（最も高確率）: 「お食事はいかがでしたか？よろしければGoogleに感想をいただけると嬉しいです」
2. **テーブルQRコード**: 会計前にテーブル上のQRコードスタンドで自然に誘導
3. **レシートQRコード**: レシートにQRコード印字で持ち帰り後の投稿を促進
4. **LINE公式連携**: 来店翌日にLINEで口コミ依頼メッセージ送信
5. **常連客への声がけ**: 店長・スタッフが顔馴染みに直接依頼（最も質の高い口コミ）

#### 口コミ獲得ツール
```
【テーブル設置型】
  ┣ QRコードスタンド（アクリル製テーブルPOP）
  ┣ ショップカード裏面にQRコード印刷
  ┗ 卓上タブレット（レジ横に設置）

【デジタル施策】
  ┣ LINE公式アカウントの自動メッセージ
  ┣ 予約確認メール/SMS内にGoogleマップリンク
  ┗ Instagram投稿→ストーリーズでGoogleレビュー誘導
```

> **⚠️ ステマ規制（景品表示法）**: 口コミ投稿と引き換えに「ドリンク1杯サービス」「次回10%OFF」等の報酬提供は**法律違反**。「気に入っていただけたら」の自然な依頼のみ。

### 4.3 ABSA属性（Googleが飲食店口コミから抽出するキーワード）

Googleの NLP が飲食店レビューから自動抽出し、「ハイライト」タグとして表示する属性：

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **料理の品質** | 新鮮、美味しい、ボリューム、盛り付け、素材の味 |
| **提供スピード** | 早い、待たされた、すぐ出てきた |
| **コスパ** | 安い、リーズナブル、お得、コスパ良い、値段相応 |
| **雰囲気** | 居心地がいい、静か、賑やか、おしゃれ、落ち着く |
| **接客** | 親切、笑顔、気が利く、丁寧、元気 |
| **個室・空間** | 個室が良い、広い、清潔、ゆったり |
| **立地・アクセス** | 駅近、わかりやすい、隠れ家的 |
| **ドリンク** | 日本酒が豊富、ビールが旨い、ワインのセレクション |

> **口コミ獲得の誘導テクニック**: 「料理の味や雰囲気の感想を書いていただけると嬉しいです」と伝えることで、上記の属性ワードが自然に含まれやすくなる → AIハイライトに好印象なタグが表示される。

### 4.4 飲食店固有のリスク・注意点

- **食中毒・衛生関連の口コミ**: 即座に事実確認 → 保健所への報告が必要な場合は迅速に対応。放置は炎上リスク
- **料理写真と実物の乖離**: 過度に加工した公式写真と口コミ写真の差がネガティブ口コミの原因に。リアル感重視
- **酔客による不適切レビュー**: ガイドライン違反（誹謗中傷・関係のない内容）の場合はGoogleに報告
- **競合店からのネガティブ攻撃**: 不自然なレビューパターン（同日に複数の低評価等）は証拠を保存してGoogleに報告

## 6. KPIベンチマーク（飲食店・居酒屋）

### 6.1 口コミ目安値

| 指標 | 目安値 | 備考 |
|------|--------|------|
| ローカルパック上位3位入り | **80〜150件** | 都市部の居酒屋は競合が多く高水準が必要 |
| 競合上位の目安 | **300件以上** | 繁華街の人気店は500件超も |
| ユーザー信頼の最低ライン | **50件以上** | 50件未満は選択肢から外れるリスク |
| 平均評価の推奨帯 | **4.0〜4.5星** | 4.8以上で少件数は不自然と疑われる |
| 月間口コミ獲得目標 | **8〜15件/月** | 鮮度（Velocity）が重要 |

### 6.2 プロフィール閲覧→アクション転換率

| アクション | 転換率目安 | 改善ポイント |
|-----------|----------|-------------|
| →Webクリック | 3-5% | メニューページへの直リンク設定 |

## 9. 飲食店固有の広告規制・ガイドライン

### 9.1 景品表示法の注意点
- **優良誤認表示**: 「日本一の刺身」「No.1居酒屋」等の根拠のない表現は禁止
- **有利誤認表示**: 通常価格を不当に高く設定して割引を謳う行為は禁止
- **レビュー報酬**: 口コミ投稿への報酬提供は**ステマ規制違反**

### 9.2 食品表示法の注意点
- メニュー名と実際の食材が一致すること（例：「和牛」表記なら和牛を使用）
- アレルギー情報の提供推奨
- 原産地表示（「築地直送」等の表現に裏付けが必要）

### 9.3 GBP投稿の禁止事項（飲食店特有）
- **電話番号の直接記載**: 投稿内に電話番号を書くのはポリシー違反
- **過度なアルコール販促**: 「飲み放題で飲みまくろう！」等の過度な飲酒促進表現は制限対象
- **虚偽のメニュー写真**: 実際の提供物と著しく異なる写真はNG

### 9.4 飲食店のGBP新機能（2025-2026）

| 機能 | 概要 | 対応策 |
|------|------|--------|
| **クーポン表示機能（2025年5月〜）** | ぐるなび・食べログ等のクーポンがGBPに自動表示 | グルメサイトのクーポン情報を最新に保つ |
| **AIメニューデジタル化** | メニュー画像/PDFをAIが自動スキャン→デジタルメニュー化 | 高品質・読みやすいメニュー画像をアップロード |
| **予約ボタン連携** | Google経由の予約がGBPから直接可能 | 予約システム（TableCheck / TORETA等）との連携 |
| **Gemini in Maps** | 「子連れ可 新宿 居酒屋」等の複合検索にAIが回答 | 属性設定の完全性が引用の鍵 |
