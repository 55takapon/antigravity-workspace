> **対象**: 学習塾・個別指導塾・集団指導塾・予備校・英語塾・プログラミング教室・習い事教室

## 1. 学習塾のMEO市場環境（2025-2026）

### 1.1 学習塾×ローカル検索の現状

- **塾選びの入口がGoogleマップへ移行**: 保護者の塾探しは「地域名＋塾」「○○駅 個別指導」等のGoogle検索→マップ→口コミ確認→問い合わせの流れが定着
- **口コミが入塾決定を左右**: 保護者は「成績が上がった」「先生が丁寧」等の口コミを重視。子供の将来に関わる決断のため、飲食店以上に口コミを精読する
- **競合の多様化**: 大手チェーン塾（個別指導のトライ・明光義塾等）と個人塾が同じローカルパックで競合。大手はブランド力、個人塾は口コミの質で差別化
- **季節変動が非常に大きい**: 春期・夏期・冬期講習シーズンと入塾説明会シーズンで検索量が3〜5倍変動
- **意思決定者≠利用者**: 意思決定者=保護者（特に母親）、利用者=生徒という二層構造。GBPの情報設計は保護者目線が最優先

### 1.2 学習塾MEOの難易度と特徴

| 項目 | 学習塾の特徴 |
|------|------------|
| 競合密度 | **高い**（都市部では半径1km内に10〜30塾） |
| 口コミ優先度 | **最重要**（保護者の入塾判断に直結） |
| 写真の影響度 | **中程度**（教室の雰囲気・清潔感が判断材料） |
| 季節変動 | **非常に大きい**（講習シーズンで検索量3〜5倍） |
| ターゲット構造 | **二層**（意思決定者=保護者、利用者=生徒） |
| LTV（顧客生涯価値） | **高い**（平均通塾期間2〜3年。月謝の継続収入） |
| 特殊リスク | **口コミ機能制限リスク**（カテゴリ設定ミスで口コミ停止） |

→ コアスキル セクション1（MEO全体像・ランキング要因）を前提知識として参照

## 2. カテゴリ・属性の最適設定

### 2.1 GBPカテゴリ設定

#### ⚠️ 最重要注意: 口コミ機能制限リスク

> **2024年4月以降、Googleは「小学校」「中学校」「高等学校」等の普通教育機関のGBPから口コミ機能を停止**。学習塾・予備校は対象外だが、**カテゴリを「学校」系に設定すると口コミが停止される事例が報告されている**。

```
【口コミ機能が停止されるカテゴリ（絶対に設定しない）】
  ❌ 「学校」
  ❌ 「小学校」
  ❌ 「中学校」
  ❌ 「高等学校」
  ❌ 「高校」
  ❌ 「教育機関」（Googleが「学校」と判断する可能性あり）

【口コミ機能が維持されるカテゴリ（推奨）】
  ✓ 「学習塾」
  ✓ 「予備校」
  ✓ 「個別指導塾」（使用可能な場合）
  ✓ 「学習センター」
  ✓ 「教育サービス」
```

> **もし口コミが突然停止した場合**: まずカテゴリ設定を確認 → 「学校」系カテゴリが混入していれば即削除 → 改善しない場合はGoogleサポートに問い合わせ

## 4. 口コミ獲得・管理（学習塾特化）

### 4.1 学習塾の口コミ獲得タイミング

学習塾は**「成果を実感した瞬間」**に保護者へ依頼するのが鉄則。

#### 最適タイミング
1. **合格発表後**（最高の口コミが得られる瞬間）: 志望校合格の喜びが口コミへの動機に
2. **定期テストの成績向上時**: 「○○点上がった！」の実感が最も鮮明なタイミング
3. **三者面談後**: 講師への信頼感が高まっている場面
4. **体験授業後（入塾決定時）**: 入塾を決めた理由を書いてもらう
5. **進級・卒塾時**: 長期通塾の感謝の気持ちを口コミに

#### 口コミ依頼の声がけ例（学習塾向け）
```
【合格発表後（保護者へ）】
「○○くん/さんの合格、本当におめでとうございます！
 私たちも大変嬉しく思います。
 もしよろしければ、これから受験を控えるご家庭の参考になりますので、
 Googleマップに塾の感想をいただけると大変ありがたいです」

【定期テスト成績向上時】
「○○くん/さん、今回のテスト頑張りましたね！
 お母様、もしよろしければ
 塾選びで悩んでいるご家庭の参考になりますので、
 当塾の感想をGoogleに書いていただけると嬉しいです」

【卒塾時】
「○年間お通いいただきありがとうございました。
 ○○くん/さんの成長を見守れたことは私たちの喜びです。
 今後の塾選びで悩む方のために、
 ぜひ体験談をお聞かせいただけないでしょうか」
```

> **依頼先は保護者が中心**（意思決定者＝口コミ執筆者）。ただし、高校生以上は本人+保護者の両方に依頼可。

### 4.3 ABSA属性（Googleが学習塾口コミから抽出するキーワード）

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **指導力** | わかりやすい、丁寧、熱心、教え方が上手 |
| **成績向上** | 成績が上がった、テストの点が伸びた、偏差値UP |
| **雰囲気** | アットホーム、集中できる、明るい、静か |
| **講師** | 親身、面倒見が良い、若い先生、ベテラン |
| **料金** | リーズナブル、妥当、コスパが良い |
| **カリキュラム** | 個別対応、オーダーメイド、充実している |
| **合格実績** | 志望校合格、○○高校合格、受験対策が充実 |
| **自習室** | 自習室が使える、集中できる環境 |
| **アクセス** | 駅近、送迎しやすい、通いやすい |
| **安全性** | 入退室連絡、安心して通わせられる |

### 4.4 学習塾固有のリスク・注意点

- **口コミ機能停止リスク（最重要）**: カテゴリに「学校」系が含まれると口コミが全停止。セクション2.1を厳守
- **生徒間のトラブルに起因する口コミ**: いじめ・人間関係の問題は慎重に対応。個別対応に誘導
- **講師の指名口コミ**: 特定講師への依存が強い口コミは、退職時のリスク。塾全体の魅力を返信で補完
- **合格実績の誇張**: 実際と異なる合格実績の掲載は景品表示法違反。合格者数は正確に
- **他塾との比較口コミ**: 「○○塾より良い」等の比較は助長しない（不正競争防止法リスク）
- **未成年の個人情報**: 口コミに生徒のフルネームが含まれる場合は、保護者に確認の上、Googleに削除依頼

## 9. 学習塾の広告規制・注意事項

### 9.1 適用される法規制

| 法規制 | 対象 | 主な制限 |
|--------|------|---------|
| **景品表示法** | すべての広告表現 | 優良誤認・有利誤認の禁止 |
| **不正競争防止法** | 競合との比較 | 虚偽事実の告知禁止 |
| **個人情報保護法** | 生徒・保護者の情報 | 未成年の顔写真・個人情報の取り扱い |
| **特定商取引法** | 役務提供 | 中途解約・クーリングオフへの対応 |

### 9.2 GBP投稿・説明文での注意事項

#### やってはいけないこと
1. ❌ **合格実績の誇張**: 「合格率100%」「全員合格」等の根拠のない表現
2. ❌ **「必ず成績が上がる」等の保証表現**: 成果の保証は景品表示法違反
3. ❌ **他塾との比較広告**: 「○○塾より安い」「○○塾では無理だった子も」
4. ❌ **未成年の顔写真を無許可で掲載**: 保護者の書面同意なしの掲載は違法
5. ❌ **合格者の氏名を無許可で公開**: 生徒本人・保護者の同意が必須
6. ❌ **不正な口コミ誘導**: 「口コミを書いたら入塾金無料」等はステマ規制違反

#### 合格実績の正しい掲載方法
```
【合格実績掲載のルール】
  ✓ 実際の合格者数を正確に記載
  ✓ 対象年度を明記（例：「2026年度入試 合格実績」）
  ✓ 「講習のみの生徒を含む」等の注意書きが正直
  ✗ 他塾との併用者を全員自塾の実績としてカウント
  ✗ 前年度以前の実績を最新年度と混同して掲載
```
