# GBP MEO運用スキル｜小売・物販

> **対象**: アパレルショップ・雑貨店・花屋・パン屋・書店・食料品店・酒屋・ドラッグストア・家具店・専門店全般
> **フォーカス**: 地域密着型の専門小売店（個人経営〜小規模チェーン）
> **前提**: コアスキル（`gbp-meo-core/SKILL.md`）の知識を前提とする
> **最終更新**: 2026-03-28

## 1. 小売店のMEO市場環境（2025-2026）

### 1.1 小売店×ローカル検索の現状

- **「近くの○○」検索が小売店集客の生命線**: 「近くの花屋」「○○駅 パン屋」「○○区 雑貨屋」等のローカル検索がリアルタイムの来店に直結
- **EC（オンライン）との共存が課題**: AmazonやZOZOと競合するのではなく、「実物を見たい」「今すぐ欲しい」「地域限定品」の強みを活かす
- **Googleショッピング連携**: GBPの「商品」機能でオンライン上に商品を掲載可能。在庫情報の連携で「この店にある」が伝わる
- **AI検索の影響**: 「○○駅周辺でプレゼントに最適な雑貨屋」等の複合検索にAI Overviewsが回答。商品ラインナップと口コミの充実度が引用の鍵
- **Googleの在庫情報表示**: 「近くのパン屋 今営業中」等のリアルタイム検索が増加。営業時間と商品情報の正確性が来店直結

### 1.2 小売店MEOの難易度と特徴

| 項目 | 小売店の特徴 |
|------|------------|
| 競合密度 | **業種による**（パン屋高密度vs専門店低密度） |
| 口コミ優先度 | **高い**（商品の品質・品揃え・接客が来店に直結） |
| 写真の影響度 | **極めて大きい**（商品写真がCTR・来店意思決定に最も影響） |
| 商品回転 | **高い**（新商品・季節商品の更新頻度が重要） |
| 客単価 | 業種による（パン屋500〜2,000円 / 家具店5万〜50万円） |
| EC連携 | 店舗＋ECの両輪が理想 |
| 季節変動 | **大きい**（クリスマス・バレンタイン・母の日等で売上2〜5倍） |

→ コアスキル セクション1（MEO全体像・ランキング要因）を前提知識として参照

### 2.3 GBP「商品」機能の活用（小売店最重要）

GBPの「商品」機能は小売店にとって**最も効果的な差別化ツール**。

```
【商品登録のベストプラクティス】
  ✓ 主力商品を10〜30点登録
  ✓ 高品質な商品写真を添付
  ✓ カテゴリ分けして整理（「新商品」「ギフト」「定番」等）
  ✓ 価格を必ず記載
  ✓ 季節商品は入れ替えを都度反映
  ✓ ボタン設定: 「詳細を見る」→自社ECページにリンク
  ✓ ボタン設定: 「電話で注文」→電話CTAに設定

【更新頻度】
  ✓ 週1回以上の新商品追加が理想
  ✓ 季節の変わり目に大規模入れ替え（年4回）
  ✓ 売り切れ商品は速やかに削除
```

## 3. 写真・動画コンテンツ戦略

### 3.1 小売店の必須写真カテゴリ

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **商品写真（主力商品）** | 15〜30枚 | 白背景or店内ディスプレイ。正面＋アップ |
| **新商品/季節商品** | 5〜10枚 | 入荷時にすぐ撮影・投稿 |
| **店内ディスプレイ** | 5〜8枚 | 商品が美しく並んだ陳列風景 |
| **外観** | 3〜5枚 | 看板・入口・ショーウィンドウ |
| **スタッフ** | 2〜3枚 | 笑顔の接客シーン・商品説明シーン |
| **ギフトラッピング** | 1〜2枚 | プレゼント用ラッピングの仕上がり |
| **店内の雰囲気** | 2〜3枚 | お客様が居心地よく買い物できる空間 |

### 3.2 商品写真の撮影テクニック

```
【基本ルール】
  ✓ 自然光（窓際で撮影が最も美しい）
  ✓ 背景はシンプルに（白 or ナチュラルな木目）
  ✓ 複数アングル（正面・斜め・クローズアップ）
  ✓ 使用シーンも撮影（花なら飾ったイメージ、パンなら断面）

【業態別ポイント】
  花屋: アレンジメントは上から/横から両方。色彩が映えるように
  パン屋: 焼きたての湯気・断面のふわふわ感。暖色ライティング
  アパレル: モデルorトルソー着用。コーディネート提案
  雑貨: ライフスタイルシーン。使用感がわかるカット
  酒屋: ボトル＋グラス。ラベルが読めるアングル

【ファイル最適化】
  ✓ ファイル名: 「世田谷_花屋_母の日_アレンジメント.jpg」
  ✓ 解像度: 1200x900px以上
  ✓ ジオタグ: 店内で位置情報ONにして撮影
```

## 4. 口コミ獲得・管理（小売店特化）

### 4.1 口コミ獲得タイミング

1. **購入直後（会計時）**: 満足度が高い商品を購入した瞬間
2. **ギフト利用後**: 「プレゼントした相手にとても喜ばれた」のフィードバック時
3. **リピート来店時**: 常連客に自然な形で依頼
4. **イベント参加後**: ワークショップ・試飲会等のイベント参加者に

#### 声がけ例
```
【会計時】
「ありがとうございます！この商品、とても人気なんですよ。
 もし気に入っていただけましたら、
 Googleに当店の感想をいただけると嬉しいです」

【ギフト利用後（常連客へ）】
「先日のブーケ、お相手の方に喜んでいただけましたか？
 もしよろしければ、お花選びで悩んでいる方の参考になりますので
 Googleに口コミを書いていただけるとありがたいです」
```

## 9. 小売店の広告規制

### 9.1 適用法規制

| 法規制 | 主な制限 |
|--------|---------|
| **景品表示法** | 優良誤認・有利誤認・二重価格表示の禁止 |
| **不正競争防止法** | 産地偽装・品質誤認の禁止 |
| **特定商取引法** | EC販売の表示義務 |
| **食品表示法**（食品小売の場合） | 原材料・アレルゲン表示義務 |
| **酒税法**（酒類販売の場合） | 酒類販売免許・20歳未満販売禁止 |
| **薬機法**（化粧品・健康食品の場合） | 効能効果の表現制限 |

### 9.2 注意事項

1. ❌ **二重価格表示**: 通常価格を不当に高く設定して割引を謳う
2. ❌ **「限定○個」の虚偽**: 実際は限定でない商品を限定と表記
3. ❌ **産地偽装**: 「国産」表示で実際は輸入品
4. ❌ **口コミ報酬**: 「口コミを書いたら○%OFF」はステマ規制違反
5. ✓ **「期間限定セール」は正当な理由と期間明示があればOK**
