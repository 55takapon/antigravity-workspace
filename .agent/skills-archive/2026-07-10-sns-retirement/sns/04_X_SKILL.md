## 🧠 PART 1：2026年 X アルゴリズム完全解説

### ■ 核心思想：Xは「会話の深度」でコンテンツを評価する

> 2026年のXアルゴリズム（コードネーム「Phoenix」）は、Grok AIを統合した**予測型レコメンデーションエンジン**。  
> 「どれだけバズったか」ではなく「どれだけ価値ある会話を生み出したか」を基準に配信を決定する。

### ■ エンゲージメント重み付け（2026年4月最新値）

| アクション | アルゴリズム重み | 解説 |
|-----------|---------------|------|
| **往復会話（リプ応酬）** | ✕150（いいね換算） | **最重要**。投稿者⇔閲覧者の対話が最大加点 |
| **リポスト（再投稿）** | ✕20（いいね換算） | 拡散シグナルとして依然高評価 |
| **リプライ（単発返信）** | ✕13.5（いいね換算） | 会話の起点。深度に発展すると150xに化ける |
| **ブックマーク** | ✕10（いいね換算） | 「沈黙のいいね」。保存価値の証明 |
| **プロフィールクリック** | ✕5（いいね換算） | フォロワー転換の前段階 |
| **いいね** | ✕1（基準） | 単体では弱い。補助シグナルに過ぎない |
| **外部リンク** | **マイナス50〜90%** | プラットフォーム外への離脱＝大幅ペナルティ |

> **v1.0 → v2.0 の最大変更点：** 会話（往復リプライ）の重みが13xから**150x**に更新。  
> 「投げっぱなし投稿」は2026年のXでは伸びない。投稿後のコミュニティ作りがスコアの鍵。

### ■ 配信判断の「ゴールデン30分」

```
【投稿後の拡散メカニズム】

投稿 → 【0〜30分】AIが少数ユーザーにテスト配信
         ↓
    エンゲージメント速度を計測
    （特にリプライ率・リポスト率）
         ↓
    高速度 → より広いネットワークへ拡散
    低速度 → 配信を絞り込む（露出減）
         ↓
【決定的分岐点：最初の30〜60分が全て】
```

> **プロの鉄則**：投稿後は「ポスト＆ゴースト」厳禁。  
> 投稿後30分は必ずリプライ対応に充てる。これが配信量を2〜4倍変える。

### ■ 投稿の半減期（Time Decay）

投稿は **6時間で到達ポテンシャルが半減** する。24時間後にはほぼゼロ。  
→ 1日に複数回投稿するより「最適な1回」に集中し、投稿後30分のエンゲージメントを最大化する方が効率的。

### ■ アカウントスコアリング（3軸）

| 軸 | 評価内容 | 改善アクション |
|----|---------|--------------| 
| **Reputation（信頼性）** | ブロック・ミュート・報告の少なさ | 価値ある投稿の継続。炎上・スパム回避 |
| **Relevance（関連性）** | 特定ニッチへの特化度（Vector Consistency） | 投稿テーマをジャンルに絞る。迷走しない |
| **Reach（リーチ力）** | フォロワーの質。Premiumユーザー比率 | ビジネス層・専門職層に響く内容を発信 |

## 📝 PART 2：投稿フォーマット別攻略法

### 2-1. 長文投稿 vs スレッド（2026年版判断基準）

> **重要変更：** 2026年のアルゴリズムは**長文単体投稿**を優遇する傾向。  
> スレッドは1ツイート目が低評価だと全ツイートが沈没するリスクがある。

| 項目 | 長文投稿（推奨） | スレッド |
|------|----------------|---------|
| アルゴリズム | 全体で1つの評価 | ツイートごとに個別評価 |
| リスク | 低い（1投稿の勝負） | 高い（1ツイート目が死ぬと全滅） |
| 最大文字数 | 25,000文字（Premium） | 各280/25,000文字 |
| 向いている内容 | 深い解説・体験談・ノウハウ | ステップバイステップ・リスト型 |
| SEO効果 | 外部検索エンジンに拾われやすい | 各ツイートが分散 |

**判断フロー：**
```
内容が1つのストーリー/論理 → 長文投稿
内容がステップ別/リスト別に独立 → スレッド
迷ったら → 長文投稿（2026年はこちらが安全）
```

### 2-2. 単発ポスト（Short Post）
> **目的：** 瞬発的なリーチ / 会話の起点  
> **文字数：** 100〜200文字

**黄金構造：**
```
[フック1行]（スクロールを止める）
↓
[核心1〜3行]（価値 or 驚き or 共感）
↓
[問いかけCTA]（リプライを誘発する）
```

### 2-3. ネイティブビデオ
> ⚠️ YouTube/TikTokリンクは厳禁。必ずX内に直接アップロード

**推奨尺：**
| 尺 | 用途 |
|----|------|
| 15〜30秒 | リーチ拡大（ショートフォーム） |
| 1〜3分 | ノウハウ解説・信頼構築 |
| 3分以上 | 深掘りインサイト（Premium長尺） |

### 2-4. 画像・インフォグラフィック
> **目的：** ブックマーク・リポスト誘発（保存価値の高い「まとめ」）

## 🏗️ PART 4：フォロワー成長「70/30戦略」

```
70%の時間：他者への「質の高いリプライ」
30%の時間：自分のオリジナル投稿

→ Premiumアカウントのリプライは最上部に優先表示

→ 1つの秀逸なリプライで数百〜数千人にリーチ可能
```

**リプライ品質基準：**
```
❌ NG：「素晴らしい投稿です！」（価値ゼロ）
✅ OK：「○○の点が興味深いです。私の経験では△△でした。」（視点の付加）
✅ OK：「逆の視点から言うと○○ではないでしょうか？」（建設的な反論）
```

## 🎯 PART 5：投稿の型ライブラリ（X最適化 全10型）

### TYPE X-1：ノウハウ型（ブックマーク誘発）
```
フック：「○○する人が絶対知らない△つのこと」
→ 箇条書きで5〜7個のノウハウ
→ 「どれが刺さりましたか？→リプで！」
```

### TYPE X-2：意見・主張型（リプライ誘発）
```
フック：「正直に言います。○○は間違いです。」
→ 理由を3〜4行
→ 「あなたはどう思いますか？」
```

### TYPE X-3：体験談型（Before→After）
```
フック：「○年前、私は△△でした。今は□□。」
→ Situation → Trouble → Action → Result → Insight
→ 「同じ体験がある人、いますか？」
```

### TYPE X-4：データ/調査型（リポスト最強）
```
フック：「○○を分析した結果、予想外なことがわかった。」
→ データ提示（画像活用）→ 解説 → 意見募集
```

### TYPE X-5：リスト型（保存推奨）
```
フック：「○○に悩む人が知らない△選【保存推奨】」
→ ①〜⑦のリスト → 「1番刺さったのは？」
```

### TYPE X-6：速報・トレンド乗り型
```
フック：「【速報】○○が変わります。」
→ 事実→プロ解説→今すぐやること→リポスト促進
```

### TYPE X-7：引用リポスト展開型
```
[誰かの投稿を引用]
→ 「追記すると…」「少し違う見方をすると…」
→ 独自視点の付加 → 「どちらが正しい？」
```

### TYPE X-8：コーチング・マインドセット型 🆕
```
フック：「成果を出す人と出せない人の違いは、たった1つの○○です。」
→ 認知科学・ゴール設定・コンフォートゾーンの概念を平易に解説
→ 「何かに挑戦しようとしている人、リプで宣言してみてください」
→ 例テーマ：セルフイメージ / エフィカシー / 現状の外側のゴール
```

### TYPE X-9：GBP・MEO運用ノウハウ型 🆕
```
フック：「Googleマップで上位表示されてる店が必ずやっている3つのこと。」
→ GBP最適化の具体的なテクニックを箇条書き
→ 「あなたのGBP、最後に更新したのいつですか？」
→ 例テーマ：口コミ獲得 / 写真戦略 / 投稿頻度 / カテゴリ設定
```

### TYPE X-10：Web集客・マーケティング型 🆕
```
フック：「月100万円の広告費をかけても集客できない会社の共通点。」
→ SEO/MEO/SNS/広告の使い分けをプロ視点で解説
→ 「あなたのビジネスに1番効くのはどれだと思いますか？」
→ 例テーマ：LP改善 / CVR最適化 / 無料集客 / ローカルSEO
```

## ⚙️ PART 7：テクニック集

### 外部リンクルール
```
❌ 本文にリンク → インプレ50〜90%減
✅ 方法1：「リンクはリプ欄↓」と書きリプライで別投稿
✅ 方法2：画像内テキストにURL記載
✅ 方法3：「DMに送ります」→ DMでリンク送付（エンゲージメントも上がる）
```

### プロフィールの「ABO公式」
```
【A】Authority：実績・資格を1行で（例：「MEO対策200社以上支援」）
【B】Benefit：フォローすると何が得られるか（例：「毎日Web集客の知恵を発信」）
【O】Offer：CTA（例：「↓ 無料相談はプロフリンクから」）
```
