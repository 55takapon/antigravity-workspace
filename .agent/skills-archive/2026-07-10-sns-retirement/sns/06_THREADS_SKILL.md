**バージョン:** v1.0 (2026-04-29作成)  
**視点:** プロマーケター（PDCA前提・アルゴリズム準拠）  
**対象:** コーチング / マインドセット / GBP運用 / Web集客 の発信者

## 🧠 PART 1：2026年 Threads アルゴリズム完全解説

### ■ 核心思想：「会話ファースト」プラットフォーム

> Threadsは「ブロードキャスト（一方通行の発信）」ではなく  
> **「カンバセーション（双方向の会話）」** を最重視するプラットフォーム。  
> 投稿の約50%がリプライで構成されるほど「対話」が文化の中心。

### ■ 最重要ランキングシグナル（2026年4月確定版）

| シグナル | 重要度 | 解説 |
|---------|--------|------|
| **エンゲージメント速度** | ★★★★★ | 投稿後30分の反応量が配信の分岐点。50いいね/30分 > 100いいね/24時間 |
| **リプライの深度・質** | ★★★★★ | 往復する対話が最高評価。「いいね」の代わりに返信が通貨 |
| **シェア・保存** | ★★★★☆ | 「いいね」より重いシグナル |
| **滞在時間** | ★★★★☆ | 投稿+リプライチェーンに留まる時間を計測 |
| **関係性シグナル** | ★★★★☆ | Threads上のやりとり+Instagram連携の交流履歴 |
| **投稿の鮮度** | ★★★☆☆ | For Youフィードでは新しい投稿が優先 |
| **いいね** | ★★☆☆☆ | 補助指標。単体では弱い |

### ■ 「おすすめ」タブの仕組み

```
投稿 → AIが少数ユーザーにテスト配信
  ↓
エンゲージメント速度を計測（特にリプライ）
  ↓
高速度 → 「おすすめ」タブに掲載 → フォロワー外に拡散
低速度 → 配信縮小（フォロワーのみに限定）
  ↓
【決定的分岐点：最初の30〜60分】
```

### ■ Threads独自の特性（X/IGとの違い）

| 特性 | Threads | X | Instagram |
|------|---------|---|-----------|
| トーン | ポジティブ・建設的 | 議論・速報 | ビジュアル・ブランド |
| 最重要KPI | リプライ深度 | リプライ速度 | DM送信数 |
| 外部リンク | 抑制される傾向あり | 大幅ペナルティ | ストーリー/bioのみ |
| 先行者メリット | **大きい**（まだ成長期） | 成熟市場 | 成熟市場 |
| IG連携 | アカウント統合 | なし | 本体 |

> **プロの視点：** Threadsは2026年現在まだ成長フェーズ。小規模アカウントが有機的リーチを得やすい「ゴールドラッシュ」状態。今から参入する価値は非常に高い。

## 👤 PART 2：プロフィール最適化

### ■ Threadsのプロフィール = Instagramの延長

ThreadsアカウントはInstagramと統合されているため、IGのプロフィール設計がそのまま反映される。

```
【名前フィールド】
  → IG同様、専門キーワードを含める
  → 例：「田中太郎｜認知科学コーチ×MEO専門家」

【bio】
  → Threadsでの発信テーマを明記
  → 例：「コーチングの裏側と本音をここで語ります。ビジネスの相談→IGのDMへ」

【戦略的ポイント】
  → IGが「世界観・ブランド」、Threadsが「本音・会話」の使い分けを明示
  → 「Threads限定の話はここだけ」と希少性を出す
```

## 📝 PART 3：投稿フォーマット攻略

### 3-1. テキスト投稿（メイン形式）

> Threadsの主戦場。テキストの質と構造で勝負。

**黄金構造：**
```
[フック1行]（続きを読みたくなる導入）
↓
[本文3〜5行]（価値・気づき・体験）
↓
[問いかけ or 意見募集]（リプライ誘発）
```

**フック例（10パターン）：**
```
① 共感：「○○してるのに結果が出ない人、実は原因はそこじゃない。」
② 告白：「恥ずかしい話、私もずっと○○を間違えてました。」
③ 問い：「ぶっちゃけ聞きたいんだけど、○○ってどう思う？」
④ 断定：「○○は、もうやめた方がいい。理由は3つ。」
⑤ 逆説：「実は○○しない方が△△になる。」
⑥ 数字：「○○を△年やって分かった、たった1つの真実。」
⑦ 速報：「○○が変わった。今すぐ知るべき理由。」
⑧ 本音：「正直に言う。○○は□□だと思ってる。」
⑨ 体験：「昨日○○があった。そこで気づいたことがある。」
⑩ 対話：「今日のテーマ。○○ vs △△、あなたはどっち派？」
```

### 3-2. 画像・動画付き投稿

> テキストのみより高パフォーマンスの傾向。最大10枚まで。

```
活用シーン：
→ インフォグラフィック（まとめ・図解）
→ ビフォーアフター（GBP改善事例など）
→ スクリーンショット（実績・データ）
→ 短尺動画（15〜30秒のTipsリール）
```

### 3-3. 投票（Poll）機能

> 気軽に参加できるため、エンゲージメント初速が取りやすい。

```
例：「Web集客で1番効果があったのは？」
① SEO対策
② MEO/Googleマップ対策
③ SNS運用
④ 広告
→ 結果発表を別投稿で行い、2段階のエンゲージメントを得る
```

## 🎯 PART 4：コーチング / GBP / Web集客 投稿型ライブラリ

### TYPE TH-1：マインドセット変革型 🧠
```
フック：「"やる気が出ない"の正体は、ゴールが間違ってるだけ。」
本文：コンフォートゾーン → 現状の外側のゴール → セルフイメージ
CTA：「あなたの"本当にやりたいこと"、リプで教えて。一緒に言語化しよう。」
```

### TYPE TH-2：コーチング実践型（Before→After） 🎯
```
フック：「"自分には無理"と言ってたクライアントが、3ヶ月後に○○を達成した話。」
本文：課題 → 気づき（認知の変化） → 行動変容 → 結果
CTA：「同じ壁にぶつかってる人、どんな壁か教えてください。」
```

### TYPE TH-3：GBP・MEOあるある型 📍
```
フック：「Googleマップの口コミ返信、テンプレそのまま使ってない？」
本文：よくある失敗3つ → 正しい運用 → 効果の差
CTA：「正直、口コミ返信ってどのくらい力入れてる？教えて。」
```

### TYPE TH-4：Web集客ノウハウ対話型 💻
```
フック：「月5万円でWeb集客を始めるなら、正直これ1択。」
本文：選択肢の比較 → 結論（理由付き）
CTA：「あなたのビジネスだったら何を選ぶ？リプで議論しよう。」
```

### TYPE TH-5：業界ニュース解説型 📰
```
フック：「Googleが○○を変更。これ、小さなお店にめちゃくちゃ影響ある。」
本文：変更内容 → 影響範囲 → 今すぐやるべきこと
CTA：「あなたのお店、対応済み？」
```

### TYPE TH-6：問いかけ・議論喚起型 💬
```
フック：「ぶっちゃけ聞きたい。SNS運用って外注すべき？自分でやるべき？」
本文：両方のメリデメを簡潔に
CTA：「あなたの経験、リプで聞かせてください。」
```

### TYPE TH-7：認知科学×日常の気づき型 💡
```
フック：「"忙しい"が口癖の人、RAS（脳のフィルター）が"忙しさ"を選んでます。」
本文：認知科学の概念を日常の言葉で説明
CTA：「これ読んで、今日から変えてみようと思うこと、1つ書いてみて。」
```

## 📊 PART 5：成長戦略 — 「3-2-5ルール」

### ■ 毎日の基本ルーティン

```
【3】毎日3本のオリジナル投稿
  → 朝：マインドセット/気づき系
  → 昼：ノウハウ/Tips系
  → 夜：問いかけ/対話系

【2】自分の投稿に2回以上返信
  → リプライに丁寧に返すことでスレッドを「育てる」
  → 自分のリプライもフォロワーのフィードに表示される

【5】同ジャンルの他クリエイターに5回エンゲージメント
  → 質の高いリプライを大型アカウントに残す
  → 「Great post!」はNG。独自の視点を付加する
```

### ■ トピックタグの使い方

```
ルール：1投稿1タグ（複数タグは逆効果）
選び方：ニッチで具体的なタグを使う
  ✅「#認知科学コーチング」（ニッチ）
  ❌「#コーチング」（広すぎ）
```

### ■ Instagram連携戦略

```
IGストーリーズ → Threads投稿への誘導
「Threadsで○○について話してます。意見聞かせて」
→ IGの既存フォロワーをThreadsに送客
→ 初速エンゲージメントの底上げ
```

## 📈 PART 6：KPI設計

```
【Threads KPI（2026年プロ標準）】

① リプライ率（Reply/View）: 目標 1%以上
② インプレッション成長率: 週次で前週比+10%
③ フォロワー外リーチ率: おすすめ経由の表示比率
④ 引用スレッズ数: 週5件以上
⑤ 他者リプライからの流入: 週10件以上
```

### 投稿後72時間チェックリスト
- [ ] リプライ数と深度確認（対話が生まれたか）
- [ ] インプレッション数確認
- [ ] おすすめタブ掲載の有無
- [ ] フォロワー増減
- [ ] 最も反応が良かったフックの型を記録

## ⚠️ PART 8：NGリスト（2026年版）

```
❌ エンゲージメントベイト（「同意なら"はい"とリプして」等→ペナルティ対象）
❌ 外部リンクの直貼り（リーチ抑制の傾向）

❌ IG投稿のそのままコピペ（ネイティブ最適化必須）
❌ 「いいね・フォローしてください」の直接懇願
❌ トピックタグの大量使用（1投稿1タグが原則）
❌ リプライへの無返信（会話ファーストの文化に反する）
❌ フォロワー数だけを追うマインドセット（インプレッションと対話の質が本質）
```

## 🤖 PART 9：AI実行プロンプト

### Threads テキスト投稿生成
```
あなたはThreadsのプロコンテンツストラテジストです。
以下の情報をもとに、2026年のThreadsアルゴリズムに最適化した
テキスト投稿を3パターン生成してください。

【テーマ】: [ここに入力]
【一次情報（自分の体験・数字）】: [ここに入力]
【投稿の目的】:
□ リプライ誘発（会話を生む）
□ おすすめ掲載（拡散）
□ フォロワー転換

出力要件：
- 使用した「フック型」を明記
- フック（1行）+ 本文（3〜5行）+ 問いかけCTA
- トーン：ポジティブ・建設的・本音感
- 外部リンクなし
- トピックタグ候補1つ
```

### Threads 週間カレンダー生成
```
あなたはThreadsの運用コンサルタントです。
以下のテーマで1週間分（月〜日）の投稿カレンダーを作成してください。

【発信テーマ】: [コーチング / GBP / Web集客 等]
【ターゲット】: [ここに入力]
【トーン】: ポジティブ・会話重視・本音

出力フォーマット：
月：[朝] テーマ＋フック / [夜] テーマ＋フック

各投稿に推奨トピックタグ1つを付与
```

## 🔗 PART 10：クロスプラットフォーム連携

```
【Threads × Instagram 使い分け】
Instagram：世界観・ブランド・ビジュアル
Threads：本音・対話・コミュニティ

【コンテンツリサイクルフロー】
STEP1: Threadsで対話型テキスト投稿（反応テスト）
  ↓ 反応が良かったテーマを確認
STEP2: Instagramカルーセルに変換（ビジュアル化）
  ↓

【ルール】
→ 各プラットフォームのネイティブ最適化必須（コピペ厳禁）
```
