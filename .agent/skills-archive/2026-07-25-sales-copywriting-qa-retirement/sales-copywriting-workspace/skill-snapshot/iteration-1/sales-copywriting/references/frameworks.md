## BAB（Before → After → Bridge）

**使い所**: 実績・事例が強いとき。「変化後の世界」を先に見せる。

```
Before: 相手が今いる現実（痛みの場所）
After:  貴社が提供できる理想の状態
Bridge: どうやってそこに連れて行くか
```

## PAS（Problem → Agitate → Solution）

**使い所**: 痛みが明確なターゲット。「こんな悩みありますよね」から入る。
損失回避の心理を活用するが、脅しではなく**事実の共有**として。

```
Problem: 相手が抱えている課題を明示
Agitate: その課題が放置されるとどうなるか（事実として、煽りにならない程度に）
Solution: それを解決できる存在として自分を提示
```

## AIDA（Attention → Interest → Desire → Action）

**使い所**: 幅広いアプローチ。相手にとって未知の切り口で興味を引くとき。

```
Attention: 相手が思わず止まる一文（問いかけ・事実・数字）
Interest:  「なぜ自分に関係あるか」を感じさせる情報
Desire:    具体的なベネフィットで「欲しい」と思わせる
Action:    低ハードルの1アクション
```

## SPIN応用（状況 → 問題 → 影響 → 解決）

**使い所**: 論理的な相手向け。段階的に「自分ごと」と感じさせる。

```
状況（S）: 相手の現状を確認する文脈
問題（P）: その状況で生じている課題
影響（I）: その問題が放置されると起きること（事実として）
解決（N）: その解決策として自分を提示
```
