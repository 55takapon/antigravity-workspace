# 心理原則辞典 — 「気づきの渡し方」として使う

## 基本思想

煽り = 自分のメリットのために書く。操作する。
事実共有 = 相手のメリットのために書く。気づきを渡す。

この辞典の原則はすべて「気づきの渡し方」として設計する。

---

## 認知的容易性（最重要）

**定義**: 人は読みやすい情報を「正しい」と感じやすい。

**フォーム営業での活用:**
- 短い文（1文20文字以内が理想）
- 段落は2〜3行で区切る
- ①②③の記号で箇条書きにする
- 余白を作る（詰め込まない）

**なぜ重要か:**
日々の業務で疲弊している相手の判断力・意志力を奪わない。
すっと読めてすっと行動できる設計が、長期的な関係につながる。

**NG例**: 長文・密集した段落・専門用語の多用

---

## 社会的証明

**定義**: 「他の人もやっている」という安心感。

**気づきの渡し方として使う:**
```
OK: 「同業種のWeb制作会社さまとお話しする中で、
     こんな声をよく聞きます。」
→ 「自分だけじゃない」という安心感 + 課題の事実共有
```

**絶対NG:**
- 数字の水増し・誇張
- 「業界No.1」等の根拠のない主張
- 「○○社が導入!」の羅列（自慢になる）

---

## 損失回避

**定義**: 人は「得ること」より「失うこと」を2倍強く感じる（プロスペクト理論）。

**気づきの渡し方として使う:**
```
OK: 「できる人が辞めていく問題は、これから加速する一方です。
     人材が来てくれない時代になっていく。」
→ 脅しではなく、業界の現実を事実として共有
```

**絶対NG:**
- 「今すぐ動かないと損します」の脅し
- 「限定○社だけ」の人工的な希少性
- 「このままでは廃業する」等の恐怖訴求

**境界線:**
> 「今の状況をそのまま伝えること」はOK。
> 「相手を動かすために現実を誇張・歪曲すること」はNG。
> 読んだ相手が、契約しなくても視点が変わればそれで十分。

---

## 返報性

**定義**: 先に何かをもらうと「返したい」と感じる。

**気づきの渡し方として使う:**
- 読むだけで業界の現実が分かる情報を含める
- 「この切り口は考えたことなかった」と感じる視点を提供する
- 相手のためになる気づきを「先に渡す」

**注意**: 見返りを期待して与えるのではない。
純粋に相手のために書いた結果、返報性が働くのが理想。

---

## 希少性

**このスキルでは使わない。**

「限定○社」「今月だけ」等は煽りそのもの。
短期的な行動を促すためだけに機能し、長期的な関係にならない。
伴走者として長く付き合いたい相手に使う原則ではない。

---

## 権威性（安心装置として）

**定義**: 信頼できる情報源・実績から来る安心感。

**フォーム営業での特別な役割:**
「何者か分からない人の文章は読み進めない」
→ 権威性 = 不審者フィルターを突破するための「安心装置」

**正しい使い方:**
- Block 1（冒頭2〜3行）に最短で収める
- 最も強い実績を1つだけ自然に溶け込ませる
- 「自慢」ではなく「名刺代わりの事実」として提示

**NG:**
- 5行以上の自己紹介（自分語り化）
- 実績の羅列（「○年の実績、○社導入、○個の受賞」）
- 盛った数字・誇張

**適切な例:**
```
「Googleマップ集客を担うジェットプロデュース田中です。
 現在11社・継続率90%超で運用中です。」（2行で完結）
```

---

## パーソナライズ効果

**定義**: 自分のことを「分かってもらえた」と感じると心が開く。

**業種レベルでのパーソナライズ（現実的な方法）:**
- 業種固有の課題・言葉を使う
- 「Web制作会社さまと話す中で」等の業種限定フレーズ
- その業種が日々感じている痛みを具体的に言語化する

**将来の改善項目:**
- 相手のサイトを見た具体的な気づきを入れる
- company-search でのデータ収集 or AI 自動生成

---

## 認知的不協和の解消

**定義**: 「自分の現状と理想のギャップ」を意識させると、解消したくなる。

**気づきの渡し方として使う:**
Block 3（課題共感）で相手の現状を言語化し、
Block 5（ベネフィット）で理想の状態を提示する。

「あ、確かにそれ課題だ。で、こういう状態になれるのか」という流れ。

**注意**: 課題を指摘するのは Block 1（安心装置）の後。
権威性がない状態で課題指摘から入ると「お前に言われたくない」と反発される。
