# バズコピーの型と使い分け — 2026年7月時点

writerサブエージェントが全プラットフォーム共通で使う文章の型。
プラットフォーム別の制約（文字数・トーン・NG）は各 `*-writing-rules.md` が優先する。

---

## バズ投稿の5ステップ構造（全投稿の共通骨格）

バズる投稿は例外なくこの流れを持つ。書き終えたら5要素が揃っているか照合すること。

1. **フック**（指を止める）… 冒頭1〜2行
2. **共感 or 驚き**（感情を動かす）… 「自分のことだ」「え、そうなの?」
3. **価値**（読んで得をさせる）… 気づき・ノウハウ・視点
4. **具体性**（信頼させる）… 実体験・数字・固有名詞
5. **行動導線**（反応させる）… 問いかけ・保存/共有の一言。CTAは1つだけ

## フックの型カタログ（冒頭1〜2行に使う）

| 型 | 骨組み | 補足 |
|:--|:--|:--|
| ターゲット呼びかけ | 「◯◯で悩んでいる△△へ」 | 誰向けかを即決させる |
| ベネフィット提示 | 「これを知るだけで◯◯が変わります」 | 誇大にしない（下記信憑性ルール） |
| 逆説 | 「実は、◯◯は間違いでした」 | 常識への異論。根拠必須 |
| 数字 | 「◯年やって分かった、たった1つの真実」 | 数字は3・5・7が記憶に残りやすい |
| 告白 | 「恥ずかしい話、私もずっと◯◯を間違えてました」 | 人柄系素材と好相性 |
| 問い | 「ぶっちゃけ、◯◯ってどう思う?」 | Threads向き |
| 断定 | 「◯◯は、もうやめた方がいい。理由は3つ」 | X向き。Threadsでは柔らかく |
| 速報 | 「【速報】◯◯が変わります」 | ニュース素材限定。乱用禁止 |
| 体験 | 「昨日◯◯があった。そこで気づいたことがある」 | 日常系素材の入口 |
| 対話 | 「◯◯ vs △△、あなたはどっち派?」 | 二択で参加ハードルを下げる |

## 本文フレームワークの使い分け

| フレーム | 流れ | 使う場面 |
|:--|:--|:--|
| PREP | 結論→理由→具体例→結論 | X長文・ノウハウ系の基本形 |
| PAS | 問題提起→あぶり立て→解決策 | 悩み解決系。短文でも成立しSNS向き |
| STAR+学び | 状況→つまずき→行動→結果→学び | 体験談・倫理法人会の講話素材 |
| Before/After | 過去の自分→転機→今の自分 | 認知の変化・成長ストーリー |

- PASONA（問題→煽り→解決→絞込→行動）はセールス色が強いため、売り込み投稿以外では使わない。
- どのフレームでも**結論の出し惜しみ禁止**。「続きはプロフで」型の引っ張りは2026年のアルゴリズムでは逆効果。

## 心理トリガー（本文に自然に織り込む）

- **社会的証明**: 「よくご相談いただきます」「◯◯な方が多い」
- **感情的共鳴**: 読者が言語化できていない気持ちを先に言葉にする
- **具体性**: 数字・固有名詞・場面描写。「関空のトイレで」は「空港で」より強い
- **ギャップ**: 表向きの評価と本音の落差（例:「積極的だね」と言われたが実は消去法だった）

## 一次情報の使い方（このスキルの生命線）

- 投稿の中核には必ず一次情報（本人の体験・数字・失敗談・現場の観察）を置く。AIが生成した一般論の再構成はテンプレ感として減点され、バズしない。
- 人柄系素材は `clients\knowledge-taka-jet\` の台帳カード（逐語つき）から使う。**逐語は改変せず**、前後の文脈だけ整える。
- ビジネス系素材はユーザー入力のテキスト・実案件の観察から使う。クライアントの固有情報（店名・数値）は伏せるか抽象化する。

## 信憑性・トーンルール（全プラットフォーム共通・違反は品質チェックで即差し戻し）

- 効果の保証禁止: 「必ず集客できます」→「〜しやすくなります」
- 根拠のない数値断言禁止: 「◯◯で9割決まる」→「〜といわれています」「〜の傾向があります」
- アルゴリズムへの因果断言禁止: 「投稿すれば順位が上がる」→「評価されやすくなるといわれています」
- 過度な一般化禁止: 「みんな〜する」→「多くの場合」「〜なケースをよく見ます」
- 上から目線・威圧・断罪の禁止。基本トーンは「伴走するパートナー」（自社アカウントの正本は `clients\jetproduce\knowledge.md`）
- 「丸投げでOK」等、安価な代行業者と同列に見られる表現の禁止

## プラットフォーム展開の原則（X承認後のThreads/IG作成時）

- **コピペ・語尾変更だけのリライトは禁止**。各プラットフォームの文化に合わせて再構成する
- X = 論理と価値提供（長文OK・議論を仕掛ける） / Threads = 会話と本音（500字・ツッコミ代を残す） / IG = 共感と世界観（検索キーワードを意識）
- 同じ素材でも「切り口」を変える: Xで出した結論を、Threadsでは問いとして投げ、IGでは体験の場面から入る
