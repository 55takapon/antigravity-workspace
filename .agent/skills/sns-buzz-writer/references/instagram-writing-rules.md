# Instagramフィードキャプション執筆ルール — 2026年7月時点

writerサブエージェントがInstagramキャプションを書く時に必ず読む資料。
このスキルの対象は**フィード投稿のキャプション＋ハッシュタグ設計のみ**。画像・カルーセルスライド・リール台本は作らない（必要なら画像の方向性メモを1行添えるだけにする）。

---

## アルゴリズム前提（2026年時点で確認済みの事実）

1. **最重要シグナルは「送信（DMシェア）」**。「親しい友人にDMで教えたくなる」内容が最もリーチを伸ばす。かつての「保存が鍵」から2026年は送信重視へシフトした。
2. 次点が**保存**（後で見返したい価値）と**深いコメント**。いいねは「タップひとつの受動的アクション」として優先度が低い。
3. **キャプション内キーワードが発見の主エンジン**（Instagram SEO）。ハッシュタグはカテゴリ分類の補助に格下げされた。
4. **ハッシュタグは上限5個が標準**（2026年から）。数より投稿内容との関連性。
5. キャプション滞在時間（読み込み時間）もシグナル。読ませる長文キャプションは有効。
6. 転載・類似投稿はオリジナル側が優先され、リーチが減る。

## キャプションの構成ルール

- **冒頭2行が勝負**。フィードでは冒頭しか表示されない。「続きを読む」を押させるフックを置く（型は copywriting-frameworks.md から選ぶ）。
- 本文は3〜8行を標準にする。専門的な内容は長くしてよいが、段落を短く切る。体験談・価値提供を中心に、2〜3行ごとに改行して読みやすくする。
- **検索されたいキーワードを自然な文脈で本文に含める**（例:「Googleマップ集客」「加古川 Web集客」「倫理法人会」）。不自然な羅列は逆効果。
- CTAは「保存」「共有（送信）」「コメント」「DM」「プロフィール導線」から目的に最も近い**1つだけ**選ぶ。混ぜない。露骨な懇願にしない。
- 書き終えたら次の2問に答えられるか自己照合する: **「読者が後で見返す理由（保存理由）は何か」「読者が誰かに送りたくなる具体性（共有理由）はどこか」**。どちらも答えられない原稿は提出しない。
- ハッシュタグは**3〜5個**をキャプション末尾に。ニッチ寄りを選ぶ（例: #認知科学コーチング は #コーチング より強い）。
- X版からの流用は再構成必須。Xの「議論を仕掛ける」文体ではなく、IGは「世界観と共感」の文体に寄せる。
- 画像方針メモ（任意・1行）: 「体験談の場面写真1枚」「要点3つを載せた画像」など方向性だけ示す。

## NG事項（1項目ずつ原稿と照合すること）

- ハッシュタグ6個以上・無関係タグの混入
- エンゲージメントベイト（「いいねしてね!」等の露骨な依頼は規制対象）
- キーワードの不自然な詰め込み
- 外部リンクの本文記載（IGはキャプションのリンクが機能しない。誘導は「プロフィールのリンクから」の一言まで）
- 他SNS本文のコピペ
- 誇大表現・効果の断言（「必ず集客できる」→「〜しやすくなります」）

## 関連スキル（キャプション以外のInstagram業務）

リール台本・カルーセル構成・ストーリーズ・プロフィール改善・月間カレンダー・インサイト分析を求められた場合は、このスキルで作らず、codex側スキル基盤の `instagram-content-pro` へ委譲する（フォーマット別の制作ルール・品質ゲートを完備している）。
