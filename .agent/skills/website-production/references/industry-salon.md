# 業種ごと: サロン・美容

## 目的

美容室、ネイル、エステ、まつげ、リラクゼーション、ヨガなどで、雰囲気、施術価値、予約導線が伝わるサイトを作る。

## 使う材料

- 施術写真、空間写真、スタッフ、メニュー、料金、予約導線
- Before/After、口コミ、Instagram
- ターゲットの悩みや理想像

## 見る観点

- 自分へのご褒美感や安心感が伝わるか
- 予約前にメニューと料金が分かるか
- 美容素材が過度に加工されて不自然になっていないか

## デザイン方針

- トーン: 美しさ、洗練、リラックス、特別感
- 配色: ローズベージュ、ローズゴールド、ゴールド、モーブ、アイボリー
- 写真: 施術風景、手元、空間、自然素材
- フォント: エレガントなセリフまたは細めのサンセリフ

## 作業手順

1. ファーストビューで誰のどんな悩みに向くサロンか伝える。
2. メニューは価格と所要時間を見やすく整理する。
3. 施術写真と空間写真を分け、来店前の不安を減らす。
4. 予約導線を固定または複数箇所に置く。

## 出力形式

- Header
- First View
- Concept
- Menu
- Staff
- Space
- Voice
- Reservation
- Footer

## 確認方法

- 予約前に必要な情報が揃っている。
- 画像や色がターゲットに合っている。

## 不合格時の対応

- メニューや価格が未確認なら仮情報にせず、公開前差し替え項目として分ける。
