# 依頼整理と最低ヒアリング

## 目的

ユーザーの依頼から、Webサイト制作に必要な最小情報と不足情報を分ける。材料不足でも止まりすぎず、品質に影響する項目だけ質問する。

## 使う材料

- ユーザー依頼文
- 添付画像やローカル素材
- 参考URL、SNS、Googleビジネスプロフィールなどの公開情報
- 既存のプロンプト、ワイヤーフレーム、ヒアリングシート
- 未確認だが必要な材料

## 見る観点

- 制作対象がトップページ、LP、コーポレート、店舗サイトのどれか
- ユーザーが欲しい成果物が、制作プロンプト、画像、実装ファイル、レビューのどれか
- 未確認情報を事実として書く危険があるか
- 画像素材が完成素材か、参考素材か

## 作業手順

1. 依頼文から、店名・会社名、業種、地域、作る範囲、目的、希望成果物を抜き出す。
2. 素材を「そのまま使える」「参考に使う」「未確認で使えない」に分ける。
3. 最低ヒアリング12項目を埋める。埋まらない項目は、前提で進めるか質問するかを決める。
4. 制作品質に影響する不足だけ質問する。質問は一度に3つまでにする。
5. 質問せず進める場合は、前提条件として出力内に明記する。

## 最低ヒアリング12項目

| 項目 | 確認する内容 |
|:---|:---|
| 店名・会社名 | 表記ゆれ、英字表記、ロゴ有無 |
| 業種 | 業種別ルール選択に使う |
| 地域 | 地域性、検索導線、アクセス表現 |
| サイトの目的 | 来店、問い合わせ、予約、購入、採用など |
| 一番取らせたい行動 | CTAの優先順位 |
| メインターゲット | 年齢層、利用シーン、悩み |
| 強み・看板商品 | ファーストビューと主役セクション |
| 参考にしたい雰囲気 | 写真、余白、配色、文字組み |
| 避けたいデザイン | NG方向性 |
| 既存素材の有無 | 写真、ロゴ、SNS、メニュー表 |
| 必要な機能 | 予約、地図、フォーム、EC、SNS |
| 作る範囲 | トップのみ、下層あり、画像のみ、実装あり |

## 出力形式

```markdown
## 材料カード
- 確認済み:
- 未確認:
- 参考素材:
- 使わない素材:
- 前提:
- 追加質問:
```

## 確認方法

- 未確認情報が本文の事実表現へ混ざっていない。
- 画像素材の扱いが明確である。
- 追加質問が3つ以下である。

## 不合格時の対応

- 情報不足でブランドやCTAが決められない場合は、制作へ進まず質問する。
- 未確認の住所、価格、営業時間は仮情報として分ける。
