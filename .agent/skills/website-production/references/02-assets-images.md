# 素材と画像制作

## 目的

実写真、添付画像、SNS画像、生成画像を、Webサイト内で使える状態へ整理する。参考画像はそのまま貼らず、魅力を抽出してサイト用のビジュアルへ展開する。

## 使う材料

- 店舗写真、商品写真、人物写真、メニュー表、看板写真
- 参考画像、添付画像、SNS URL
- 業種別デザイン方針
- 制作範囲と必要セクション

## 見る観点

- その画像が完成素材か、参考素材か
- 人物が写る場合、権利・印象・表情に問題がないか
- 画像内文字に重要情報を依存していないか
- ファーストビューで使える余白や主役があるか
- スマホで主役が切れないか
- コーポレート、士業、相談型サービスでは、机やカウンターの素材が白基調または薄グレー基調に指定されているか

## 作業手順

1. 画像を用途別に分ける。例: ヒーロー、メニュー、空間、人物、外観、SNS、イベント。
2. 参考画像から、色、質感、商品特徴、雰囲気、差別化要素を抽出する。
3. サイト挿入用画像の一覧を作る。ファイル名、用途、alt想定、推奨比率を決める。
4. 画像生成が必要な場合は、被写体、構図、光、色、禁止事項を含むプロンプトを作る。
5. コーポレート、士業、相談型サービスの画像プロンプトでは、white desktop、white consultation table、light gray interior、navy folder、clean modern Japanese officeを肯定指定する。
6. コーポレート、士業、相談型サービスの画像プロンプトでは、wood grain tabletop、brown desk、dark wood reception room、Showa-era office、rural old-fashioned moodを禁止条件に入れる。
7. 生成または保存した画像はサイトで扱いやすい形式にし（下記「画像の技術基準」参照）、元素材を上書きしない。
8. 確認用コンタクトシートを作れる場合は作り、主役、文字混入、歪み、トーンを確認する。

## 画像の技術基準

- サイズ: ヒーロー画像は横1920px以下・300KB目安、通常セクション画像は横1200px以下・200KB以下に抑える。
- 形式: WebPを優先し、生成ツールや互換の制約がある場合はJPG（品質80前後）にする。PNGは透過が必要なロゴ・アイコンのみ。
- 読み込み: ファーストビュー以外の `img` には `loading="lazy"` を付ける。ヒーロー画像には付けない。
- CLS防止: すべての `img` に `width`/`height` 属性（またはCSSの `aspect-ratio`）を指定し、読み込み時のレイアウトずれを防ぐ。
- 実装後にPageSpeed Insightsまたは同等の計測で画像起因の減点がないことを確認する（静的サイトはモバイル90点以上を目標にする）。

## 出力形式

| ファイル名 | 用途 | alt想定 | 扱い |
|:---|:---|:---|:---|
| `creative-01-hero.jpg` | First View | 主役が伝わる説明 | サイト挿入 |

## 確認方法

- サイト挿入用画像と参考画像が混ざっていない。
- 生成画像に読めない文字、不要ロゴ、歪んだ人物がない。
- 画像内文字に価格や営業時間などの重要情報を依存していない。
- 画像の技術基準（サイズ上限、形式、lazy loading、width/height指定）を満たしている。
- コーポレート、士業、相談型サービスの画像が、木目机や古い応接室に寄っていない。

## 不合格時の対応

- 画像品質が弱い場合は、参考画像として残し、生成・撮影指示を追加する。
- 人物や文字に不自然さがある場合は、該当画像を主役にしない。
