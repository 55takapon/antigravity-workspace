# 入力と出力の実例

このファイルは、実際の会話で扱った入力と、完成後の成果物の型を示す。コピー用の完成文ではなく、何を成果物に含めるかを確認するために使う。

## 例1: カフェのデモサイト

### 入力

- 依頼: 飲食店向けスライド用プロンプトを、カフェのWebサイトトップページ制作用プロンプトに変換したい。
- 条件: デモサイト用。店名や詳細は制作者側で設定してよい。洗練されたファーストビューにしたい。
- 追加条件: サイト挿入画像も先に生成し、JPGで保存する。人物が入る場合は日本人にする。

### 出力

- フォルダ: `demo-cafe/`
- 制作プロンプト: `website-prompt.md`
- 画像プロンプト集: `image-prompts.md`
- サイト挿入画像: `images/01-hero-cafe-liora.jpg` など複数枚
- 確認用画像: `contact-sheet.jpg`
- 確認結果: 画像の用途、ファーストビュー、レスポンシブ、実装後チェックをプロンプト内に記載

## 例2: アジアンレストランのデモサイト

### 入力

- 依頼: 店名「アジアンキッチンTanTra」。店舗写真、メニュー写真、キッチンカー、ナンバーガー参考画像を使い、`demo-asian` として作る。
- 条件: 添付写真は完成素材ではなく参考素材として扱い、よりクリエイティブに店舗の魅力が伝わるようにする。
- 追加条件: サイト挿入画像をJPGで保存する。

### 出力

- フォルダ: `demo-asian/`
- 制作プロンプト: `website-prompt.md`
- 参考画像メモ: `attached-reference-notes.md`
- 画像生成プロンプト集: `creative-image-prompts.md`
- サイト挿入画像: `images/creative-01-hero-naan-burger.jpg` など複数枚
- 確認用画像: `creative-contact-sheet.jpg`
- 確認結果: ナンバーガーと黄色いキッチンカーを主役化し、参考素材とサイト挿入素材を分けた

## 異常系の出力型: 情報不足

### 入力

- 依頼: 「いい感じの会社サイトを作って」
- 不足: 会社名、業種、目的、CTA、素材、作る範囲が不明

### 出力

- 材料カード:
  - 確認済み: 会社サイトを作りたい
  - 未確認: 会社名、業種、目的、CTA、素材、作る範囲
  - 前提: 汎用コーポレートの仮設計なら可能
- 追加質問:
  1. 会社名と業種は何ですか
  2. 一番取らせたい行動は問い合わせ、資料請求、採用応募のどれですか
  3. トップページのみか、下層ページも必要ですか
