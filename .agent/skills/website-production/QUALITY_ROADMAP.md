# 品質ロードマップ — デザインクオリティの現在地と次への指標

作成: 2026-07-06（v2.0〜v2.2 統合・改修時の評価記録）
用途: 次回アップデート時の指標。案件を重ねて実感とズレた箇所はこのファイル自体を更新すること。

## 1. 現在地の評価（v2.2時点の率直な結論）

**「プロが作ったかのようなサイト」がコンスタントに出るか？ → まだ保証はできない。**

### 下限は高い（安定して70〜75点）

- テンプレ感の禁止、文字量ルール、セクション造形差、品質ゲート（初見3秒・ロゴ隠し・シルエット）が揃っており、「素人が作った安っぽいサイト」はほぼ出ない状態。
- 業種別ルール＋画像基準＋日本語タイポ基準＋デザイントークン初期値で、ばらつきの底は抑えられている。

### 上限を押し上げる仕組みは v2.2 でようやく着手（狙いは85〜90点）

- プロのデザインは「ルール遵守」ではなく**「複数案の探索→比較→選定→一貫展開」**から生まれる。
- v2.1までは一発生成で全ページを作るため、FVの当たり外れが運任せだった。外れても「ルールは守っているが記憶に残らない」80点止まりになる——これが解像度の粗さの正体。
- v2.2のデザインオーケストレーション（09）がこの欠落への回答。効果検証はこれから。

### v2.2設計時に加えた4つの補強（ユーザー構想への追加分）

1. **差分軸の明示発注** — 「3案作れ」だけだと似た案が3つ出る。構図の方向性（大判写真型/タイポ主役型/モチーフ構成型）を管理者が指定。
2. **視覚レビューの強制** — コードではなく描画結果（スクリーンショット）で採点。合意なしに1案へ絞ることを禁止。
3. **デザインロック** — FV合意後にトークン・モチーフ・写真トーンを design-system.md へ固定。これがないとバッチ展開中にデザインが漂流し「別サイトの寄せ集め」になる。
4. **バッチレビュー観点の固定** — トークン逸脱 / 直前セクションとのシルエット差 / FVとの一貫性。最後に07の全体最終レビュー必須。

## 3. それでも残る天井（仕組みでは埋まらない最後の10点）

1. **画像素材の質がサイトの天井を決める。** 生成画像が平凡ならFVコンペをしても平凡な3案が並ぶ。素材への投資が最優先。
2. **参考サイトの視覚入力が最強の補正。** 「このサイトの空気感で」とスクリーンショットを渡す方が、テキストルール100行より効く。品質モード案件では参考スクショ1〜2枚を添えるのを習慣化する（SANKOU! / BRIK / Web Design Clip）。
3. **コストとのトレードオフ。** コンペ方式は時間・トークンが体感2〜3倍。受託=品質モード、デモ=簡易モードの二段構えを崩さない。
4. **視覚センスそのものはモデル依存。** スキルは判断の質を上げるが、造形の引き出し自体は実行するモデルの能力に依存する。モデルが強くなるほどこのスキルの効果も上がる構造。

## 4. 次回アップデート候補（未実装の指摘・優先度順）

v2.1実装時のレビューで洗い出したが、まだ実装していない項目:

1. **industry-*.md の深度格差是正** — corporateだけ「画像標準ルール＋品質ルール＋心理導線」まであり、cafe/salon/clinic/ec は配色とセクション羅列で薄い。全業種をcorporate水準へ。**次に使う業種から順次でよい。**
2. **モーション/インタラクション基準** — hover状態、スクロール出現アニメの抑制（多用=安っぽさの典型）、固定ヘッダー挙動。「プロっぽさ」の体感の半分は動きで決まるが現状無言。03または04へ。
3. **プロジェクト内の画像トーン統一ルール** — 全生成画像に共通のライティング・カラーグレード指定を1つ決めて全プロンプトに含める（02へ。09のdesign-system.mdには写真トーン項目を入れたので、02側と接続する）。
4. **コアフローへの競合調査追加** — 受託の静的案件がコアフローを通ると競合を見ずに設計してしまう。ステップ2に「受託なら近隣競合2〜3サイトの構成・コピー確認」を追加。
5. **09の効果検証** — 品質モードを実案件で2〜3回回し、FVコンペの差分軸・バッチサイズ（2セクション）が適切か検証してこのファイルに結果を記録する。

## 5. 品質が上がったかを判定する基準（アップデート効果の測り方）

- 品質ゲート合格率: 初見3秒 / ロゴ隠し / シルエット / コピー削減 / モバイル初見の5テストを最終レビューで採点し、案件ごとに記録する。
- FVコンペで「どの案も採用したくない」が起きた回数（起きる=ブリーフか素材の問題。09の不合格対応へ）。
- 完成サイトを国内ギャラリー掲載サイトと並べて見て、浮かないか（管理者の主観でよいので毎回やる）。
- 顧客・ユーザーの初見リアクション（「おお」が出るか、無言か）。
