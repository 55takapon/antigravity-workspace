## 1. 美容室のMEO市場環境（2025-2026）

### 1.1 美容室×ローカル検索の現状

- **美容室は全国約26万軒**: 信号機よりも多い超激戦市場。差別化が極めて困難
- **ホットペッパービューティーの圧倒的支配**: 予約の60〜70%がホットペッパー経由。しかし手数料負担が重く、Googleマップ直接予約への移行を目指す美容室が増加
- **「地域名＋美容室」検索の増加**: 特に「○○駅 美容室 メンズ」「○○区 カラーが上手い美容室」等の具体的検索でGBPの口コミ・写真が来店決定に直結
- **AI検索の影響**: 「縮毛矯正の持ちはどのくらい？」「ブリーチなしでできるカラー」等のAI Overviewsに、E-E-A-Tの高いサロンが引用される
- **Instagram×GBPの相乗効果**: スタイル写真はInstagram→GBPに転載で一石二鳥。AIはGBPの写真を解析してスタイル・雰囲気をタグ付け

### 1.2 美容室MEOの難易度と特徴

| 項目 | 美容室の特徴 |
|------|------------|
| 競合密度 | **極めて高い**（都市部では半径500m内に20〜50軒） |
| 口コミ優先度 | **最重要**（スタイリストの技術力・雰囲気が来店決定に直結） |
| 写真の影響度 | **極めて大きい**（スタイル写真がCTR・来店意思決定に最も影響） |
| リピート率 | **高い**（平均来店周期: 2〜3ヶ月。年4〜6回来店） |
| 客単価 | 中程度（カット4,000〜8,000円、カラー含む8,000〜15,000円） |
| 予約方式 | ネット予約主流（ホットペッパー・自社予約・LINE予約） |
| 季節変動 | 中程度（3-4月の新生活、12月の年末が繁忙） |

## 3. 写真・動画コンテンツ戦略

### 3.1 美容室の必須写真カテゴリ

美容室は**スタイル写真の品質と量が最もCTR・来店に影響する業種**。最低30枚、理想80枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **スタイル写真（仕上がり）** | 20〜40枚 | 施術後のヘアスタイル。多様な年代・性別 |
| **ビフォーアフター** | 5〜10枚 | 同アングルのBefore/After（カラー・矯正） |
| **店内** | 3〜5枚 | セット面・シャンプー台・待合い空間 |
| **外観** | 3〜5枚 | 看板・入口（初来店でも迷わないカット） |
| **スタイリスト** | 3〜5枚 | 施術中・笑顔のポートレート |
| **カラーチャート/素材** | 2〜3枚 | 使用するカラー剤・トリートメント |
| **個室/半個室** | 2〜3枚 | プライバシー空間（あれば） |

### 3.2 スタイル写真の撮影テクニック

```
【照明】
  ✓ 自然光 or 明るいライティング（髪のツヤ・色味が正確に出る）
  ✓ リングライトで瞳のキャッチライト＋髪のツヤ感
  ✗ 暗い照明（色味が正確に伝わらない）

【アングル】
  ✓ 正面/斜め45度/横顔/後ろ姿の4カット
  ✓ 髪の動き・レイヤー感がわかるカット
  ✓ カラーの場合は光が当たる角度で色味を正確に

【モデル】
  ✓ お客様の同意を得て撮影（施術直後が最も美しい仕上がり）
  ✓ 多様な年代・性別のスタイルを揃える
  ✓ Instagramと同時投稿でコンテンツ効率UP

【ファイル最適化】
  ✓ ファイル名: 「渋谷_美容室_ハイライトカラー_ボブ.jpg」
  ✓ 解像度: 1200x900px以上
  ✓ ジオタグ: サロン内で位置情報ONにして撮影
```

### 3.3 動画コンテンツ案

| 動画テーマ | 尺 | 内容 |
|-----------|-----|------|
| **スタイルチェンジ** | 30〜60秒 | Before→施術→After（タイムラプス風） |
| **サロンツアー** | 45〜75秒 | 外観→受付→セット面→シャンプー台 |

## 4. 口コミ獲得・管理（美容室特化）

### 4.1 口コミ獲得タイミング

#### 最適タイミング
1. **施術直後（鏡で仕上がり確認時）**: 「良い感じですね！」の瞬間が最高の依頼タイミング
2. **写真撮影後**: スタイル撮影の許可をもらった時に合わせて口コミも依頼
3. **2〜3回目の来店時**: 指名リピーターになった段階（質の高い口コミ）
4. **イメージチェンジ成功時**: 大きなスタイルチェンジに満足した瞬間

#### 声がけ例
```
【施術後の仕上がり確認時】
「仕上がりいかがですか？気に入っていただけましたか？
 もし良ければ、Googleに当サロンの感想を
 書いていただけると嬉しいです。
 こちらのQRコードから簡単に投稿できます」

【スタイル撮影時】
「素敵に仕上がりましたね！お写真撮らせてもらってもいいですか？
 あと、もしよろしければGoogleの口コミもお願いできると
```

### 4.3 ABSA属性

| 属性カテゴリ | キーワード例 |
|-------------|------------|
| **技術力** | カットが上手い、カラーがきれい、センスが良い |
| **雰囲気** | おしゃれ、居心地がいい、リラックスできる |
| **スタイリスト** | 話しやすい、相談しやすい、提案してくれる |
| **仕上がり** | イメージ通り、持ちが良い、周りに褒められた |
| **接客** | 丁寧、気遣い、圧が少ない、押し売りがない |
| **価格** | コスパが良い、お手頃、値段以上 |
| **空間** | 清潔、個室で落ち着く、おしゃれな内装 |

### 4.4 美容室固有のリスク

- **スタイリスト退職の口コミ影響**: 指名スタイリストの退職で「もう行かない」の口コミリスク。サロン全体の魅力を日頃から発信
- **仕上がりイメージの相違**: 「イメージと違う」は最も多いクレーム。カウンセリング強化＋お直し対応の明示で予防
- **施術ダメージのクレーム**: ブリーチ・縮毛矯正後の髪のダメージに関する口コミは慎重に対応
- **予約の取りにくさ**: 人気スタイリストの予約困難への不満口コミ

## 9. 美容室の広告規制

### 9.1 適用法規制

| 法規制 | 主な制限 |
|--------|---------|
| **美容師法** | 美容師免許の保持義務、衛生基準の遵守 |
| **景品表示法** | 優良誤認・有利誤認・ステマ規制 |
| **薬機法** | 化粧品・医薬部外品の効能表現制限 |

### 9.2 GBP投稿での注意事項

1. ❌ **「髪が生える」「薄毛が治る」等の医学的効能表現**: 美容室では使用不可
2. ❌ **カラー剤の効能を誇大に表現**: 「一生ダメージゼロ」等は薬機法違反リスク
3. ❌ **他店との比較広告**: 「○○サロンより上手い」
4. ❌ **無許可のお客様写真**: 施術写真は必ずお客様の同意を得てから
5. ✓ **「ダメージを抑えたカラー」「ツヤ感のある仕上がり」等の事実ベースの表現はOK**
