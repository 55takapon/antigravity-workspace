# 本文・お願い欄の構成ルールとNG表現

## 何をするか
サービス内容（1,000字以内）と購入にあたってのお願い（500字以内）を組み立て、NG表現を排除する。

## 読み手のリテラシー前提（全パーツ共通）

- 一般ユーザーは「GBP」「MEO」「CTA」を知らない前提で書く
- 専門用語を使う場合は直後に括弧で補足する（例: GBP（Googleビジネスプロフィール））
- 購入後ヒアリングで聞くのは「業種・強み・ターゲット客層」の3点まで
- 購入者に調査・リサーチ作業を求めない

## サービス内容（1,000字以内）の構成順序（CVR最大化）

| 順 | ブロック | 字数目安 |
|:--|:---------|:---------|
| 1 | 共感（悩みの言語化） | 〜150字 |
| 2 | 解決提示 | 〜100字 |
| 3 | 納品物（箇条書き） | 〜150字 |
| 4 | 制作の流れ | 〜150字 |
| 5 | 対応業種 | 〜100字 |
| 6 | アップセル導線 | 〜80字 |

合計目安700〜800字。残りはポートフォリオ画像・Q&Aで補完する。

## 購入にあたってのお願い（500字以内）の構成

1. 必要情報（3項目以内）— 購入後ヒアリングで聞くことを予告する
2. 納期 — 通常日数+急ぎオプション
3. 注意事項（箇条書き3〜4点）— 含まないもの・保証できないこと
4. 複数店舗ルールなど個別条件

## NG表現表（作成後に必ず照合する）

| NG | 理由・置き換え |
|:---|:---------------|
| ━━━ などの装飾区切り線 | 1本20〜25字消費して情報ゼロ。使わない |
| 絵文字を見出しに多用 | 文字数消費。全体3個以内に抑える |
| 「競合店のURL・GBPリンクを教えてください」 | 一般ユーザーは回答不能。「参考にしたいお店があれば」に変える |
| 注意書きの多重化 | 500字制限の「お願い」欄で同じ注意を繰り返さない |
| 効果・順位の保証表現 | 禁止。代わりに「保証はできません」を1箇所明記する |
| 「まずはお気軽に〜」の多用 | 1回のみ |
| 「〜させていただきます」 | 冗長。「〜します」に統一する |

## 確認方法
完成した本文・お願い欄をNG表現表と1行ずつ照合し、該当ゼロを確認する。

## 不合格時の対応
該当があれば置き換え、字数が浮いた分は納品物・制作の流れの具体化に回す。
