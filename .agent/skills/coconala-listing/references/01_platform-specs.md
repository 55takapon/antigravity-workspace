# ココナラ公式仕様（文字数制限）

## 何をするか
出品文の各項目を作る前に、この上限一覧を把握する。この仕様を守らないと、タイトル・キャッチコピーを全て作り直すことになる。

## 使う材料
出品画面のスクショで実確認した仕様（確認記録は references/changelog.md 参照）。画面の表示と食い違う場合は画面を正とし、実確認できた場合のみこのファイルを更新する。

## 文字数・仕様一覧

| 項目 | 制限 | 備考 |
|:-----|:-----|:-----|
| サービスタイトル | **25字以内（末尾「ます」含む）** | 「ます」は必須・削除不可（画面に明記）。出品者が入力できるのは**実質23字以内**（画面カウンターは「23」表示） |
| タイトル補足説明（キャッチコピー） | **15〜30字（必須）** | 短すぎても長すぎてもエラー。範囲内に必ず収める |
| サービス内容（本文） | **1,000字以内** | 絵文字・記号もカウント対象 |
| 購入にあたってのお願い | **500字以内** | トークルームトップに表示される |
| 有料オプション | **各60文字以内・最大10件** | オプション名+説明で60文字 |
| よくある質問（Q&A） | **各400字以内・最大10件** | 設問文側の文字数制限は未確認 |
| 予約お届け日数 | 最大99日 | 「要相談と表示する」オプションあり |
| 一度に受注可能な件数 | 最大20件 | デフォルト5件 |
| 事前すり合わせ | オプション | ビデオチャット対応可否を設定 |
| 定期購入 | オプション | 定期購入可否を設定 |

## 確認方法
作成した各パーツをこの表と突き合わせ、SKILL.md ステップ5の検証表（項目 / 文字数 / 上限 / 判定）を作る。

## 不合格時の対応
超過した項目は、優先順位の低い語から削る。タイトルで削った語はキャッチコピー枠への移動を検討する（references/02_keyword-strategy.md 参照）。
