# 出力の型と実例

## 実例1: キーワード分散のNG/OK対（出品検討時の実作業より）

```
【NG例】キーワードが重複している
タイトル:      GBP投稿文4本｜MEO集客強化し
キャッチコピー: MEO実績あり｜GBP投稿文作成
→「GBP投稿文」「MEO」が両方に入っていて文字数の無駄
```

```
【OK例】キーワードを分散させている
タイトル:      GBP投稿文4本｜集客に繋がる文章作成し
キャッチコピー: MEO実績10社以上｜歯科・士業・飲食対応
→「GBP投稿文・集客・文章作成」と「MEO・実績・業種」で分散
```

## 実例2: キャッチコピーの字数収め（15〜30字）

```
MEO実績10社以上｜歯科・士業・飲食対応（22字）✅
公式認定3資格｜Googleマップ集客を強化（21字）✅
```

## 型: 文字数検証表（ステップ5で必ず出力する形）

```
| 項目 | 文字数 | 上限 | 判定 |
|:-----|:------|:-----|:-----|
| サービスタイトル | 〔実際に数えた字数〕 | 23（ます込み25） | OK / 超過 |
| キャッチコピー | 〔字数〕 | 15〜30 | OK / 範囲外 |
| サービス内容 | 〔字数〕 | 1,000 | OK / 超過 |
| 購入にあたってのお願い | 〔字数〕 | 500 | OK / 超過 |
| 有料オプション（各） | 〔字数〕 | 60 | OK / 超過 |
| Q&A（各） | 〔字数〕 | 400 | OK / 超過 |
```

- 依頼範囲にない項目は行ごと省く
- 「超過 / 範囲外」が1つでもあれば納品せず、作成工程に戻る
