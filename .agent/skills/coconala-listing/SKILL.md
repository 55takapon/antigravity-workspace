# coconala-listing

> **目的**: ococona라出品文をProマーケター視点で作成・改善する。公式仕様を正確に把握し、文字数制限を厳守した上で、ユーザーリテラシーを踏まえた実用的な構成を作る。

---

## 公式文字数制限（確定済み仕様）

| 項目 | 上限 | 重要仕様 |
|---|---|---|
| **タイトル** | **25文字以内（「ます」含む）** | ⚠️ 末尾に「ます」が強制固定・変更不可。実質の入力可能文字数は **23文字以内** |
| **キャッチコピー** | 確認要（目安〜50文字） | 検索結果に表示される補足文 |
| **サービス内容** | **1,000文字以内** | 絵文字・装飾記号もカウント対象 |
| **購入にあたってのお願い** | **500文字以内** | トークルームトップに表示される最重要欄 |
| **よくある質問（Q&A）** | **400文字以内/1問** | 複数設定可。本文で書ききれない補足に活用 |
| **トークルーム回答例** | 300文字以内 | |

> ⚠️ 仕様は予告なく変更される。出品作業の前に必ず[公式ヘルプ](https://coconala.com/help)または出品画面の入力制限で最新値を確認すること。

## タイトル設計のルール

### 絶対ルール
- タイトル末尾は「**ます**」で固定（システム強制・変更不可）
- 「ます」の2文字は25文字のカウントに**含まれる**
- 出品者が入力できるのは実質 **23文字以内**
- タイトル案を作成する際は「ます」を除いた23文字で設計し、末尾の「ます」は自動付与として扱う

### タイトル設計の優先順序
1. **検索キーワードを先頭に置く**（「GBP投稿文」「MEO」など）
2. **サービスの核心を1語で言い切る**（「作成」「代行」「設計」）
3. **差別化要素を後半に入れる**（「4本」「実績10社」など）
4. 末尾「ます」に自然につながる語尾で終わる（「〜し」→「します」など）

### タイトル案の作り方（例）
```
入力部（23文字以内）: GBP投稿文4本｜集客直結の文章設計し
自動付与「ます」:     →「します」として自然につながる
完成形（25文字）:     GBP投稿文4本｜集客直結の文章設計します
```

## サービス内容（1,000文字以内）の構成設計

### 構成の基本順序（CVR最大化）

1. **共感（悩みの言語化）** — 読者が「これ自分のことだ」と感じる状態から始める（〜150文字）
2. **解決提示** — このサービスで何が解決するかを1文で言い切る（〜100文字）
3. **具体的な納品物** — 「〜します」ではなく「〜を納品します」と箇条書きで明示（〜150文字）
4. **プロセス（安心感）** — 購入後の流れを短く明示してハードルを下げる（〜150文字）
5. **対応範囲** — 業種・条件を明記して無駄なやり取りを減らす（〜100文字）
6. **アップセル導線** — 別出品への自然な誘導（〜80文字）
- **合計目安: 700〜800文字**（残りはポートフォリオ画像・Q&Aで補完）

## NGパターン（禁止事項）

| NG | 理由 |
|---|---|
| ━━━ などの装飾区切り線 | 1本あたり20〜25文字を消費。情報ゼロで文字数を食う |
| 📌 🎯 などの絵文字を見出しに多用 | 1文字ぶんカウント。使うなら全体で3個以内 |
| 「競合店のGBPリンクを教えてください」 | ほぼ回答不能。ハードルを上げるだけ。「参考にしたいサービスや店舗があれば」に変える |
| 注意書きの多重化 | 500文字制限の「お願い」欄で同内容を繰り返さない |
| 効果・順位の保証表現 | トラブル防止のため「保証はできません」を1箇所明記 |
| 「まずはお気軽に〜」の多用 | 1回のみ。繰り返しは信頼性を下げる |
| 「〜させていただきます」の多用 | 冗長。「〜します」に統一 |

## ユーザーリテラシーの前提

- 一般ユーザーは「GBP」「MEO」「CTA」「PDCA」を知らない前提で書く
- 専門用語は使う場合、直後に括弧で補足する（例: GBP（Googleビジネスプロフィール））
- ヒアリングで聞く内容は「業種・強み・ターゲット客層」の3点に絞る
- 購入者に調査・リサーチ作業を求めない（競合URLの収集など）

---

## 購入にあたってのお願い（500文字以内）の構成設計

1. **必要情報（3項目以内）** — 購入後ヒアリングで聞くことを予告する
2. **納期** — 通常日数 + 急ぎオプション
3. **注意事項（箇条書き3〜4点）** — 含まないもの・保証できないことを明記
4. 複数店舗ルールなど個別条件
