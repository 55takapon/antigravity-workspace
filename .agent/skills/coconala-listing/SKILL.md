## タイトル設計のルール

### 絶対ルール
- タイトル末尾は「**ます**」固定（画面に「※「ます」は必須のため削除できません」と明記）
- 「ます」の2文字は25字のカウントに**含まれる**（画面のカウンターが「23」と表示）
- 出品者が入力できるのは実質 **23字以内**

### タイトル設計の優先順序
1. 検索キーワードを先頭に置く
2. サービスの核心を端的に言い切る
3. 差別化要素を後半に入れる
4. 末尾「ます」に自然につながる語尾で終わる

### タイトル文字数カウント例
```
入力: GBP投稿文4本作成し（12文字）
表示: GBP投稿文4本作成します（14文字）→ 余裕あり

入力: Googleビジネス投稿文を4本作成し（17文字）
表示: Googleビジネス投稿文を4本作成します（19文字）→ OK

上限: 23文字（入力部分）
```

---

## キャッチコピー設計のルール

- **15〜30字の範囲内に必ず収める（必須項目）**
- 短すぎると入力エラーになる（15字未満NG）
- サービス内容で書けない差別化要素・実績・資格を入れる

```
例: MEO実績10社以上｜歯科・士業・飲食対応（22字）✅
例: 公式認定3資格｜Googleマップ集客を強化（21字）✅
```

## サービス内容（1,000字以内）の構成設計

### 構成の基本順序（CVR最大化）

1. **共感（悩みの言語化）** — 〜150字
2. **解決提示** — 〜100字
3. **納品物（箇条書き）** — 〜150字
4. **制作の流れ** — 〜150字
5. **対応業種** — 〜100字
6. **アップセル導線** — 〜80字
- **合計目安: 700〜800字**（残りはポートフォリオ画像・Q&Aで補完）

## NGパターン（禁止事項）

| NG | 理由 |
|---|---|
| ━━━ などの装飾区切り線 | 1本20〜25字消費。情報ゼロ |
| 絵文字を見出しに多用 | 文字数消費。全体3個以内に抑える |
| 「競合店のURL・GBPリンクを教えてください」 | 一般ユーザーは回答不能。「参考にしたいお店があれば」に変える |
| 注意書きの多重化 | 500字制限の「お願い」欄で繰り返さない |
| 効果・順位の保証表現 | 必ず「保証はできません」を1箇所明記 |
| 「まずはお気軽に〜」の多用 | 1回のみ |
| 「〜させていただきます」 | 冗長。「〜します」に統一 |

---

## ユーザーリテラシーの前提

- 一般ユーザーは「GBP」「MEO」「CTA」を知らない前提
- 専門用語は使う場合、直後に括弧で補足（例: GBP（Googleビジネスプロフィール））
- ヒアリングで聞くのは「業種・強み・ターゲット客層」の3点まで
- 購入者に調査・リサーチ作業を求めない

---

## 購入にあたってのお願い（500字以内）の構成

1. 必要情報（3項目以内） — 購入後ヒアリングで聞くことを予告
2. 納期 — 通常日数＋急ぎオプション
3. 注意事項（箇条書き3〜4点） — 含まないもの・保証できないこと
4. 複数店舗ルールなど個別条件
