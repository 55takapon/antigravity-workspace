# coconala-listing

> ココナラ出品文をプロマーケター視点で作成・改善する。公式の文字数制限（特にタイトル実質23字）を厳守し、検証表を付けて納品する。

## ステップ1: 依頼内容の確認

- [ ] 新規作成か既存出品の改善かを判別した（自社出品の一覧は [knowledge/own-listings.md](knowledge/own-listings.md) を必要な時だけ読む）
- [ ] ヒアリングは「サービス対象（業種）・強み・ターゲット客層」+実績数値の4点までに絞った
- [ ] 既存出品の改善の場合、現行の出品文全文を必ず先にもらった

#### 完了条件
- 対象サービスと「新規/改善」の別が確定していること
- 実績・数値・資格はユーザー提供分のみ使う前提を確認済みであること。満たすまで次のステップに進んではならない

## ステップ2: 公式仕様の確認

必要資料: この工程で必ず [references/01_platform-specs.md](references/01_platform-specs.md) を読むこと。

- [ ] 今回作成・修正する全項目の文字数上限を把握した

#### 完了条件
- タイトル実質23字・キャッチコピー15〜30字を含む上限一覧を把握済みであること。満たすまで次のステップに進んではならない

## ステップ3: キーワード設計

必要資料: この工程で必ず [references/02_keyword-strategy.md](references/02_keyword-strategy.md) を読むこと。

- [ ] 狙うキーワードを書き出し、タイトル枠とキャッチコピー枠に重複ゼロで振り分けた

#### 完了条件
- 「タイトルで取る語 / キャッチコピーで取る語」の振り分けが決まり、重複が0件であること。満たすまで次のステップに進んではならない

## ステップ4: 各パーツの作成

必要資料: この工程で必ず [references/03_copy-rules.md](references/03_copy-rules.md) を読むこと。出力の型に迷う場合だけ [examples/good-output.md](examples/good-output.md) を読む。

- [ ] 依頼された範囲のパーツ（タイトル→キャッチコピー→サービス内容→お願い欄→オプション/Q&A）を作成した
- [ ] 実績・数値・資格はユーザー提供分のみ使った。未提供の数値は創作せず、確認するかプレースホルダーにした

#### 完了条件
- 依頼範囲の全パーツが揃っていること。満たすまで次のステップに進んではならない

## ステップ5: 文字数検証（省略禁止）

- [ ] 全項目の文字数を実際に数え、検証表（項目 / 文字数 / 上限 / 判定）を必ず作成した
- [ ] 超過項目があればステップ4に戻って削り、再検証した

#### 完了条件
- 検証表の全項目が上限内で判定OKであること。検証表なしで納品してはならない。満たすまで次のステップに進んではならない

## ステップ6: セルフチェックと納品

- [ ] [references/03_copy-rules.md](references/03_copy-rules.md) のNG表現表と照合し、該当ゼロを確認した
- [ ] 成果物を項目別に提示し、文字数検証表を添えた

#### 自己完了確認（省略禁止）
- [ ] ステップ1〜5を全て実行したか
- [ ] 文字数検証表を出力したか
- [ ] タイトルとキャッチコピーのキーワード重複が0件か
- [ ] 創作した実績・数値がないか

1つでも未実施の場合、納品してはならない。

## エッジケース

| 状況 | 対応 |
|:-----|:-----|
| タイトルが実質23字に収まらない | 優先順位の低いキーワードをキャッチコピー枠へ移す。全部入れる要望には、入らない旨と分散案をセットで提示する |
| 出品画面の実際の表示が references の仕様と異なる | 画面の表示を正として作業し、references/01_platform-specs.md の更新をユーザーに提案する（スクショ等で実確認できた場合のみ更新） |
| 実績・資格・数値が未提供 | 創作せず、ユーザーに確認するか数値なしの表現で作る |
| 既存出品の改善で現行文がもらえない | 全文なしでは書き換え案を確定させず、一般論の指摘に留まる旨を明示する |

## 禁止事項

- 文字数検証表なしで納品してはならない
- 入力されていない実績・数値・資格を創作してはならない
- 効果・順位の保証表現を書いてはならない（「保証はできません」を1箇所必ず明記する）
- 公式仕様を推測で書き換えてはならない（出品画面の実確認がある場合のみ更新）
- 専門用語を補足なしで使ってはならない（例: GBP（Googleビジネスプロフィール））
- タイトルとキャッチコピーで同じキーワードを重複させてはならない
