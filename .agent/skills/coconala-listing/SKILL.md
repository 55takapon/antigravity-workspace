# coconala-listing

> **目的**: ココナラ出品文をProマーケター視点で作成・改善する。文字数制限の厳守と、ユーザーリテラシーを踏まえた実用的な構成を徹底する。

## 公式文字数制限（要確認）

| 項目 | 文字数上限 | 備考 |
|---|---|---|
| タイトル | **25文字以内** | 検索に直結。キーワードを先頭に置く |
| キャッチコピー | 非公開（〜50文字目安） | 検索結果に表示される補足文 |
| サービス内容 | **1,000文字以内** | 本文。絵文字・装飾は文字数を消費する |
| 購入にあたってのお願い | **500文字以内** | トークルームトップに表示される重要欄 |
| よくある質問（Q&A） | **400文字以内/1問** | 複数設定可。本文で書ききれない補足に使う |
| トークルーム回答例 | 300文字以内 | |

> ⚠️ 仕様は変更される可能性があるため、出品画面または[公式ヘルプ](https://coconala.com/help)で必ず確認すること。

## 文章設計の原則（Proマーケター視点）

### 構成の基本順序
1. **共感（悩みの言語化）** — 読者が「これ自分のことだ」と感じる状態から始める
2. **解決提示** — このサービスで何が解決するかを1文で言い切る
3. **具体的な納品物** — 「〜します」ではなく「〜を納品します」と明示
4. **プロセス（安心感）** — 購入後の流れを短く明示してハードルを下げる
5. **対応範囲** — 業種・条件を明記して無駄なやり取りを減らす
6. **アップセル導線** — 別出品への導線を自然に入れる

### NGパターン（やらないこと）

| NG | 理由 |
|---|---|
| ━━━ などの装飾区切り線 | 文字数を消費するだけ。情報密度が下がる |
| 📌 などの絵文字を見出しに多用 | 文字数消費 + 読みにくい。使うなら1〜2個まで |
| 「競合店のGBPリンクを教えてください」 | ココナラユーザーのリテラシー上、回答不能なケースが多い。ハードルを下げる表現に変える |
| 「〜のご注意」「〜についてのお願い」の多重化 | 500文字制限内で重複する注意書きは削除 |
| 効果・順位の保証表現 | 薬機法・景表法ではないが、ユーザーとのトラブル防止のため「保証はできません」を必ず明記 |
| 「まずはお気軽に〜」の多用 | 1回のみ。繰り返すと安っぽく見える |

### ユーザーリテラシーの前提

- ococona라の一般ユーザーは「GBP」「MEO」「CTA」を知らないことが多い
- ヒアリングで聞く内容は「業種・強み・ターゲット」程度に絞る
- 「競合店のURL」などの調査作業を購入者に求めない
- 専門用語を使う場合は必ず直後に括弧で補足する

## 出品文のカウント目安

サービス内容1,000文字の使い方（目安）：
- 冒頭の悩み提示: 〜150文字
- 解決提示: 〜100文字
- 納品物リスト: 〜150文字
- 制作の流れ: 〜150文字
- 対応業種: 〜100文字
- アップセル導線: 〜80文字
- **合計目安: 700〜800文字**（残り200字はポートフォリオ画像で補完）
