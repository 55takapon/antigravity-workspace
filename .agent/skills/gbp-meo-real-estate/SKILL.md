## 1. 不動産のMEO市場環境（2025-2026）

### 1.1 不動産×ローカル検索の現状

- **ポータルサイトとGoogleマップの競合**: SUUMO・HOME'S・アットホーム等の大手ポータルが検索上位を占める中、Googleマップは「今すぐ相談したい」「近くの不動産屋に行きたい」のニーズに対応
- **「地域名＋不動産」検索の増加**: 特に引っ越しシーズン（1-3月）は「○○駅 不動産」「○○区 賃貸」の検索が急増。Googleマップ経由の来店・電話が増加傾向
- **口コミの決定力**: 不動産取引は高額＆人生の重要決断。「対応が丁寧だった」「無理な営業がなかった」等の口コミが来店決定に強く影響
- **AI検索の影響**: 「○○駅の家賃相場」「○○区で子育てしやすいエリア」等の情報クエリにAI Overviewsが回答。地域情報の充実度が引用の鍵
- **Googleマップの物件表示**: 一部地域でGoogleマップ上に物件情報が直接表示される機能のテスト中。今後、GBPと物件情報の連携が重要になる可能性

### 1.2 不動産MEOの難易度と特徴

| 項目 | 不動産の特徴 |
|------|------------|
| 競合密度 | **高い**（都市部では半径1km内に10〜30店舗。大手チェーンと個人店が混在） |
| 口コミ優先度 | **非常に高い**（高額取引のため口コミを精読する傾向が強い） |
| 客単価 | **非常に高い**（仲介手数料: 賃貸1ヶ月分〜、売買3%+6万円） |
| LTV（顧客生涯価値） | **中〜高い**（売買は一度きりだがリフォーム・管理に展開可能） |
| 季節変動 | **非常に大きい**（1-3月が年間の40〜50%を占める） |
| 写真の影響度 | **高い**（店舗の信頼感＋スタッフの親しみやすさ） |
| 電話アクション比率 | **高い**（5-9%。物件問い合わせは電話が主流） |

→ コアスキル セクション1（MEO全体像・ランキング要因）を前提知識として参照

### 2.2 属性設定チェックリスト（不動産固有）

#### 必須属性
- [ ] **駐車場**: あり/なし（車で来店する顧客に重要）
- [ ] **バリアフリー**: 車椅子対応入口
- [ ] **支払い方法**: 現金 / 銀行振込 / クレジットカード
- [ ] **予約**: 来店予約制 / 予約優先 / 飛び込み歓迎
- [ ] **オンライン対応**: オンライン内見 / Web相談可

#### 不動産重要属性
- [ ] **対応エリア**: 取り扱いエリア（市区町村・沿線名）
- [ ] **取り扱い物件種別**: 賃貸 / 売買 / 投資用 / 事業用
- [ ] **対応言語**: 英語 / 中国語等（外国人顧客対応）
- [ ] **キッズスペース**: あり/なし（ファミリー物件検討者に重要）
- [ ] **女性スタッフ**: 在籍（一人暮らし女性の安心材料）
- [ ] **相談無料**: 物件相談・査定無料

> **「オンライン内見対応」は2025年以降の差別化属性**: コロナ以降定着したオンライン内見。地方→都市部への転居者に特に重要。

## 4. 口コミ獲得・管理（不動産特化）

### 4.1 口コミ獲得タイミング

#### 最適タイミング
1. **契約完了・鍵渡し時**（最高の口コミが得られる）: 新居が決まった喜びが最大の瞬間
2. **入居後1〜2週間目**: 引っ越し完了の安心感＋対応への感謝が残っている段階
3. **売却完了後**: 高額取引の責任感から解放された安堵のタイミング
4. **更新手続き時**: 長期入居者に自然に依頼

#### 口コミ依頼の声がけ例
```
【鍵渡し時】
「本日はおめでとうございます！
 良いお部屋が見つかって私も嬉しいです。
 もしよければ、お部屋探しで悩んでいる方の参考になりますので、
 Googleに当店の感想をいただけると大変ありがたいです」

【入居後フォロー】
「お引っ越しはいかがですか？新しいお住まいは快適でしょうか。
 もしよろしければ、当店でのお部屋探しの体験談を
 Googleマップに書いていただけると嬉しいです」
```

#### 高評価（4-5星）向け


### 4.3 ABSA属性（Googleが不動産口コミから抽出するキーワード）

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **対応の丁寧さ** | 親身、丁寧、親切、寄り添ってくれた |
| **提案力** | 希望通り、良い物件を紹介、条件に合った |
| **営業姿勢** | 無理な営業がない、押し付けがない、誠実 |
| **レスポンス** | 対応が早い、すぐに連絡をくれた |
| **知識** | 地域に詳しい、専門知識が豊富 |
| **初期費用** | 費用の説明が明確、安心できた |
| **アフターフォロー** | 入居後も相談できる、アフターフォローが良い |

### 4.4 不動産固有のリスク・注意点

- **契約トラブル口コミ**: 初期費用・退去費用・原状回復の紛争は最も多い不動産クレーム。返信では法的詳細に触れず個別対応へ誘導
- **営業手法への不満**: 「しつこい電話」「おとり物件」等の指摘は真摯に受け止め改善姿勢を示す
- **退去時トラブル**: 管理会社は退去精算の口コミに注意。ガイドラインに基づく対応を示す
- **個人情報の漏洩リスク**: 口コミ返信で物件住所・契約条件に触れないこと

## 9. 不動産の広告規制（宅建業法）

### 9.1 適用される法規制

| 法規制 | 主な制限 |
|--------|---------|
| **宅地建物取引業法** | 誇大広告禁止・取引態様の明示義務 |
| **不動産の表示に関する公正競争規約** | 物件広告の表示基準 |
| **景品表示法** | 優良誤認・有利誤認の禁止 |

### 9.2 GBP投稿での禁止事項

1. ❌ **おとり広告**: 成約済み・架空の物件を投稿に掲載
2. ❌ **「駅徒歩○分」の虚偽記載**: 80m=1分で計算（端数切り上げ）
3. ❌ **「格安」「激安」等の曖昧な価格表現**: 具体的根拠が必要
4. ❌ **「日当たり良好」等の主観表現を断定的に使用**: バルコニーの向き等の客観情報で
5. ❌ **新築の虚偽定義**: 建築後1年未満かつ未入居のみ「新築」と表示可
