# Threads執筆ルール — 2026年7月時点

writerサブエージェントがThreads投稿を書く時に必ず読む資料。

---

## アルゴリズム前提（2026年時点で確認済みの事実）

1. **会話ファーストのSNS**。Threads上のコンテンツの約半分はリプライで構成され、いいねよりリプライ（特に投稿者との往復）が圧倒的に重い。
2. **4段階の評価ステージ**で配信範囲が決まる:

| ステージ | 配信範囲 | 評価ポイント | 書き手が打てる対策 |
|:--|:--|:--|:--|
| 1 初期配信 | フォロワーの一部 | 初速反応（特にリプライ） | 投稿後1時間はリプライに即返信 |
| 2 拡大配信 | フォロワー全体 | 反応の持続性 | テキストで文脈を補足する |
| 3 おすすめ掲載 | フォロワー外 | トピック関連性 | トピックタグを1つに絞る |
| 4 広範囲拡散 | 外部まで | シェア価値 | ステージ3を安定して超える |

3. **テキストがAIの文脈理解の鍵**。画像を付ける場合も、何の話かが分かる本文を必ず書く。
4. 投稿後30〜60分の初速が「おすすめ」掲載の分岐点。
5. ポジティブ・建設的なトーンが文化。攻撃的・断罪調はXでは通ってもThreadsでは沈む。

## 書き方ルール

- **500字以内**を基本にする（簡潔なテキスト＋問いかけが最も返信を集めやすい）。Xの長文をそのまま持ち込まない。
- 冒頭1〜2行で「続きを読む」を押させる。フックの型は copywriting-frameworks.md から選ぶ。
- **「ツッコミ代」を残す**。完璧に語り切らず、読者が意見・体験を書き込める余白（あえて断定しない一文、二択の投げかけ等）を作る。
- 投稿の最後は自然な問いかけで終える。リプライのハードルを下げる聞き方にする（「どう思う?」より「あなたはどっち派?」）。
- トピックタグは**1投稿1つ**。ニッチで具体的なタグを選ぶ。
- 本音・等身大の一人称で書く。Xより「人柄」を強く出してよい（倫理法人会・家族・日常系の素材はThreadsと相性が良い）。

## 構成の型（旧sns/スキルから継承。構成の骨組みとして使う）

| 型 | 骨組み |
|:--|:--|
| マインドセット型 | 気づきのフック→概念を日常の言葉で→「あなたの場合は?」 |
| 実践Before/After型 | 「〜だった人が◯ヶ月後に…」→課題→気づき→行動→結果→同じ壁の人への問いかけ |
| あるある型 | 「〜してない?」→よくある失敗→正しいやり方→正直どうしてる?の問いかけ |
| 対話ノウハウ型 | 「〜するなら正直これ1択」→比較→結論→「あなたなら何を選ぶ?」 |
| ニュース解説型 | 「〜が変わった。小さなお店に影響大」→変更点→影響→対応→「対応済み?」 |
| 議論喚起型 | 「ぶっちゃけ聞きたい」→二択提示→両方のメリデメ→経験募集 |
| 日常の気づき型 | body: 日常の一場面→そこで気づいたこと→ゆるい問いかけ |

## NG事項（1項目ずつ原稿と照合すること）

- エンゲージメントベイト（「同意なら『はい』とリプして」等はペナルティ対象）
- 外部リンクの直貼り（リーチ抑制傾向）
- Xやインスタ本文のコピペ・語尾だけ変えたリライト
- 1日5本以上の連投前提の構成（リーチの食い合い）
- トピックタグの複数付け
- 攻撃的・ネガティブ断罪調
- 完璧に説明し切って会話の余地を消すこと
