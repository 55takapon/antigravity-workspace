# GBP月次レポート — データ入力テンプレート 使い方ガイド

## テンプレートの概要

GBP管理画面の「パフォーマンス」から取得できる全指標を、1年分（1〜12月）蓄積するためのシートです。
顧客ごとにファイルをコピーして使います。

## テンプレートの場所

```
templates/gbp_monthly_report_template.csv
```

## Google Sheetsへのアップロード手順

1. Google Drive を開く
2. 「新規」→「ファイルのアップロード」で上記CSVをアップロード
3. アップロードしたファイルを開く →「Google スプレッドシートで開く」
4. ファイル名を「【顧客名】GBP月次データ_2026」に変更
5. 新規顧客の場合はこのファイルを「コピー」して使い回す

## データ入力のタイミング

| タイミング | 取得するデータ | 所要時間 |
|-----------|--------------|---------|
| **毎月1〜5日** | 前月のパフォーマンス指標（閲覧数・アクション数） | 5〜10分/顧客 |
| **毎月1〜5日** | 前月の口コミ数・評価・返信率 | 3分/顧客 |
| **毎月1〜5日** | 前月の投稿数・写真追加数 | 2分/顧客 |
| **毎月1〜5日** | 検索クエリTOP10 | 5分/顧客 |
| **四半期ごと** | 競合ベンチマーク（口コミ数・評価） | 10分/顧客 |
| **随時** | 月次アクションログ（施策内容と気づき） | 3分/顧客 |

## GBP管理画面からのデータ取得手順

```
1. business.google.com にログイン
2. 対象ビジネスを選択
3. 左メニュー「パフォーマンス」をクリック
4. 期間を「前月」に設定
5. 以下を転記:
   - 閲覧数（合計・プラットフォーム別）
   - ウェブサイトクリック数
   - ルート検索数
   - 通話数
   - 検索語句（クエリ）
```

## テンプレートの8セクション

| # | セクション | 用途 | データソース |
|---|-----------|------|------------|
| 1 | パフォーマンス指標 | 閲覧数・アクション数の月次推移 | GBP管理画面「パフォーマンス」 |
| 2 | アクション率 | 閲覧→行動の転換率（自動計算） | 上記から計算 |
| 3 | 口コミ | 件数・評価・返信率の推移 | GBP管理画面「口コミ」 |
| 4 | 投稿 | 月間投稿数・タイプ別内訳 | GBP管理画面「投稿」 |
| 5 | 写真 | 枚数・閲覧数の推移 | GBP管理画面「写真」 |
| 6 | 検索クエリTOP10 | 表示されたキーワード分析 | GBP管理画面「パフォーマンス」→検索語句 |
| 7 | 競合ベンチマーク | 競合との比較（四半期） | Googleマップで手動確認 |
| 8 | 月次アクションログ | 施策の記録と振り返り | 運用者が記入 |

## 顧客ごとのファイル命名規則

```
【英和塾】GBP月次データ_2026.csv
【ジェットプロデュース】GBP月次データ_2026.csv
【〇〇クリニック】GBP月次データ_2026.csv
```

## 月次レポートへの活用

このデータシートをベースに、コアスキル §8.8.2「月次報告テンプレート」に沿った
クライアント向けレポート（A4 1枚 or スライド3〜4枚）を作成する流れ。
