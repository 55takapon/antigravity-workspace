# GBP投稿文 品質チェックスキル

> gbp-meo-post-core §6「事実確認・信憑性チェック」を実運用レベルに展開したQAスキル。  
> **投稿文をオーナーに納品・報告する前に必ず実行する。出稿は「チェック完了報告」の後。**

---

## 起動条件

以下のいずれかに該当する場合に使用する：
- GBP投稿案を新規作成したとき（1記事〜複数記事）
- 既存投稿ファイルを修正したとき
- 「誇大では？」「断言では？」とユーザーから指摘を受けたとき
- 歯科クリニック・医療機関クライアントの投稿を作成したとき
- 税理士・司法書士・士業クライアントの投稿を作成したとき

---

## チェック6軸

### 軸1｜誇大表現・最上級断言（全業種共通）

**禁止パターン（即修正）:**

| NG表現 | 修正方向 |
|---|---|
| 「〜で**一番**〜」「**最高の**〜」 | 「〜で好評の〜」「多くの方に喜ばれている〜」 |
| 「**必ず**〜になります」 | 「〜しやすくなります」 |
| 「**絶対に**〜」 | 削除または「〜の傾向があります」 |
| 「**あっという間に**〜が解決します」 | 「〜が和らぎやすくなります」 |
| 「雨の日の憂鬱が**吹き飛んでしまいます**」類 | 「気分が切り替わりやすくなります」 |

---

### 軸2｜根拠のない体験・感情の断言（全業種共通）

**禁止パターン（即修正）:**

| NG表現 | 修正方向 |
|---|---|
| 「〜と**笑顔になれる**一皿です」 | 「〜という声もいただく一皿です」 |
| 「体の緊張が**ふっとほぐれます**」 | 「〜という感覚があった、という声もいただきます」 |
| 「〜と感じる**はずです**」 | 「〜と感じる方も多いのではないでしょうか」 |
| 「**誰でも**経験があるはずです」 | 「経験がある方も多いのではないでしょうか」 |
| 「〜に**違いありません**」 | 「〜かもしれません」 |

**口コミ・感想を引用する場合の安全な形式:**
> ✅ 「〜という声をいただくことも多い一品です」  
> ✅ 「〜という感想をいただいています」  
> ❌ 「〜と笑顔になってくれるはずです」（来店前の体験を断言）

---

### 軸3｜医療・健康・栄養効能の断言（全業種共通）

飲食店であっても、「身体に効く」系の表現は特に注意。

**禁止パターン（即修正）:**

| NG表現 | 修正方向 |
|---|---|
| 「夏バテを**深刻にさせます**」 | 「夏バテにつながりやすいとも言われています」 |
| 「もつは栄養が**豊富な食材**です」 | 「コラーゲンやたんぱく質を含む食材として知られています」 |
| 「体調を**整えます**」 | 「体調を整えるとも言われています」 |
| 「免疫力が**上がります**」 | 「免疫力に関わると言われる〜が含まれています」 |

> ⚠️ 「〜と言われています」「〜として知られています」は許容。根拠元を断言しないことが重要。

---

### 軸4｜誤字・脱字・表記ミス（全業種共通）

以下を必ず目視確認する：

- 「くださいい」等の二重入力
- 「〜です。です。」などの文末重複
- 固有名詞の表記ゆれ
- 電話番号・URL の本文記載（スパム判定リスク → 即削除）

---

### 軸5｜医療広告ガイドライン遵守（歯科・クリニック）

**適用条件**: クライアントが歯科医院・クリニック・医療機関の場合に必須。

#### 根拠法令
- **医療法 第6条の5・6条の7**（広告規制の基本）
- **医療広告ガイドライン**（厚生労働省、最新版2018年〜随時改訂）
- **薬機法**（医療機器・未承認薬の効能表示）
- **景品表示法**（優良誤認・有利誤認）

#### 基本原則
GBP投稿・SNS投稿はすべて「医療広告」に該当する。患者の受診を誘引する意図があり医療機関名が特定できれば、すべて規制対象。**原則として「広告可能事項」として認められたもの以外は広告不可。**

#### 禁止表現（NG → 修正方向）

| NG表現 | 問題 | 修正方向 |
|---|---|---|
| 「地域No.1」「最高の治療」 | 比較優良広告禁止（医療法） | 「年間○○件の治療実績」等の客観事実に |
| 「絶対痛くない」「必ず治る」「成功率98%」 | 治療効果の保証禁止（誇大広告） | 「痛みに配慮した治療を心がけています」 |
| 「100%成功」等の確実性保証 | 医療に絶対はない（誇大広告） | 「丁寧な治療で多くの方にご満足いただいています」 |
| 患者体験談・口コミの選定掲載 | 医療広告規制の制限対象（体験談広告） | 投稿本文での体験談引用は避ける。口コミは自然発生のみ |
| ビフォーアフター写真（説明なし） | 症例写真4点セット未満は不可 | ①治療内容 ②費用 ③期間・回数 ④リスク/副作用（＋個人差注記）を同一画面内に全て明記 |
| 「ゴッドハンド」「名医」「一流の技術」 | 品位を損なう表現 | 「○○学会認定医」「〇〇専門医」等の正式資格名に |
| 「激安」「業界最安値」 | 景品表示法・医療広告 | 「○○円（税込・保険適用）」等で明示 |
| インビザライン効能の断言 | 薬機法（未承認医療機器） | 「マウスピース矯正に対応しています」に留める |
| 「○○疾患が治ります」 | 疾患名への効能断言禁止 | 「○○のお悩みについてご相談ください」 |

#### 必須確認チェックリスト（軸5）
- [ ] 費用記載がある場合、「税込/税別」「保険適用/自費」の区分が明示されているか
- [ ] 設備・機器の紹介で、未承認機器の効能を断言していないか
- [ ] 症例紹介がある場合、4点セット＋個人差注記が揃っているか
- [ ] 患者の体験談を意図的に引用していないか
- [ ] 「治る」「改善する」等の治療効果を断言していないか

> ⚠️ GBP口コミへの返信においても、治療効果を保証するような表現は禁止。具体的な治療内容への言及は守秘義務違反リスク。

### 軸6｜士業広告規制遵守（税理士・司法書士）

**適用条件**: クライアントが税理士・司法書士・弁護士・行政書士等の場合に必須。

#### 根拠法令
- **税理士法 第33条・第48条**（広告規制・品位保持）
- **日本税理士会連合会「業務の広告に関する細則」**
- **司法書士法 第22条**（品位保持義務）
- **日本司法書士会連合会 会則・倫理規程**
- **弁護士法 第72条**（非弁行為禁止 ← 司法書士も対象）
- **景品表示法**（優良誤認・有利誤認）

#### 税理士・共通の禁止表現

| NG表現 | 問題 | 修正方向 |
|---|---|---|
| 「税務調査が絶対にゼロになる」「贈与税が必ずタダになる」 | 成果保証禁止（誇大広告） | 「税務調査対応のご相談を承ります」 |
| 「地域No.1の実績」「業界最安値」 | 比較広告禁止・品位保持義務 | 「相続税申告 年間○件以上」「顧問料 月額○円〜」 |
| 「スーパー税理士」「神の手」等の誇張 | 品位を損なう表現 | 「○○学会会員」「認定税理士」等の正式資格名 |
| 「どんな案件でも必ず解決」 | 結果保証禁止 | 「お気軽にご相談ください」 |
| 「元○○税務署長」等の行政庁役職名 | 役職名の不適切使用（細則違反） | 使用不可または「税務行政の経験を持つ税理士」等に |
| 依頼者・関与先の氏名・案件内容（同意なし） | 守秘義務違反・個人情報保護法 | 「多くのお客様にご利用いただいています」等一般化 |
| 紹介料・キックバック目的のリード広告 | 非弁提携・倫理規程違反 | 正当な広告対価のみ利用可 |

#### 司法書士の追加禁止表現（弁護士法72条・非弁行為）

| NG表現 | 問題 | 修正方向 |
|---|---|---|
| 「揉めている遺産をまとめます」「トラブルを解決します」 | **非弁行為（弁護士法72条）** 紛争への介入・代理交渉を示唆 | 「話し合いがまとまった後の遺産分割協議書作成をサポートします」 |
| 「相手方と交渉します」「代理で対応します」（140万円超） | 代理権の範囲超過 | 「簡裁代理権の範囲内でのご相談については対応可能です」 |
| 「相続登記しないと**罰金**になります」 | 法律用語の誤用（正確には「過料」） | 「行政上のペナルティ（**過料**）が科される可能性があります」（過料には前科なし） |
| 「ポータルサイト経由の事件紹介」（対価が紹介料） | 非弁提携の疑い | 広告費の性質を精査。紹介料形式は禁止 |
| 他事務所・弁護士を中傷・比較 | 品位保持義務違反 | 自事務所の強みのみを客観的に記述 |

#### 必須確認チェックリスト（軸6）
- [ ] 司法書士投稿に「紛争・トラブル解決」「代理交渉」を示唆する表現がないか（非弁行為リスク）
- [ ] 相続登記義務化に関して「罰金」と記載していないか（正確には「過料」）
- [ ] 税理士投稿に成果保証（「必ず節税できる」等）がないか
- [ ] 行政庁在職時の役職名を掲載していないか
- [ ] 依頼者・案件内容を同意なく公開していないか
- [ ] 他事務所との比較・中傷表現がないか

> ⚠️ 口コミ返信でも守秘義務は同様に適用。「相続税の申告を担当しました」程度でも本人同意なき案件内容の公開はリスク。

### 軸7｜誤解を招く表現（全業種共通）

**概念**: 事実として誤りではないが、読み手が誤った印象・期待を持つ可能性がある表現。景品表示法の「優良誤認・有利誤認」および消費者契約法の「誤認惹起行為」に相当するリスクを含む。

**禁止パターン（即修正）:**

| NG表現 | 問題 | 修正方向 |
|---|---|---|
| 「手続きを進められるようになります」（断言） | 法的手続きは個々の状況・裁判所判断に依存するため、断言は誤解を招く | 「進められるようになる場合があります」 |
| 「〜さえすれば解決します」 | 複合的な要因がある手続きを単純化しすぎ、過度な期待を与える | 「〜が解決の一助となる場合があります」 |
| 「簡単にできます」「すぐに終わります」 | 手続き期間・難易度を過小評価させ、実態と乖離した印象を与える | 「専門家のサポートのもとで進めることができます」 |
| 「〜すれば大丈夫です」 | 保証を意味する断言で、実際の結果に個人差があることを隠す | 「〜することで対応できる場合が多くあります」 |
| 「口座が凍結されます」（金融機関の判断を断言） | 実際は金融機関が取引制限をする「運用」であり、法的凍結ではない | 「口座取引が制限される場合があります」（ただし業界慣用語として許容範囲内） |
| 「必ず相談に来てください」 | 義務的なニュアンスで誤解を与える | 「ぜひお気軽にご相談ください」 |

**判定のポイント:**
- 「読んだ消費者が、実際より有利・簡単・確実だと思う可能性がないか」を基準に判断する
- 士業・医療系では特に「手続き結果の保証」「期間・コストの過少表示」に注意

#### 必須確認チェックリスト（軸7）
- [ ] 手続きの結果・効果を断言していないか（「〜になります」→「〜になる場合があります」）
- [ ] 手続きの容易さ・期間を過小評価させる表現がないか
- [ ] 読み手が「必ずそうなる」と誤解しそうな表現がないか
- [ ] 専門用語を使う場合、一般消費者が誤読しやすい文脈になっていないか

## チェックフロー

```
STEP 1: 対象クライアントの業種を確認
       ↓
STEP 2: 対象ファイル（または文章）を読み込む
       ↓
STEP 3: 軸1〜4（全業種共通）をスキャン
       ↓
STEP 4: 業種に応じて 軸5（医療）or 軸6（士業）を追加スキャン
       ↓
STEP 5: 軸7（誤解を招く表現）を全業種スキャン
       ↓
STEP 6: 問題箇所を列挙（出力フォーマット参照）
       ↓
STEP 7: 合否判定
       ↓
STEP 8: 「チェック完了報告」を出力 → 合格の場合のみ出稿
```

## チェック完了報告フォーマット（出稿前に必ず出力）

合格判定が出た投稿のみ、以下の形式で報告してから出稿する。

```
## ✅ 品質チェック完了報告

**対象クライアント**: [クライアント名]
**対象ファイル**: [ファイル名]
**チェック実施日**: [YYYY-MM-DD]

### 実施チェック軸と結果

| チェック軸 | 確認内容 | 結果 |
|---|---|---|
| 軸1｜誇大表現・最上級断言 | 「一番」「絶対」「必ず」等 | [✅ 問題なし / ❌ 要修正] |
| 軸2｜体験・感情の断言 | 「はずです」「になれる」等 | [✅ 問題なし / ❌ 要修正] |
| 軸3｜医療・健康効能の断言 | 栄養・体調改善効果の根拠なき断言 | [✅ 問題なし / ❌ 要修正] |
| 軸4｜誤字・禁止記載 | 誤字脱字・電話番号/URL直書き | [✅ 問題なし / ❌ 要修正] |
| 軸5｜医療広告GL（医療法・薬機法・景表法） | ※医療機関の場合のみ | [✅ 問題なし / ❌ 要修正 / ➖ 対象外] |
| 軸6｜士業広告規制（税理士法・司法書士法・弁護士法72条） | ※士業の場合のみ | [✅ 問題なし / ❌ 要修正 / ➖ 対象外] |
| 軸7｜誤解を招く表現（景表法・消費者契約法） | 有利誤認・断言・手続き容易さの過小表示 | [✅ 問題なし / ❌ 要修正] |

### 修正実施内容
（発見・修正した項目があれば箇条書き。なければ「なし」）

### 出稿判定
✅ **全軸クリア。GBP投稿への出稿を承認します。**
```
