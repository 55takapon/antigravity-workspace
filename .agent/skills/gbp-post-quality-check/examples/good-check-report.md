# QAチェック結果の良い報告型

このファイルは、完成投稿本文の良い例ではなく、品質チェック報告の型を示す。良好事例本文はユーザーが選ぶため、ここにはコピー用の完成投稿を置かない。

## 例1: 要修正がある場合

### 入力

- 対象: GBP投稿文1件
- 業種: 歯科
- 確認済み材料: 医院ナレッジ、過去投稿
- 未確認材料: 実際の患者口コミ、予約状況、家庭ごとの予定

### 出力

```markdown
## QAチェック結果

対象クライアント: かまだ歯科医院
対象投稿: 8月投稿案
判定: 要修正

### 要修正

| # | 箇所 | NG表現 | 該当軸 | 悪い理由 | 安全な修正方向 |
|:---|:---|:---|:---|:---|:---|
| 1 | 投稿2本文 | 夏休み中なら予定を調整しやすい | 軸7 | 家庭ごとの予定を決めつけている | 予約可能日や相談案内など確認済み事実へ戻す |
| 2 | 投稿2本文 | 歯医者さんは怖くない場所だと思ってもらえる | 軸2・軸5 | 患者の感情変化を保証している | 医院が行う段階的な対応や配慮の説明にする |

### 問題なし

| 軸 | 結果 | 根拠 |
|:---|:---|:---|
| 軸1 | 問題なし | 最上級、絶対、必ずの保証表現はなし |
| 軸4 | 問題なし | 店名、表記、電話番号、URL直書きはなし |
| 軸6 | 対象外 | 士業投稿ではない |

### 出稿判定

要修正です。上記2件を修正後、再チェックしてください。チェック完了報告はまだ出しません。
```

## 例2: 合格の場合

### 入力

- 対象: GBP投稿文1件
- 業種: 飲食店
- 確認済み材料: 店舗ナレッジ、メニュー情報、過去投稿
- 未確認材料: 実際の口コミは使わない方針

### 出力

```markdown
## QAチェック結果

対象クライアント: iami加古川
対象投稿: 6月投稿案
判定: 合格

### 確認結果

| 軸 | 結果 | 根拠 |
|:---|:---|:---|
| 軸1 | 問題なし | 最上級、絶対、必ずの保証表現なし |
| 軸2 | 問題なし | 未確認の口コミ、お客様の声、感情断定なし |
| 軸3 | 問題なし | 健康効果、栄養効能の断定なし |
| 軸4 | 問題なし | 誤字、表記ゆれ、電話番号、URL直書きなし |
| 軸5 | 対象外 | 医療機関ではない |
| 軸6 | 対象外 | 士業ではない |
| 軸7 | 問題なし | 季節、家庭状況、予定、来店行動の決めつけなし |
| 軸8 | 問題なし | 固定冒頭を除く可変本文が投稿目的型に合う魅力から始まり、主要訴求のベネフィットと来店導線が整合 |

### 修正実施内容

- 未確認の口コミ風表現は使用していません。
- 季節テーマは提案に留め、読者の予定や家族構成を断定していません。

## 品質チェック完了報告

対象クライアント: iami加古川
対象投稿: 6月投稿案

8軸チェックを実施し、要修正箇所はありませんでした。GBP投稿として出稿可能です。
```

## 例3: 保留の場合

### 入力

- 対象: GBP投稿文1件
- 業種: 士業
- 確認済み材料: 事務所ナレッジ
- 未確認材料: 制度解釈、具体的な実績数

### 出力

```markdown
## QAチェック結果

対象クライアント: 士業クライアント
対象投稿: 相続手続き投稿案
判定: 保留

### 保留理由

| # | 箇所 | 表現 | 該当軸 | 保留理由 | 確認が必要なもの |
|:---|:---|:---|:---|:---|:---|
| 1 | 投稿本文 | 手続きを進められるようになります | 軸6・軸7 | 個別状況により結果が変わるため、断定すると誤解を招く | 業務範囲と制度説明の確認 |

### 出稿判定

保留です。制度・業務範囲の確認後に修正し、再チェックしてください。
```
