# iami/kamada 由来の失敗ケース

このファイルは、クライアント固有本文をスキル本体へ入れず、再利用できる失敗型だけを残すための例である。実際の投稿本文を丸ごと保存せず、具体表現、何が悪いか、安全な修正方向で扱う。

## iami型: 飲食店投稿の失敗

| 具体表現 | 何が悪いか | 安全な修正方向 |
|:---|:---|:---|
| 「口コミでビールの美味しさに言及してくださるお客様が多くいらっしゃいます」 | 実際の口コミを確認していない場合、未確認のお客様の声を作った表現になる | 実口コミが確認できる場合だけ内容を広げず要約する。確認できなければ、ビールの温度管理や提供内容など事実へ戻す |
| 「家族の席がパッと和みます」 | 家族構成、利用シーン、感情変化を断定している | 家族利用に対応できる事実やメニュー構成に留める |
| 「今夜の予定がまだ決まっていないなら」 | 読者の予定を決めつけている | 来店提案や予約案内に留める |
| 「この時期こそ、もつ鍋が一番美味しく食べられるタイミング」 | 季節行動と最上級の主観を断定している | 季節の提案として弱める。味や人気の優位性は確認済み事実に限定する |
| 「お父さんが一番好きなもの」 | 家族関係と嗜好を決めつけ、最上級表現も含む | 父の日の利用提案に留め、本人の好みは断定しない |
| 「常連さんたちが、まず必ず頼む一品」 | 常連行動の実績が未確認なら作り話になる。「必ず」も強すぎる | 注文実績の確認がなければ、看板メニューやおすすめメニューとして説明する |

## kamada型: 歯科投稿の失敗

| 具体表現 | 何が悪いか | 安全な修正方向 |
|:---|:---|:---|
| 「夏休み中なら予定を調整しやすい」 | 各家庭の予定を決めつけている | 休診日や予約可能枠など確認済み情報へ戻す。予定は各家庭で異なる前提にする |
| 「ご家族みなさんで一度お口の状態を確認してみませんか」 | 家族構成と同伴行動を前提にしている | 子ども、保護者、本人など対象を明確にし、希望者向けの相談案内にする |
| 「歯医者さんは怖くない場所だと安心してもらう」 | 患者の感情変化を保証している | 医院が行う配慮や段階的な対応という事実へ戻す |
| 「受診すれば原因をきちんと確認できる」 | 診断や結果を保証する印象がある | 診療で状態を確認し、必要に応じて説明する範囲に留める |
| 「季節の変わり目はお口のトラブルも起こりがち」 | 医療的因果や発生傾向の根拠が曖昧な場合がある | 一般的注意として弱めるか、確認済み資料がある場合だけ慎重に書く |
| 「健康をキープしやすくなります」 | 医療・健康効果の断定に見える | 定期検診やクリーニングの対応内容、相談できる内容へ戻す |

## チェック時の使い方

1. 投稿文に似た型の表現がないか探す。
2. 似た型があれば、出典の有無を確認する。
3. 出典がなければ要修正にする。
4. 問題の役割に応じて、修正方向を次から選ぶ。
   - ファクト・安全性の問題: 確認済み事実へ戻す、断定を弱める、削除する、保留にする。
   - 軸8の問題: 投稿目的型に合う冒頭への変更、確認済み事実のベネフィット翻訳、CTAの段階調整、同月重複を避ける企画差し替え。

## 追加する時の型

新しい失敗ケースは、次の表で追加する。

| 具体表現 | 何が悪いか | 安全な修正方向 |
|:---|:---|:---|
| 新しく見つかった表現 | 未確認事実、断定、広告リスクなど | 確認済み事実へ戻す、削除、保留、専門家確認 |
