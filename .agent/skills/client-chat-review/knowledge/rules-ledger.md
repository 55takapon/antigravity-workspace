# 壁打ち学習メモ（台帳）

壁打ち中のユーザーフィードバックを1行ずつためて、スキルを育てるファイル。このスキルの最終目的は毎回の代筆ではなく、ユーザー自身が相手目線で文章を設計できる状態を作ること。

## 書き方

- 1件1行。形式: `- 日付 | 種類（好み / NG表現 / 再発） | メモ`
- 同種のメモが3件たまったら、定型文化またはマイルール昇格を提案する
- 昇格したルールは references/01_review-principles.md 等の本則へ移し、この台帳の行には「昇格済み」と印を付ける（行の削除はしない）

## 実例・ナレッジ置き場（任意。あれば添削が一般論から実戦になる）

入手できたらこのフォルダに置くこと:

- 実際に送ったチャットと添削後の文章（改善前後のペア）→ examples/good-output.md の型を実例に差し替える材料
- 料金表 / 基本プランと追加対応の範囲 / 標準納期 / 対応できない業務 / 成果保証の方針 → プレースホルダーを実数値で埋められる
- 成約したチャット事例 / 相手の反応が悪かったチャット事例
- よくある質問と標準回答
