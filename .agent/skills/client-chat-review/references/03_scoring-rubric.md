# 採点基準と送信可否判定

## 何をするか
ステップ4で8軸をアンカー（点数帯の判定基準）に沿って採点し、合計点と送信可否を出す。

## 採点の前提
- 平均的なビジネス文章は60〜75点に収まるように付ける。80点以上は「そのまま送ってよい」水準にのみ与える
- 印象で点を付けない。必ず各軸のアンカー表から該当する帯を選んでから点数化する

## 8軸アンカー

### 軸1: 相手目線（20点）
| 点数帯 | 状態 |
|:--|:-----|
| 17〜20 | 相手の知りたいこと・判断・負担軽減が起点。自分都合の匂いがない |
| 10〜16 | 概ね相手起点だが、一部に自分の確認・都合を優先した箇所がある |
| 0〜9 | 自分が聞きたいこと・守りたいことが主役になっている |

### 軸2: 回答の早さ（15点）
| 点数帯 | 状態 |
|:--|:-----|
| 13〜15 | 冒頭2〜3行で相手の質問への結論が出ている |
| 7〜12 | 回答はあるが前置きの後、または一部の質問にしか答えていない |
| 0〜6 | 回答がない・質問だけを返している（C1該当時は必ずこの帯） |

### 軸3: 明確さ（15点）
| 点数帯 | 状態 |
|:--|:-----|
| 13〜15 | 内容・条件・対応範囲・期限が一読で分かる |
| 7〜12 | 概ね分かるが、曖昧語（「状況により」等）が判断を妨げる箇所がある |
| 0〜6 | 何が確定で何が未定か分からない |

### 軸4: 信頼形成（15点）
| 点数帯 | 状態 |
|:--|:-----|
| 13〜15 | 逃げ・冷たさ・不安定さの印象がなく、温度感が適切 |
| 7〜12 | 丁寧だが冷たい / 回りくどい / 謝罪過多など印象を弱める箇所がある |
| 0〜6 | 責任回避・転嫁・立場の下げすぎで信頼を落とす（C4/C6該当時は必ずこの帯） |

### 軸5: 提案力（10点）
| 点数帯 | 状態 |
|:--|:-----|
| 8〜10 | 相手の負担軽減か先回り提案が1〜2個、具体策つきである |
| 4〜7 | 配慮の言葉はあるが具体策がない |
| 0〜3 | 受け身で、回答のみ |

### 軸6: 行動喚起（10点）
| 点数帯 | 状態 |
|:--|:-----|
| 8〜10 | 何を・いつまでに・誰が、が明確 |
| 4〜7 | 次の行動は分かるが期限や主語が曖昧 |
| 0〜3 | 読後に相手が何をすべきか不明（M4該当時は必ずこの帯） |

### 軸7: リスク管理（10点）
| 点数帯 | 状態 |
|:--|:-----|
| 8〜10 | 約束・保証・対応範囲・費用の線引きが明確 |
| 4〜7 | 断定気味・譲歩気味だが致命ではない |
| 0〜3 | 成果保証誤認・無償確約・事実の創作がある（C2/C3/C5該当時は必ずこの帯） |

### 軸8: 読みやすさ（5点）
| 点数帯 | 状態 |
|:--|:-----|
| 4〜5 | 長さ・改行・敬語・温度感が適切 |
| 2〜3 | 長すぎ・詰め込み・敬語過剰のいずれかがある |
| 0〜1 | 読むのに労力がいる |

## 連動ルール（必須）
- 致命問題（C1〜C6）が1件でもあれば、合計点に関係なく判定は必ず「送信不可」とする
- 致命に対応する軸は、上のアンカー表の指定どおり最下帯で採点する

## 送信可否の判定表

| 判定 | 条件 |
|:-----|:-----|
| 送信可 | 致命0件・重大0件、かつ80点以上 |
| 修正推奨 | 致命0件だが重大が1件以上、または65〜79点 |
| 送信不可 | 致命1件以上、または64点以下 |

## 点数帯の目安（総評で使う言葉）
- 90以上: そのまま送れる完成度
- 80台: 使えるが磨きの余地がある
- 70台: 事故はないが営業・信頼形成の面で弱い
- 60台: 違和感があり、修正してから送るべき
- 50台以下: 心象・受注・案件進行に悪影響の可能性が高い

## 確認方法
合計が8軸の内訳（20/15/15/15/10/10/10/5）の合算と一致していること。致命の検出結果と送信可否が矛盾していないこと。

## 不合格時の対応
アンカーのどの帯か決められない場合は、下の帯を選ぶ（辛口側に倒す）。
