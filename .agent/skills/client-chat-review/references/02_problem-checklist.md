# 問題検出チェックリスト（致命度分類つき）

## 何をするか
ステップ3で下書きを1項目ずつ照合し、該当した問題を致命/重大/軽微に分類する。ステップ5では修正版の自己検査にも同じ表を使う。

## 見る観点
- **致命**: 1件でもあれば点数に関係なく「送信不可」。相手の信頼・受注・契約に直接ダメージを与えるもの
- **重大**: 送信前に修正すべき。営業成果・信頼形成を明確に弱めるもの
- **軽微**: 送っても事故にはならないが、磨けば良くなるもの

## 致命（1件で送信不可）

| ID | 問題 | 検知のサイン |
|:--|:-----|:------------|
| C1 | 相手の質問に答えていない | 費用・納期・可否を聞かれたのに、回答ゼロで質問だけ返している |
| C2 | 成果保証と誤認される表現 | 「必ず上位表示」「確実に増えます」等の断定 |
| C3 | 無償対応・過剰譲歩の確約 | 契約範囲外の作業を無条件で「対応します」と書いている |
| C4 | 責任転嫁に見える表現 | 「〜していただかなかったので」等、相手や第三者のせいにする構文 |
| C5 | 事実でない・未確認の情報 | 入力にない金額・実績・仕様を断定している |
| C6 | 事実確認前の全面過失承認 | クレームで原因未確認のまま「全て弊社の責任です」と認めている |

## 重大（要修正）

| ID | 問題 | 検知のサイン |
|:--|:-----|:------------|
| M1 | 結論が遅い | 前置き・経緯説明が3行以上続いてから本題に入る |
| M2 | 自分都合が透ける | 質問の理由が自分の確認・安心のため。工数・保身の匂いがする |
| M3 | 質問の丸投げ・過多 | 相手への質問が4つ以上、または判断材料を渡さず質問のみ |
| M4 | 次の行動が不明 | 読み終えて相手が何をすべきか分からない |
| M5 | 判断材料を渡していない | 「状況によります」で終わり、目安・条件・選択肢がない |
| M6 | 冷たい・機械的 | 相手の状況への反応が一切なく用件のみ（短文自体は問題ではない） |
| M7 | 謝罪過多・立場の低下 | 謝罪が2回以上、または不要な場面での謝罪 |
| M8 | 約束しすぎ | 確定していない納期・範囲を断定している |
| M9 | 社内事情の押しつけ | 「社内確認が取れず」等を相手の待ち理由として多用している |

## 軽微（磨き）

| ID | 問題 | 検知のサイン |
|:--|:-----|:------------|
| L1 | 回りくどい・長すぎ | 同じ内容の重複、1メッセージに論点4つ以上 |
| L2 | 不要な言い訳 | 遅れた理由の詳細説明が謝罪や対応策より長い |
| L3 | 提案がなく受け身 | 質問への回答だけで、先回りの提案がゼロ |
| L4 | 温度感の不足 | 感謝・反応の一言がない（チャネル・関係により許容） |
| L5 | 誤字脱字・敬語の誤り | 変換ミス・二重敬語（指摘は最後にまとめる。これだけを減点の主役にしない） |

## 出力形式
検出結果は「ID / 原文の該当箇所（短く引用）/ 相手からどう見えるか / 分類」で1件ずつ記録する。「相手目線が足りません」のような抽象指摘だけで終わらせてはならない。

## 確認方法
致命6件は1件ずつ照合結果を残す（該当なしでも確認したことを記録する）。重大・軽微は該当したものだけ記録すればよい。

## 不合格時の対応
分類に迷う場合、軽微か重大かの迷いは重大に倒す（辛口側）。ただし致命は誤爆の影響が大きいため、検知のサインに明確に一致する場合のみ致命とする。
