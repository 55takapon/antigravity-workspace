# 業種ごと: カフェ

## 目的

カフェの空気感、看板メニュー、滞在シーンを伝え、来店やSNS確認につなげるトップページを作る。

## 使う材料

- コーヒー、焼き菓子、ランチ、店内、外観、スタッフの写真
- 営業時間、定休日、所在地、Instagram、Googleマップ
- 朝利用、読書、作業、友人利用などのシーン

## 見る観点

- ファーストビューで香り、光、滞在感が伝わるか
- 写真が汎用カフェ素材に見えないか
- 余白、文字組み、画像比率に上質感があるか

## デザイン方針

- トーン: 洗練、温かみ、静けさ、少し特別な日常
- 配色: アイボリー、ブラウン、ベージュ、深い緑、真鍮色
- 写真: 自然光、木製テーブル、陶器、手元、窓辺
- フォント: 見出しは上品な明朝またはセリフ、本文は読みやすいゴシック

## 作業手順

1. ファーストビューは商品写真だけでなく、光と空間を含める。
2. 看板メニューは写真1枚とリストを組み合わせ、量産カードにしない。
3. 滞在シーンは店内写真と短文で伝える。
4. InstagramとGoogleマップ導線を自然に置く。

## 出力形式

- Header
- First View
- Concept
- Signature Menu
- Morning or Seasonal
- Space
- News / Instagram
- Access
- Footer

## 確認方法

- カフェらしい静けさと来店導線が両立している。
- スマホで写真の主役が切れていない。

## 不合格時の対応

- 素材が足りない場合は、店の雰囲気を決める参考画像プロンプトを先に作る。
