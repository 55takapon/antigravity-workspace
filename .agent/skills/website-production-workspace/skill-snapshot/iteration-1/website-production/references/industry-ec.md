# 業種ごと: EC・物販

## 目的

商品の魅力、使用シーン、購入理由を伝え、購入や問い合わせへつなげるサイトを作る。

## 使う材料

- 商品写真、使用シーン、価格、商品特徴、レビュー、FAQ
- ブランドストーリー、配送、返品、定期購入情報
- 購入CTA、カート、外部ショップURL

## 見る観点

- 商品写真が主役になっているか
- 購入前の不安を解消しているか
- CTAが目立ち、購入導線が迷わないか

## デザイン方針

- トーン: 魅力的、洗練、購買意欲、ブランドストーリー
- 配色: ブランドに合わせる。購入CTAは目立つ1色を使う
- 写真: 商品、利用シーン、同梱物、レビュー、比較
- フォント: ブランド世界観に合わせるが、本文は読みやすくする

## 作業手順

1. ファーストビューで商品、誰向けか、購入理由を示す。
2. 商品特徴はスペックだけでなく、利用者の変化や使用シーンで伝える。
3. レビュー、FAQ、配送/返品などの不安解消要素を置く。
4. 購入CTAをファーストビュー、中盤、終盤に置く。

## 出力形式

- Header
- First View
- Product
- Benefit
- Story
- Review
- FAQ
- Purchase
- Footer

## 確認方法

- 商品が映え、購入導線が明確である。
- スマホで価格、CTA、FAQが読みやすい。

## 不合格時の対応

- 商品情報や価格が未確認なら、購入導線を仮実装せず確認事項に分ける。
