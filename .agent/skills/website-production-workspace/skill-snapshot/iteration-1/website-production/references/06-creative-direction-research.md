# クリエイティブ品質リサーチ

## 目的

「プロっぽく」「テンプレ感をなくす」「安っぽい」「文字が多い」「もっとクリエイティブにしたい」という依頼で使う。単にNGを増やすのではなく、プロのアートディレクションとして、初見の記憶、情報の削り方、セクションの造形、余白、タイポグラフィ、国内参考の読み解きまで制作指示へ変換する。

## Webリサーチからの要点

- NN/gの読まれ方調査では、平均的なページでユーザーが読める語数は多くない。ファーストビューと見出しは、長文説明ではなく、瞬時に判断できる情報設計にする。
  Source: https://www.nngroup.com/articles/how-little-do-users-read/
- NN/gのFパターン調査では、ユーザーは全文を精読しない前提で、重要情報を冒頭と見出しの先頭に置く必要がある。
  Source: https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content-discovered/
- デジタル庁デザインシステムでは、余白は情報伝達、関係性、視覚的階層を作るための設計要素として扱われている。余白は「空いている場所」ではなく、重要度を作る素材とする。
  Source: https://design.digital.go.jp/dads/foundations/spacing/
- デジタル庁デザインシステムでは、レイアウトは情報を視覚的に伝達する技術であり、グリッド、マージン、カラム、ガター、ブレークポイントを目的に応じて選ぶものとされている。
  Source: https://design.digital.go.jp/dads/foundations/layout/
- デジタル庁デザインシステムでは、色はブランド、意味、機能、優先度を伝えるものとされている。配色は雰囲気ではなく、役割で指定する。
  Source: https://design.digital.go.jp/dads/foundations/color/
- デジタル庁デザインシステムでは、タイポグラフィは視覚的アイデンティティ、読みやすさ、ユーザー体験に影響するとされている。フォントは「おしゃれ」ではなく、情報階層の設計として扱う。
  Source: https://design.digital.go.jp/dads/foundations/typography/
- IBM Carbon Design Systemでは、空白は関係性と階層を作り、情報過密はユーザーを圧迫すると説明されている。余白量の差で主従を作る。
  Source: https://carbondesignsystem.com/elements/spacing/overview/
- 国内参考は、SANKOU!、BRIK、Web Design Clipなどで、業種、サイト種別、写真、タイポグラフィ、動き、配色、レイアウトの観点に分解して見る。表層コピーではなく、構図、余白、セクション遷移、情報量を抽出する。
  Sources: https://sankoudesign.com/ / https://brik.co.jp/gallery / https://webdesignclip.com/

## 弱い指示から強い指示への置き換え

| 弱い指示 | 強い指示 |
|:---|:---|
| テンプレ感を避ける | ロゴを隠しても、この業種・地域・提供価値が伝わる固有の構図、コピー、セクション形状を最低3箇所に入れる |
| おしゃれにする | 初見3秒で記憶に残す対象を1つに絞り、写真、見出し、余白、CTAの主従をその対象へ集中させる |
| 文字を減らす | ファーストビューでは説明をしない。約束、対象者、次の行動だけを残し、根拠は次セクションへ送る |
| 3カラムを避ける | 3項目を横並びにする前に、主役1+補助2、罫線リスト、比較表、ステップ、写真バナーのどれが情報の役割に合うか選ぶ |
| プロっぽく | 余白、書体、配色、写真比率、カード形状、CTA階層をデザイントークン化し、セクションごとに役割差を作る |
| 日本のサイトっぽく | 国内ギャラリーや近接業種を参照し、コピー量、余白、ボタン文言、導線、下層展開の現実感を国内向けに調整する |

## 制作プロンプトに入れる必須文言

以下のような命令文を、制作プロンプトへ状況に応じて入れる。

```text
整っているだけのサイトではなく、初見3秒で「誰の何をどう助けるサイトか」が記憶に残るトップページにしてください。
```

```text
ロゴと社名を隠しても成立するように、業種・地域・提供価値に紐づいた固有の視覚モチーフを最低1つ設計してください。
```

```text
ファーストビューは説明の場ではなく、印象を決める場です。メインコピー、1から2行の補足、CTA最大2つに絞り、タグや業務列挙は置かないでください。
```

```text
各セクションのシルエットが同じにならないように、フルブリード写真、編集的な罫線リスト、主役1+補助2、比較表、ステップ、CTA帯を使い分けてください。
```

```text
抽象語をそのまま置かず、安心、丁寧、わかりやすい等の言葉は、対応範囲、手順、必要書類、相談方法、実績、よくある不安への回答に変換してください。
```

```text
余白、書体、色、線、影、角丸、写真比率は雰囲気ではなく役割で決めてください。どの要素が主役で、どの要素が補助なのかが一目で分かる設計にしてください。
```

## クリエイティブ品質ゲート

- 初見3秒テスト: 3秒見ただけで、業種、対象者、提供価値、次の行動が分かるか。
- ロゴ隠しテスト: ロゴと社名を隠しても、同業の汎用テンプレではなく、その案件らしさが残るか。
- セクションシルエットテスト: 各セクションをぼかして見ても、同じ白背景、中央見出し、カードの繰り返しに見えないか。
- コピー削減テスト: ファーストビューの本文、タグ、バッジ、カード内説明を半分にしても意味が通るか。通るなら削る。
- 余白階層テスト: 重要な情報ほど広い余白と強い視覚階層を持ち、補助情報は控えめに扱われているか。
- モバイル初見テスト: スマホの1画面目で、画像の主役、メインコピー、CTAが破綻せず見えるか。
