# 業種ごと: 飲食店

## 目的

料理、空間、来店導線が伝わる飲食店サイトを作る。カフェ、レストラン、居酒屋、バー、ベーカリー、菓子店に使う。

## 使う材料

- 料理写真、店内写真、外観、メニュー、価格、営業時間、地図
- 予約、電話、Instagram、Googleマップの導線
- 看板商品、客単価、利用シーン

## 見る観点

- 食欲を刺激する主役写真があるか
- 店の雰囲気が伝わるか
- 予約やアクセスが迷わず分かるか
- 暖色を使いすぎて安く見えないか

## デザイン方針

- トーン: 温かみ、活気、親しみ、地域感
- 配色: 深い赤、濃いオレンジ、黄金色、深い緑、温かい白
- 写真: 料理、湯気、テーブルウェア、スタッフ、空間
- フォント: 見出しは個性を出してよいが、本文は読みやすくする

## 作業手順

1. ファーストビューは料理または空間を大きく使う。
2. メニューは画像だけにせず、主要商品をHTMLテキストで補足する。
3. アクセス、営業時間、予約導線を下部だけでなく中盤にも置く。
4. 3カラムカードではなく、写真主役、メニュー札、横並びリストで編集感を出す。

## 出力形式

- Header
- First View
- Concept
- Signature Menu
- Scene
- News
- Access
- Footer

## 確認方法

- 来店前に料理、雰囲気、場所が分かる。
- 画像内文字だけに重要情報が閉じていない。
- スマホでCTAが押しやすい。

## 不合格時の対応

- 料理写真が弱い場合は、参考画像から画像生成・撮影指示を作る。
