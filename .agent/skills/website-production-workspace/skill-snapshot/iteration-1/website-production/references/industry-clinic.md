# 業種ごと: クリニック・治療院

## 目的

患者や利用者が安心して予約・問い合わせできる、清潔感と信頼性のあるサイトを作る。

## 使う材料

- 院内写真、院長・スタッフ写真、診療内容、診療時間、アクセス
- 予約方法、保険/自費、初診の流れ、よくある質問
- 資格、実績、設備

## 見る観点

- 医療広告として誇大表現になっていないか
- 不安を減らす説明と予約導線があるか
- 清潔感と専門性が両立しているか

## デザイン方針

- トーン: 信頼、清潔、専門性、安心感
- 配色: 青、緑、白、ペールブルーを基本にする
- 写真: 施設、スタッフ、診療フロー、安心感のある図解
- フォント: 読みやすさ最優先のゴシック

## 作業手順

1. ファーストビューで診療内容、対象患者、予約導線を明確にする。
2. 強みは断定的な治療効果ではなく、設備、説明、通いやすさで伝える。
3. 初診の流れとFAQを用意する。
4. 診療時間とアクセスをスマホで見やすくする。

## 出力形式

- Header
- First View
- Treatment
- Reason
- Flow
- Staff
- FAQ
- Access
- Footer

## 確認方法

- 誇大な効果保証がない。
- 予約導線と診療時間が分かりやすい。

## 不合格時の対応

- 医療表現に不安がある場合は、断定表現を避け、確認事項として報告する。
