# 提案スライドテンプレート集の変換

## 目的

提案スライド用プロンプトテンプレートを、そのままスライド生成へ使わず、Webサイト制作プロンプト・業種別設計・ヒアリング項目へ変換する。

## 確認済み材料

- 参照元: Googleドキュメント「プロンプトテンプレート集」
- 収録数: 全6種類
- 種類: 汎用、飲食店向け、クリニック・治療院向け、コーポレートサイト向け、サロン・美容業向け、EC・物販向け
- 用途: Claude Designで10枚構成の提案プレゼン資料を生成するためのプロンプト集

## 6種類の整理

| 種類 | Web制作で使う変換先 |
|:---|:---|
| 汎用 | 業種が薄い会社、士業、教育、介護、ITなどの基本設計 |
| 飲食店向け | レストラン、カフェ、ベーカリー、テイクアウトなどの店舗設計 |
| クリニック・治療院向け | 医療、歯科、整体、整骨院、薬局などの安心感設計 |
| コーポレートサイト向け | 中小企業、製造業、IT、商社、士業法人などの信頼設計 |
| サロン・美容業向け | 美容室、ネイル、エステ、ヨガなどの予約導線設計 |
| EC・物販向け | D2C、オンラインショップ、メーカー直販などの購入導線設計 |

## 変換ルール

1. スライド番号、見積り、ガントチャート、提案ミーティング用の文言は、Web制作プロンプトへそのまま入れない。
2. 15問のヒアリング項目は、Web制作の材料カードへ変換する。
3. 業種別のトーン、配色、ビジュアル、フォントは、`references/industry-*.md` へ反映する。
4. Q4やQ6の「クライアントの言葉を活かす」原則は、サイト内コピーやファーストビュー設計へ変換する。
5. Q2の数字可視化は、実績、KPI、導入効果、メニュー価格、予約数などの表示設計へ変換する。
6. Q3とQ7の競合・離脱理由は、差別化、FAQ、CTA、導線改善へ変換する。

## Web制作プロンプトへ入れる形

```markdown
# 大前提
# 使用画像または参考画像
# サイト概要
# ターゲットと導線
# デザイン方針
# ファーストビュー
# トップページ構成
# UI / コンポーネント設計
# レスポンシブ要件
# 実装条件
# 実装後チェック
```

## 確認方法

- スライド制作指示が残っていない。
- 業種別の特性がサイトの写真、配色、CTA、セクションに変換されている。
- 6種類のどれに該当するか判断できる。

## 不合格時の対応

- スライド用語が残っている場合は削除し、サイト制作の言葉へ置き換える。
- 該当業種が6種類にない場合は汎用を使い、業種固有要素を材料カードへ追加する。
