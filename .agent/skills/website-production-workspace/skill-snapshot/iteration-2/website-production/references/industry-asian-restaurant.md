# 業種ごと: アジアンレストラン

## 目的

スパイス感、料理の楽しさ、店舗の入りやすさ、キッチンカーやイベント出店などの動きを伝えるサイトを作る。

## 使う材料

- 料理写真、ナン、カレー、プレート、ドリンク、キッチンカー、店外観
- メニュー表、価格、Instagram、イベント出店情報
- 看板商品や持ち歩きメニュー

## 見る観点

- アジアン料理らしさがあるが、過剰なエスニック装飾になっていないか
- 看板商品が記憶に残るか
- 店舗ランチとイベント出店の両方が分かるか
- 黄色、赤、緑を使いすぎて安く見えないか

## デザイン方針

- トーン: 明るい、スパイス感、親しみ、地域感、少し旅気分
- 配色: クリーム、マサラブラウン、ターメリックイエロー、チリレッド、ハーブグリーン
- 写真: ナン、カレー、プレート、イベント、キッチンカー
- フォント: 読みやすいゴシックを基本にし、過度な装飾フォントは禁止

## 作業手順

1. ファーストビューでは看板商品を主役にする。
2. キッチンカーがある場合は補足ではなく、独立セクションとして強く見せる。
3. メニュー表画像だけに依存せず、主要メニューをテキスト化する。
4. イベント出店情報はInstagram導線と合わせて見せる。

## 出力形式

- Header
- First View
- Concept
- Lunch Menu
- Signature
- Kitchen Car
- Shop Information
- Access
- Footer

## 確認方法

- 店舗利用とイベント利用の導線が分かれている。
- スマホでメニュー情報が読める。
- キッチンカーや看板商品の記憶が残る。

## 不合格時の対応

- 看板商品の写真がない場合は、参考素材から画像生成プロンプトを作る。
