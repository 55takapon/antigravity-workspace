# 業種ごと: 汎用

## 目的

業種特性が強くない案件で、信頼感とビジネス感のあるトップページを作る。

## 使う材料

- 会社概要、サービス、強み、実績、顧客の声
- 代表者や社員の写真、オフィス写真、図解素材
- 問い合わせ、資料請求、相談予約などのCTA

## 見る観点

- 信頼、洗練、分かりやすさがあるか
- 抽象的すぎて何の会社か分からなくなっていないか
- KPIカードや図解が飾りになっていないか

## デザイン方針

- トーン: 信頼感、洗練、モダン、落ち着き
- 配色: 濃紺、ブルー、白、薄いグレーを基本にする
- 写真: ビジネスシーン、業務風景、抽象幾何、データ表現
- フォント: 読みやすい日本語ゴシック

## 作業手順

1. ファーストビューで、事業内容と選ばれる理由を1文で伝える。
2. 強みは3等分カードだけにせず、図解、実績、工程、比較で見せる。
3. CTAは問い合わせまたは資料請求を主導線にする。

## 出力形式

- Header
- First View
- Business
- Strength
- Service
- Case
- Company
- Contact
- Footer

## 確認方法

- 何の会社か3秒で分かる。
- 抽象素材だけで終わっていない。
- スマホでサービス内容が読みやすい。

## 不合格時の対応

- 業種固有の素材が不足する場合は、ユーザーへ事業内容・強み・実績を質問する。
