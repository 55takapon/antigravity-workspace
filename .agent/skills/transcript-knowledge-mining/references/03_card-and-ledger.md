# 03_素材カードの型・ナレッジ台帳・投稿フックの種

抽出した素材を、後でブログ/SNS発信に取り出しやすい「カード」にして、1つの台帳へ追記蓄積する。

## 何をするか

ステップ3の抽出リストを、ID付きの素材カードに変換し、既存台帳と重複を避けて追記する。
完成投稿は作らず、「投稿フックの種」までを付ける。

## 使う材料

- ステップ3の抽出リスト（逐語・出典・文脈・カテゴリ）
- 既存のナレッジ台帳（あれば。重複チェックに使う）

## 素材カードの型

1素材1カード。逐語は改変禁止。

```
### [TKM-0007] C1 名言
- 逐語: 「その『ハードル』って、誰が決めたものでした？」
- 出典: 2026-06-13_coaching_tanaka.txt / L046
- 話者: コーチ（確度: 確定）
- 言葉の出所: 自分／引用／―（モードOのみ記入。Sは「―」）
- 文脈メモ: クライアントが自分で課題を難しくしていた場面。直後にL047で気づきが起きる。
- 重要度: ★★★
- 物語ID: STORY-02（A1→A2→A3で連結）
- 投稿フックの種: 「ハードルは誰が決めた？」という問いで、自己制限に気づかせる導入に使える。
- 公開フラグ: 固有名詞マスキング要（田中→Aさん）
```

### フィールドの決まり

- **ID**: `TKM-` + 連番。台帳の最後の番号の続きを使う。台帳（S/O）ごとに連番を持つ。
- **カテゴリ**: 02のA1〜A4／B1〜B3／C1〜C3／D のいずれか。
- **逐語**: 一字一句そのまま。語尾・フィラーも残す。
- **出典**: ファイル名＋タイムスタンプ／行番号。**必須**。無ければカードを作らない。
- **話者**: 発言者。役割が断定できない時は「コーチ（確度: 推定）」「話者不明」と確度付きで書く（05参照）。
- **言葉の出所**: モードOのみ必須。`自分`（ボイス素材）／`引用(登壇者名)`／`出所不明` のいずれか。モードSは「―」。
- **重要度**: ★（参考）／★★（使える）／★★★（強い・優先的に発信したい）。
- **物語ID**: ビフォー→介入→アフターで繋がる束に共通IDを振る（任意）。
- **公開フラグ**: 個人特定情報があれば「マスキング要」と書く。

## 投稿フックの種（完成投稿は作らない）

カードに、その素材から発信を起こすための「種」を1行で添える。種は次のどれか。

- 問いの種: 読者に投げられる問い（「あなたのハードルは誰が決めた？」）
- ビフォーアフターの種: B1→B2を見せる対比（「『どうせ』→『まずやってみる』に変わった瞬間」）
- エピソードの種: A1〜A4を1場面として語る切り口
- 名言の種: C1をそのまま立てて、一言コメントを足す形

種は1行まで。ここで完成文・長文ドラフトを書かない（それは別の発信スキルの仕事）。

## 作業手順

1. 既存台帳を読み、最後のID番号と既出の逐語を把握する。
2. 抽出リストの各素材をカード化する。出典の無い素材はカードにしない。
3. 既出の逐語と重複する場合は、新カードを作らず既存カードの出典欄に今回の出典を追記する。
4. 各カードに投稿フックの種を1行付ける。
5. 台帳のカテゴリ別セクションに、今回のカードを追記する。
6. 物語IDで繋がる束は、台帳末尾の「物語インデックス」に1行追記する（物語ID・要約・構成カードID）。

## 台帳ファイルの構造（モードごとに別ファイル）

入力モードで台帳を分ける（05参照）。保存先フォルダはユーザー指定、初回に確認。

- モードS（対話セッション）: 既定名 `session-knowledge-ledger.md`
- モードO（自己アウトプット・学び）: 既定名 `self-output-knowledge-ledger.md`

どちらの台帳も同じセクション構成を使う。

```
# ナレッジ台帳（モードS / モードO のどちらか）

## A 物語素材
（A1〜A4のカード）

## B 認知の変容
（B1〜B3のカード）

## C 言葉・口調素材
（C1〜C3のカード。C3はボイス素材として蓄積。モードOは「言葉の出所」で自分/引用を区別）

## D 要確認（意味不明だが大事そう）
（Dのカード）

## 物語インデックス
| 物語ID | 要約 | 構成カードID |
```

## 確認方法

- 全カードに出典が付いているか。
- 逐語が元と一字一句一致しているか。
- 既出素材を重複追記していないか。
- 完成投稿ではなく「種」までで止まっているか。

## 不合格時の対応

- 出典の無いカードがある → そのカードを外し、抽出に戻って出典を取る。
- 逐語が改変されている → 元に戻す。
- 種が長文ドラフトになっている → 1行の種に削る。
