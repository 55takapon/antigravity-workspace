# 05_入力モードの振り分けと話者の扱い

入力には性質の違う2種類があり、混ぜると台帳が破綻する。先にモードを判定し、別々の台帳に蓄積する。

## 2つの入力モード

| モード | 入力 | 主な話者 | 蓄積先（既定名） |
|:---|:---|:---|:---|
| S 対話セッション | コーチング／コンサル／カウンセリング | コーチ ⇄ クライアント（2話者） | `session-knowledge-ledger.md` |
| O 自己アウトプット・学び | 倫理法人会・セミナー・勉強会の参加メモ／気づき／ボイスメモ | 自分（1話者）＋登壇者の引用 | `self-output-knowledge-ledger.md` |

保存先フォルダはユーザー指定。初回にモードごとの台帳の場所を確認し、以降は同じ台帳に追記する。

## モード判定

1. トリガー語で判定する。
   - 「コーチング」「セッション」「クライアント」「コンサル」「カウンセリング」→ モードS
   - 「セミナー」「勉強会」「倫理法人会」「ボイスメモ」「参加メモ」「学び」「気づき」「アウトプット」→ モードO
2. 判定できない場合は、「対話セッション(S)か、自分のアウトプット・学び(O)か」を必ずユーザーに確認する。
3. 1本の文字起こしに両方が混在する場合は、混ぜて1台帳に入れず、ユーザーに分割を促す。

## モード別のカテゴリの当て方

4カテゴリ（A物語／B認知の変容／C言葉・口調／D要確認）は共通だが、主語が変わる。

| カテゴリ | モードS（対話セッション） | モードO（自己アウトプット・学び） |
|:---|:---|:---|
| A 物語 | クライアント（または受け手）の悩み→介入→気づき | 自分の体験・現場・学びのエピソード |
| B 認知の変容 | クライアントの思い込みのビフォーアフター、介入はコーチ | 自分の思い込みが変わった瞬間、介入は登壇者の言葉/出来事/問い |
| C 言葉・口調 | コーチ／クライアント双方の名言・口調を出所付きで | 【自分の言葉】と【登壇者の引用】を必ず分ける |
| D 要確認 | 意味不明だが大事そうな発言 | 同左 |

## 言葉の出所を必ず分ける（モードO最重要）

- **自分の言葉** = ボイス素材。口調・キャラクター・価値観に使える。
- **登壇者・他者の言葉** = 引用素材。発信時に出所明記が必要。自分のボイスとして扱わない。
- どちらか判別できないものは「出所不明」とし、ボイス素材に混ぜない。

カードの「言葉の出所」欄に `自分 / 引用(登壇者名) / 出所不明` のいずれかを必ず記す。

## 話者が区別できない時（Zoom文字起こし等）の手順

コーチ／クライアントのラベルが無い、または取り違えそうな場合に使う。

1. まず話者を「話者A」「話者B」と機械的に分け、**取り違えないIDだけ先に固定**する（逐語と出典は必ず残す）。
2. 役割の手がかりで推定する。
   - 問いかけ・言い換え・要約・承認が多い → コーチの可能性
   - 悩み・出来事の語り・感情・「あ」「そっか」等の気づき → クライアントの可能性
3. 推定できたら「コーチ(推定)」「クライアント(推定)」と**確度付き**で記す。断定で埋めない。
4. 手がかりが無い発言は「話者不明」とする。
5. 役割を取り違えても壊れないよう、カードは逐語・出典を主、役割は確度付きの補助情報として扱う。
6. 話者・役割が「推定」または「不明」のカードは、ステップ5で**必ずまとめて報告**し、ユーザーに確認する。

## 確認方法

- モードが決まり、対応する台帳に振り分けられているか。
- モードOで、自分の言葉と登壇者の引用が分かれているか。
- 話者が推定/不明のカードに確度が付き、報告対象に入っているか。

## 不合格時の対応

- モードが判定できない → 抽出を始めず、ユーザーにモードを確認する。
- 1本に両モードが混在 → 分割をユーザーに促し、台帳を分ける。
- モードOで自分と引用が混ざった → 出所欄を埋め直し、引用をボイス素材から外す。
- 話者を断定してしまった → 手がかりが無い箇所を「推定」または「不明」に戻し、報告に含める。
