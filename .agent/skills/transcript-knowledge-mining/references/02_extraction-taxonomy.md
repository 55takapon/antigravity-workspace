# 02_MECEナレッジ抽出カテゴリと抽出プロンプト

文字起こしから「発信素材になるナレッジ」を漏れ・ダブりなく拾うための分類と手順。
プロのテーマ分析（逐語＋出典＋解釈）とコンテンツ・アトマイゼーションの考え方に基づく。

## 抽出カテゴリ（MECE・4分類）

入力の全発言を、この4カテゴリで走査する。1つの発言が複数カテゴリに該当してよいが、
4カテゴリのどれにも目を通さずに完了してはならない。

### A. 物語素材（ナラティブ）— 発信のエピソード/一次情報になる

| 小分類 | 拾うもの | 見分け方 |
|:---|:---|:---|
| A1 悩み・現状（ビフォー） | クライアント/自分が抱えていた困りごと・つまずき・葛藤 | 「〜できなくて」「ずっと〜だった」 |
| A2 転機・介入 | コーチ/コンサルの問い・指摘・関わり、流れが変わった瞬間 | 問いかけ、間（…）、「あ。」等の気づきの直前 |
| A3 気づき・変化（アフター） | 介入の後に起きた認識・感情・行動の変化 | 「そうか」「やってみます」「楽になった」 |
| A4 具体例・一次情報 | 固有の数字・固有名詞・実体験エピソード・場面描写 | 具体的な場面、日時、数字、固有の出来事 |

A1→A2→A3が1本の物語として繋がる場合は、同じ物語IDで紐づける（ビフォー→介入→アフター）。

### B. 認知の変容（思い込み・認知バイアスのビフォーアフター）

| 小分類 | 拾うもの |
|:---|:---|
| B1 思い込み・認知バイアス（ビフォー） | 本人を縛っていた決めつけ・前提・「〜すべき」「どうせ〜」 |
| B2 リフレーム後（アフター） | 捉え直した後の新しい解釈・前提 |
| B3 変化を起こした介入 | B1→B2を生んだ問い・言葉・出来事 |

B1とB2は必ずペアで拾う。「ビフォーだけ」「アフターだけ」の片側でも、片側であることを明記して残す。
認知バイアスの型（白黒思考・過度の一般化・〜すべき思考・自己否定 等）が読み取れれば文脈メモに付す。

### C. 言葉・口調素材（逐語・改変厳禁）— 発信でそのまま使う

| 小分類 | 拾うもの |
|:---|:---|
| C1 名言・パンチライン | そのまま投稿で立つ一言、言い切り、比喩 |
| C2 価値観・思想・世界観 | 大切にしている言葉、繰り返す主張、信念が出た発言 |
| C3 口調・キャラクター | 本人“らしさ”が出る語尾・口癖・言い回し・テンション |

Cは**一字一句そのまま**拾う。C3の詳しい観点は [04_voice-persona-guide.md](04_voice-persona-guide.md) を必ず読む。

### D. 要確認（意味不明だが大事そう）

- 文脈が取れない／論理が飛んでいるが、語気・繰り返し・本人の食いつきから重要そうな発言。
- 捨てずに逐語のまま保留し、ステップ5で「なぜ大事そうか」を添えて報告する。

## 抽出プロンプト（この観点で全文を走査する）

### 何をするか

整形済みの文字起こしを上から走査し、A〜Dの各カテゴリに当たる発言を逐語で抜き出す。

### 使う材料

- 01で整形した、出典付き逐語ブロック
- 話者の対応

### 作業手順

1. 全文を一度通読し、物語の山（悩み→介入→気づき）がどこにあるかを把握する。
2. もう一度頭から走査し、A1〜A4を出典付きで抜き出す。物語として繋がる束は物語IDで紐づける。
3. B（思い込みのビフォー/アフターと、その介入）をペアで抜き出す。片側のみなら片側と明記。
4. C（名言・価値観・口調）を**一字一句そのまま**抜き出す。要約・敬語化はしない。
5. D（意味不明だが大事そう）を逐語のまま保留に入れる。
6. 各カテゴリで「該当なし」のものは、空欄ではなく「該当なし」と記録する（走査漏れと区別するため）。

### 見る観点（採用/不採用）

- 採用: 固有・具体・一次情報・本人の言葉。発信で「この人だから言える」素材。
- 不採用: 一般論、AIが既に知っている知識、改変しないと意味が通らない断片（→Dへ回す）。
- 迷ったら捨てずにDへ。後で人が判断できるようにする。

### 出力形式

カテゴリごとに、逐語・出典・文脈メモを並べた抽出リスト。カード化と台帳追記は
[03_card-and-ledger.md](03_card-and-ledger.md) の型に従う。

### 確認方法

- A〜Dの4カテゴリ全てに目を通したか（各カテゴリに抽出結果または「該当なし」があるか）。
- C・名言・価値観の逐語が、元の言葉と一字一句一致しているか。
- 物語素材が、ビフォー→介入→アフターで紐づいているか。

### 不合格時の対応

- 一部カテゴリを走査していない → そのカテゴリを走査してから次へ。
- 逐語を整えてしまった → 元に戻す。
- ビフォー/アフターが噛み合っていない → 出典に戻って対応を取り直す。
