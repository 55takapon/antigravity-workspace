# 04_口調・キャラクター・価値観の抽出ガイド（カテゴリC）

SNS発信で「私というキャラクター」がにじむように、口調・価値観・世界観の素材を逐語で溜める。
ブランドボイスは「言葉選び・好きな言い回し・繰り返す主張」の集積で形づくられる、という考え方に基づく。

## 何をするか

文字起こしの中から、本人“らしさ”が出ている言葉を、一字一句そのまま抜き出し、
ボイス素材としてカテゴリCに蓄積する。要約・標準語化・敬語化は禁止。

## 拾う3種類

### C1 名言・パンチライン
- そのまま投稿で立つ一言、言い切り、独自の比喩。
- 見分け方: 短い／断定／リズムがある／本人が力を込めている箇所。

### C2 価値観・思想・世界観
- 繰り返し出てくる主張、「大切にしているのは〜」「結局〜だと思う」のような信念。
- 見分け方: 別の話題でも同じ趣旨が再登場する／一般論ではなく本人の立場が出ている。

### C3 口調・キャラクター（“らしさ”の素材）
本人の話し方そのものを素材化する。次の観点で拾う。

| 観点 | 拾う例 |
|:---|:---|
| 口癖・接続 | 「結局さ」「なんていうか」「逆に」 |
| 語尾・テンション | 「〜なんですよね」「〜じゃん」「〜かもしれない」 |
| 比喩・たとえの癖 | その人が好んで使うたとえ方 |
| 強調の仕方 | 「マジで」「ほんとに」「圧倒的に」 |
| 避ける言葉 | 本人が言い換えている／嫌っている言い方（あれば） |

## 作業手順

1. C1・C2・C3に当たる発言を、出典付きで逐語のまま抜き出す。
2. C3は「単語・言い回し」単位でも拾い、ボイス素材として台帳のCセクションに溜める。
3. 同じ口癖・価値観が複数回出たら、新カードを作らず既存カードの出典に追記し、出現回数が分かるようにする。
   （繰り返し出る＝その人の核に近い、という重み付けに使う。）
4. 価値観・世界観のカードには、それが出た文脈（どんな話題で出たか）を文脈メモに残す。

## 出力形式

カテゴリCの素材カード（型は [03_card-and-ledger.md](03_card-and-ledger.md)）。
C3のボイス素材は、繰り返し出るものほど重要度を上げる。

## 確認方法

- 逐語が元の話し言葉と一字一句一致しているか（語尾・フィラー・崩れを残しているか）。
- 一般論ではなく、本人らしさ／本人の立場が出ている言葉になっているか。
- 繰り返し出る口癖・価値観に、出現の重みが付いているか。

## 不合格時の対応

- きれいな標準語・敬語に直してしまった → 元の話し言葉に戻す。
- 一般論（誰でも言う言葉）を価値観として拾っている → 本人の立場が出ている発言に差し替える。
- 単発の言い間違いを口癖として扱っている → 複数回出ているか出典で確認し、単発なら重要度を下げる。
