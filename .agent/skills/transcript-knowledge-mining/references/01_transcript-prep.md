# 01_文字起こしの整形と出典付与

抽出の前に、文字起こしを「逐語を保ったまま、どの一文も出典で引ける」状態にする。

## 何をするか

文字起こし本文を、後工程で逐語をそのまま引用でき、出典位置（タイムスタンプ／行番号）で
追跡できる形に整える。中身の言葉は一切変えない。

## 使う材料

- ユーザーから受け取った文字起こし本文、またはファイルパスの中身
- 話者の対応（誰がコーチ／クライアント／カウンセラー／自分か）

## 見る観点（逐語保持の原則）

- 言い回し、口調、語尾、方言、フィラー（「えーと」「なんか」）、言い淀みは**そのまま残す**。
  これらは口調・キャラクター素材そのものなので削らない。
- 誤字脱字の明らかな変換ミスだけは直してよいが、話し言葉の崩れ・省略・倒置は直さない。
- 要約・敬語化・標準語化・語順の整理は禁止。整えるのは「参照しやすさ」だけ。

## 作業手順

1. 文字起こしにタイムスタンプがあるか確認する。
   - ある場合 → タイムスタンプをそのまま出典に使う（例: `[12:34]`）。
   - ない場合 → 発言の固まりごとに行番号を振り、行番号を出典に使う（例: `L045`）。
2. 話者ラベルを各発言に付ける。ラベルが無い・取り違えそうな場合（Zoom文字起こし等）は、
   [05_source-modes.md](05_source-modes.md) の「話者が区別できない時」に従い、話者A/Bを先に固定し、
   役割は「コーチ（推定）」のように確度付きで記す。判別できない発言は「話者不明」と明記し、断定で埋めない。
3. 長すぎて一度に扱えない場合は、タイムスタンプ／行番号の範囲でブロック分割する
   （例: `L001-L120` / `L121-L240`）。範囲を後工程の出典に使う。
4. 整形後、元の言葉が一字一句変わっていないかを目視で確認する。

## 出力形式

後工程が引用できる、出典付きの逐語ブロック。例:

```
[02:15] クライアント: えーと、結局…自分でハードル上げてただけなんですよね。
L046 コーチ: その「ハードル」って、誰が決めたものでした？
L047 クライアント: ……あ。誰も決めてない。
```

## 確認方法

- どの一文もタイムスタンプか行番号で引けるか。
- 整形後の言葉が、元の文字起こしと一字一句一致しているか（口調・語尾・フィラー含む）。

## 不合格時の対応

- 出典が振れない一文が残る → 行番号を振り直してから次工程へ進む。
- 言葉を整えてしまった箇所がある → 元の逐語に戻す。
- 話者がほぼ全て不明で物語の主体が取れない → ステップ1に戻り、話者対応をユーザーに確認する。
