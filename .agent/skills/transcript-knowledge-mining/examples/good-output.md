# 入力→出力の例

実データが無いため、下記は**出力の型**を示すサンプル。逐語はサンプル文字起こしから一字一句引用しており、
カードの逐語が入力と一致していることを示す（改変禁止の確認用）。実運用では実際の文字起こしを使う。

---

## 例1: 正常系・モードS（コーチングセッションの抜粋）

> モード判定: トリガー語「コーチング」→ モードS。追記先 `session-knowledge-ledger.md`。

### 入力（受け取った文字起こし・タイムスタンプあり）

```
[02:10] クライアント: 新しい挑戦、したいんですけど…どうせ私には無理だなって、いつも止まっちゃって。
[02:31] コーチ: その「どうせ無理」って、誰かに言われた言葉ですか？
[02:40] クライアント: ……いや、誰にも言われてないです。自分で勝手に。
[02:52] コーチ: 自分で作ったルールなら、自分で書き換えていいんじゃないですか。
[03:05] クライアント: あ……ほんとだ。なんか、急に軽くなった感じ。やってみます。
[03:20] クライアント: 結局さ、勝手に自分でフタしてただけなんですよね。
```

### 出力（素材カード — 台帳へ追記）

```
### [TKM-0012] B1 思い込み（ビフォー）
- 逐語: 「どうせ私には無理だなって、いつも止まっちゃって。」
- 出典: 2026-06-13_coaching.txt / [02:10]
- 話者: クライアント
- 文脈メモ: 新しい挑戦の前に毎回止まる。認知バイアス＝自己否定/過度の一般化。
- 重要度: ★★★
- 物語ID: STORY-04
- 投稿フックの種: ビフォーアフターの種「『どうせ無理』が外れた瞬間」

### [TKM-0013] B3/A2 介入（転機）
- 逐語: 「その『どうせ無理』って、誰かに言われた言葉ですか？」
- 出典: 2026-06-13_coaching.txt / [02:31]
- 話者: コーチ
- 文脈メモ: 思い込みの出所を問い、自作のルールだと気づかせる問い。
- 重要度: ★★★
- 物語ID: STORY-04
- 投稿フックの種: 問いの種「その制限、誰に言われた？」

### [TKM-0014] C1 名言
- 逐語: 「自分で作ったルールなら、自分で書き換えていいんじゃないですか。」
- 出典: 2026-06-13_coaching.txt / [02:52]
- 話者: コーチ
- 文脈メモ: リフレームを起こした一言。直後に気づきが発生。
- 重要度: ★★★
- 物語ID: STORY-04
- 投稿フックの種: 名言の種 そのまま立てて一言コメント

### [TKM-0015] B2/A3 気づき（アフター）
- 逐語: 「あ……ほんとだ。なんか、急に軽くなった感じ。やってみます。」
- 出典: 2026-06-13_coaching.txt / [03:05]
- 話者: クライアント
- 文脈メモ: 「どうせ無理」→「やってみます」への変容。身体感覚（軽くなった）を伴う。
- 重要度: ★★★
- 物語ID: STORY-04
- 投稿フックの種: ビフォーアフターの種

### [TKM-0016] C3 口調・キャラクター
- 逐語: 「結局さ、勝手に自分でフタしてただけなんですよね。」
- 出典: 2026-06-13_coaching.txt / [03:20]
- 話者: クライアント
- 文脈メモ: 「結局さ」「〜なんですよね」が口癖。「フタしてた」は本人の比喩。
- 重要度: ★★
- 投稿フックの種: エピソードの種「自分でフタしてた話」
```

物語インデックス追記:
```
| STORY-04 | 「どうせ無理」を自作ルールと気づき、軽くなって一歩踏み出した | TKM-0012,0013,0014,0015 |
```

ステップ5の報告（抜粋）:
- 収穫サマリ: 今回 5カード（B×2 / A連結1物語 / C1×1 / C3×1）。STORY-04はビフォーアフターが綺麗に揃った強い素材。
- 要確認(D): なし。
- 台帳: `…/transcript-knowledge-ledger.md` に追記済み。

## 例2: 異常系（タイムスタンプ無し・話者ラベル無し・意味不明だが重要そう）

### 入力

```
新規事業やりたいって言ってたけど 本当はこわい だから売上って言ってる
水たまり 飛び越えないと濡れる でも濡れてもいいやって思えたら 走れる
うん それ
```

### 出力（処理の流れと型）

1. タイムスタンプが無いため行番号を付与（L001〜）。話者ラベルが無く判別不能なため「話者不明」と明記。

```
### [TKM-0020] B1 思い込み（ビフォー・片側）
- 逐語: 「新規事業やりたいって言ってたけど 本当はこわい だから売上って言ってる」
- 出典: memo.txt / L001
- 話者: 話者不明
- 文脈メモ: 表向きの理由（売上）と本音（こわい）のズレ。アフターは未出のため片側。
- 重要度: ★★
- 投稿フックの種: ビフォーアフターの種（アフターは未取得）

### [TKM-0021] D 要確認（意味不明だが大事そう）
- 逐語: 「水たまり 飛び越えないと濡れる でも濡れてもいいやって思えたら 走れる」
- 出典: memo.txt / L002
- 話者: 話者不明
- 文脈メモ: 比喩。完全な意味は取れないが、語気と次行「うん それ」の食いつきから本人の核に近い可能性。
- 重要度: ★★（保留）
- 投稿フックの種: 名言の種候補（要本人確認）
```

2. ステップ5の報告で要確認として提示:
- 「『水たまり…濡れてもいいやと思えたら走れる』は意味は取りきれませんが、本人が『うん それ』と強く反応しており、価値観の核を表す比喩の可能性があります。本人に意図を確認しますか？」

### 材料が決定的に足りない場合

文字起こしが数語のみ・文脈ゼロで話者も主体も取れない場合は、カードを作り込まず
ステップ1に戻り、セッション種別・話者・前後の文脈をユーザーに質問する（想像で物語を作らない）。

## 例3: モードO（倫理法人会・セミナーの自己アウトプット／ボイスメモ）

> モード判定: トリガー語「倫理法人会」「気づき」→ モードO。追記先 `self-output-knowledge-ledger.md`。
> モードOでは「自分の言葉（ボイス素材）」と「登壇者の引用」を必ず分ける。

### 入力（自分のボイスメモ書き起こし）

```
L001 今日の倫理法人会、講師の方が「経営は人格の表現だ」って言ってて、ぐさっときた。
L002 自分はずっと、数字さえ出せば中身は後でいいって思ってたんだよな。
L003 でもさ、結局のところ、人として信用されてないと数字も続かない、ってことなんだと思う。
L004 明日から、朝礼の話し方ひとつ変えてみよう。
```

### 出力（素材カード — モードO台帳へ追記）

```
### [SELF-0031] C2 価値観（引用）
- 逐語: 「経営は人格の表現だ」
- 出典: 2026-06-13_rinri_voicememo.txt / L001
- 話者: 講師
- 言葉の出所: 引用(倫理法人会 講師)
- 文脈メモ: この一言に「ぐさっときた」。自分の価値観を揺らした外部の言葉。発信時は出所明記。
- 重要度: ★★★
- 投稿フックの種: 名言の種（引用として紹介し、自分の受け取りを添える）

### [SELF-0032] B1 思い込み（ビフォー・自分）
- 逐語: 「自分はずっと、数字さえ出せば中身は後でいいって思ってたんだよな。」
- 出典: 2026-06-13_rinri_voicememo.txt / L002
- 話者: 自分
- 言葉の出所: 自分
- 文脈メモ: 自分が握っていた前提。L003でリフレームされる。
- 重要度: ★★★
- 物語ID: SELF-STORY-07

### [SELF-0033] B2 リフレーム後（アフター・自分）
- 逐語: 「結局のところ、人として信用されてないと数字も続かない、ってことなんだと思う。」
- 出典: 2026-06-13_rinri_voicememo.txt / L003
- 話者: 自分
- 言葉の出所: 自分
- 文脈メモ: 「数字優先」→「信用が先」への捉え直し。
- 重要度: ★★★
- 物語ID: SELF-STORY-07
- 投稿フックの種: ビフォーアフターの種

### [SELF-0034] C3 口調・キャラクター（自分）
- 逐語: 「でもさ、結局のところ、〜なんだと思う。」
- 出典: 2026-06-13_rinri_voicememo.txt / L003
- 話者: 自分
- 言葉の出所: 自分
- 文脈メモ: 「でもさ」「結局のところ」「〜なんだと思う」が自分の口癖。SNSの語り口に使える。
- 重要度: ★★
- 投稿フックの種: エピソードの種（学びを自分の言葉で語る）
```

ステップ5の報告（抜粋）:
- 使用モード: O（自己アウトプット）／台帳: `…/self-output-knowledge-ledger.md`
- 収穫サマリ: 4カード。うち自分の言葉3・引用1。SELF-STORY-07はビフォーアフターが揃った強い素材。
- 引用素材（L001）は発信時に「倫理法人会の講師の言葉」と出所明記が必要。

## 例4: 異常系・モードS（Zoom文字起こしで話者が区別できない）

> 話者ラベルが無く、コーチ/クライアントが取り違えやすいケース。

### 入力（話者ラベル無しのZoom自動文字起こし）

```
[00:42] 最近どうですか、進み具合は。
[00:48] それが、また手が止まっちゃって。やる気はあるのに。
[00:55] 「やる気はあるのに止まる」って、その時いちばん頭にあるのは何ですか。
[01:07] ……失敗したら、って。見られてる気がして。
```

### 出力（話者A/Bを固定 → 役割は確度付き）

```
### [TKM-0040] A2/B3 介入（話者A=コーチ推定）
- 逐語: 「『やる気はあるのに止まる』って、その時いちばん頭にあるのは何ですか。」
- 出典: zoom_auto.txt / [00:55]
- 話者: 話者A（コーチ推定：問いかけ・言い換えが中心）
- 言葉の出所: ―
- 文脈メモ: 相手の言葉を引用して掘り下げる問い。役割は推定（要確認）。
- 重要度: ★★

### [TKM-0041] B1 思い込み（話者B=クライアント推定）
- 逐語: 「……失敗したら、って。見られてる気がして。」
- 出典: zoom_auto.txt / [01:07]
- 話者: 話者B（クライアント推定：悩み・感情の語り）
- 言葉の出所: ―
- 文脈メモ: 「失敗＝見られる」という評価懸念。役割は推定（要確認）。
- 重要度: ★★★
```

ステップ5の報告（抜粋）:
- 話者未確定リスト: TKM-0040（話者A＝コーチ推定）／TKM-0041（話者B＝クライアント推定）。
  「問いかけ役を話者A、語り役を話者Bとして推定しました。役割が逆でないか確認をお願いします。逐語と出典は確定なので、役割だけ直せば台帳はそのまま使えます。」
