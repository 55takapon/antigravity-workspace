# 文字起こしナレッジ抽出（transcript-knowledge-mining）

セッションや自己リフレクションの文字起こしから、ブログ・SNS発信で使える一次情報を
プロマーケター視点でMECEに抽出し、逐語を改変せず素材カードとして台帳に蓄積する。

## 動作ルール（必ず守る）

- 必要なツール（読み書き）を使って即座に自動実行すること。各工程ごとのユーザー確認は不要。
  ただし**台帳の保存先が未確定の初回**と**モードが判定できない時**だけ、ユーザーに確認すること。
- 入力モード（S=対話セッション／O=自己アウトプット・学び）を必ず判定し、**モードごとに別の台帳**へ振り分けること。
  2モードを1つの台帳に混ぜてはならない。
- セリフ・口調・名言・価値観が出た言葉は、**一字一句そのまま（逐語）で保持し、改変・要約・敬語化・標準語化してはならない**。
- 抽出した各素材には必ず出典位置（タイムスタンプまたは行番号）を付けること。出典のない素材を台帳に入れてはならない。

## ステップ1: 材料確認・モード判定・台帳の振り分け

必要資料: [references/05_source-modes.md](references/05_source-modes.md) をこの工程で必ず読む。

- [ ] 文字起こし本文またはファイルパスを受け取った
- [ ] 入力モードを判定した（S=対話セッション／O=自己アウトプット・学び）。トリガー語で判定できなければユーザーに確認した
- [ ] モードに対応する台帳を決めた（S=`session-knowledge-ledger.md`／O=`self-output-knowledge-ledger.md`、保存先はユーザー指定、初回のみ確認）
- [ ] 話者の対応を確認した（モードS=コーチ/クライアント、モードO=自分/登壇者の引用）

#### 完了条件
- 文字起こし本文が手元にあり、モードと対応台帳が決まっていること
- 1本に両モードが混在する場合は、分割をユーザーに促していること
- 材料が無い／モードが判定できないなら、ステップ2へ進まずユーザーに質問すること
- この完了条件を全て満たすまで、次のステップに進んではならない

## ステップ2: 文字起こしの整形と出典付与

必要資料: [references/01_transcript-prep.md](references/01_transcript-prep.md) をこの工程で必ず読む。話者が区別できない場合（Zoom文字起こし等）は [references/05_source-modes.md](references/05_source-modes.md) の「話者が区別できない時」も必ず読む。

- [ ] 逐語を改変せずに、行番号またはタイムスタンプで参照できる形に整えた
- [ ] 発言を話者ごとに区別した。区別困難な場合は話者A/Bで固定し、役割は確度付き（推定）または「話者不明」で記した

#### 完了条件
- どの一文も出典位置で引けること
- 逐語を一切書き換えていないこと
- 話者・役割が推定/不明の発言を、断定で埋めず確度付きで残していること
- この完了条件を全て満たすまで、次のステップに進んではならない

## ステップ3: MECEナレッジ抽出

必要資料: [references/02_extraction-taxonomy.md](references/02_extraction-taxonomy.md) をこの工程で必ず読む。口調・キャラクター・価値観（カテゴリC）を抽出する際は [references/04_voice-persona-guide.md](references/04_voice-persona-guide.md) も必ず読む。モード別のカテゴリの当て方は [references/05_source-modes.md](references/05_source-modes.md) に従う。

- [ ] 4カテゴリ（A物語素材 / B認知の変容 / C言葉・口調素材 / D要確認）を漏れなく走査した
- [ ] 各カテゴリの逐語・出典・文脈メモを抜き出した
- [ ] モードO（自己アウトプット）では、自分の言葉（ボイス素材）と登壇者の引用（出所明記）を分けた
- [ ] 「意味不明だが大事そう」な発言（カテゴリD）を捨てずに保留として拾った

#### 完了条件
- 4カテゴリ全てを走査済みで、拾えた素材と「該当なし」を区別していること
- 逐語が改変されていないこと、各素材に出典があること
- モードOで、自分の言葉と引用が分かれていること
- この完了条件を全て満たすまで、次のステップに進んではならない

## ステップ4: 素材カード化・台帳追記・投稿フックの種付与

必要資料: [references/03_card-and-ledger.md](references/03_card-and-ledger.md) をこの工程で必ず読む。

- [ ] 各素材をIDカード形式（逐語／出典／文脈／カテゴリ／重要度／投稿フックの種）にした
- [ ] 既存台帳を読み、重複を避けて追記した（完成投稿は作らず、フックの種まで）
- [ ] 口調・キャラクターが出た言い回しを「ボイス素材」として蓄積した

#### 完了条件
- 台帳ファイルに今回分のカードが追記済みであること
- 逐語が改変されておらず、出典が全カードに付いていること
- この完了条件を全て満たすまで、次のステップに進んではならない

## ステップ5: ピックアップ報告

- [ ] 使用モード（S／O）と追記先の台帳パスを報告した
- [ ] 今回の収穫サマリ（カテゴリ別の件数・特に強い素材）を提示した
- [ ] 「意味不明だが大事そう」な発言を、理由付きでユーザーに報告した
- [ ] 話者・役割が「推定」または「不明」のカードを、まとめてユーザーに報告し確認を促した

#### 完了条件
- ユーザーに使用モード・台帳パス・収穫サマリ・要確認発言・話者未確定リストを報告済みであること

## ステップ6: 自己完了確認（省略禁止）

以下を1つずつ振り返り、未実施があれば完了報告してはならない。

- [ ] ステップ1〜5を全て実施したか
- [ ] モードを判定し、正しい台帳（S／O）に振り分けたか。2モードを混ぜていないか
- [ ] 逐語を一切改変していないか（要約・敬語化・標準語化していないか）
- [ ] 全カードに出典位置が付いているか
- [ ] 4カテゴリを漏れなく走査し、Dの要確認発言を報告したか
- [ ] 話者・役割が推定/不明のカードを報告したか
- [ ] モードOで自分の言葉と引用を分けたか
- [ ] 台帳に追記し、保存先パスを報告したか

## エッジケース

| 状況 | 対応 |
|:-----|:-----|
| 文字起こしにタイムスタンプも区切りも無い | ステップ2で行番号を振り、行番号を出典に使う |
| Zoom文字起こしでコーチ/クライアントの区別がつかない | 話者A/Bだけ先に固定し、問いかけ＝コーチ推定/語り＝クライアント推定で確度付きに。不明は「話者不明」。ステップ5で必ず報告 |
| 入力がセッションか自分のアウトプットか判定できない | 抽出を始めず、モード（S／O）をユーザーに確認 |
| 1本の文字起こしにセッションと自己アウトプットが混在 | 1台帳に混ぜず、ユーザーに分割を促して台帳を分ける |
| モードOで自分の言葉か登壇者の引用か不明 | 「出所不明」とし、ボイス素材に混ぜない |
| 同じ名言・口調が過去の台帳に既出 | 重複追記せず、既存カードの出典に今回の出典を追記する |
| 発言が断片的で意味が取れないが重要そう | 捨てずにカテゴリD（要確認）へ逐語のまま入れ、ステップ5で報告 |
| 文字起こしが長大で一度に扱えない | タイムスタンプ/行番号の範囲で分割し、範囲ごとに抽出→同じ台帳へ追記 |
| 個人を特定できる固有名詞が含まれる | 逐語は保持しつつ、台帳カードに「公開時は要マスキング」のフラグを付ける |

## 禁止事項

- セリフ・口調・名言・価値観の逐語を、要約・改変・敬語化・標準語化してはならない。
- 出典位置（タイムスタンプ／行番号）の無い素材を台帳に入れてはならない。
- 「意味不明だが大事そう」な発言を、分かりにくいという理由で捨ててはならない。
- 4カテゴリのうち一部だけ走査して完了してはならない（MECE走査が必須）。
- 対話セッション(S)と自己アウトプット(O)を1つの台帳に混ぜてはならない。モードごとに別台帳へ振り分けること。
- モードOで、登壇者・他者の引用を自分のボイス素材として扱ってはならない（出所を必ず分ける）。
- 話者・役割が不明な発言を、断定で埋めてはならない。確度付き（推定）または「話者不明」で残すこと。
- このスキルで完成した投稿文を量産してはならない（成果物は素材カード＋投稿フックの種まで）。
- 想像で作ったセリフやエピソードを、実際の発言として台帳に入れてはならない。
- 自己完了確認（ステップ6）をスキップして完了報告してはならない。
