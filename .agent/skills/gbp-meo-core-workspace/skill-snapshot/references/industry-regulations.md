# 業種別 広告規制・カテゴリ設定の落とし穴

旧・業種別スキル（gbp-meo-beauty / bodywork / education / legal / medical / real-estate / restaurant / retail / service。2026-07廃止）から、法規制・コンプライアンス部分だけを救出して集約したもの。

**読むタイミング**: GBP投稿作成・口コミ返信作成・カテゴリ/説明文設定・診断レポート作成で、該当業種のクライアントを扱う工程で必ず読むこと。

**注意**: 法規制は改正される。重要な判断（クライアントへの断言、レポートへの記載）の前には最新の公式情報（消費者庁・厚労省・各士業会）を確認すること。

## 医療（歯科・クリニック）

| 法規制 | 対象 | 主な制限 |
|--------|------|---------|
| 医療法（医療広告ガイドライン） | Webサイト・GBP投稿・SNS | 虚偽広告・誇大広告・比較優良広告の禁止 |
| 薬機法 | 医療機器・材料の広告 | 未承認機器の効能表示制限 |
| 景品表示法 | すべての広告表現 | 優良誤認・有利誤認の禁止 |

### 禁止事項
1. ビフォーアフター写真の無条件掲載 — 症例写真は「①治療内容 ②費用 ③治療期間 ④リスク・副作用」の**4点セット併記**がなければ掲載不可（2018年ガイドライン改正後は4点併記で掲載可）
2. 「地域No.1」「最高の治療」等の比較優良広告
3. 患者の体験談・感想を事業者が選定して広告掲載すること
4. 「絶対に痛くない」「100%成功」「完治します」等の断言・誇大表現
5. 費用の虚偽表示（最低価格のみ表示して実際は高額になるケース）

### 使える表現 / 使えない表現
| 分類 | ○ 使える | ✗ 使えない |
|------|---------|-----------|
| 治療の特徴 | 「痛みに配慮した治療を心がけています」 | 「無痛治療」「絶対痛くない」 |
| 設備 | 「歯科用CT完備」「マイクロスコープ導入」 | 「最新鋭の設備で日本一の治療」 |
| 実績 | 「開院20年、年間○○件の治療実績」 | 「地域No.1の実績」「名医」「ゴッドハンド」 |
| 矯正 | 「マウスピース矯正に対応しています」 | 「マウスピースで必ず綺麗になれる」 |
| 料金 | 「ホワイトニング 15,000円（税込）〜」 | 「激安」「業界最安値」 |

### インビザライン等（薬機法未承認機器）の注記
効果を謳う場合は「個人輸入にて入手」「薬機法上の承認を得ていない」「国内にも薬機法承認のマウスピース矯正あり」「適応外ケースでは効果不十分の可能性」の明記が推奨される。

## 施術院（整体・整骨・鍼灸）

### 業態の対照表（カテゴリ設定と広告規制の出発点）
| 項目 | 整体院 | 整骨院（接骨院） | 鍼灸院 |
|------|--------|----------------|--------|
| 国家資格 | 不要（民間資格） | 必要（柔道整復師） | 必要（はり師/きゅう師） |
| 保険適用 | なし | あり（急性外傷のみ） | あり（医師の同意書が必要な6疾患のみ） |
| GBPメインカテゴリ | 「整体」 | 「整骨院・接骨院」 | 「鍼灸院」 |
| Schema @type | HealthAndBeautyBusiness | MedicalBusiness | MedicalBusiness |
| 適用法規 | 景品表示法のみ | 柔道整復師法＋景表法 | あはき法＋景表法 |

- **カテゴリの誤登録が最多の失敗**: 整体院（無資格）が「整骨院・接骨院」カテゴリを設定するとポリシー違反リスク。資格に基づいて正確に選ぶ。
- 鍼灸の保険適用6疾患: 神経痛・リウマチ・五十肩・頸腕症候群・腰痛症・頸椎捻挫後遺症。

### 禁止事項（全業態共通）
1. 「治る」「治療します」「治した」— 口コミ返信でも使わない（患者が「治った」と書くのは自由だが、返信では「改善」「楽になった」等に言い換える）
2. 「必ず改善」「100%効果あり」等の効果保証
3. 「医師推薦」等の虚偽の権威表現
4. 「他院では治らなかった症状も改善」等の比較優良広告
5. 「○○症候群に効く」等、特定疾患名への効能を謳うこと（整体院）

### 整骨院固有
- 肩こり・腰痛等の慢性症状に保険適用を示唆しない（保険は急性外傷のみ）
- 保険適用外の施術を保険適用と謳わない

### 使える表現 / 使えない表現
| 分類 | ○ 使える | ✗ 使えない |
|------|---------|-----------|
| 施術効果 | 「肩こりの改善を目指します」「腰の負担を軽減」 | 「肩こりを治します」「腰痛が完治」 |
| 技術 | 「国家資格保有」「○○認定」 | 「ゴッドハンド」「日本一の技術」 |
| 体験 | 「多くのお客様にご好評いただいています」 | 「100%の方が効果を実感」 |
| 症状 | 「肩こり・腰痛・骨盤の歪みに対応」 | 「ヘルニア・坐骨神経痛を治す」 |

## 士業（税理士・司法書士等）

| 法規制 | 主な制限 |
|--------|---------|
| 景品表示法 | 優良誤認・有利誤認の禁止 |
| 税理士法 / 司法書士法 / 弁護士職務基本規程 | 品位を損なう広告の禁止 |

### 禁止事項
1. 「勝訴率○%」「還付金必ず取り戻す」等の成果保証
2. 「地域No.1の実績」等の根拠のない比較
3. 依頼者の案件内容の公開（守秘義務違反。口コミ返信でも案件内容に触れない）
4. 「日本一安い」等の過度な価格強調

### 司法書士特有のリーガルチェック（絶対厳守・実案件フィードバック由来）
1. **非弁行為（弁護士法72条違反）の回避**: 「揉めないような遺産分割をご提案します」「トラブルを解決します」等、紛争介入・代理交渉を匂わせる表現は一発アウト。「話し合いがまとまった後の遺産分割協議書の作成をサポートします」等、**中立的立場**を明記する。
2. **過料と罰金の使い分け**: 相続登記義務化のペナルティを「罰金」と書くのは法的に不正確。正しくは「行政上のペナルティである『過料（かりょう）』」（前科がつかない点で明確に区別）。
3. **抵当権抹消書類の「有効期限」**: 書類自体に有効期限があると書くのは不正確。「長期間放置すると銀行の合併や代表者変更により書類がそのまま使えなくなり、再発行の手間がかかるリスクがある」と実務に即して書く。

## 教育（学習塾）

### 口コミ機能停止リスク（最重要の落とし穴）
2024年4月以降、Googleは普通教育機関（学校）のGBPから口コミ機能を停止。学習塾でも**カテゴリに「学校」系を設定すると口コミが停止される事例がある**。

| 設定してはいけないカテゴリ | 推奨カテゴリ |
|---------------------------|-------------|
| 「学校」「小学校」「中学校」「高等学校」「教育機関」 | 「学習塾」「予備校」「学習センター」「教育サービス」 |

口コミが突然停止したら: カテゴリ確認 → 「学校」系が混入していれば即削除 → 改善しなければGoogleサポートへ。

### 禁止事項
1. 合格実績の誇張（「合格率100%」「全員合格」等）。掲載時は実数＋対象年度を明記し、「講習のみの生徒を含む」等の注記が正直
2. 「必ず成績が上がる」等の保証表現
3. 未成年の顔写真の無許可掲載 — **保護者の書面同意が必須**。同意がなければ背面・手元・モザイクで対応
4. 合格者氏名の無許可公開
5. 「口コミを書いたら入塾金無料」等の口コミ誘導（ステマ規制違反）

## 美容（美容室・エステ・ネイル）

| 法規制 | 主な制限 |
|--------|---------|
| 美容師法 | 美容師免許の保持義務・衛生基準 |
| 景品表示法 | 優良誤認・有利誤認・ステマ規制 |
| 薬機法 | 化粧品・医薬部外品の効能表現制限 |

### 禁止事項
1. 「髪が生える」「薄毛が治る」等の医学的効能表現（美容室では不可）
2. 「一生ダメージゼロ」等のカラー剤・薬剤の誇大な効能（薬機法違反リスク）
3. 他店との比較広告
4. お客様の施術写真の無断掲載（必ず同意を得る）
- ○ 「ダメージを抑えたカラー」「ツヤ感のある仕上がり」等の事実ベース表現はOK

## 飲食店

- **優良誤認**: 「日本一の刺身」「No.1居酒屋」等の根拠のない表現は禁止
- **有利誤認**: 通常価格を不当に高く設定して割引を謳う二重価格は禁止
- **食品表示法**: メニュー名と実食材の一致（「和牛」表記なら和牛）。「築地直送」等の産地表現には裏付けが必要
- 過度な飲酒促進表現（「飲み放題で飲みまくろう！」等）は制限対象
- 実際の提供物と著しく異なるメニュー写真はNG

## 不動産

| 法規制 | 主な制限 |
|--------|---------|
| 宅地建物取引業法 | 誇大広告禁止・取引態様の明示義務 |
| 不動産の表示に関する公正競争規約 | 物件広告の表示基準 |

1. おとり広告（成約済み・架空物件の掲載）は禁止
2. 「駅徒歩○分」は**80m＝1分**で計算（端数切り上げ）
3. 「格安」「激安」等の曖昧な価格表現には具体的根拠が必要
4. 「新築」表示は建築後1年未満かつ未入居のみ

## 工務店・リフォーム

| 法規制 | 主な制限 |
|--------|---------|
| 建設業法 | 建設業許可の明示、施工実績の正確な表示 |
| 住宅品質確保法 | 新築住宅の10年保証義務 |

1. 施工実績（棟数・施工例）の過大表示は禁止
2. 実際と異なる保証年数の表示は禁止
3. 他社施工写真の無断転用は禁止（自社施工のみ）

## 小売・物販

| 法規制 | 主な制限 |
|--------|---------|
| 景品表示法 | 優良誤認・有利誤認・二重価格表示の禁止 |
| 食品表示法（食品小売） | 原材料・アレルゲン表示義務 |
| 酒税法（酒類販売） | 販売免許・20歳未満販売禁止 |
| 薬機法（化粧品・健康食品） | 効能効果の表現制限 |

1. 二重価格表示・「限定○個」の虚偽・産地偽装は禁止
2. 「口コミを書いたら○%OFF」はステマ規制違反
- ○ 「期間限定セール」は正当な理由と期間明示があればOK

## 全業種共通（Googleポリシー）

1. 投稿本文への電話番号・URL直書きは非承認リスク
2. 口コミへの報酬提供・やらせ口コミ・スタッフ投稿は禁止
3. ビジネス名へのキーワード詰め込みは停止リスク
4. 「○○より上手い」等の他社比較は自社有利でも助長しない（不正競争防止法リスク）
