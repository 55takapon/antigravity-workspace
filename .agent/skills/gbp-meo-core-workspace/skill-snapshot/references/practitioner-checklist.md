### 8.5.1 GBP情報完全度スコアリング

> GBP情報の「埋まり度」を100点満点でスコア化し、優先改善箇所を即座に特定する。完全度スコアはGoogleのアルゴリズムに直結（GBPシグナル32%の主要構成要素）。

#### スコアリングシート（満点: 100点）

| カテゴリ | 項目 | 配点 | 判定基準 |
|----------|------|------|---------- |
| **基本情報（30点）** | ビジネス名（正式名称・ガイドライン準拠） | 5 | 完全一致=5、誤表記=0 |
| | メインカテゴリ（最適な1択） | 5 | 最適=5、次善=2、ミスマッチ=0 |
| | サブカテゴリ（2〜3個） | 3 | 3個=3、1〜2個=1、0個=0 |
| | 住所（正確・フォーマット統一） | 4 | 完全正確=4、軽微な誤り=1、不正確=0 |
| | 電話番号（GBPとサイト一致） | 3 | 一致=3、不一致=0 |
| | 営業時間（通常＋特別日設定済み） | 4 | 両方設定=4、通常のみ=2、未設定=0 |
| | ウェブサイトURL（正確・追跡パラメータ付き） | 3 | UTM付き=3、あるが未最適=1、なし=0 |
| | サービスエリア（該当業種） | 3 | 設定済み=3、未設定=0 |
| **コンテンツ（35点）** | ビジネス説明文（750文字、KW含有） | 8 | 700字以上+KW自然含有=8、500字以上=4、250字以下=0 |
| | サービス項目（全サービス+説明文） | 7 | 全設定+説明文あり=7、一部のみ=3、未設定=0 |
| | 商品/メニュー（該当業種） | 5 | 詳細設定済み=5、一部=2、未設定=0 |
| | 写真（枚数・品質・鮮度） | 8 | 20枚以上+直近1ヶ月更新=8、10枚以上=4、10枚未満=0 |
| | 動画（75秒以内・高品質） | 4 | 設定済み=4、なし=0 |

| **エンゲージメント（20点）** | 投稿（直近30日に4件以上） | 6 | 4件以上=6、2〜3件=3、1件以下=0 |

| | SNSリンク（3媒体以上設定） | 3 | 3媒体以上=3、1〜2媒体=1、なし=0 |
| **一貫性（15点）** | NAP一貫性（GBP/サイト/各ディレクトリ） | 7 | 全一致=7、軽微な揺れあり=3、不一致多数=0 |
| | LocalBusinessスキーマ実装（@id/sameAs含む） | 5 | 完全実装=5、一部=2、なし=0 |
| | GBPとサイトのビジネス説明整合性 | 3 | 一致=3、概ね一致=1、乖離=0 |

#### スコア評価基準

| スコア | ランク | 解釈 | 優先アクション |
|--------|--------|------|---------------|
| **90〜100点** | S（最適化完了） | 競合優位を維持する鮮度管理フェーズ | 週次鮮度維持・口コミ速度維持 |
| **75〜89点** | A（高品質） | 上位表示を十分に狙えるレベル | 低スコア項目の重点改善 |
| **60〜74点** | B（改善余地大） | 中位表示止まりのリスクあり | 基本情報+コンテンツを集中整備 |
| **40〜59点** | C（要緊急対応） | ローカルパック落ちのリスク高 | 基本情報から全面見直し |
| **39点以下** | D（放置状態） | 機会損失が深刻 | 即日着手・プロへの相談推奨 |

> **診断のタイミング**: 新規支援開始時（ベースライン）、施策実施後30日、四半期ごとの定点観測

### 8.5.4 A/Bテスト手法

> MEOでの「感覚施策」を「データ施策」に転換する。GBPは直接的なA/Bテスト機能を持たないため、**時系列比較・コントロール設計・セグメント分離**の3手法を使い分ける。

#### MEO A/Bテストの基本原則

```
【前提制約の理解】
  ✗ Google公式のA/Bテスト機能はない（広告とは異なる）
  ✗ 同時並行で2パターンを同じGBPに設定不可
  ✓ 時系列での「Before/After」比較が基本
  ✓ 多拠点展開の場合は「拠点間比較」が可能
  ✓ 投稿は複数パターンを交互に出して「CTR差」を測定可能

【テスト設計の鉄則】
  1変数の原則 : 1回のテストで変更するのは1要素のみ
  十分な期間  : 最低14日間、推奨28日間（アルゴリズムが安定するため）
  有意水準   : 前後比較で±15%以上の変化を「有意な差」とみなす（MEO特性）
  外部要因排除: 競合の大きな変化・季節要因・Googleアップデートを記録
```

#### テスト手法①：時系列Before/After比較（単拠点向け）

```
【テスト設計例：ビジネス説明文の最適化】

設計:
  Before期間 : 2026年3月1日〜3月28日（4週間）
  変更実施   : 2026年3月29日に説明文をパターンBに変更
  After期間  : 2026年3月29日〜4月25日（4週間）
  測定指標   : 電話クリック数、Webクリック数、ルート検索数

計測フォーマット:
  | 指標          | Before（3/1〜3/28） | After（3/29〜4/25） | 変化率 |
  |---------------|---------------------|---------------------|--------|
  | 電話クリック  | [____]件             | [____]件             | [±__]% |
  | Webクリック   | [____]件             | [____]件             | [±__]% |
  | ルート検索    | [____]件             | [____]件             | [±__]% |
  | 表示回数      | [____]回             | [____]回             | [±__]% |

判定基準:
  電話/Webクリック/ルート検索のいずれかが+15%以上 → パターンBを採用
  全指標が-5%以下 → パターンAに戻す（即時）
  変化が±14%以内 → 次の変数をテスト（差は誤差範囲内）
```

#### テスト手法②：投稿コンテンツのA/Bテスト（CTR比較）

```
【投稿パターンの交互テスト】

最も手軽に実施できるMEO A/Bテスト。
同じ週に似たテーマの投稿を2種類作り、
翌月に「閲覧数・CTR・電話クリック増加」を比較する。

【テスト変数の例】
  ① 画像スタイル   : 商品単体 vs スタッフ笑顔付き
  ② CTAボタン       : 「詳細を見る」vs「今すぐ予約」vs「電話する」
  ③ 冒頭テキスト   : 数字あり（「3ヶ月で80件獲得！」）vs 感情訴求（「こんな悩みありませんか？」）
  ④ 投稿タイミング : 月曜朝8時 vs 木曜夜7時
  ⑤ 投稿長         : 80文字以内（短文）vs 250文字前後（詳細説明）

【計測シート（4週間・8投稿）】
  投稿1（パターンA）: [____]閲覧 / [____]クリック / CTR[____%]
  投稿2（パターンB）: [____]閲覧 / [____]クリック / CTR[____%]
  投稿3（パターンA）: [____]閲覧 / [____]クリック / CTR[____%]
  投稿4（パターンB）: [____]閲覧 / [____]クリック / CTR[____%]
  ...
  平均CTR A: [____%]  vs  平均CTR B: [____%]
  勝者: [A/B]（差が+10%以上あれば採用、以降はこのパターンを標準化）
```

#### テスト手法③：多拠点比較テスト（チェーン・FC向け）

```
【設計：口コミ依頼フローのA/Bテスト（2店舗）】

  店舗A（コントロール群）: 既存のQRコード口コミ依頼のみ継続
  店舗B（テスト群）      : QRコード + SMS送付の2段階依頼を追加

  期間: 8週間
  測定: 口コミ獲得件数/月・平均評価・来店数変化

  | 指標            | 店舗A（Before）| 店舗A（After）| 店舗B（Before）| 店舗B（After）|
  |-----------------|----------------|---------------|----------------|---------------|
  | 月間口コミ件数  | [__]件          | [__]件         | [__]件          | [__]件         |
  | 平均評価        | [___]           | [___]          | [___]           | [___]          |
  | ルート検索数    | [____]          | [____]         | [____]          | [____]         |

  判定: 店舗Bの口コミ件数増加率 > 店舗Aの増加率+15% → 全店舗に展開
```

> **注意**: MEO A/Bテストは「科学的仮説→測定→意思決定」のサイクルが目的。結果が出ない・差がない場合も「その変数は効かない」という知見として蓄積する。

### 8.6 GBP初期設定ワークフロー（HP・テキスト情報からの候補抽出）

> **目的**: クライアントのHP・パンフレット・テキスト情報を読み取り、GBP初期設定（メインカテゴリ・サブカテゴリ・サービス項目・商品・ビジネス説明文・属性）の候補を**悩まず・漏れなく**提案するための標準ワークフロー。
> **前提**: 業種別スキル（`gbp-meo-restaurant`等）のカテゴリ・サービス一覧を参照辞書として使用する。

#### STEP 1：情報収集（インプット）

```
【収集すべき情報源（優先度順）】

①【必須】クライアントのHP（公式サイト）
  ┣ トップページ → ビジネス概要・キャッチコピー
  ┣ サービス/メニューページ → 提供サービスの全量
  ┣ 会社概要/About → 住所・電話・営業時間・代表者情報
  ┣ アクセスページ → 所在地・駐車場・最寄り駅
  ┣ 料金/価格表ページ → 価格帯・コース・プラン
  ┗ お知らせ/ブログ → 季節メニュー・イベント・専門分野

②【推奨】ポータルサイト上の登録情報
  ┣ 食べログ/ホットペッパー（飲食）
  ┣ ホットペッパービューティー（美容）
  ┣ EPARK（医療・施術）
  ┣ SUUMO/HOME'S（不動産）
  ┣ 塾ナビ（教育）
  ┗ ホームプロ/リショップナビ（工務店）

③【あれば】テキスト情報
  ┣ パンフレット・チラシのテキスト
  ┣ SNSプロフィール文
  ┣ 既存GBPの現在の情報
  ┗ クライアントからのヒアリングメモ
```

#### STEP 2：業種判定 → 該当スキル特定

```
【業種判定フロー】

Q1: 食べ物・飲み物を提供する実店舗か？
  → Yes → gbp-meo-restaurant（飲食店）

Q2: 髪・肌・爪・まつ毛の施術を行うか？
  → Yes → gbp-meo-beauty（美容室・エステ・ネイル）

Q3: 国家資格に基づく医療行為を行う施設か？
  → Yes → gbp-meo-medical（クリニック）

Q4: 体の施術を行う（整体・整骨・鍼灸・リラクゼーション）か？

  → Yes → gbp-meo-legal（士業）

Q6: 不動産の売買・賃貸・管理を行うか？
  → Yes → gbp-meo-real-estate（不動産）

Q7: 建築・リフォーム・塗装・外構工事を行うか？
  → Yes → gbp-meo-service（工務店・リフォーム）

Q8: 学習指導・受験対策・習い事教室を運営しているか？
  → Yes → gbp-meo-education（教育）

  → Yes → gbp-meo-retail（小売・物販）

Q10: 上記のいずれにも当てはまらない

```

### 8.7 競合連動の投稿頻度・施策調整ガイドライン

> **目的**: 「週2回投稿」を一律の標準とするのではなく、**競合の活動レベル**に応じて投稿頻度・施策の強度を動的に調整する判断基準を定義する。
> **前提**: §8.5.3（競合分析5ステップ）のSTEP 4で取得した競合データを使用。

#### 競合活動レベルの定義

```
【競合活動レベル判定マトリクス】

競合上位3社の「直近30日の平均値」で判定:

              投稿頻度
              低（月3以下） 中（月4-8）  高（月9+）
口コミ速度 ┌──────────┬──────────┬──────────┐
高（月10+）│  Lv.3      │  Lv.4      │  Lv.5     │
中（月4-9）│  Lv.2      │  Lv.3      │  Lv.4     │
低（月3以下）│ Lv.1      │  Lv.2      │  Lv.3     │
           └──────────┴──────────┴──────────┘
```

#### レベル別の推奨施策

| | Lv.1（休眠競合） | Lv.2（通常競合） | Lv.3（活発競合） | Lv.4（攻勢競合） | Lv.5（超攻勢） |
|---|---|---|---|---|---|
| **投稿頻度** | 週1.5回（月6） | **週2回（月8）** | 週2.5回（月10） | **週3回（月12）** | 週3-4回（月14） |
| **写真追加** | 月2枚 | 月3-4枚 | 月4-6枚 | **月6-8枚** | 月8枚+ |
| **口コミ獲得目標** | 月2-3件 | 月4-6件 | **月6-8件** | 月8-12件 | 月12件+ |
| **動画** | 四半期1本 | 月1本 | **月1-2本** | 月2本 | 月2-3本 |
| **投稿タイプ比率** | 最新情報90% | 最新70%+特典20%+イベント10% | 最新60%+特典25%+イベント15% | **全タイプ均等に活用** | 全タイプ+商品投稿 |
| **競合チェック頻度** | 月1回 | 月2回 | **週1回** | 週1回 | 週2回 |
| **運用コスト目安** | 標準の70% | **標準（100%）** | 標準の130% | 標準の160% | 標準の200% |

#### レベル判定の実施手順

```
【毎月第1営業日に実施】

1. 競合上位3社のGBPを開く
2. 以下を記録:
   ┣ 直近30日の投稿件数
   ┣ 直近30日の新規口コミ件数
   ┣ 写真の追加状況（最新写真の日付）
   ┗ 新しいサービス項目・属性の変更有無

3. マトリクスに当てはめてレベルを判定

4. 前月との変化を確認:
   ┣ レベルが上がった → 施策強度を引き上げ（翌週から）
   ┣ レベルが下がった → 現状維持 or 2ヶ月連続低下で施策縮小
   ┗ レベル変化なし → 現行施策を継続

【判定結果の記録フォーマット】
  判定月: YYYY年MM月
  競合A: 投稿[__]件 / 口コミ[__]件 → Lv.[__]
  競合B: 投稿[__]件 / 口コミ[__]件 → Lv.[__]
  競合C: 投稿[__]件 / 口コミ[__]件 → Lv.[__]
  → 総合判定: Lv.[__]
  → 前月比: [↑/→/↓]
  → 今月の推奨施策: {上記テーブルから該当行を適用}
```

#### 施策調整のエスカレーション基準

```
【即時エスカレーション（待たずに施策強化するシグナル）】

🚨 競合がGBPを大幅リニューアル（写真20枚以上追加、説明文全面改定）
   → 1週間以内に自社GBPの情報鮮度を最新化

🚨 競合が急激に口コミを獲得（1ヶ月で20件以上増）
   → 口コミ獲得施策を2倍に強化

🚨 自社の主要KWで競合が新たにローカルパック入り
   → 投稿頻度を即座に+2件/月

🚨 競合がGoogle広告（ローカル検索広告）を開始
   → オーガニックMEOでの差別化施策を強化

【コスト最適化（施策を縮小できるシグナル）】

💚 3ヶ月連続でローカルパック1位を維持 → Lv.を1段階下げて運用可
💚 競合が2ヶ月連続で投稿ゼロ → 最低限の鮮度維持で十分
💚 口コミ件数が競合上位の2倍以上 → 口コミ獲得ペースを緩和可
```

#### 業種別の投稿頻度目安（ベースライン）

```
【業種による競合活動レベルの一般的傾向】

                    一般的な   推奨ベース   上振れ時の
                    競合Lv.    投稿頻度      最大頻度
```

#### 8.8.4 クライアントからよくある質問への回答集

```
Q: 「成果はどのくらいで出ますか？」
A: 一般的には、プロフィール最適化の効果は1〜2週間で表示回数に反映され、
   投稿や口コミの継続的な取り組みは2〜4ヶ月で順位・アクション数に効果が
   表れるのが目安です。競合の少ないエリアでは1ヶ月目から変化が見えること
   もあります。

Q: 「自社でやるのとプロに任せるのと何が違いますか？」
A: 最も大きな違いは「戦略的な最適化」と「継続性」です。
   カテゴリ設定1つの判断ミスで検索表示回数が30〜50%変わること
   もあります。また、週2回の投稿を1年間欠かさず続けるのは
   想像以上に大変です。プロは業種別のノウハウを持ち、
   データに基づいた改善を継続的に実行します。

Q: 「口コミは依頼していいんですか？ステマにはなりませんか？」
A: 「気に入っていただけたら口コミをいただけると嬉しいです」
   という自然な声がけは問題ありません。禁止されているのは
   「口コミを書いてくれたら○○をプレゼント」等の報酬提供です。

Q: 「順位が急に下がることはありますか？」
A: Googleのアルゴリズムは定期的に更新されるため、
   一時的な変動はあります。ただし、ガイドラインに沿った
   正しい運用を継続していれば、中長期的には安定します。
   小手先のテクニックではなく本質的な最適化が重要な理由です。

Q: 「AI検索でGoogleマップは意味なくなりませんか？」
A: むしろ逆です。AI検索（AI Overviews/Gemini）は
   ローカルパック上位のGBPデータを最も高い確率で「引用」します。
   GBPを充実させることは、AI検索時代にも直結する投資です。

Q: 「競合がMEO業者に頼んでいるようですが対抗できますか？」
A: はい。大切なのは「業者を使っているか」ではなく
   「正しい施策を実行しているか」です。
   毎月の競合分析で相手の動きを把握し、
   弱点を突いた施策を打つことで十分に対抗できます。
```
