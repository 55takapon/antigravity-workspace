# GBP MEO運用スキル｜士業（税理士・司法書士）

> **対象**: 税理士・司法書士・行政書士・社会保険労務士・弁護士・公認会計士
> **フォーカス**: 税理士事務所、司法書士事務所

## 1. 士業のMEO市場環境（2025-2026）

### 1.1 士業×ローカル検索の現状

- **「地域名＋税理士」検索が主要集客経路に**: 法人・個人事業主の税理士探しは「○○区 税理士」「○○駅 税理士 相続」等のGoogle検索→マップ確認→口コミ精読→問い合わせの流れが定着
- **相続登記義務化（2024年4月〜）で司法書士需要が急増**: 「相続登記 司法書士 ○○市」の検索が大幅増。3年以内の登記義務化で今後も需要拡大
- **YMYL領域の最重要カテゴリ**: 税務・法務は「Your Money or Your Life」の中核。Googleは士業に対して最高水準のE-E-A-T（経験・専門性・権威性・信頼性）を要求
- **口コミの質が決定的**: 士業は件数より**質（「丁寧に説明してくれた」「不安が解消された」等の具体的な信頼感）**が来所決定を左右
- **AI検索の影響**: 「相続税の計算方法」「会社設立の流れ」等の情報クエリにAI Overviewsが回答。E-E-A-Tの高い専門家サイトが引用される

### 1.2 士業MEOの難易度と特徴

| 項目 | 士業の特徴 |
|------|----------|
| 競合密度 | **中程度**（飲食・施術より少ないが都市部は密集） |
| 口コミ優先度 | **高い**（件数より質が重要。15〜40件で上位入り可能） |
| E-E-A-T要件 | **最重要**（YMYL領域。資格・実績・専門性の明示が必須） |
| 客単価 | **高い**（顧問: 月3〜10万円、相続: 30〜100万円/案件） |
| LTV（顧客生涯価値） | **非常に高い**（顧問契約は平均3〜10年継続） |
| 電話アクション比率 | **全業種中最高（6-11%）** |
| 写真の影響度 | **中程度**（事務所の雰囲気・資格者の信頼感） |
| 季節変動 | **大きい**（確定申告期・決算期・相続発生時） |
| 守秘義務 | **厳格**（口コミ返信での案件内容言及は厳禁） |

**税理士事務所の場合:**
1. 「会計事務所」

**司法書士事務所の場合:**
1. 「法律事務所」※慎重に（弁護士事務所と混同リスクあり）
2. 「行政書士」（行政書士資格も保有する場合）
3. 「公証人役場」× 使用不可
4. 「不動産業者」（不動産関連業務が多い場合）※慎重に

### 2.2 属性設定チェックリスト（士業固有）

#### 必須属性
- [ ] **バリアフリー**: 車椅子対応入口 / エレベーター（高齢の相続相談者に重要）
- [ ] **駐車場**: あり/なし（法人経営者・高齢者の来所に重要）
- [ ] **支払い方法**: 銀行振込 / 現金 / クレジットカード
- [ ] **予約**: 予約制（相談は事前予約が基本）
- [ ] **オンライン対応**: オンライン相談可（Zoom/Teams等）

#### 士業重要属性
- [ ] **初回無料相談**: 対応可否（最重要のCTA。問い合わせ率に直結）
- [ ] **土日対応**: 土曜/日曜/祝日の相談対応（会社員からの個人相談に重要）
- [ ] **夜間対応**: 19時以降の相談対応（差別化ポイント）
- [ ] **訪問対応**: 出張相談可（高齢者・身体不自由の方への配慮）
- [ ] **対応言語**: 英語/中国語等（インバウンド対応、外国人経営者向け）
- [ ] **Wi-Fi**: あり（来所時のオンライン確認用）

> **「初回無料相談」は士業MEOの最強CTA**: 「初回相談無料」を属性・投稿・説明文に設定するだけで問い合わせ率が**2〜3倍**に上がるケースが多い。

## 3. 写真・動画コンテンツ戦略

### 3.1 士業の必須写真カテゴリ

士業は**信頼感・専門性・親しみやすさ**が来所決定の鍵。最低15枚、理想30枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **外観** | 3〜5枚 | 看板・ビル外観・入口（初来所でもわかるカット） |
| **受付・エントランス** | 2〜3枚 | 清潔感・落ち着いた雰囲気 |
| **相談室** | 2〜3枚 | プライバシーが保たれた個室空間 |
| **事務所内** | 2〜3枚 | スタッフが働いている様子（活気） |
| **資格者ポートレート** | 3〜5枚 | スーツ姿の公式ポートレート＋自然な笑顔カット |
| **資格証書・登録証** | 1〜2枚 | 壁に掲げた税理士証票・登録証（信頼性の視覚的証明） |
| **セミナー風景** | 2〜3枚 | 相続セミナー・経営者勉強会の様子 |
| **メディア掲載** | 1〜2枚 | 取材記事・書籍・TV出演（E-E-A-T強化） |
| **チーム写真** | 1〜2枚 | スタッフ集合写真（組織力のアピール） |

### 3.2 士業写真の撮影テクニック

```
【ポートレート写真のコツ】
  ✓ スーツ・ネクタイ着用（信頼感の演出）
  ✓ 明るい背景（書棚が映ると知的な印象）
  ✓ やや斜めのアングル（正面直撮りは証明写真になる）

  ✓ 清潔で落ち着いた空間が伝わるカット
  ✓ テーブル上に書類・PC等の仕事道具を配置
  ✓ プライバシーが保たれる個室であることが伝わるように
  ✗ 散らかった机・書類は映さない

【ファイル最適化】
  ✓ ファイル名: 「新宿_税理士_代表_相談室.jpg」
```

## 4. 口コミ獲得・管理（士業特化）

### 4.1 士業の口コミ獲得タイミング

士業は**「問題が解決した安心感を得た瞬間」**に依頼するのが鉄則。

#### 最適タイミング
1. **案件完了時**: 登記完了・申告完了・決算完了の報告時が最良
2. **確定申告完了後（税理士）**: 毎年2〜3月の確定申告完了報告のタイミング
3. **相続手続き完了後（司法書士）**: 安堵感が最も大きいタイミング
4. **会社設立完了時**: 依頼者の達成感＋感謝の気持ちが高い
5. **顧問契約更新時**: 継続的な信頼関係が築けている段階

#### 口コミ依頼の声がけ例（士業向け）
```
【案件完了時（相続登記完了）】
「相続登記が無事完了いたしました。
 ご不安な中、当事務所にお任せいただきありがとうございました。
 もしよろしければ、同じようにお悩みの方の参考になりますので、
 Googleマップに当事務所の感想をいただけると大変ありがたいです」

【確定申告完了後】
「○○様の確定申告、無事に完了いたしました。
 もしよろしければ、税理士選びで迷っている方の参考になりますので、
 当事務所の対応について一言いただけると嬉しいです。
 こちらのQRコードから簡単に投稿いただけます」

【会社設立完了時】
「会社設立おめでとうございます！
 ○○様の事業のスタートをお手伝いできたことを嬉しく思います。
 これから起業される方のご参考になりますので、
 ぜひGoogleに体験談をお聞かせいただけないでしょうか」
```

> **士業は「守秘義務」が最優先**。口コミ依頼時も案件の詳細には触れず、「当事務所の対応について」と一般的な表現に留める。

### 4.2 士業向けレビュー返信テンプレート

#### 高評価（4-5星）向け — 対応の丁寧さを褒められた場合
```

{評価内容（例：丁寧な説明/迅速な対応/不安の解消）}について
ご評価いただけたこと、大変励みになります。
当事務所では{こだわり（例：専門用語をなるべく使わず、
お客様に分かりやすくご説明することを心がけております）}。
今後も何かお困りごとがございましたら、
お気軽にご相談ください。
{事務所名} {代表名}
```

#### 高評価（4-5星）向け — 専門性を褒められた場合
```
{お客様のお名前}様、ありがとうございます。
{評価内容（例：相続の手続きをスムーズに進めていただいた）}
とのこと、お力になれたことを嬉しく思います。
{専門性アピール（例：当事務所は相続関連の手続きを

経験豊富なスタッフが対応しております）}。

```

#### 低評価（1-2星）向け
```
{お客様のお名前}様、貴重なご意見をいただきありがとうございます。
ご期待に沿えなかった点について、深くお詫び申し上げます。
{改善姿勢（例：いただいたご意見を真摯に受け止め、
対応品質の向上に努めてまいります）}。

```

> **⚠️ 返信で案件の具体的内容に絶対に触れない**: 「相続税の申告をお手伝いしました」程度でも、本人の同意なく案件内容を公開することは**守秘義務違反**のリスク。返信は一般的な表現に徹する。

### 4.3 ABSA属性（Googleが士業口コミから抽出するキーワード）

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **対応の速さ** | 迅速、レスポンスが早い、すぐに対応してくれた |
| **説明の丁寧さ** | わかりやすい、丁寧に説明、専門用語を使わない |
| **費用の透明性** | 見積りが明確、追加料金なし、料金が明朗 |
| **解決力** | 的確なアドバイス、問題が解決、安心して任せられた |
| **親身さ** | 親身、寄り添ってくれた、相談しやすい |
| **専門性** | 詳しい、経験豊富、専門的なアドバイス |
| **信頼感** | 信頼できる、安心、誠実 |
| **アクセス** | 駅近、通いやすい、オンライン対応 |

> **口コミ誘導テクニック**: 「当事務所の対応や分かりやすさについて、率直なご感想をいただけると嬉しいです」と伝えると、上記属性ワードが含まれやすくなる。

### 4.4 士業固有のリスク・注意点

- **守秘義務の厳守**: レビュー返信で依頼内容・案件金額・相手方情報に触れることは厳禁
- **懲戒処分情報の口コミ**: 過去の懲戒に関する口コミは、事実であればGoogleは削除しない。誠実な対応で信頼を回復
- **競合士業からのネガティブ口コミ**: 同業者による中傷は証拠を保存してGoogleに報告
- **報酬トラブル**: 「高すぎる」等の料金不満は、料金表の透明性改善で予防。返信では具体的な金額に触れない
- **元依頼者の感情的な口コミ**: 離婚・相続等は感情が絡む案件が多い。冷静かつ誠実な返信を心がける

## 9. 士業の広告規制・ガイドライン

### 9.1 適用される法規制

| 法規制 | 対象 | 主な制限 |
|--------|------|---------|
| **景品表示法** | すべての広告表現 | 優良誤認・有利誤認の禁止 |
| **税理士法** | 税理士の広告 | 品位を損なう広告の禁止 |
| **司法書士法** | 司法書士の広告 | 品位保持の義務 |
| **弁護士職務基本規程** | 弁護士の広告 | 誇大・誤導の禁止 |
| **不正競争防止法** | 競合との比較 | 虚偽事実の告知禁止 |

### 9.2 GBP投稿での注意事項

#### やってはいけないこと
1. ❌ **「勝訴率○%」「還付金必ず取り戻す」等の成果保証**: 結果は案件により異なる
2. ❌ **「地域No.1の実績」等の比較広告**: 根拠のない比較表現は禁止
3. ❌ **他の事務所の中傷・比較**: 品位に関わる
4. ❌ **依頼者の案件内容を公開（同意なし）**: 守秘義務違反
5. ❌ **「日本一安い」等の価格の過度な強調**: 品位の問題＋景品表示法
6. ❌ **ステマ口コミ**: 口コミと引き換えに報酬を提供することは禁止

#### 使える表現 / 使えない表現

| 分類 | ○ 使える表現 | ✗ 使えない表現 |
|------|------------|---------------|
| 実績 | 「相続税申告 年間○○件の実績」 | 「地域No.1の相続実績」 |
| 料金 | 「顧問料 月額30,000円〜」 | 「業界最安値」「激安」 |
| 専門性 | 「相続税に強い税理士」「登記の専門家」 | 「この分野では誰にも負けない」 |
| 資格 | 「税理士・中小企業診断士のダブル資格」 | 「スーパー税理士」 |
| 対応 | 「初回相談無料・土日対応可」 | 「どんな案件でも必ず解決」 |

#### 司法書士特有の厳格なリーガルチェック（絶対厳守）
1. ⚠️ **非弁行為（弁護士法72条違反）の回避**:
   - ✖ 「揉めないような遺産分割をご提案します」「トラブルを解決します」等、紛争の介入や代理交渉を匂わせる表現は**一発アウト**（弁護士法違反）。
   - ◯ 「（揉める前の段階で）法的な選択肢をご説明します」「話し合いがまとまった後の遺産分割協議書の作成をサポートします」と明記し、必ず**中立的立場**であることを強調する。
2. ⚠️ **ペナルティ用語の正確な使い分け（過料と罰金）**:
   - ✖ 相続登記義務化のペナルティを「罰金」や「罰金のようなもの」と表現するのは法的に不正確。
   - ◯ 正しくは「行政上のペナルティである『過料（かりょう）』」と記載する（過料には前科がつかないため明確に区別する）。
3. ⚠️ **抵当権抹消書類の「有効期限」の正確な表現**:
   - ✖ 銀行から交付される解除書類自体に「数ヶ月の有効期限がある」と書くのは実務上不正確。
   - ◯ 「長期間放置すると銀行の合併や代表者の変更により、書類がそのまま使えなくなり再発行の手間がかかるリスクがある」と実務に即した正確な表現にする。

```
  ┣ 「会社設立 ○○区 安い」 → 会社設立特化
```
