# GBP MEO運用スキル｜工務店・リフォーム

> **対象**: 工務店・リフォーム会社・ハウスメーカー（地域密着型）・塗装店・外構工事・設備工事会社

## 1. 工務店のMEO市場環境（2025-2026）

### 1.1 工務店×ローカル検索の現状

- **「地域名＋リフォーム」検索が主要集客経路**: ポータル（ホームプロ・リショップナビ等）経由に加え、Googleマップからの直接問い合わせが増加
- **施工事例写真が決定打**: 工務店は「実際にどんな家を建てるのか」が最大の関心事。施工事例のビフォーアフター写真が来店・問い合わせを左右
- **口コミの信頼性が極めて重要**: 住宅は人生最大の買い物。口コミを徹底的に精読してから問い合わせる傾向が全業種中最も強い
- **AI検索対応**: 「リフォーム費用の相場」「外壁塗装の時期」等の情報クエリにAI Overviewsが回答。施工実績と専門知識を持つ会社が引用される
- **Googleの保証制度**: 一部地域でGoogleの「保証済み」バッジ（Google Guaranteed）がホームサービス業者に提供されている

### 1.2 工務店MEOの難易度と特徴

| 項目 | 工務店の特徴 |
|------|------------|
| 競合密度 | **中程度**（都市部半径3km内に10〜30社。大手HMと個人工務店が混在） |
| 口コミ優先度 | **最重要**（高額案件のため口コミを最も精読する業種） |
| 客単価 | **非常に高い**（リフォーム50〜500万円、新築2,000〜5,000万円） |
| LTV | **高い**（リフォーム→増改築→建替えの長期関係） |
| 商圏 | **広い**（車で30分〜1時間圏内が商圏。半径5〜20km） |
| 写真の影響度 | **極めて大きい**（施工事例が最強の営業ツール） |
| 季節変動 | **中程度**（春・秋に相談増。台風/豪雨後に修繕需要急増） |
| 検討期間 | **長い**（初回相談→契約まで1〜6ヶ月） |

## 3. 写真・動画コンテンツ戦略

### 3.1 工務店の必須写真カテゴリ

工務店は**施工事例が最強の営業ツール**。最低30枚、理想80枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **施工事例（完成写真）** | 20〜40枚 | キッチン/リビング/外観。明るい日中に撮影 |
| **ビフォーアフター** | 10〜15枚 | 同アングルでのBefore/After（最強コンテンツ） |
| **施工中の様子** | 5〜10枚 | 構造/断熱材/上棟式等（技術力の証明） |
| **外観** | 3〜5枚 | 事務所・ショールームの外観 |
| **事務所・ショールーム** | 3〜5枚 | 打ち合わせスペース・素材サンプル展示 |
| **スタッフ** | 3〜5枚 | 現場のヘルメット姿＋事務所でのポートレート |
| **モデルハウス** | 5〜10枚 | 見学可能なモデルハウスの内外観 |
| **お引き渡し式** | 2〜3枚 | お客様との記念撮影（許可必須/顔モザイク） |

### 3.2 施工事例写真の撮影テクニック

```
【完成写真のコツ】
  ✓ 自然光（晴れた日の午前中がベスト）
  ✓ 広角レンズで空間の広さを伝える
  ✓ 生活感のある小物をスタイリングに配置
  ✓ 外観は青空の日に（天気が悪いと印象ダウン）
  ✓ 夜の外観も撮影（照明の雰囲気が伝わる）

【ビフォーアフターのコツ】
  ✓ Before: 施工前に必ず同アングルで撮影を忘れない
  ✓ After: 同じアングル・同じ照明条件で撮影
  ✓ 2枚セットで投稿（比較画像は最もエンゲージメントが高い）
  ✓ キャプションに「工期○日」「費用○○万円〜」を記載

【ファイル最適化】
  ✓ ファイル名: 「世田谷_リフォーム_キッチン_ビフォーアフター.jpg」
  ✓ 解像度: 1200x900px以上
  ✓ ジオタグ: 現場/事務所で位置情報ONにして撮影
```

### 3.3 動画コンテンツ案

| 動画テーマ | 尺 | 内容 |
|-----------|-----|------|
| **施工事例ツアー** | 60〜75秒 | 完成物件の室内ウォークスルー |
| **リフォームの流れ** | 45〜75秒 | 相談→現地調査→プラン→工事→完了 |

## 4. 口コミ獲得・管理（工務店特化）

### 4.1 口コミ獲得タイミング

#### 最適タイミング
1. **お引き渡し時**（最高の口コミ）: 完成の喜びが最大の瞬間
2. **入居後1〜3ヶ月**: 新居の快適さを実感している段階
3. **定期点検時**: 継続的な関係性の中で自然に依頼
4. **リフォーム完了後**: 変化への満足感が高いタイミング

#### 声がけ例
```
【お引き渡し時】
「本日はおめでとうございます！
 ○○様のこだわりが詰まった素敵なお家が完成しましたね。
 もしよろしければ、家づくりを検討されている方の参考になりますので、
 Googleに当社の感想をいただけると大変嬉しいです」

【リフォーム完了後】
「キッチンの使い心地はいかがですか？
 今回のリフォームでご満足いただけたようで何よりです。
 同じようにリフォームを検討している方のために、
 よろしければ体験談を書いていただけませんか？」
```

### 4.3 ABSA属性

| 属性カテゴリ | キーワード例 |
|-------------|------------|
| **施工品質** | 丁寧、きれい、仕上がりが良い、職人の腕が良い |
| **対応力** | 要望を聞いてくれた、柔軟に対応、提案力がある |
| **費用** | 見積りが明確、追加料金なし、適正価格 |
| **工期** | 予定通り、遅延なし、スピーディー |
| **アフター** | アフターフォローが良い、定期点検、何かあれば対応 |
| **信頼感** | 安心して任せられた、誠実、地元で信頼 |

### 4.4 工務店固有のリスク

- **施工トラブルの口コミ**: 雨漏り・ひび割れ等の品質問題は即座に現地確認→修繕対応。放置は炎上＋法的リスク
- **工期遅延の口コミ**: 天候等やむを得ない場合も事前の説明不足が原因になりやすい
- **見積りと最終金額の差異**: 「追加料金が発生した」は最も多いクレーム。見積書の透明性が予防策
- **近隣トラブル**: 騒音・粉塵の苦情が口コミに反映されるケースも

## 9. 工務店の広告規制（建設業法）

### 9.1 適用される法規制

| 法規制 | 主な制限 |
|--------|---------|
| **建設業法** | 建設業許可の明示義務、施工実績の正確な表示 |
| **住宅品質確保法** | 10年保証の義務（新築住宅） |
| **景品表示法** | 優良誤認・有利誤認の禁止 |
| **建築基準法** | 法令遵守の施工 |

### 9.2 GBP投稿での禁止事項

1. ❌ **施工実績の虚偽**: 実績棟数・施工例の過大表示
2. ❌ **「業界最安値」「地域No.1」等の根拠なき表現**
3. ❌ **建設業許可の未表示**: 建設業を営む場合は許可番号の表示が望ましい
4. ❌ **保証内容の虚偽**: 実際と異なる保証年数の表示
5. ❌ **他社施工写真の無断転用**: 自社の施工事例以外の写真使用
