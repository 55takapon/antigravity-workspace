# content-strategy

> ジェットプロデュース専用コンテンツ戦略スキル。ピラークラスター管理・編集カレンダー・KPI設計を統合。

## ブランドボイス定義

```
【Who】  誰が書いているか
→ Googleマップ×Web戦略で店舗の集客を改善するプロデューサー

【What】 何を伝えるか
→ 店舗・クリニック・士業が「見つけてもらえる仕組み」を作る具体的な方法

【Why】  なぜ伝えるか
→ 「良いサービスが、正しく見つけられる世の中に」

【How】  どう伝えるか
→ プロの知見を惜しみなく公開し、読者が自分で行動できる状態を作る
```

## ピラー・クラスター構造

```
【A】GBP運用・MEO対策
  └ ピラー: GBP完全攻略ガイド
    └ クラスター: A-01〜A-08（8本）

【B】SEO・AI検索対策
  └ ピラー: 2026年版 店舗のためのSEO入門
    └ クラスター: B-01〜B-07（7本）

【C】SNS集客（Instagram/LINE）
  └ ピラー: SNS×店舗集客の最強導線設計
    └ クラスター: C-01〜C-07（7本）

【D】ホームページ活用
  └ ピラー: 集客できるHPの条件
    └ クラスター: D-01〜D-05（5本）

【E】集客戦略・マーケ思考
  └ ピラー: 小さな店舗の集客プロデュース入門
    └ クラスター: E-01〜E-05（5本）

【F】成功事例・実践レポート
  └ ピラー: クライアント事例で学ぶ集客改善
    └ クラスター: F-01〜F-03（3本）
```

**内部リンク設計**:
1. ピラー→クラスター: ピラーから全クラスターへリンク
2. クラスター→ピラー: 各クラスターからピラーへリンク（末尾）
3. クラスター間: 関連クラスター同士を相互リンク（2〜3本）

## KPI管理（3Tier）

### Tier 1: ビジネスKPI
| 指標 | 計測方法 |
|------|---------|
| 問い合わせ数 | フォーム/LINE送信数 |
| 無料診断申込数 | LINE経由の予約数 |
| 指名検索数 | Search Console「ジェットプロデュース」 |

### Tier 2: コンテンツKPI
| 指標 | 計測方法 |
|------|---------|
| オーガニック流入数 | Google Analytics |
| 検索順位 | 各記事のメインKW順位 |
| 平均滞在時間 | Google Analytics（目標: 3分以上） |

### Tier 3: AI検索・新指標
| 指標 | 確認方法 |
|------|---------|
| AI Overviews引用 | 手動チェック（月1回） |
| SNSからの流入 | GA4のリファラ |

## 運用の鉄則

**やるべきこと**:
1. 週2本ペースの安定更新
2. 月1回のリライト（上位記事更新＋下位記事改善）
3. GBP投稿との連動（ブログ→GBP投稿で相乗効果）
4. SNSでの記事シェア（Instagram/LINE公式）
5. Search Consoleの定期確認（流入KW→新記事ネタ）

**やってはいけないこと**:
1. AIで丸投げ量産（品質低下→サイト評価下落）
2. 検索ボリュームだけで記事テーマを決める
3. 公開して放置
4. 全カテゴリを同時に攻める（A→Bの順で集中）

## 連携スキル

- `blog-title-research` → タイトル設計
- `blog-writing` → 記事執筆

**3スキル統合フロー**: content-strategy（戦略）→ blog-title-research（タイトル）→ blog-writing（執筆）

## NGパターン

- カテゴリ設計なしにバラバラに記事を書く
- 優先順位（A→B→C順）を無視してランダムに執筆
- KPIを設定せずに運用を開始する
