## SERP分析ステップ（STEP 0の詳細）

執筆開始前に必ず実施する。

### STEP 0-1: 上位記事の見出し構成を確認する

対象キーワードで検索し、上位3〜5記事の H1〜H2 見出しを記録する。

```
確認ポイント:
□ 上位記事が共通して扱っているトピックは何か（必ず入れるべき内容）
□ 上位記事が扱っていない角度・切り口は何か（情報ギャップ）
□ 上位記事の想定文字数はどの程度か（自記事の目安を決める）
□ 上位記事のフォーマットは何か（ハウツー/FAQ/事例/比較 など）
```

### STEP 0-2: 共起語・関連質問を収集する

```
収集方法:
1. PAA（「他の人はこちらも質問」）のボックスを確認・記録
2. 検索結果最下部の「関連する検索」を記録
3. 対象KWのサジェストを記録（Google検索窓・虫眼鏡マーク）
→ ブリーフ12番「共起語・関連語リスト」に記入
→ PAAのうち、費用・効果・手間などCV前の不安に関する質問は
  ブリーフ15番「想定される反論・不安」の素材にもなる
```

### STEP 0-3: 情報ギャップを特定する

```
上位記事が全員書いていないが、読者が知りたそうなこと:
- 「現場ではどうなのか」のリアルな情報
- 「〇〇市・〇〇エリア」の地域固有情報
- 上位記事の説明が抽象的で「具体的なやり方」が足りない部分
→ ブリーフ14番「この記事独自の要素」に記入
```
