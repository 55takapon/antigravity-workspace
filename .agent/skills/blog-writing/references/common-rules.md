# 共通ルール（blog-writing / blog-writing-qa 共通参照）

> このファイルは **blog-writing** と **blog-writing-qa** の両スキルから参照する。
> 二重管理による矛盾を防ぐため、断言境界・禁止表現・用語言い換えルールはすべてここに集約する。

---

## 1. 断言境界ルール（両スキル共通）

執筆スキルの「断言する」指示と、QAスキルの「過度な断定NG」は対象領域が異なる。
以下の区分に従い、領域を誤った断言を行わないこと。

### ✅ 断言してよい対象

| 対象 | 例 |
|------|----|
| 手順・操作方法・仕組みの説明 | 「この画面で〜を押すと、○○が表示されます」 |
| 一般的な事実・原則 | 「Googleマップに登録すると検索結果に表示されます」 |
| 自社のスタンス・提供内容 | 「ジェットプロデュースは〜します」 |
| 定量的な仕様（文字数・期間等） | 「メタディスクリプションは80〜120文字です」 |

### ❌ 断言してはいけない対象（必ず可能性・傾向表現に変換）

| 対象 | NGの例 | OKの例 |
|------|--------|--------|
| 集客成果・問い合わせ数 | 「必ず集客できます」 | 「集客につながりやすくなります」 |
| 読者の売上・収益への影響 | 「売上が上がります」 | 「売上改善のきっかけになる場合があります」 |
| 医療・健康効果 | 「〇〇が治ります」 | 「改善をサポートします」 |
| 投資・資産への効果 | 「必ず利益が出ます」 | 不可（景表法） |
| SEO・MEO の順位保証 | 「1位になれます」 | 「上位表示を目指せます」 |

> ⚠️ 「必ずうまくいく」「確実に〜できる」「100%効果がある」はすべて法令違反リスクあり（景表法・薬機法）。

## 2. 禁止表現一覧

| 禁止表現 | 理由 | 代替 |
|----------|------|------|
| 「〜という方は多いです」 | 他人事・距離感あり | 「〜と感じていませんか？」 |
| 「いかがでしたか？」 | 記事末尾定型文・読者が嫌う | まとめの内容で自然に締める |
| 「〜はずです」「〜かもしれません」 | 断言回避（手順・事実の説明で使う場合） | 「〜です」「〜になります」 |
| 「〜を解説します」だけで終わる導入 | 締まりがない・読者の関心を引けない | 問いかけ＋ベネフィット提示 |
| 「GBP」（略称） | 読者が知らない | 「Googleビジネスプロフィール」→「マップ情報」 |
| 「MEO」（略称） | 読者が知らない | 初出説明後「マップ集客」「マップ対策」 |
| 「CTR」「CTA」「E-E-A-T」 | 読者向け記事では不要な業界用語 | 読者に伝わる日本語で表現 |
| 「**〜**」（アスタリスク強調記法） | テキストのゴミになる | 文章構成・語順・短文独立で表現 |
| 業界No.1・日本一・最強 | 根拠なし最上級（景表法リスク） | 具体的な特徴・強みで表現 |
| 競合他社の名指し批判 | リスクあり | 「一部の業者では〜という事例も」程度 |

## 3. 用語言い換え表（15語）

| 専門用語 | 初出時の書き方 | 以降の言い換え |
|---------|-------------|-------------|
| Googleビジネスプロフィール | ～（Googleマップに表示されるお店の情報ページのことです） | マップ情報、マップページ |
| MEO対策 | ～（Googleマップで上位に表示されるための対策） | マップ集客、マップ対策 |
| SEO | ～（検索結果で上のほうに表示されるための対策） | 検索対策 |
| SNS運用 | ～（InstagramやFacebookなどの投稿を継続的に行うこと） | SNS発信 |
| 口コミ / レビュー | ～（Googleマップなどに書き込まれるお客さまの感想） | 口コミ |
| インサイト | ～（閲覧数・クリック数などのアクセスデータ） | データ、数字 |
| コンバージョン | ～（問い合わせや予約など、集客の成果につながる行動） | 問い合わせ・予約 |
| アクセス解析 | ～（ホームページへの訪問数や行動を分析すること） | アクセスの確認 |
| ランディングページ | ～（広告などからアクセスした人が最初に見るページ） | 集客専用ページ |
| ファネル | ～（認知→検討→行動という顧客の段階） | 集客の段階、流れ |
| ペルソナ | ～（想定するお客さまの具体像） | ターゲットのお客さま |
| KPI | ～（目標達成を測るための指標） | 目標の数字 |
| CTA | 読者向け記事では使わない | 「次の一歩」「問い合わせへの誘導」 |
| オーガニック検索 | ～（広告ではなく、自然な検索結果からの流入） | 自然検索 |
| インプレッション | ～（コンテンツが表示された回数） | 表示回数 |

## 4. 文体・トーンルール

```
【基本スタイル】
- 「あなた」と語りかける（です・ます調）
- 一文60文字以内
- 1段落は3〜4文まで（スマホで1画面に収まる塊にする。長文の壁を作らない）
- 比較・選択肢は表、手順・列挙は箇条書きにする（スキャンして読める構成）
- 漢字2：ひらがな8の感覚（堅くなりすぎない）
- 「伴走者・相談相手」の立場（上から教えない）

【読者への接し方】
- 読者を「オーナーさん」と呼ぶのは自然。「経営者様」は固い。
- 「〇〇ですよね？」という確認調の問いかけが親近感を生む
- 命令形（「〜しなさい」「〜すべき」）は避ける
```

## 5. FAQ作成ルール

FAQは「創作」禁止。以下のいずれかを出典とすること：

1. **PAA（他の人はこちらも質問）**: 対象キーワードのGoogle検索結果に表示されるもの
2. **サジェスト**: 対象キーワードを入力した際にサジェストされるキーワード
3. **現場の実質問**: 実際にオーナーから受けた質問（「よく聞かれます」と注記可）

> ❌ 創作FAQ例: 「Q. GBPとはなんですか？」（記事内で解説済みのことを再度質問にしている）
