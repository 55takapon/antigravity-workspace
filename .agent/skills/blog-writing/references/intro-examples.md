## 基本導入：NG vs OK 比較

### パターン1: 「問いかけ」がない導入

❌ **NG例（知識説明から入るタイプ）**
```
Googleビジネスプロフィール（GBP）を登録したものの、
「この先、何を設定すればいいのかわからない」という方は多いです。
今回はGBPの活用方法について解説します。
```
問題点: 「という方は多いです」(他人事) ／ 「解説します」(締まりのない導入) ／ 読者との距離が遠い

✅ **OK例（問いかけ→共感→ベネフィット）**
```
「Googleマップにお店の情報を載せたほうがいいらしい」——
そう聞いて登録してみたものの、
「登録はした。で、次は何をすればいいの？」と
画面の前で止まっていませんか？

その気持ち、よくわかります。
この記事では、登録後にやるべき3つのことを、
操作の手順ごとにお伝えします。

結論から言うと、「写真・営業時間・説明文」この3つだけ整えれば、
マップからの問い合わせが増えてきます。
```

### パターン2: 「偏見・嫌な記憶を代弁する」上級テクニック

**いつ使うか**: テーマに悪い印象・警戒感・疲れが伴う場合（MEO・SNS運用・HP制作等）

---

#### 実例A: MEO/マップ集客記事

```
「SEOならなんとなく聞いたことがある。でもMEOって、
営業電話が何度もかかってきて正直いい印象がない…」

そう感じているオーナーさんが、実は多いです。わかります。

「よくわからないけど毎月何万円も払ってください」と言われても、
何に払うのか意味が見えなければ、信用できるわけがないですよね。

この記事は、そういった営業代行とは一切関係ありません。
ジェットプロデュースが実際に店舗オーナーと向き合いながら感じてきた
「マップ集客ってこういうことだよ」を、できるだけ正直に、
わかりやすく伝えるものです。
```

---

#### 実例B: SNS運用記事

```
「Instagramは結局、毎日更新しないといけないんでしょ？
もう疲れた…」

そう思って、気づいたら半年以上投稿が止まっている——
そんなオーナーさん、実は少なくないんです。

「頑張ったのに全然フォロワーが増えない」「いいねが来ても予約につながらない」
そういう経験が重なると、SNSそのものが嫌になってしまいますよね。

この記事は「毎日投稿しなければいけない」という思い込みを、
ひとつずつほぐしていきます。
```

---

#### 実例C: ホームページ制作記事

```
「ホームページを作ったのに、全然問い合わせが来ない。
作るだけで何十万円も払ったのに…」

そう感じているオーナーさんの話を、よく聞きます。

制作会社に頼めば「いいものができる」と思っていたのに、
完成してみたら「何か違う」「検索しても出てこない」。
あの後悔、経験した方にはわかると思います。

この記事は、ホームページを「作った後どうするか」について
正直にお話しします。
```

## 導入の型ローテーション（全記事同型化の防止）

「問いかけ→共感→ベネフィット→結論予告」を全記事で同じ並びのまま繰り返すと、
2記事目を読んだ読者に「テンプレだ」と気づかれる。
4要素は必ず含めつつ、冒頭の入り方は以下の3型をローテーションする。
**直近に公開した記事と同じ型を連続で使わない。**

### 型1: 問いかけ型（基本形）

上記「基本導入 OK例」の形。悩みを質問形で言語化して始める。

### 型2: エピソード型

現場の相談場面から始める。使用するエピソードは `primary-info.md` の使用台帳の対象。

```
先日、加古川のカフェオーナーさんから、こんな相談を受けました。

「インスタもマップも一応やってるんです。でも、何が正解か
わからないまま、なんとなく続けてしまっていて…」

もし同じモヤモヤを感じているなら、この記事はそのためのものです。
「なんとなく運用」から抜け出す手順を、順番にお伝えします。

結論から言うと、最初に整えるべきは投稿の頻度ではなく
「お店の基本情報」です。
```

### 型3: 結論先出し型（意外な事実型）

読者の予想を裏切る結論・事実を先に置いて始める。

```
ホームページへのアクセスを増やしたいなら、
最初にやるべきはブログの毎日更新ではありません。

意外に思われたでしょうか。
実は、多くのお店で成果につながりやすいのは
「すでにあるページの手直し」のほうです。

この記事では、なぜ新しい記事を書くより先に
既存ページを整えるべきなのか、その理由と手順をお伝えします。
```

> どの型でも、4要素（悩みの言語化・共感・ベネフィット・結論の予告）は
> 冒頭400文字以内に必ず含めること。型が変わるのは「入り方」だけ。

## 上級テクニックの注意点

```
✅ やること:
- 読者のネガティブな本音をそのまま言語化（引用形式で）
- 「そう感じているのは当然です」と共感・肯定
- 「この記事は○○とは違います」と転換を入れる
- 記事のベネフィットと結論の予告で締める

❌ やらないこと:
- 特定の競合・業者名を出して批判する
- ネガティブな共感で終わる（転換なし）
- 同じ記事内で2回以上使う（慣れると効果ゼロ）
- 嫌な印象が弱いテーマに使う（浮いてしまう）
```
