# 初回ヒアリングシート

このファイルは、初回相談、実案件化、プロフィール改善、月間運用、アカウント分析、素材不足時に必ず読む。

## 目的

Instagram運用の品質差は、投稿制作前の情報整理で決まる。最初に事業目的、対象者、導線、素材、リソースを固定し、足りない情報は質問または仮説として分ける。

## 必須ヒアリング

| 項目 | 確認すること | 不足時の仮置き |
|---|---|---|
| 1. 事業目的 | 認知、保存、相談、購入、来店、採用、信頼構築、ファン化のどれか | 相談/来店を仮目的にする |
| 2. 対象者 | 地域、属性、悩み、購買権限、検討タイミング | 「まだ比較検討中の見込み客」と置く |
| 3. 商材/オファー | 商品、サービス、価格帯、提供範囲、強み | 代表メニューまたは主サービスを仮採用 |
| 4. 導線 | DM、LINE、予約、LP、EC、GBP、来店、資料請求 | 直接予約または問い合わせを主導線にする |
| 5. 既存アカウント | URL、フォロワー、投稿頻度、伸びた投稿、弱い投稿 | 新規アカウントとして扱う |
| 6. インサイト | リーチ、保存、共有、プロフィールアクセス、リンクタップ、DM | 4週間ログ取得を提案する |
| 7. 素材 | 写真、動画、顧客の声、実績、現場、スタッフ、FAQ | 素材ゼロの代替フローを使う |
| 8. リソース | 週の投稿本数、撮影可否、制作担当、確認者、予算、納期 | 週3投稿、月1撮影ブロックで仮置き |
| 9. 制約 | NG表現、法規制、守秘、顔出し、撮影許可、ブランドトーン | 安全側の表現と匿名素材を使う |
| 10. 競合/代替 | 競合アカウント、比較される選択肢、選ばれない理由 | 「価格、実績、近さ、安心感」で仮説化 |

## 最初に聞く質問

情報が足りない時は、質問を最大3つに絞る。

1. 今月Instagramで一番増やしたい行動は何ですか。例: DM、予約、来店、LINE登録、保存。
2. 見てほしい相手は誰ですか。地域、悩み、検討状況を1文で教えてください。
3. 使える素材は何がありますか。写真、動画、実績、口コミ、FAQ、既存投稿URLの有無を教えてください。

## ヒアリングシート出力形式

初回整理では、この順で返す。

1. 目的: 主目的と補助目的。
2. 対象: 誰が、どんな状況で、何を決めたいか。
3. 商材: 提供内容、価格帯、選ばれる理由。
4. 導線: 投稿後に進ませる1本道。
5. 素材: 使える素材、不足素材、代替素材。
6. リソース: 投稿本数、制作体制、撮影可否、確認期限。
7. 制約: NG表現、法規制、守秘、撮影許可。
8. 仮説: 足りない情報をどう仮置きしたか。
9. 作る成果物: 戦略、プロフィール、月間運用、投稿案、分析のどれか。

## 不合格条件

- 目的が「集客したい」だけで、増やしたい行動が決まっていない。
- 対象者が「全員」「男女問わず」「Instagramを見る人」になっている。
- 導線がDM、LINE、予約、LP、EC、来店で分散している。
- 素材とリソースを確認せずに月間投稿本数を決めている。
- 法規制やNG表現の可能性があるのに確認していない。
