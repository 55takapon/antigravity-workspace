# プロフィール導線設計

このファイルは、プロフィール改善、bio、名前欄、ハイライト、ピン留め、リンク導線、DM/LINE/予約導線を作る時に読む。

## プロフィールの役割

プロフィールは投稿後の転換地点。目的は「この人/店/会社は自分向けだ」と3秒以内に理解させ、次の1行動へ進ませること。

## MECE監査フレーム

| 層 | 見る項目 | 合格条件 |
|---|---|---|
| 検索性 | ユーザーネーム、名前欄 | 名前欄に専門キーワード、地域、業種のいずれかが入る |
| 視認性 | アイコン、グリッド、表紙 | 小さく表示されても誰/何のアカウントか分かる |
| 価値宣言 | bio | 誰に、何を、どんな変化を、なぜ任せられるかが分かる |
| 証拠 | ピン留め、ハイライト | 実績、口コミ、FAQ、サービス内容、自己紹介が常設されている |
| 出口 | リンク、DM、LINE、予約 | 次に取る行動が1つに絞られている |

## 名前欄

名前欄は検索される前提で作る。標準は次のどれか。

| 型 | 例 |
|---|---|
| 人名 + 専門 | 田中太郎｜奈良の整体師 |
| 屋号 + 地域 | 静カフェ｜奈良古民家カフェ |
| サービス + 対象 | 中小企業向けInstagram運用 |
| 悩み + 解決 | 肩こり改善｜女性専門整体 |

業種別のbio、ピン留め、ハイライト、主CTAが必要な時は [08_industry_profile_patterns.md](08_industry_profile_patterns.md) を読む。

## bio

150文字以内を前提に、4要素を入れる。

1. 誰向けか。
2. 何が得られるか。
3. 信頼できる根拠。
4. 次に何をすればよいか。

標準テンプレート:

```text
[対象]へ、[得られる変化]を発信
[実績/専門性/地域性]
[提供内容や世界観]
[CTA]
```

CTAは1つだけにする。複数リンクを置く場合も、bio上の主CTAは1つに固定する。
3行目と4行目で同じ行動を繰り返さない。例: 「予約はこちら」と「予約/アクセス」は重複なので、片方は証拠、利用条件、更新情報に変える。

## ピン留め3本

| 位置 | 役割 | 内容 |
|---|---|---|
| 1本目 | 何者か | 自己紹介、思想、対象者、提供価値 |
| 2本目 | 信頼 | 実績、事例、口コミ、Before/After |
| 3本目 | 行動 | サービス案内、無料相談、予約方法、資料 |

ピン留めは、最新投稿ではなく「初訪問者が判断するための常設資料」として選ぶ。

## ハイライト

標準は5から7個。順番も導線として扱う。

| 順番 | ハイライト | 中身 |
|---|---|---|
| 1 | はじめに | 自己紹介、対象者、見てほしい投稿 |
| 2 | サービス | メニュー、料金、流れ、対応範囲 |
| 3 | 実績/口コミ | 顧客の声、事例、数字 |
| 4 | FAQ | よくある不安、準備物、キャンセル、所要時間 |
| 5 | 裏側 | 人柄、現場、制作背景、日常 |
| 6 | 無料特典 | 資料、診断、相談、チェックリスト |
| 7 | アクセス | 店舗、予約、営業時間、地図 |

## リンク導線

原則は1本道。最終行動が明確なら直接URLを使う。

| 最終行動 | 推奨リンク | 補足 |
|---|---|---|
| 予約 | 予約ページ | 空き状況、料金、場所を明示 |
| 相談 | LINEまたはフォーム | 相談で分かることをbioと固定投稿に明記 |
| 購入 | 商品ページ/EC | 商品、価格、配送、FAQへすぐ進める |
| 比較検討 | LPまたは記事 | 料金、事例、FAQ、保証を置く |
| ポートフォリオ | 実績ページ | DMまたはメールへ自然に進める |

複数リンク集を使う時は、1番上を主CTAにし、他リンクは補助情報にする。

## プロフィール監査の出力形式

1. 現状評価: 検索性、視認性、価値宣言、証拠、出口。
2. 問題点: 離脱が起きる箇所。
3. 改善案: 名前欄、bio、ピン留め、ハイライト、リンク。
4. 投稿側への反映: どの投稿からプロフィールへ誘導するか。
5. 計測: プロフィールアクセス、フォロー率、リンクタップ、DM、予約。

## 不合格条件

- bioが自己紹介だけで、対象者とCTAがない。
- bio内で同じCTAや同じ意味の案内を2回繰り返している。
- リンク先が多すぎて主導線が分からない。
- ピン留めが古い告知や偶然バズった投稿だけ。
- ハイライトに価格、FAQ、実績、利用手順がない。
- 投稿のCTAとプロフィールのCTAが違う。
