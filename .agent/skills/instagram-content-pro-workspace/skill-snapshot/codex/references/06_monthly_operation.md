# 月間運用テンプレート

このファイルは、月間投稿カレンダー、週次改善、運用ルーティン、分析ログを作る時に読む。

## 月間運用の目的

毎回の思いつき投稿をやめ、目的、訴求、フォーマット、CTA、計測を事前に決める。投稿数ではなく、仮説検証の回数を増やす。

## 月間設計のMECE構造

| 層 | 決めること | 成果物 |
|---|---|---|
| 戦略 | 今月の目的、対象、主訴求 | 月間テーマ |
| 配分 | 投稿カテゴリと本数 | 投稿ミックス |
| 制作 | 必要素材、撮影、デザイン、代替素材 | 制作リスト |
| 投稿 | 日付、時間、フォーマット、CTA | 30日カレンダー |
| 改善 | KPI、振り返り、次回テスト | 分析ログ |

## 投稿ミックス

標準は週3から5本。毎日投稿は素材と品質を維持できる時だけ使う。

| 目的 | 週3本 | 週5本 |
|---|---|---|
| 発見 | Reels 1 | Reels 2 |
| 保存 | カルーセル 1 | カルーセル 2 |
| 証拠/導線 | 事例またはFAQ 1 | 事例 1、導線投稿 1 |
| 関係維持 | ストーリーズ週3日以上 | ストーリーズ毎日 |

## 素材レベル別の運用

素材状況でルーティンを変える。撮影できない週に、無理にReels制作日を置かない。

| 素材レベル | 状態 | 使う投稿 | 避けること |
|---|---|---|---|
| A. 新規撮影可 | 店舗、現場、スタッフ、商品を撮れる | Reels、Before/After、裏側、体験導線 | 撮影しすぎて確認が詰まる |
| B. 既存素材のみ | 写真、過去動画、口コミ、FAQがある | カルーセル、FAQ、事例、リメイクReels | 同じ素材を文脈なしで再掲する |
| C. 素材ゼロ | 写真も動画もほぼない | テキストカルーセル、質問箱、チェックリスト、撮影依頼投稿 | 架空の実績や顧客の声を作る |

## 30日カレンダーの列

月間カレンダーは必ず30行で作る。週3から5本運用でも、投稿しない日は「ストーリーズ」「制作」「分析」「素材回収」などの運用予定を入れ、省略しない。

| 列 | 内容 |
|---|---|
| 日付 | 1日から30日まで。実月が31日の場合は31日目も追加する |
| 曜日/時間 | 初期は業種別ベンチマーク、後でインサイトで上書き |
| カテゴリ | 発見、保存、証拠、導線、関係、制作、分析 |
| フォーマット | Reels、カルーセル、ストーリーズ、フィード、制作、分析 |
| テーマ | 投稿または作業の主題 |
| 訴求軸 | 悩み、実績、専門性、共感、地域性、安心など |
| CTA | 保存、共有、コメント、DM、LINE、予約、LP、なし |
| 必要素材 | 写真、動画、顧客の声、数字、FAQ、撮影リスト |
| KPI | Views、保存、共有、プロフィールアクセス、DM、予約、完了有無 |
| 次回改善 | 投稿後または作業後に記入 |

## 週次運用

固定曜日ではなく、週ごとに「分析、企画、制作、投稿、反応、素材回収」の6作業を入れる。曜日はクライアントの営業日と撮影可否に合わせて変える。

| 作業 | やること | 素材がない時の代替 |
|---|---|---|
| 分析 | 先週のTOP/FLOP、CTA、プロフィールアクセスを見る | 数値がなければ投稿ログだけ作る |
| 企画 | 今週の目的、投稿3から5本、CTAを確定する | FAQ、よくある相談、失敗談から作る |
| 制作 | Reels撮影、カルーセル制作、キャプション作成 | 既存素材、テキスト、画面収録、図解に置換 |
| 投稿 | 予約投稿または手動投稿、ストーリーズ連動 | 投稿本数を減らし、導線投稿を優先 |
| 反応 | コメント、DM、質問箱、アンケートに対応する | 質問を翌週のネタに変換 |
| 素材回収 | 写真、動画、口コミ、実績、現場メモを集める | 撮影依頼リストを作り、次回撮影日にまとめる |

## 投稿後の計測

| タイミング | 見る指標 | 判断 |
|---|---|---|
| 24時間 | 冒頭維持、初速、ストーリーズ反応 | フックと投稿時間 |
| 72時間 | 保存、共有、プロフィールアクセス | テーマとCTA |
| 7日後 | フォロー、DM、リンクタップ、予約 | 導線と信頼形成 |
| 月末 | TOP3/FLOP3、カテゴリ別成果 | 翌月の配分 |

## 月次改善ルール

1. TOP3投稿は、テーマ、冒頭、訴求、CTA、素材を分解する。
2. FLOP3投稿は、対象ズレ、素材不足、導線ズレ、投稿時間、表現過多に分ける。
3. 翌月は勝ちテーマを2倍にし、負けテーマを削る。
4. 新規テストは月3つまでにする。多すぎると何が効いたか分からない。
5. インサイト数値がない場合は、まず4週間ログを取る。

## 出力形式

月間運用を作る時は、この順で出す。

1. 今月の目的。
2. 投稿ミックス。
3. 素材レベルと代替フロー。
4. 30日カレンダー。
5. 制作素材リスト。
6. 週次ルーティン。
7. 計測ログ。
8. 翌月改善ルール。

## 不合格条件

- カレンダーが30行未満で終わっている。
- カレンダーにCTAがない。
- 投稿カテゴリが偏り、発見か導線だけになっている。
- 必要素材が未定のまま量産計画になっている。
- 素材ゼロ日の代替フローがない。
- KPIがViewsだけ。
- 月末に何を変えるか決まっていない。
