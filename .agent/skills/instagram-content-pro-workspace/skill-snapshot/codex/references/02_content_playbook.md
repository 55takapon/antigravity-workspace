# 制作プレイブック

このファイルは、投稿案、リール台本、カルーセル構成、ストーリーズ、プロフィール改善、月間カレンダーを作る工程で読む。

## 依頼整理

必ず以下を確認する。
初回、情報不足、実案件化では [00_initial_intake.md](00_initial_intake.md) を優先し、この表は投稿制作前の簡易確認として使う。

| 項目 | 確認する内容 |
|---|---|
| 目的 | 認知、保存、相談、購入、来店、採用、信頼構築のどれか |
| 対象 | 誰が、どんな状況で、何に困っているか |
| 一次情報 | 体験、実績、失敗、顧客の声、数値、制作済み素材 |
| 制約 | NG表現、法規制、撮影可否、納期、ブランドトーン |
| 導線 | プロフィール、DM、LINE、予約、LP、店舗来店 |

## フォーマット選定

成果物の種類と投稿フォーマットを混ぜない。まず「戦略、プロフィール、月間運用、投稿案、分析」のどれを作るか決め、投稿を作る場合だけReels、カルーセル、ストーリーズ、フィードを選ぶ。

| 目的 | 推奨フォーマット | 理由 |
|---|---|---|
| 新規接触を増やす | Reels | 非フォロワー接触と視聴維持を狙いやすい |
| 保存と教育を増やす | カルーセル | スワイプ、保存、再読に向く |
| 既存フォロワーと関係を深める | ストーリーズ | 反応、質問、DM、リンク導線に向く |
| 相談や購入へ寄せる | プロフィール改善 + ピン留め | 投稿から流入した人の離脱を減らす |
| 継続運用する | 月間カレンダー | リズム、検証、改善を回しやすい |

## Reelsの作り方

標準は15秒から45秒。深い解説や体験談だけ60秒以上を使う。
冒頭基準は0-3秒で統一する。3秒はView Rateなどの改善確認で見やすい区切りとして扱う。2秒以内に強い映像変化を置ける場合はよいが、スキル上の不合格判定は0-3秒で行う。

| 秒数 | 内容 | 合格条件 |
|---|---|---|
| 0-3秒 | 結論、違和感、質問、強い映像変化 | 音なしでも何の話か分かる |
| 3-12秒 | 問題の具体化、Before、よくある失敗 | 視聴者が自分ごと化できる |
| 12-30秒 | 解決策、証拠、手順、比較 | 1カット1メッセージで余白がある |
| 最後 | 保存、共有、コメント、DM、プロフィール導線 | 目的に合う行動が1つに絞られている |

出力には必ず、秒数別台本、画面テキスト、撮影カット、キャプション、CTA、計測KPIを含める。

## カルーセルの作り方

標準は7枚から10枚。1枚1メッセージで作る。

| 枚 | 役割 | 内容 |
|---|---|---|
| 1 | 表紙 | 誰の何が変わるかを一文で示す |
| 2 | 問題提起 | 読者の悩み、誤解、損失を具体化する |
| 3-6 | 本編 | 手順、比較、チェックリスト、事例を順番に出す |
| 7-8 | 証拠 | 一次情報、顧客の声、数字、Before/Afterを出す |
| 9 | まとめ | 今日使うポイントを3つ以内に整理する |
| 10 | CTA | 保存、共有、DM、プロフィール導線のどれかに絞る |

出力には必ず、各スライドの見出し、本文、デザイン指示、ALTテキスト、キャプションを含める。

## ストーリーズの作り方

標準は3枚から5枚。投稿後の再接触とDM誘導に使う。

1. 1枚目: 日常、問題提起、投稿の入口。
2. 2枚目: アンケート、質問、クイズ、スライダーのいずれか。
3. 3枚目: 投稿または導線への誘導。
4. 4-5枚目: 顧客の声、裏側、補足、FAQ。

## キャプションの作り方

- 1行目はフック。読み手が続きを読む理由を作る。
- 本文は3から8行を標準にする。専門投稿は長くしてもよいが、段落を短くする。
- キーワードは自然な文脈に入れる。羅列しない。
- ハッシュタグは3から5個を標準にする。広すぎるタグだけで構成しない。
- CTAは1つに絞る。保存、共有、コメント、DM、プロフィール導線を混ぜすぎない。

## プロフィール改善

プロフィール改善を求められたら、次を出す。

1. 名前欄: 人名または屋号 + 専門キーワード。
2. bio: 誰に、何を、どんな根拠で、どこへ誘導するか。
3. ピン留め3本: 自己紹介、最高の教育投稿、オファーまたは実績。
4. ハイライト: サービス、実績、FAQ、裏側、無料資料、口コミ。

## インサイト分析

必ず自アカウント内の比較を優先する。
詳しい分析、投稿改善、月次振り返りでは [07_insight_analysis.md](07_insight_analysis.md) を読む。

| 指標 | 見る意味 |
|---|---|
| View Rate / 冒頭維持 | フックが効いているか |
| 平均視聴時間 / 完視聴 | 内容が最後まで届いたか |
| 保存率 | 後で見返す価値があるか |
| 共有率 | 誰かに送りたい価値があるか |
| プロフィールアクセス | 投稿から導線へ進んだか |
| フォロー率 / DM数 | 関係構築または商談化につながったか |

分析出力は、勝ち投稿、負け投稿、仮説、次回テスト、必要素材の順で書く。
