# 月間カレンダーの出力例

この例は30日分を省略しない。週3から5本運用でも、投稿しない日はストーリーズ、制作、分析、素材回収を入れる。

## 入力

- 業種: Web制作会社
- 目的: 中小企業から月5件の相談
- 対象: 20名以下の中小企業経営者
- 訴求軸: Web集客、制作後の改善、GBP/MEO、費用対効果、事例
- 導線: 無料相談フォーム
- 運用可能本数: 週4投稿、ストーリーズ週3回
- 素材レベル: B. 既存素材のみ。制作事例、FAQ、画面キャプチャ、顧客の声はあり。新規撮影は月1回。

### 週次改善

毎週末にTOP投稿とFLOP投稿を1本ずつ選ぶ。

見る項目:
1. CTAに対する反応。
2. プロフィールアクセス。
3. 保存と共有。
4. Views。

翌週の修正:
- プロフィールアクセスが高い投稿は、同テーマで導線投稿を追加する。
- 保存が高い投稿は、カルーセル第2弾を作る。
- Viewsだけ高い投稿は、相談導線へ接続する続編を作る。
- 素材が不足した週は、FAQ、既存画面、テキストカルーセルに切り替える。
