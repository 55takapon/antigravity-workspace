# プロフィール監査の出力例

## 入力

- 業種: 奈良の古民家カフェ
- 目的: 新規来店、予約、保存
- 現状bio: 古民家カフェです。ランチとスイーツを提供しています。
- リンク: 複数リンク集
- ハイライト: 日常、ランチ、店内
- ピン留め: なし

## 出力

### 現状評価

| 項目 | 評価 | 理由 |
|---|---|---|
| 検索性 | 要改善 | 名前欄に地域名、業態、利用シーンが入っていない |
| 視認性 | 未確認 | アイコンとグリッドの情報がない |
| 価値宣言 | 要改善 | 誰が、なぜ行きたい店なのかが弱い |
| 証拠 | 要改善 | 口コミ、予約方法、価格、席情報が常設されていない |
| 出口 | 要改善 | 複数リンクで予約導線が薄まっている |

### 改善案

名前欄:
静カフェ｜奈良の古民家ランチ

bio:
奈良で静かにランチを楽しみたい方へ  
古民家空間で季節ランチと手作りスイーツ  
営業日・席情報はハイライトで更新  
予約/アクセスは下のリンクへ

ピン留め3本:
1. はじめての方へ: 店内、席、利用シーン、アクセス。
2. 季節ランチ: メニュー、価格、予約の必要性。
3. お客様の声/FAQ: よくある質問、駐車場、混雑時間。

ハイライト:
はじめに、ランチ、スイーツ、口コミ、FAQ、アクセス、予約。

リンク:
最上段は予約ページ。複数リンク集を使う場合は、予約、営業日、アクセスの3つまでにする。

### 投稿側への反映

- ReelsのCTA: 「営業日と予約はプロフィールから」
- カルーセルのCTA: 「保存して、来店前にFAQを確認」
- ストーリーズ: アンケート後に予約リンクを出す

### 計測

- プロフィールアクセス率
- リンクタップ率
- ストーリーズリンクタップ
- 予約時のInstagram経由申告
- DMでの席/営業時間質問数
