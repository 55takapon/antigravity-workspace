# Instagram実践投稿運用

## 概要

日本向けのInstagram運用で、アカウント戦略、プロフィール導線、月間運用、投稿企画、制作指示、投稿文、分析、改善までを実務で使える形にする。旧来の「それっぽいSNS案」ではなく、ユーザーの一次情報、公開事例、公式情報、インサイト数値から勝ち筋を作る。

## ワークフロー

1. 依頼を整理すること。
   - 入力: 目的、ターゲット、業種、投稿素材、一次情報、既存アカウント、直近インサイト、制約。
   - 出力: 今回の目的、足りない素材、仮説、作る成果物を箇条書きで確定する。
   - 初回、情報不足、実案件化、月間運用、プロフィール改善では、必ず [references/00_initial_intake.md](references/00_initial_intake.md) のヒアリングシートで整理する。
   - 最新仕様、成功事例、アルゴリズム根拠が必要な場合は、必ずWebまたはユーザー提供資料で確認すること。確認時は [references/01_research_evidence.md](references/01_research_evidence.md) を読む。
   - このステップの完了条件を満たすまで、次のステップに進んではならない。

2. 成果物の種類と投稿フォーマットを分けて選ぶこと。
   - 入力: 目的と素材。
   - 出力1: 成果物の種類。アカウント戦略、プロフィール導線、月間カレンダー、投稿案、投稿改善、アカウント分析、インサイト分析のうち推奨1案と補助案。
   - 出力2: 投稿を作る場合のフォーマット。Reels、カルーセル、ストーリーズ、フィードのうち推奨1案と補助案。
   - アカウント戦略や訴求設計が必要なら [references/04_account_strategy.md](references/04_account_strategy.md) を読む。
   - プロフィール、ハイライト、ピン留め、リンク導線が必要なら [references/05_profile_funnel.md](references/05_profile_funnel.md) を読む。
   - 月間カレンダー、投稿頻度、週次改善が必要なら [references/06_monthly_operation.md](references/06_monthly_operation.md) を読む。
   - インサイト、アカウント分析、投稿改善が必要なら [references/07_insight_analysis.md](references/07_insight_analysis.md) を読む。
   - 業種別プロフィール型が必要なら [references/08_industry_profile_patterns.md](references/08_industry_profile_patterns.md) を読む。
   - リール台本を複数本作る場合は [references/09_reels_script_matrix.md](references/09_reels_script_matrix.md) を読む。
   - 制作ルールが必要なら [references/02_content_playbook.md](references/02_content_playbook.md) を読む。
   - このステップの完了条件を満たすまで、次のステップに進んではならない。

3. 成果物を作ること。
   - 入力: 確定したフォーマット、一次情報、根拠、制約。
   - 出力: 戦略シート、プロフィール改善案、月間カレンダー、投稿案、リール台本、カルーセル構成、キャプション、ハッシュタグ、ストーリーズ展開、制作メモ、計測KPI。
   - 投稿の出力例が必要なら [examples/good-output.md](examples/good-output.md) を読む。
   - プロフィール監査の出力例が必要なら [examples/profile-audit-output.md](examples/profile-audit-output.md) を読む。
   - 月間運用の出力例が必要なら [examples/monthly-calendar-output.md](examples/monthly-calendar-output.md) を読む。
   - CTAは「保存」「共有」「コメント」「DM」「プロフィール導線」のうち目的に合うものだけを選ぶ。
   - このステップの完了条件を満たすまで、次のステップに進んではならない。

4. 品質チェックを必ず行うこと。
   - 入力: 作成した成果物。
   - 出力: 合格、不合格、修正済みの差分。
   - 必ず [references/03_quality_and_update.md](references/03_quality_and_update.md) の品質ゲートで確認し、不合格なら修正する。
   - 未実施の品質チェックがある場合、完了報告してはならない。

5. スキル更新依頼なら更新すること。
   - 「このスキルを改善して」「精度を上げて」「使いながらアップデート」などの依頼では、必ず [references/03_quality_and_update.md](references/03_quality_and_update.md) の更新手順に従う。
   - 今回だけの好み、未確認の噂、感情的な注意文を恒久ルールにしてはならない。
   - 更新後は必ず簡易シナリオで動作確認すること。

## 標準出力

通常の投稿制作では、以下の順で返す。

1. 方針: 目的、アカウント役割、作る成果物、投稿がある場合の推奨フォーマット、狙う行動。
2. 素材不足: 足りない情報と、仮置きした前提。
3. 導線: プロフィール、ピン留め、ハイライト、リンク、DM/LINE/予約導線。
4. 投稿案: 台本、スライド構成、キャプション、CTA。
5. 制作メモ: 撮影、デザイン、投稿前チェック。
6. 計測: 投稿後24時間、72時間、7日後、月次で見るKPI。

## エッジケース

| 状況 | 対応 |
|---|---|
| 素材がほぼない | まず質問を最大3つに絞る。急ぎなら仮説を明記して叩き台だけ作る。 |
| 撮影できない週がある | 素材レベルを判定し、既存素材、FAQ、テキストカルーセル、ストーリーズ質問箱で代替する。 |
| 医療、金融、法律、健康効果を扱う | 断定表現を避け、公式資料またはユーザー提供根拠を必ず確認する。 |
| ユーザーが「最新」「成功事例」「プロ事例」を求める | 必ずWeb確認し、根拠と推測を分ける。 |
| インサイト数値がない | 汎用ベンチマークで断定せず、次回取得すべきKPIを指定する。 |

## 禁止事項

- 根拠のない「アルゴリズム最新情報」を断定してはならない。
- 他アカウントの投稿文、構成、画像をそのままコピーしてはならない。
- ハッシュタグ、いいね、保存だけで成果が出るように見せてはならない。
- 露骨なエンゲージメント稼ぎ、誇大広告、実績の水増しを提案してはならない。
- プロ事例を確認していないのに「成功事例」として扱ってはならない。

## 自己完了確認

完了前に必ず確認すること。

- [ ] 依頼目的、ターゲット、素材不足を整理した。
- [ ] 成果物の種類と投稿フォーマットを分けて選び、理由を書いた。
- [ ] 一次情報または確認済み根拠を使った。
- [ ] CTAとKPIが目的に合っている。
- [ ] 品質ゲートを実行し、不合格箇所を修正した。
