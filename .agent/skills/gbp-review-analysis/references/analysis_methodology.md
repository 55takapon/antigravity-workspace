> SKILL.md のセクション3で参照される詳細資料

## 1. テーマ分類の設計思想

口コミ本文に含まれるキーワードを、事前定義した業種別辞書で照合し、テーマに分類する。
1つの口コミが複数テーマに該当することがある（例: 「美味しくて接客もいい」→ 味・品質 + 接客）。

### 分類粒度のバランス

- **粗すぎる**: 「良い/悪い」だけでは改善アクションに落とせない
- **細かすぎる**: カテゴリが20個あると読み手が混乱する
- **推奨**: 業種あたり6-8テーマが最適

## 3. 感情分析辞書

### ポジティブキーワード（29語）
美味し, おいし, 最高, 素晴らし, 嬉し, 楽し, 満足, おすすめ, オススメ, リピ, また行, また来, 大好き, 絶品, 感動, 幸せ, 感謝, 丁寧, 親切, 笑顔, コスパ, 本格, ジューシー, 柔らか, お気に入り, 癖になる, 間違いない, 文句なし, 大満足

### ネガティブキーワード（19語）
残念, 不満, 微妙, 期待外れ, 冷た, うるさ, 騒, 高い, 不味, まずい, 汚, 狭, 遅い, 待たさ, 対応が悪, 感じが悪, 二度と, 不衛生, 物足りな

### 感情判定ロジック

```
posScore = ポジティブKW出現数 + (星4以上なら+2)
negScore = ネガティブKW出現数 + (星2以下なら+2)

posScore > negScore → ポジティブ
negScore > posScore → ネガティブ
同点 → 中立
```

## 4. 辞書のメンテナンス方針

- 実運用で新たなキーワードを発見したら追記する
- 業種ごとに最低5つ、最大10テーマを維持
- 汎用（general）辞書はフォールバック用に保守
