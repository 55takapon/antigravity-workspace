# 出力例（正常系・異常系）

実データがない案件で完成文をコピーしないこと。ここでは出力の型と、移植パターン（旧3col-design-toolの実CSS由来）を使った構成例を示す。文言・色は案件の材料カードから毎回作る。

---

## 例1（正常系）: 「税理士サイトの『選ばれる理由』を3項目で作って」

### 入力

- 業種: 税理士事務所
- 項目: 相続税申告の実績 / 節税提案 / 決算・顧問対応
- 補足ヒアリング結果: 問い合わせの7割が相続。ブランド色 ネイビー #1e3a5f × ゴールド #c8a96e

### 出力（この構成で返す）

**1. レイアウト判定結果**

- 採用型: 主役1+補助2型（2:1グリッド、相続を主役に写真+面積で強調）
- 採用理由: 3項目は対等ではなく、問い合わせの7割を占める相続が主契機のため
- 不採用型と理由: 造形差つき3カラム型 — 対等扱いになり主契機が埋もれる / ステップ型 — 順序がない
- 造形ルール: （3カラム非採用のため対象外。主役側にP5オーバーラップ、補助側はP1ファインラインを使用）

**2. 確定トークン表 + コントラスト検証表**

| テキスト色 | 背景色 | 比率 | 判定 |
|:---|:---|:---|:---|
| #1f2a37 | #ffffff | 14.5:1 | 合格 |
| #ffffff | #1e3a5f | 11.5:1 | 合格 |
| #8a6d3b（金の暗色調整後） | #ffffff | 4.8:1 | 合格（元の #c8a96e は白文字と2.2:1で不合格のため小さい文字への使用を禁止し、罫線・CTA背景のみに限定） |

**3. SWELL貼付用コード**（スコープ済み・カスタムプロパティ・959px/599px込みの完全なHTML/CSS）

**4. 貼付手順**: A. カスタムHTMLブロック方式 / 難易度 hard（オーバーラップの調整箇所を明記）

**5. プレビュー保存先と確認結果**: `（案件フォルダ）\preview\reason-section.html`、959px/599pxの崩れなし、シルエットテスト合格

## 例2（異常系）: 「背景をゴールド #c8a96e にして文字は白で」

### 入力

- ユーザー指定: 背景 #c8a96e / 文字 #ffffff

### 出力（この構成で返す）

**コントラスト検証で不合格のため、そのまま実装しない。**

- 検証結果: #ffffff × #c8a96e = 2.2:1（本文基準4.5:1、大見出し基準3:1のいずれも不合格）
- 対応: ブランド色は変えずにテキスト側・背景階調側を調整した代替2案を提示する
  - 案A: 背景はゴールドのまま、文字を #3d2f14（濃茶）へ → 5.8:1 合格
  - 案B: ゴールドは罫線・ラベルに限定し、背景を #faf6ee（生成り）+ 文字 #1f2a37 → 13.5:1 合格
- ユーザーが選定するまでコード生成（ステップ4）へ進まない
