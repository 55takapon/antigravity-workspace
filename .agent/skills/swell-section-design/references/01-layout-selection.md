# レイアウト型の判定基準

## 何をするか

セクション材料カード（目的・項目・主従関係）から、レイアウト型を1つ選ぶ。
「3項目だから3カラム」という項目数ベースの判断を禁止し、情報の役割ベースで判定する。

## 使う材料

- セクション材料カード（ステップ1の出力）
- 業種別方針（website-production 案件の場合）
- 写真素材の有無と品質

## 判定表（上から順に確認し、最初に合致した型を採用する）

| 情報の役割 | 採用する型 | 型の骨格 |
|:---|:---|:---|
| 順序・手続きがある（流れ・ステップ・工程） | ステップ型 | 番号＋接続線または矢印。番号を視覚の主役にする |
| プラン・料金・コースを選ばせる | 比較表型 | 表またはカード比較。推奨プランに主従差をつける |
| 1つが主契機で他は補助（例: 相続が主、顧問・決算が補助） | 主役1+補助2型 | 2:1グリッド。主役は写真・面積・余白で明確に大きく |
| 項目が4つ以上ある、または短い定義の列挙 | 罫線編集リスト型 | border-top罫線＋余白のみのエディトリアル。カード化しない |
| 写真が主役として成立する（空間・料理・施工例・人物） | 写真主役バナー型 | 写真7割＋短いラベル。文字で説明しない |
| 上記に該当せず、3項目が本当に対等 | 造形差つき3カラム型 | 下記の造形ルールを最低2つ適用した3カラム |

## 3カラムを採用する場合の造形ルール（最低2つ必須）

1. **番号**: 背景大数字（透過6〜8%）または先頭ナンバリング
2. **写真比率**: カード上部に写真、比率は3枚で統一（16:10前後）
3. **罫線**: border-top 1本のみのファインライン。影と併用しない
4. **ラベル**: 英字または業務カテゴリの小ラベル（11〜13px・letter-spacing広め）
5. **主従差**: 1枚目だけ背景色・面積・要素数を変える
6. **余白差**: gap 40px以上をとり、カード内は詰める（余白で区切り、線と影を減らす）

適用した2つを判定結果に記録する。「影＋角丸＋ホバー浮上」だけの組み合わせは造形ルールに数えない（既製テーマの既定値と区別がつかないため）。

## 型ごとの避ける条件

| 型 | 避ける条件 |
|:---|:---|
| ステップ型 | 順序が実際にはない内容に番号を振らない |
| 比較表型 | 比較軸が1つしかない場合は使わない（罫線リストへ） |
| 主役1+補助2型 | 主役を決められない（全部推したい）場合は使わない。先に主役を決めてもらう |
| 罫線編集リスト型 | 各項目に長い説明文が必要な場合は使わない（詳細は下層ページへ送る） |
| 写真主役バナー型 | 写真が低品質・未提供の場合は使わない。生成写真で代用する場合は website-production の画像工程を通す |
| 造形差つき3カラム型 | 同一ページ内で2回以上使わない（シルエット重複） |

## 見る観点

- ぼかして見ても、同じ白背景・中央見出し・角丸カードの繰り返しに見えないか
- 各項目の説明文を半分に削っても意味が通るか（通るなら削る）
- 主役素材（良い写真・強い実績数値）を小さな添え物として弱く扱っていないか
- 同一ページの他セクションとシルエットが重複していないか

## 出力形式

判定結果は次の項目で記録する。

- 採用型: （型名）
- 採用理由: （情報の役割との対応を1〜2文）
- 不採用型と理由: （検討した型ごとに1行）
- 適用する造形ルール: （3カラム採用時のみ、2つ以上）

## 不合格時の対応

- 主従関係が決められない場合は、型を仮決めして進めず、ステップ1へ戻り主役を確認する
- どの型にも合致しない場合は、罫線編集リスト型を基準に据えた上で、ユーザーへ2案を提示する
