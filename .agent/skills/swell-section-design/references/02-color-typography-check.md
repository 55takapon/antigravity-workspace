# 配色・タイポグラフィの確定と検証

## 何をするか

レイアウト判定結果に対して、色と文字をトークンとして確定し、コントラスト比を数値で検証する。
旧ツール（3col-design-tool）の失敗原因だった「背景色は変えられるのにテキスト色が固定」を再発させないための工程。

## 使う材料

- セクション材料カード（ブランド色・仮置きトークン）
- レイアウト判定結果
- デザイントークン初期値・日本語タイポグラフィ基準: `../../website-production/references/03-site-design.md`（トークン表・フォントペア表はこのファイルを正本とし、本ファイルへ複製しない）

## トークン導出ルール

- 色トークンは「ベース（背景）/ テキスト / プライマリ / アクセント（CTA専用）」の4役割で確定する
- テキスト色は必ずベース色から導出する。明るいベースなら濃色テキスト、暗いベースなら明色テキストを割り当て、固定値 `#1a1a1a` や `#555` をベース無関係に流用しない
- 罫線色はテキスト色の20〜30%透過、背景階調はベース色の±3〜6%の明度差で作る
- アクセント色はCTAと1箇所の強調にだけ使う。カード全面・見出し全部への使用は禁止

## コントラスト検証手順（省略禁止）

1. テキストが載る「テキスト色 × 背景色」の全ペアを列挙する（カード上・写真オーバーレイ上・バッジ内も含む）
2. 各色の相対輝度を計算する: sRGB各成分を0〜1化し、`c <= 0.04045 ? c/12.92 : ((c+0.055)/1.055)^2.4` で線形化後、`L = 0.2126R + 0.7152G + 0.0722B`
3. コントラスト比 `(L明 + 0.05) / (L暗 + 0.05)` を求める
4. 合格基準: 本文・小さめテキストは **4.5:1以上**、24px以上（太字は18.5px以上）の大見出しは **3:1以上**
5. 写真の上に載せる文字は、写真の最暗部/最明部が読めない前提で、グラデーションスクリムまたは帯を敷いてから判定する
6. 全ペアの数値を検証結果として記録する

計算はスクリプト・電卓のどちらでもよいが、目視の「読める気がする」で合格にしてはならない。

## タイポグラフィ確定ルール

- 本文16px基準・line-height 1.8前後・letter-spacing 0.02〜0.05em、見出しはline-height 1.3〜1.5（詳細な数値・フォントペアは上記 03-site-design.md の「日本語タイポグラフィ基準」を必ず参照する）
- 同一セクション内の文字サイズは3段階まで（ラベル/見出し/本文）。4段階以上使う場合は情報を削る
- 英字ラベルを使うのは1セクション1箇所まで。全項目の頭に英字ラベルを並べる処理は既製テンプレの主因なので避ける
- メインとなる見出しは意味の切れ目で改行位置を制御する

## 出力形式

- 確定トークン表（色4役割＋spacing＋角丸＋罫線＋影の採用値）
- コントラスト検証表: 「テキスト色 / 背景色 / 比率 / 判定」の行を全ペア分

## 確認方法

- 全ペアが基準値以上であること
- テキスト色・罫線色がトークン導出で決まっており、根拠なしの固定値がないこと

## 不合格時の対応

- テキスト色の明度を先に調整する（ブランド色そのものは変えない）
- それでも不合格なら背景階調を調整する
- ブランド指定色同士の組み合わせが原因で調整できない場合は、代替配色を2案作りユーザーに選定を仰ぐ
