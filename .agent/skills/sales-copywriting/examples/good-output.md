# 出力の型と実例の所在

## 実例（実データ）の所在

作成者が創作した完成文は実例として置かない方針のため、実際に稼働している提案文本文は実ファイルを直接読むこと:

```
C:\Users\hangy\.cursor\test\contact-form-assist\config\profiles\
├── web-company.json      ← subject + message に実際の提案文全文
├── web-marketing.json
└── web-production.json
```

`message` フィールドが提案文本文（{{company}} 等の差し込みプレースホルダー入り）。改善時はこの実文を旧版として引用・比較する。

## 型1: 提案文の出力構造（7ブロック）

```
件名: 〔20字以内。相手のメリットor課題。自社名なし〕

〔Block1: 宛名+名乗り+権威性の事実1つ。2〜3行〕
〔Block2: 相手の業種・事業への具体的言及。1〜2行〕
〔Block3: 「同業種でよく聞く声」の箇条書き2〜3点〕
〔Block4: 「1つでも当てはまれば、お役に立てます」系の橋渡し1行〕
〔Block5: ①②③で貴社主語の理想の未来。3〜5行〕
〔Block6: 15分の情報共有CTA+カジュアルでOKの一言+実績URL。1〜2行〕
〔Block7: 社名・氏名の署名2行〕
```

## 型2: 納品時の検証報告（ステップ4で必ず添える）

```
文字数実測: 本文〔N〕字（目標600〜800 / 上限1,000未満）… OK/超過
件名: 〔N〕字（上限20）… OK/超過
sales-copywriting-qa 判定: 合格 / 要修正（→修正して再検査）
```

## 型3: プロファイル反映時の記録（ステップ5）

```
追加ファイル: 〔業種〕-v〔N〕.json（既存版は残置）
pdca-log 記録: 前版の懸念点 / 変えた点 / 良くなる仮説 / 検証結果（送信後追記）
```
