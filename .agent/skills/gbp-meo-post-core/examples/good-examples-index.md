# 良好事例インデックス

このファイルは、ユーザーが選定済みの良好投稿だけを追加する場所。現時点では良好事例本文を追加しない。

## 追加前チェック

- [ ] ユーザーが良好事例として明示的に選定した
- [ ] 出典パスがある
- [ ] クライアントと業種が分かる
- [ ] 主な読者、GBP投稿種別、投稿目的型、意思決定段階、切り口が分かる
- [ ] 採用理由が分かる
- [ ] 抽出できる再利用ルールがある
- [ ] 使ってはいけない条件が書ける
- [ ] 未確認事実、口コミ風表現、季節・家庭状況の断定を成功法則として扱っていない

## 運用ルール

- 作成者が想像した投稿本文を良好事例として追加してはならない。
- ユーザーが選定していない投稿を、仮の良好事例として追加してはならない。
- クライアント固有の価格、キャンペーン、個人情報、機密情報を汎用ルール化してはならない。
- 失敗例は [failure-patterns.md](failure-patterns.md) に入れ、良好事例へ混ぜない。
