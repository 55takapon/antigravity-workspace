# 冒頭設計とベネフィット翻訳のルール

## 目的

ファクトガード([02-fact-guard-writing-rules.md](02-fact-guard-writing-rules.md))を通過した確認済み材料を、読まれて行動につながる文章に変換する。事実の羅列で終わる平坦な投稿は、全チェックに合格していても不合格として扱う。

このルールとファクトガードが矛盾して見える場合は、必ずファクトガードを優先する。訴求のために未確認事実や断定を戻してはならない。

## 使う材料

- 工程1で確認済みになった材料だけを使う。
- 翻訳・言い換えの過程で、新しい事実、感情の断定、効果保証を追加してはならない。

## 共通ブロック構造

投稿は「見出し・タイトル(必要な場合)→固定冒頭(定義時のみ)→可変本文→固定フッター(定義時のみ)」で扱う。

- 固定冒頭は共通ブランドブロックであり、ナレッジの文言・位置・改行を正とする。固定フッターも同様に扱う。
- ナレッジに定義がない固定文は推測で作らない。クライアント固有文言をこのコアスキルへ書かない。
- 第1文、冒頭100文字、冒頭3秒、問いかけ、続きを読む理由の評価は、固定冒頭を除いた可変本文の冒頭へ適用する。固定冒頭が問いかけでないことを不合格理由にしない。
- 固定冒頭、可変本文、固定フッターを分けて文字数を管理する。キーワードと文字数はナレッジ指定を優先し、指定がない場合のみ標準値を使う。

## 投稿目的別の3型

業種ではなく投稿目的で、次のいずれか1つを選ぶ。

### A. 課題・疑問型

医療、歯科、士業、学習塾、車買取、マーケティング支援、悩み起点のサロン投稿、FAQ、予防啓発などに使う。

具体的な生活場面または問いかけ → 読者の気持ちや行動への共感 → 意外な気づき1つ → 確認済みの理由 → 不安や負担を軽くする説明 → 判断材料または実行しやすい行動1〜3個 → 目的に合った次の一歩。

### B. 魅力・価値型

飲食店の商品・料理紹介、季節メニュー、商品紹介、サロンのスタイル提案、サービスの特徴紹介などに使う。

商品・料理・サービスの魅力や新情報 → 確認済みの具体的特徴 → 選ぶ理由、楽しみ方、利用場面 → 提供条件や判断材料 → 目的に合った次の一歩。悩みへの問いかけや共感を無理に入れない。

### C. 告知型

キャンペーン、イベント、営業時間変更、休業案内、新サービス、期間限定企画などに使う。

結論 → 日時・対象・内容 → メリット・注意点 → 必要な行動。問いかけではなく、確定情報を先に出す。

## 可変本文の冒頭設計

### 標準ルール

- 課題・疑問型は具体的な生活場面または問いかけから始める。
- 魅力・価値型は商品・料理・サービスの魅力や新情報から始める。
- 告知型は確定した結論から始める。
- 共通の合格条件は、可変本文の冒頭で読者が続きを読む理由を示せていることとする。

### 問いかけと断定の境界

問いかけは読者に判断を委ねる形式であり、断定ではない。ただし問いかけ形式にすれば何を書いてもよいわけではない。

| 判定 | 例 | 理由 |
|:---|:---|:---|
| 使ってよい | 「〜を選ぶとき、何を基準にすればよいか迷ったことはありませんか」 | 読者に判断を委ねている |
| 使ってよい | 「〜という選択肢があるのをご存じですか」 | 確認済みサービスへの導入 |
| 使ってはならない | 「〜でお悩みのはずです」「皆様〜だと思います」 | 問いかけではなく断定 |
| 使ってはならない | 「子育て中の皆さん、毎日大変ですよね?」 | 問いかけ形式でも家庭状況の決めつけ |
| 使ってよい | 「暑い日が続きますが、〜」など季節の一般事実からの導入 | カレンダー事実は断定ではない。ただし同じ読者・テーマ・切り口・読後行動の組み合わせを繰り返さない |
| 使ってはならない | 「夏バテで食欲が落ちている方が多いはずです」 | 季節から読者の体調を断定 |

### テンプレ化の防止

- 同一クライアントの月次投稿で、前回と同じ冒頭型・同じ問いかけ表現を繰り返してはならない。過去投稿との照合時に冒頭の型も確認すること。
- 「〜ではありませんか?」を毎回使わない。「〜をご存じですか」「〜と迷ったことはありませんか」「なぜ〜なのか」など、問いの角度を変える。

## ベネフィット翻訳

### 3段変換

確認済み事実を、次の3段で読者側の価値に翻訳する。

1. 事実: 確認済み材料に書かれていること
2. 意味: その事実は何を可能にするか(「だから何?」に答える)
3. ベネフィット: 読者が何をできるようになるか・何を判断できるようになるか

ベネフィットは「読者の行動可能性・判断可能性」で書く。「安心できます」「満足できます」のような感情の断定に翻訳してはならない。それはベネフィットではなく効果保証である。

### 翻訳の型

前提: 左列の事実が出典付きで確認済みの場合の型。事実が未確認なら翻訳以前に使用不可。

| 確認済み事実 | 平坦な書き方(避ける) | ベネフィット翻訳の型 |
|:---|:---|:---|
| 無料体験授業を実施(公式サイト) | 無料体験授業を実施しています | 入塾を決める前に、授業の進め方や教室の雰囲気を実際に確かめられます |
| 初回にカウンセリングを実施(knowledge) | 初回カウンセリングを行います | 施術の前に体の状態や気になる点を伝えられるため、内容を理解したうえで受けるか決められます |
| 相続手続きの相談に対応(公式サイト) | 相続のご相談に対応しています | 依頼するかどうかを決める前に、手続きの進め方や必要な準備を確認できます |
| 季節限定メニューを提供中(ユーザー提供) | 季節限定メニューがあります | 提供期間が決まっているため、来店時期を決める判断材料になります |

### 翻訳の適用範囲

- 投稿の主要な訴求1〜2点に絞って翻訳する。全文をベネフィット文にすると説明の信頼感が失われる。
- 翻訳後の文がファクトガードの禁止カテゴリ(感情断定、効果保証、状況の決めつけ)に該当しないか、必ず翻訳の直後に確認すること。

## ライティングの共通原則

- 1投稿につきテーマと読後に残すメッセージを1つに絞る。
- 課題・疑問型では、注意や説明の前に読者の気持ちを一度受け止める。
- 禁止や不安だけで終わらせず、無理なくできることや判断材料を示す。
- 確認済み事実を、読者が判断・行動できる価値へ翻訳する。
- 未確認事実、感情の断定、結果保証を追加しない。
- 季節の一般事実は使えるが、読者の予定、家庭状況、体調、来店行動を断定しない。

## 意思決定段階に合わせた情報設計

投稿の狙いを絞る際、読者の意思決定段階を1つ選び、段階に合わない内容を混ぜない。

| 段階 | 読者の状態 | 書く内容 | CTAの温度 |
|:---|:---|:---|:---|
| 認知 | 悩みや選択肢を言語化できていない | FAQ、悩みの整理、専門的な見方 | 情報確認、セルフチェック、振り返り、CTAなし |
| 比較 | 選び方・判断基準を探している | 選ぶ基準、確認済みの対応範囲、利用前の判断材料 | 相談、問い合わせ |
| 行動 | 利用直前の最終確認をしたい | 利用の流れ、準備、注意点、予約方法 | 予約、来店の具体的な導線 |

認知段階の読者に予約を迫る、行動段階の読者に基礎知識を長く説くなど、段階とCTAの不一致を作らないこと。

## CTAの書き方

- クライアントナレッジ、投稿目的、読者の意思決定段階に合わせ、相談、問い合わせ、予約、来店、注文、査定、体験、メニュー・詳細確認、プロフィール確認、セルフチェックから次の一歩を選ぶ。認知目的では、明確な営業CTAを置かず気づきや振り返りで締めてもよい。
- 飲食店の商品紹介に相談CTAを付けるなど、投稿目的と合わないCTAは禁止する。
- 「今すぐ」「お急ぎください」など煽りの命令形を使わない。
- 意思決定段階との不一致(認知向けFAQ投稿で予約を迫るなど)は避ける。簡潔なままで、温度だけ段階に合わせる。
- 結果の保証(「解決します」「効果を実感できます」)へ戻さない。

## 自己チェック

投稿文の完成後、次を確認する。1つでも不合格なら修正して再確認すること。

| テスト | 合格条件 |
|:---|:---|
| 冒頭3秒テスト | 固定冒頭を除く可変本文の冒頭だけを読んで、続きを読む理由があるか |
| だから何テスト | 主要訴求1〜2点に「読者が何をできるようになるか」が書かれているか |
| 一人テスト | 想定読者一人に向けた文になっているか。全員向けの平坦な案内文になっていないか |
| テンプレ臭テスト | 可変本文の冒頭型、核となる気づき、読後行動が同月・直近投稿と重複していないか |
| ファクトガード再確認 | 翻訳の過程で感情断定、効果保証、状況の決めつけに戻っていないか |

## 不合格時の対応

- 可変本文の冒頭が平坦な場合は、確認済み材料から選択した投稿目的型に合う魅力・論点・結論を探す。問いかけへの変換を強制しない。
- ベネフィットに翻訳できない事実しかない場合は、無理に翻訳せず、判断材料・FAQとして淡々と書く。無理な翻訳は感情断定への入り口になる。
- 問いかけが決めつけに見える場合は、対象を限定しない問いへ広げるか、結論の先出しに切り替える。
- テンプレ臭テストで不合格の場合は、言い回しだけでなく対象読者または企画の切り口から差し替える。
