# 事実確認と表現ルール

## 目的

投稿文から、未確認事実、口コミ風表現、季節・家庭・来店状況の断定、効果保証を標準で除外する。ユーザーが毎回指示しなくても、このルールを投稿作成時の前提として適用する。

## 事実確認の基準

確認済み材料として扱えるのは、次のいずれかで明示されている内容だけ。

- ユーザーが今回の依頼で明示した情報
- 公式サイト、LP、メニュー、サービスページに書かれている情報
- クライアントフォルダ内の現行 knowledge、制作資料に書かれている情報
- 実際の口コミ、レビュー、アンケート、ユーザー提供の感想として出典がある情報

過去投稿と良好事例は、トーン、構成、重複、履歴の参考資料とする。そこに書かれた事実を新しい投稿で再利用する場合は、現行 knowledge、公式資料、またはユーザー提供情報で再確認し、過去投稿や良好事例だけを現在事実の根拠にしない。

次は確認済み材料として扱わない。

- 業種からの推測
- 季節や月からの読者状況(予定・家庭・体調・来店行動)の推測。出典なしで使えるのは、季節区分や「気温が高い日には」「空気が乾燥しやすい時期には」など条件形の一般表現までとする
- 店舗名や地域名からの雰囲気の想像
- 過去に別クライアントで使った表現
- AIが自然に見せるために補った情景描写

## 標準禁止ルール

| 禁止カテゴリ | NGの考え方 | 修正方向 |
|:---|:---|:---|
| 未確認事実 | 設備、内装、接客、人気、実績、料金、営業時間を出典なしに書く | 出典がある事実だけ残す |
| 口コミ風表現 | 実際の声がないのに「好評」「声をいただく」「喜ばれています」と書く | 「特徴です」「選択肢です」など事実ベースにする |
| 体験・感情の断定 | 「笑顔になれる」「満足できる」「ほっとするはず」と書く | 「落ち着いて相談しやすいよう配慮しています」など提供側の姿勢にする |
| 季節からの状況断定 | 季節を根拠に「夏休みなら時間がある」「新生活で忙しいはず」「梅雨で不調の方が多い」と読者の予定・体調を決めつける | 季節区分または条件形の一般表現に留め、現在の天候、発生傾向、人々の行動増加は確認済み材料がある場合だけ使う |
| 家庭状況の断定 | 「家族で」「お子様連れ」「主婦の方」「親子で」と決めつける | 対象が確認済みの場合だけ使う |
| 来店状況の断定 | 「初めての方」「常連様」「仕事帰りに」と決めつける | 対象者が確認済みの場合だけ使う |
| 効果保証 | 集客、順位、治療、改善、解決、節税などの結果を保証する | 可能性、相談、確認、支援の表現にする |

## 口コミ風表現の扱い

口コミ風表現は、読者に「実際の利用者の声がある」と受け取られる。出典がない場合は使ってはならない。

### 使ってよい条件

- 実際の口コミ、レビュー、アンケート、ユーザー提供の感想がある。
- どの表現がどの出典に基づくか説明できる。
- 個人情報や医療・士業の守秘義務に触れない形で要約している。

### 使ってはいけない条件

- 投稿を自然に見せるためだけに「という声」を作る。
- レビューがないのに「好評」「人気」「喜ばれています」と書く。
- 医療機関で患者体験談を投稿本文に引用する。
- 士業で依頼内容や相談内容を本人同意なく示唆する。

## 季節・家庭・来店状況の扱い

出典なしで導入に使えるのは、季節区分や「気温が高い日には」「空気が乾燥しやすい時期には」など条件形の一般表現までとする。「暑い日が続いています」「乾燥した日が続いています」「〇月は〇〇する人が増えます」など、現在の天候、発生傾向、人々の行動増加は確認済み材料がある場合だけ使う。次の順で確認する。

1. 季節から読者の予定、家庭状況、体調、来店・受診行動を断定していないか。
2. 家族構成、子どもの有無、生活状況、来店タイミングを決めつけていないか。
3. 店舗の確認済み企画・商品と結びつけられる場合は結びつける(一般事実だけより訴求が強い)。
4. 季節表現から読者の予定、家庭状況、体調、来店行動を断定していないか確認する。投稿間の企画重複は [05-annual-plan.md](05-annual-plan.md) で判定する。
5. 読者に当てはまらない人を排除する言い方になっていないか。

## 高リスク業種の表現

医療、歯科、整体、士業、税務、法務、不動産、金融に近い内容では、結果を断言してはならない。

- 治る、改善する、痛くない、効果がある、体調が整う、と断言しない。
- 節税できる、相続問題が解決する、手続きが必ず進む、と断言しない。
- Google順位が上がる、集客できる、問い合わせが増える、と保証しない。
- 制度や法律を説明する時は、一般向けに平易にしつつ、判断は専門家への相談に戻す。

## スパム・非承認回避

- 投稿本文と固定フッターに電話番号を書かない。
- URLを本文に直接貼らない。
- 絵文字は必要な場合だけ少数にする。
- ハッシュタグや地域名、サービス名を羅列しない。
- 同じキーワードを不自然に反復しない。

## 確認方法

投稿文を段落ごとに確認し、次の表を頭の中で埋める。1つでも空欄になる文は修正する。

| 確認項目 | 合格条件 |
|:---|:---|
| 事実の出典 | ユーザー提供、公式資料、ローカル実ファイルのいずれかを説明できる |
| 表現の安全性 | 誇大、保証、口コミ風、感情断定がない |
| 読者状況 | 季節、家庭、来店状況を決めつけていない |
| 業種リスク | 医療・士業・法務・税務などの規制リスクを避けている |
| GBP掲載リスク | 電話番号、URL、キーワード羅列がない |

## 不合格時の対応

- 出典のない文は削除する。
- 削除すると投稿が薄くなる場合は、確認済みのサービス説明、FAQ、相談前の判断材料へ置き換える。
- 曖昧なまま残したい場合は、本文ではなく質問候補としてユーザーに返す。
- `gbp-post-quality-check` で要修正になった表現は、修正後に再チェックする。
