# 投稿作成ワークフロー

## 目的

GBP投稿を、確認済み材料だけで読みやすく作る。既存の長文MEO投稿の強みである情報量、地域性、サービス理解は残しつつ、根拠のない盛り込みや同じ切り口の繰り返しを防ぐ。

## 使う材料

| 材料 | 扱い |
|:---|:---|
| ユーザー提供素材 | 確認済み材料として使う。曖昧なメモは質問候補にする |
| 公式サイト、LP、メニュー、サービスページ | 店舗情報、提供サービス、料金、対応地域、特徴の根拠にする |
| knowledge.md などのローカルナレッジ | 出典として使う。狙うキーワードと固定フッターはナレッジの記載を正とする。古い可能性がある項目は確認候補にする |
| 過去投稿ファイル | 月次投稿の重複回避とトーン把握に使う |
| 口コミ、感想、レビュー | 実ファイルまたはユーザー提供で確認できる場合だけ、要約材料にする |
| 未確認の推測 | 本文に使わず、質問候補または除外理由にする |

## 作業手順

1. 依頼内容から、クライアント、業種、地域、投稿種別、投稿月、テーマ、固定フッターの有無を整理する。
2. 使える材料を出典付きで並べる。出典がない事実は、本文材料に入れない。
3. ナレッジのキーワード記載から、今回狙う検索クエリを1つ選ぶ。月次投稿では、直近の過去投稿で狙ったクエリと重複しないようローテーションする。ナレッジにキーワード記載がない場合は質問候補へ回す。
4. 月次投稿では、対象クライアントの過去投稿を確認し、タイトル、テーマ、季節切り口、CTAの重複を把握する。
5. 投稿の狙いを1つに絞る。認知、来店予約、相談、サービス理解、季節企画、FAQ回答などを混ぜすぎない。
6. 冒頭、本文、固定フッターの3ブロックで構成する。
7. スマホで読みやすいように、短い段落、箇条書き、自然な改行を使う。
8. 作成後に `gbp-post-quality-check` を実行し、要修正があれば本文へ戻す。

## 構成基準

### 冒頭ブロック

- 100文字前後を目安にする。
- 第1文は読者への問いかけで始めることを標準とする。特典・イベント・確定告知は結論の先出しでよい。書き方は [04-copywriting-rules.md](04-copywriting-rules.md) に必ず従うこと。
- 狙うキーワードの語を、冒頭100文字の中に自然に含める。
- 読者、地域、サービス、今回の投稿テーマを自然に含める。
- 「続きを読む」で折り畳まれる前に、この投稿で何が分かるかまで示す。
- 未確認の読者状況を決めつけない。問いかけ形式でも家庭状況・来店状況・季節の悩みを限定しない。

### 本文ブロック

- 900文字前後を目安にする。
- 確認済みのサービス内容、対応範囲、利用前の判断材料、専門的な見方を中心に書く。
- 主要な訴求1〜2点には、事実に「読者が何をできるようになるか」を添える([04-copywriting-rules.md](04-copywriting-rules.md) のベネフィット翻訳)。
- 読者の不安や悩みに触れる場合は、「こうした悩みを持つ方もいます」程度に留め、全員に当てはまるように書かない。
- MEOキーワードは文脈内に自然に入れる。地域名やサービス名を不自然に反復しない。

### 固定フッターブロック

- ナレッジに固定フッターの記載がある場合は、それを正として使い、文言を勝手に書き換えない。
- ナレッジにも依頼にも記載がない場合は、フッターを付けず、推測で作らない。
- 新規に作る指示があった場合は、150-200文字程度を目安に、対象地域、提供サービス、相談導線を簡潔にまとめる。
- 電話番号、URL、未確認の対応範囲、保証表現を入れない。

## 投稿種別ごとの使い分け

| 投稿種別 | 使う場面 | 書く内容 |
|:---|:---|:---|
| 最新情報 | 通常の月次投稿、FAQ、サービス紹介 | 専門的な気づき、よくある質問、利用前の判断材料 |
| 特典 | 確認済みキャンペーンがある場合 | 対象条件、期間、利用方法、注意点 |
| イベント | 日時や場所が確認済みの場合 | 開催目的、対象者、内容、参加方法 |
| 商品 | 商品やメニューを紹介する場合 | 商品特徴、利用シーン、注文や予約の自然な導線 |

## 月次投稿の重複回避と年間計画

- 重複回避は [05-annual-plan.md](05-annual-plan.md) の年間計画ファイルを正とする。計画がある場合は当月行のテーマ・キーワード・切り口の型を使い、過去投稿の全件読み返しは不要。
- 計画ファイルがない場合は、直近3ヶ月の過去投稿を確認し、先月と同じタイトル・冒頭型・季節切り口を避けたうえで、年間計画の作成を提案する。
- 同一テーマの再登場は可。ただし連続月は不可とし、再登場時はタイトル・切り口の型・狙うキーワードのうち2つ以上を変える。
- 季節の一般事実は使ってよい。ただし「新生活で忙しいご家庭」「夏休みなら時間がある」など読者の予定・家庭状況・体調を季節から断定せず、同じ季節切り口を連続月で繰り返さない。

## 出力形式

投稿案の後に、確認結果を短く添える。

```markdown
## 投稿案

投稿タイプ:

タイトル(特典・イベント・商品のみ。最新情報にはタイトル欄がない):

本文:

固定フッター:

## 確認結果

- 狙ったキーワード:
- 切り口の型:
- 使用した確認済み材料:
- 未確認のため入れなかった内容:
- 過去投稿との重複回避:
- gbp-post-quality-check:
```

## 不合格時の対応

- 出典のない事実がある場合は、削除するか質問候補にする。
- 口コミ風表現の出典がない場合は、体験談に見える表現を削除する。
- 季節や家庭状況の断定がある場合は、一般的な言い方へ弱めるか削除する。
- 品質チェックで要修正が出た場合は、修正後に再チェックする。
