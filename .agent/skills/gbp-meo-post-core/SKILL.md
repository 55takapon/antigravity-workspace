# GBP MEO長文投稿ライティングスキル（コア）

> **対象**: 実店舗・ローカルビジネス全般のGBP投稿機能
> **前提**: 200社以上のMEO支援実績に基づくプロマーケター視点
> **戦略**: 情報量を最大化し（約1200文字）、ロングテールキーワードやLSI（共起語）を含めることで、ローカル検索におけるトピカルオーソリティ（特定分野の専門性）と関連性シグナルを強化する。

---

## 1. 長文特化戦略の目的とMEO効果

一般的な投稿（300文字程度）は「ユーザーへの告知」としては機能しますが、MEO（ローカルSEO）の観点では不十分です。GoogleのAIによる自然言語処理（NLP）アルゴリズムに対して自社の専門性と対応範囲を深く学習させるため、**上限（1500文字）に迫るリッチなコンテンツ**を作成します。

*   **関連性の網羅（Relevance）**: 長文にすることで、メインキーワードのみならず「個室」「ベビーカー可」「夜間対応」などのロングテールクエリに対応する単語が自然に含まれ、露出機会が増加します。
*   **専門性の誇示（E-E-A-T）**: 短い告知ではなく、プロの視点による深い解説や事例を交えることで、「その地域における専門家」としての信頼度を高めます。

---

## 2. ゴールデンフレームワーク（構成の黄金比）

投稿は以下の3つのブロックで構成し、全体で**1000〜1200文字程度**にまとめます。

### ① フックブロック（冒頭100文字）
*   **役割**: 検索結果やマップ上で「続きを読む」を押される前に表示される最も重要な領域。
*   **内容**: 「誰に」「何を」「どう解決するか」の結論と最大のベネフィット。
*   **必須**: [地域名]＋[業種/主力サービス名] を必ず1〜2回含める。

### ② 本文ブロック（約900文字）
*   **役割**: 専門性の提示と、関連キーワード群の自然な溶け込み。
*   **内容**: 以下のいずれか、または組み合わせで構成。
    *   **悩みの深掘り**: お客様が抱える課題感の具体的な描写。
    *   **解決策の詳細**: サービスの特徴、プロセス、他社との違い。
    *   **専門家の見解**: なぜそのメニュー・手法が効果的なのかの解説。
    *   **実績・事例**: 具体的なBefore/After像（個人情報を伏せた形）。
*   **注意点**: 読点や改行、箇条書きを活用し、スマホで読んでも疲れないレイアウト（余白）を意識する。

### ③ 固定フッターブロック（150〜200文字）
*   **役割**: 投稿のたびに毎回インジェクト（挿入）する「事業ドメイン宣言」。AIに対する強力なサイテーション（関連性の反復学習）として機能。
*   **内容**: 対象地域、ターゲット、提供価値、対応サービス群を網羅した定型文。
*   **【プロフェッショナル・テンプレート例（士業の場合）】**
    > 大阪市中央区・堺筋本町、北久宝寺町エリアの榊原税理士事務所です。大阪・兵庫・京都・奈良・和歌山など近畿一円の中小企業様を対象に、毎月の巡回監査を通じて黒字決算と財務経営力の強化を支援しています。TKC FXシリーズを活用した自計化支援、経営計画の策定、書面添付による融資・資金調達支援まで一貫対応。法人経営や相続・事業承継のご相談も承ります。経営のお悩みはお気軽にお問い合わせください。

## 3. ガイドライン遵守と「スパム判定（非承認）」の回避

*   **🚫 電話番号の本文記載NG**: 投稿本文（固定フッター含む）に電話番号を直接記載すると、Googleのスパムフィルターに高確率で弾かれ「非承認（Rejected）」となります。電話への誘導はシステム搭載のCTAボタン（「今すぐ電話」等）で行ってください。
*   **🚫 URLの直接貼り付け不可**: 本文へのURL直書きも非承認リスクがあります。リンク誘導はCTAボタン（「詳細」や「予約」等）を活用してください。
*   **🚫 過剰な絵文字・記号**: 1つの投稿につき、絵文字は3〜5個程度に留めます。過度な装飾はアカウントペナルティの対象になる可能性があります。
*   **🚫 無意味なキーワードの羅列**: 単語だけを並べる（例：`#新宿 #ランチ #おすすめ #安い #個室...`）のはスパム行為です。必ず意味の通る「文章」の中に自然に組み込んでください（ただし、固定フッター内での自然なサービス羅列は許容範囲です）。

## 4. 投稿タイプ（4種類）別 長文アプローチ

| 投稿タイプ | MEO上の役割 | 本文ブロック（900字）の構成例 | CTAボタン推奨 |
| :--- | :--- | :--- | :--- |
| **最新情報**（Update） | 鮮度とエンゲージメント | 日常の専門的気づき / よくある質問（FAQ）への詳細な回答 / スタッフの技術解説 | 詳細、予約 |
| **特典**（Offer） | 緊急性とCVRの向上 | キャンペーンの背景（なぜやるのか） / 対象者の詳細な条件 / 利用後のメリット（未来像）の詳しい描写 | クーポンを利用、予約 |
| **イベント**（Event） | 特定日時の確実な視認性 | イベント開催の目的 / プログラムのタイムラインと詳細な内容 / 過去参加者の声（長文） | 購入、予約、詳細 |
| **商品**（Product） | メニューの辞書化（消えない） | 商品開発の裏側 / 使用している素材・技術の極めて詳細なスペック解説 / 適した利用シーン | 注文、詳細 |

## 5. 定期運用時の必須ルール（エージェント向け：重複回避プロセス）

同一クライアントに対して、毎月の定期運用として投稿案を作成する（例：「〇〇の4月分を作って」等の指示を受ける）際は、**「マンネリ化を防ぐため、必ず前月とタイトルや切り口を変える」**ことを最優先事項とします。以下のステップを必ず実行してください。

1. **過去ファイルの参照**: 対象クライアントの `posts/` ディレクトリ配下にある、前月以前の投稿ファイル（例: `2026-03_posts.md` 等）をツールを使って必ず事前に読み込む。
2. **テーマの重複チェック**: 過去に使われたタイトルやテーマ（切り口）を把握し、それらと**絶対に被らない**新しいテーマを `knowledge.md` 等のナレッジベースから選択する。
3. **切り口（アプローチ）の意図的な変更**: 先月が「サービスの特徴紹介」だったなら、今月は「スタッフの想い・エピソード」や「その月特有の季節イベント（お花見・新生活・梅雨など）と絡めた内容」にするなど、読者に新鮮さを提供できるよう執筆の切り口を意図的にシフトさせること。

## 6. 【超重要】事実確認・信憑性チェックの二重防衛（全クライアント共通）

GBP投稿においては「事実と異なる記述（ハルシネーション）」と「根拠のない断言（信憑性リスク）」の両方を防ぐ必要があります。この2つは別の問題であり、どちらも全クライアントへの全投稿に必ず適用することを最優先事項とします。

### 6-1. ハルシネーション（虚偽記載）防止

AIが生成した投稿原稿は、必ず出力前に以下のファクトチェック工程（必須プロセス）を通さなければなりません。ありもしない設備やサービスを盛って記載することは、重大なクレームや店舗の信頼失墜（トラブル）に直結するため、絶対に許容されません。

1. **ナレッジ・公式サイトとの突き合わせ**: 生成語句（例：「木目調のインテリア」「最新のタブレット学習」など）が、提供された `knowledge.md` や直近でスクレイピングした公式サイトの文章内に**明確に記載されているか**を1文ずつ照合する。
2. **推測・誇張の完全排除**: ホームページに書かれていない修飾語や過剰な演出（例：「地域の皆様から圧倒的な支持」「行列ができる」等）、推測に基づく事実（例：「間接照明」「〜なBGM」等）が含まれている場合は、事実のみを用いた表現へ即座に修正・削除する。
3. **最終アウトプットの担保**: 「事実ベースであること」に確証が持てない修飾・機能・保証内容については、書き手を守るためにも全て削除してから出力する。

### 6-2. 断言リスク・信憑性チェック（全クライアント共通の厳守ルール）

ハルシネーションとは別に、「事実ではないとは言いきれないが、根拠のない断定的な表現」も同様に禁止します。特にGoogleのアルゴリズムや集客効果に関する断言は、MEOの専門家としての信頼を逆に損なうリスクがあるため、以下の4パターンを厳格に管理してください。

| ❌ 禁止パターン | 具体例 | ✅ 代替表現 |
|---|---|---|
| **根拠のない数値の断言** | 「週1回以上の更新が必要」「写真で9割決まる」「8割がスマホ利用」 | 「〜といわれています」「〜の傾向があります」 |
| **Googleアルゴリズムへの因果断言** | 「投稿すると順位が上がります」「写真が少ないと下がります」 | 「〜に評価されやすくなるといわれています」「〜の可能性があります」 |
| **集客・MEO効果の保証** | 「必ず集客できます」「広告費なしで集客できます」 | 「〜しやすくなります」「〜という傾向が見られます」 |
| **全ユーザーへの過度な一般化** | 「ユーザーは必ず写真を見ます」「全員がスマホで検索します」 | 「多くの場合」「〜ケースが多く見られます」 |

> **判断に迷ったら削除または軟化させる**。断言を避けることは「自信がない」ことではなく、「正直で信頼できる専門家」としての立ち位置を守ることです。

## 7. AI執筆用 基本プロンプトテンプレート（全業種対応）

このスキルを使ってAIにGBP投稿文を生成させる場合のベースプロンプトです。業種に合わせて「前提条件」を書き換えて使用します。

```text
あなたはGoogleビジネスプロフィール（GBP）の運用で200社以上の実績を持つプロフェッショナルマーケターです。
以下の【要件】と【固定フッター】に基づき、MEO（ローカルSEO）効果を最大化するためのGBP長文投稿（本文約1000文字＋固定フッター約200文字）を作成してください。

### 【前提条件：店舗情報】
* 業種：[例：税理士事務所 / 美容室 / 飲食店 など]
* メイン地域：[市区町村・駅名など]
* ターゲット顧客：[例：資金繰りに悩む中小企業経営者]
* 強み・特徴：[箇条書きで3点ほど]

### 【今回の投稿テーマ】
* テーマ：[例：決算期前に行うべき節税対策のポイント]

### 【ライティング要件】
1. **フック（冒頭100文字以内）**: 検索結果で省略される前に最大のベネフィットと結論を伝えて「続きを読む」を押させる魅力的な文章。[業種]と[メイン地域]を含めること。
2. **本文（約900文字）**: 今回のテーマについて、プロフェッショナルとしての深い知見を解説すること。箇条書きや改行を活用し、スマホで読みやすいレイアウトにすること。
3. **トピカルオーソリティの強化**: [テーマに関する周辺キーワード]を不自然にならないように文脈の中に散りばめること。
4. **禁止事項及びCTA（行動喚起）の書き方**: 誇大広告、絵文字の多用（全体で3個まで）、電話番号・URLの直書きは厳禁。また、「マップの予約ボタンから予約ください」「下のボタンを押してください」といった直接的すぎる誘導は避け、「事前予約がおすすめです」「気軽にお問い合わせください」といった、ユーザーに寄り添う自然で柔らかなトーンで行動を促すこと。

### 【品質チェック（必須・出稿前の最終工程）】
投稿文を生成した後、**そのまま出力を終了せず**、以下の品質チェックを自ら実行してください。

```
【品質チェック実行中 - gbp-post-quality-check】

■ 軸1: 誇大表現・最上級断言（「一番」「絶対」「必ず」等）
■ 軸2: 根拠のない体験・感情の断言（「はずです」「になれる」等）
■ 軸3: 医療・健康効能の断言（健康への効果を断言していないか）
■ 軸4: 誤字・脱字・禁止記載（電話番号・URL直書き）
■ 軸5: 医療広告GL → 医療機関クライアントの場合のみ実施
■ 軸6: 士業広告規制 → 士業クライアントの場合のみ実施
```

問題があれば**その場で修正してから**最終版を出力する。
問題がなければ「✅ 品質チェック完了。全軸クリア。」と宣言してから終了する。

### 【固定フッター（語尾にそのまま結合すること）】
--------------------------------------------------
（ここにユーザー指定の固定フッター文章を挿入）
--------------------------------------------------
```

## ⚠️ 投稿完成後の必須アクション（品質チェック）

**投稿文を生成したら、オーナーへの報告・GBPへの出稿前に必ず以下を実行すること。**

```
次のスキルを実行してください: gbp-post-quality-check
```

- 誇大表現・断言・健康効能の根拠なき断言・誤字の4軸チェック（全業種共通）
- 歯科・クリニックの場合は **軸5（医療広告ガイドライン）** も必須
- 士業の場合は **軸6（士業広告規制）** も必須
- チェック完了後、「✅ 品質チェック完了報告」を出力してから出稿する
