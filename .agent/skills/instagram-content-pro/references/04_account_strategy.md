# アカウント戦略と訴求設計

このファイルは、アカウント設計、訴求設計、コンセプト作成、投稿カテゴリ設計を求められた時に読む。

## 戦略の完成条件

次の6領域を分けて決める。重複や抜けがある場合は、投稿制作へ進まない。

| 領域 | 決めること | 出力 |
|---|---|---|
| 1. 事業目的 | Instagramで増やしたい行動。認知、信頼、相談、購入、来店、採用、ファン化のどれか | 主目的1つ、補助目的1つ |
| 2. 対象者 | 誰が、どの状況で、何に困り、何を決めたいか | ICP、悩み、意思決定条件 |
| 3. 提供価値 | 何を変え、なぜ選ばれるか | 価値仮説、差別化、証拠 |
| 4. 競合/代替 | 何と比較され、なぜ選ばれないのか | 競合、代替手段、勝ち筋 |
| 5. リソース制約 | どの頻度で、誰が、どの素材で運用できるか | 投稿本数、素材、撮影可否、確認体制 |
| 6. 導線/KPI | 投稿後にどこへ進ませ、何で検証するか | プロフィール、DM、LINE、予約、LP、EC、GBP、KPI |

「事業目的」はアカウントが担う役割、「導線」は投稿後の遷移先、「KPI」は改善判断の指標として分ける。

## アカウント役割の決め方

| 役割 | 主KPI | 合う投稿 | 避けること |
|---|---|---|---|
| 認知 | 非フォロワーリーチ、共有 | Reels、共感、比較、地域ネタ | 商品説明だけ |
| 信頼 | 保存、プロフィールアクセス | カルーセル、事例、FAQ、解説 | 実績なしの断定 |
| 相談 | DM、フォーム、LINE登録 | Before/After、悩み診断、無料相談誘導 | CTAの分散 |
| 購入/来店 | 予約、購入、来店報告 | メニュー、価格、利用手順、レビュー | 買い方が不明 |
| 採用 | 応募、職場理解 | 裏側、人、価値観、1日の流れ | きれいごとだけ |
| ファン化 | ストーリーズ反応、再訪 | 日常、思想、制作背景、質問箱 | 一方通行 |

## 対象者を決める質問

必ず具体語で答える。

1. 誰が見るのか。年齢、地域、職業、生活リズム、購買権限。
2. どんな場面でInstagramを見るのか。通勤、昼休み、夜、週末、検索時。
3. 何に困っているのか。表面の悩みと本音の不安。
4. 何が分かれば次の行動を取るのか。価格、実績、手順、比較、安心材料。
5. 競合、検索、口コミ、GBP、広告、紹介など、何と比較されるのか。
6. 競合ではなくこのアカウントを見る理由は何か。

## 競合/代替分析

競合分析は「競合の真似」ではなく、選ばれる理由を作るために行う。

| 見る項目 | 確認すること | 出力 |
|---|---|---|
| 競合 | 同地域、同価格帯、同カテゴリのアカウント | よくある訴求、弱い導線 |
| 代替 | 検索、GBP、紹介、広告、他SNS、来店せず済ませる選択 | Instagramで補うべき不安 |
| 差分 | 実績、専門性、価格、速さ、人柄、地域性、体験 | 主訴求に使う証拠 |
| 勝ち筋 | 見込み客が次に進む理由 | 投稿カテゴリ、プロフィール、CTA |

## リソース制約

戦略は運用できる範囲に落とす。理想本数ではなく、継続できる本数を採用する。

| リソース | 確認すること | 設計への反映 |
|---|---|---|
| 素材 | 写真、動画、口コミ、実績、FAQ、現場素材 | フォーマットと投稿本数を決める |
| 人 | 撮影者、投稿者、確認者、返信者 | 週次ルーティンを決める |
| 時間 | 週あたり制作時間、撮影可能日 | 週3/週5/毎日投稿を選ぶ |
| 予算 | デザイン、撮影、広告、外注可否 | 制作粒度と素材補強を決める |
| 制約 | 顔出し、守秘、法規制、撮影許可 | 表現と証拠の出し方を決める |

## 訴求軸マップ

1アカウントにつき、主軸2つ、補助軸3つまでに絞る。多すぎる訴求は分類を壊す。

| 訴求軸 | 使う場面 | 投稿例 |
|---|---|---|
| 悩み解決 | 見込み客が検索または保存するテーマ | よくある失敗、チェックリスト、改善手順 |
| Before/After | 相談、購入、来店へ進ませたい時 | 施策前後、利用前後、症例ではなく体験変化 |
| 実績/証拠 | 信頼不足を補う時 | 顧客の声、数値、導入事例、受賞、掲載 |
| 専門性 | 教育、保存、権威形成 | 解説、比較、仕組み、業界の誤解 |
| 共感 | 新規接触、コメント | あるある、不安、失敗談、裏側 |
| 地域性 | 店舗、士業、医療、採用 | 地域名、アクセス、地元の利用シーン |
| 価格/手軽さ | 行動直前の不安解消 | 料金、所要時間、準備物、予約方法 |
| 安心感 | 初回利用、問い合わせ前 | よくある質問、対応範囲、流れ、人柄 |
| 希少性/限定 | キャンペーン、予約枠 | 期間、数量、季節、イベント |
| 世界観 | ブランド、ファン化 | 価値観、制作背景、日常、思想 |

## 投稿カテゴリ設計

標準は5カテゴリ。各カテゴリに目的、フォーマット、CTAを割り当てる。

| カテゴリ | 目的 | 推奨フォーマット | CTA |
|---|---|---|---|
| 発見 | 新規接触 | Reels | 共有、プロフィールを見る |
| 保存 | 教育、再訪 | カルーセル | 保存 |
| 証拠 | 信頼形成 | カルーセル、Reels | プロフィール、ハイライト |
| 導線 | 相談、購入、来店 | Reels、フィード、ストーリーズ | DM、LINE、予約、LP |
| 関係 | 既存フォロワー育成 | ストーリーズ | 質問、アンケート、DM |

## 戦略シート出力形式

アカウント戦略を作る時は、この順で出す。

1. 事業目的: 主目的と補助目的。
2. 対象者: 誰が、どんな状況で、何を決めたいか。
3. 提供価値: 価値宣言一文と証拠。
4. 競合/代替: 比較対象と勝ち筋。
5. リソース制約: 投稿本数、素材、撮影可否、確認体制。
6. 訴求軸: 主訴求2つ、補助訴求3つ。
7. 投稿カテゴリ: 発見、保存、証拠、導線、関係。
8. 導線/KPI: プロフィール、DM、LINE、予約、LP、EC、GBP、30日以内に検証するKPI。

## 不合格条件

- 「誰に」が広すぎる。
- 事業目的、導線、KPIが混ざっている。
- 投稿カテゴリと最終導線がつながっていない。
- 訴求軸が6個以上あり、優先順位がない。
- 競合/代替との差が「親切」「丁寧」「高品質」だけ。
- 投稿本数、素材、撮影可否、確認体制などのリソース制約がない。
- 実績、体験、顧客の声、数字、現場素材のどれもない。
