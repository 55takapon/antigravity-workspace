# 標準出力と保存規則

このファイルは、成果物を出力・保存する時に読む。

## 通常の投稿制作の出力順序

1. 方針: 目的、アカウント役割、作る成果物、投稿がある場合の推奨フォーマット、狙う行動。
2. 素材不足: 足りない情報と、仮置きした前提。
3. 導線: プロフィール、ピン留め、ハイライト、リンク、DM/LINE/予約導線。
4. 投稿案: 台本、スライド構成、キャプション、CTA。冒頭コピー（0-3秒、表紙、1行目）は本命1案と代替2案。
5. 制作メモ: 撮影、デザイン、投稿前チェック。
6. 計測: 投稿後24時間、72時間、7日後、月次で見るKPI。

## 保存規則

成果物は必ずクライアント基盤フォルダ（スキル基盤 `skills\` と同じ `.agent` 配下にある `clients\`）へ保存する。スキルフォルダ内への保存は禁止。

```
clients\{クライアント名}\instagram\{YYYYMMDD}_{成果物種別}.md
```

- 成果物種別: `strategy`（戦略シート）/ `profile-audit`（プロフィール監査）/ `monthly-calendar`（30日カレンダー）/ `posts`（投稿案・台本）/ `insight-report`（分析）
- 自社は `jetproduce`
- チャット内での提示だけで完結する軽微な相談は保存不要。ユーザーが保存を求めた場合、または月間運用・戦略・監査の正式成果物は必ず保存する
- 最終報告では保存先パスをユーザーに提示する
