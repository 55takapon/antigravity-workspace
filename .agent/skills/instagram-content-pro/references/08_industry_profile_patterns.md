# 業種別プロフィール型

このファイルは、プロフィール改善、bio、名前欄、ハイライト、ピン留め、業種別導線を作る時に読む。

## 使い方

まず [05_profile_funnel.md](05_profile_funnel.md) で共通監査を行い、その後に業種別の型を選ぶ。型はそのまま流用せず、地域、対象者、価格帯、導線先に合わせて書き換える。

## 店舗型

対象: 飲食、美容、整体、ジム、サロン、教室、地域店舗。

| 項目 | 型 |
|---|---|
| 名前欄 | 屋号 + 地域 + 業態/利用シーン |
| bio | 誰向けの店か、何が得られるか、営業時間/予約/アクセスへの導線 |
| ピン留め | はじめての方へ、メニュー/料金、口コミ/FAQ |
| ハイライト | はじめに、メニュー、口コミ、FAQ、アクセス、予約 |
| 主CTA | 予約、来店、営業時間確認 |
| 必須証拠 | 店内写真、価格、席/設備、口コミ、アクセス |

## サービス型

対象: 士業、コンサル、BtoB支援、スクール、コーチング、専門サービス。

| 項目 | 型 |
|---|---|
| 名前欄 | 対象 + 専門領域、または人名 + 専門領域 |
| bio | 誰のどんな課題を解くか、実績/専門性、相談導線 |
| ピン留め | 自己紹介、実績/事例、相談の流れ |
| ハイライト | サービス、事例、FAQ、料金、無料相談 |
| 主CTA | 無料相談、資料請求、問い合わせ |
| 必須証拠 | 事例、実績、資格、顧客の声、対応範囲 |

## 個人ブランディング型

対象: クリエイター、講師、発信者、フリーランス、専門家。

| 項目 | 型 |
|---|---|
| 名前欄 | 人名 + 何の専門家か |
| bio | 誰に何を発信するか、実績/思想、フォローまたは相談導線 |
| ピン留め | 何者か、代表投稿、提供メニュー |
| ハイライト | はじめに、実績、裏側、FAQ、提供中 |
| 主CTA | フォロー、DM、相談、講座/資料 |
| 必須証拠 | 代表実績、制作物、考え方、顧客の声 |

## Web/制作会社型

対象: Web制作、デザイン、マーケ支援、MEO/GBP、広告運用、システム開発。

| 項目 | 型 |
|---|---|
| 名前欄 | 対象 + 提供領域。例: 中小企業のWeb集客支援 |
| bio | 制作後に何を改善するか、対応範囲、相談導線 |
| ピン留め | 失敗例/選び方、実績/改善事例、相談の流れ |
| ハイライト | 実績、料金目安、FAQ、制作流れ、無料相談 |
| 主CTA | 無料相談、診断、問い合わせ |
| 必須証拠 | 制作実績、改善数値、対応業種、顧客の声 |

## EC/商品型

対象: 物販、D2C、ハンドメイド、食品、コスメ、アパレル。

| 項目 | 型 |
|---|---|
| 名前欄 | ブランド名 + 商品カテゴリ/悩み |
| bio | 誰のどんな体験を良くする商品か、特徴、購入導線 |
| ピン留め | 人気商品、使い方、レビュー/FAQ |
| ハイライト | 商品、レビュー、使い方、配送、FAQ |
| 主CTA | 商品ページ、EC、LINE登録 |
| 必須証拠 | 商品写真、使用シーン、レビュー、価格、配送条件 |

## 採用型

対象: 採用広報、店舗採用、企業アカウント。

| 項目 | 型 |
|---|---|
| 名前欄 | 会社名 + 職種/地域/採用 |
| bio | 誰を募集しているか、働く魅力、応募導線 |
| ピン留め | 募集職種、1日の流れ、社員の声 |
| ハイライト | 募集要項、職場、社員、FAQ、応募 |
| 主CTA | 採用ページ、DM、説明会 |
| 必須証拠 | 職場写真、勤務条件、社員の声、選考手順 |

## 不合格条件

- 業種テンプレをそのまま貼り、地域、対象者、導線先に合わせていない。
- 店舗型なのに営業時間、アクセス、予約方法がない。
- サービス型なのに相談で何が分かるかがない。
- Web/制作会社型なのに制作後の成果や運用支援がない。
- EC型なのに価格、配送、購入方法がない。
- 採用型なのに募集職種、条件、応募導線がない。
