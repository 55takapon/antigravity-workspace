# 出力例（入力→出力の型）

このスキルの成果物は「タイトル3案」というマーケティング文面のため、
ここに置くのはCTR検証済みの正解ではなく、5ステップを通したときの出力の型と、
各案にどんな根拠が紐づくかを見せる作例である。タイトル本文は型を示すための例示で、
実運用では実際のリサーチ結果に差し替える。

---

## 例1: 正常系（5ステップを通した出力の型）

### 入力
- 依頼: 加古川市の整体院オーナー向けに集客系コラムのタイトルを決めたい
- 制約: ホットペッパー依存を脱したいオーナーがターゲット

### ステップ1〜4の中間出力（要約）
- ペルソナ: 加古川市で整体院を経営する40代男性
- 具体的な悩み: ホットペッパーに頼らず自力で集客したい
- 本音: 広告費を下げて利益率を上げたい
- メインKW候補: 「整体院 集客 ホットペッパー以外」（検索意図: Do ／ ボリューム目安: 100〜1,000）
- 競合の差別化チャンス: 上位は予約サイト比較ばかりで「自社集客への切替手順」が薄い
- AI Overviews: 表示なし → 従来型SEOで攻める

### 出力（タイトル3案の型）
```
【王道】整体院がホットペッパー以外で集客する方法｜広告費を抑える5ステップ
（文字数: 32 / 狙うKW: 整体院 集客 ホットペッパー以外 / 根拠: 検索意図Doに直球で応え、KWを左寄せ）

【差別化】予約サイト比較はもう古い？整体院が自社集客へ切り替える手順
（文字数: 30 / 狙うKW: 整体院 集客 / 根拠: 競合が薄い「切替手順」を前面化）

【フィルター書き換え】集客に困る整体院が、実は最初にやめるべきだったこと
（文字数: 29 / 狙うKW: 整体院 集客 / 根拠: 「もっと集客する」前提を壊し好奇心を刺激）

推奨案と理由: 【王道】。検索意図Doと一致し、KW左寄せ・文字数・差別化の全項目を満たすため。
```

### 確認結果
- 3案すべて品質チェックリスト8項目を通過
- 同サイト内に同一KW記事なし（カニバリなし）

## 例2: 異常系（入力不足で生成へ進まない）

### 入力
- 依頼: 「整体院のいい感じのブログタイトル考えて」

### 出力（生成せず質問へ戻す）
```
タイトルを設計するには、次の情報が必要です。確定するまでタイトル案は出しません。

1. 対象ペルソナ: どの地域・年代・どんな経営状況のオーナーですか？
2. 解決したい悩み: 集客全般ですか、それとも特定の悩み（予約サイト依存・口コミ等）ですか？
3. 既存コラムの有無: 同じテーマで既に公開済みの記事はありますか？（カニバリ確認のため）
```

### この対応の理由
ペルソナとKWが未確定のまま想像でタイトルを作ると、記事内容と乖離しカニバリも検知できないため、
SKILL.mdの禁止事項に従いステップ1の質問へ戻している。
