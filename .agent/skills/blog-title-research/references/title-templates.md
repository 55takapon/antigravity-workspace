# タイトルテンプレートと品質チェック

ステップ5でタイトルを生成する際に使う型と、生成後の検査リスト。
`[KW]` `[業種]` `[成果]` 等は、実際のリサーチ結果で埋める差し込み枠。

---

## 王道・差別化向けテンプレート

```
【網羅型（ピラー記事向け）】
[KW]の完全ガイド｜初心者でも失敗しない〇つのステップ

【課題解決型】
[KW]で悩んでいませんか？プロが教える最短の解決法

【リスト型】
[KW]おすすめ〇選｜徹底比較で失敗しない選び方

【ノウハウ型】
プロだけが知っている[KW]のコツ｜〇〇で差がつく方法

【警告型】
【要注意】[KW]でやってはいけない〇つのNG行動

【事例型（カテゴリF）】
[施策]で[成果]｜[業種]の集客改善レポート
```

---

## フィルター書き換えパターン

読者の「当たり前」を壊し、知的好奇心を刺激するタイトル設計。

```
【常識破壊型】
[常識]は間違い？[真実]が[成果]につながる本当の理由

【視点転換型】
[ターゲット]が本当にやるべきなのは[意外な施策]だった

【自発的行動促進型】
[成果]を出した[ターゲット]が最初の1週間でやったたった1つのこと
```

---

## タイトル品質チェックリスト

生成した3案それぞれを、この8項目で検査する。1つでも欠ける案は修正する。

```
□ メインKWが含まれているか
□ KWが文頭に近い位置にあるか
□ 30〜35文字以内か
□ 記事の内容とタイトルが一致しているか
□ 読者のベネフィットが伝わるか
□ 競合タイトルと差別化できているか
□ 同サイト内でKWカニバリしていないか
□ AI Overviewsの回答と差別化できているか
```
