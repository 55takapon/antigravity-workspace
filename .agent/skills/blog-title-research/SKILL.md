# blog-title-research

> ジェットプロデュース専用ブログタイトルリサーチスキル。SEO・CTR・AI検索を統合した5ステップフロー。

## 5ステップリサーチフロー

### Step 1: ペルソナの悩みを抽出

```
【悩み抽出シート】
- ペルソナ: （例）加古川市で整体院を経営する40代男性
- 具体的な悩み: （例）ホットペッパーに頼らず自力で集客したい
- 悩みの裏にある本音: （例）広告費を下げて利益率を上げたい
- 検索しそうな言葉: （例）「整体院 集客 ホットペッパー以外」
- 解決した先の理想: （例）指名検索で来る患者だけで予約が埋まる
```

**情報源（優先度順）**:
1. クライアントとの日常会話・問い合わせ内容
2. GBPの口コミ・質問
3. Yahoo!知恵袋 / 教えて!gooの質問
4. SNSのコメント・DM
5. 競合サイトのFAQ・ブログコメント欄

---

### Step 2: キーワード調査

**使用ツール**: Google検索サジェスト・ラッコキーワード・Googleキーワードプランナー・Search Console

**検索意図の分類**:
- **Know（知りたい）**: 「MEO対策とは」
- **Do（やりたい）**: 「GBP 設定方法」
- **Go（行きたい）**: 「加古川 整体院」
- **Buy（依頼したい）**: 「MEO対策 代行 料金」

月間検索ボリューム100〜1,000がスイートスポット。

---

### Step 3: 競合分析（上位10件）

```
【競合分析シート】
- 検索KW: ___
- 上位10件のタイトル一覧
- 共通する訴求ポイント: ___
- 不足している切り口: ___ ← 差別化チャンス
- 記事の形式: （リスト型/ガイド型/Q&A型/事例型）
- 文字数の平均: ___文字
```

---

### Step 4: AI Overviews確認

1. 対策KWでGoogle検索
2. AI Overviewsが表示されるか確認
3. 表示される場合: 引用サイト特定→回答パターン分析→含まれていない情報を差別化に活用
4. 表示されない場合: 従来型SEO（検索順位勝負）で攻める

---

### Step 5: タイトル案を3パターン生成

1. **王道パターン**: 検索意図に直球で応えるタイトル
2. **差別化パターン**: 競合にない切り口を入れたタイトル
3. **フィルター書き換えパターン**: 読者の「当たり前」を壊すタイトル

---

## SEOタイトル設計ルール

| # | ルール |
|---|--------|
| 1 | 文字数は30〜35文字 |
| 2 | 狙うKWは左寄せ（文頭に近づける） |
| 3 | タイトルと記事内容の完全一致 |
| 4 | 1記事1メインKW |
| 5 | 同一KWのカニバリ禁止 |

**推奨**: 数字を入れる / 【】記号で視認性向上 / ターゲットを明記 / ベネフィットを提示 / 時事記事のみ【2026年最新】

---

## タイトルテンプレート集

```
【網羅型（ピラー記事向け）】
[KW]の完全ガイド｜初心者でも失敗しない〇つのステップ

【課題解決型】
[KW]で悩んでいませんか？プロが教える最短の解決法

【リスト型】
[KW]おすすめ〇選｜徹底比較で失敗しない選び方

【ノウハウ型】
プロだけが知っている[KW]のコツ｜〇〇で差がつく方法

【警告型】
【要注意】[KW]でやってはいけない〇つのNG行動

【事例型（カテゴリF）】
[施策]で[成果]｜[業種]の集客改善レポート
```

---

## フィルター書き換えパターン

読者の「当たり前」を壊し、知的好奇心を刺激するタイトル設計。

```
【常識破壊型】
[常識]は間違い？[真実]が[成果]につながる本当の理由

【視点転換型】
[ターゲット]が本当にやるべきなのは[意外な施策]だった

【自発的行動促進型】
[成果]を出した[ターゲット]が最初の1週間でやったたった1つのこと
```

---

## タイトル品質チェックリスト

```
□ メインKWが含まれているか
□ KWが文頭に近い位置にあるか
□ 30〜35文字以内か
□ 記事の内容とタイトルが一致しているか
□ 読者のベネフィットが伝わるか
□ 競合タイトルと差別化できているか
□ 同サイト内でKWカニバリしていないか
□ AI Overviewsの回答と差別化できているか
```

## 連携スキル

- `blog-writing` → タイトル確定後に記事執筆

## NGパターン

- 文字数チェックをせずにタイトルを確定する
- 同一KWを複数記事で使う（カニバリ）
- 競合分析をせずにタイトルを決める
