## 材料の扱い

| 材料 | 扱い |
|:---|:---|
| ユーザー提供の口コミ本文 | 返信本文に使う主材料。本文にない事実は足さない。 |
| ユーザー提供の事業者情報 | 事業所名、業種、連絡導線だけを使う。未指定なら推測しない。 |
| SEO語・差別化ポイント | ユーザーが指定した地域名、サービス名、看板商品、こだわりだけを使う。未指定なら無理に入れない。検索順位への直接効果のエビデンスは限定的と扱い、自然さを優先する。 |
| 公式資料 | 禁止事項、医療・福祉リスク、規約違反疑いの判断に使う。 |
| 公開運用記事 | 返信の構成、温度感、避ける癖の参考にする。例文本文は使わない。 |
| ローカル実ファイル | ユーザーが指定した場合だけ参照する。指定がなければ使わない。 |
| 未確認材料 | 返信本文へ混ぜず、確認メモか質問候補に分ける。 |

## 採用する型

### 高評価

1. 評価・投稿への感謝を述べる。
2. 口コミ本文の情報量に応じて、安全な具体点を1〜4点拾う。多い場合は一文で束ねる。
3. 標準版は事業者の今後の姿勢を一般化して締める。
4. SEO語・差別化ポイント入り版は、確認済みのSEO語セットを1つだけ自然に加える。地域名と業種語が自然な一まとまりなら1セットと数える。

### 中立・要望

1. 投稿への感謝を述べる。
2. 良い点があれば短く受け止める。
3. 要望や不満点を無視せず、確認・改善姿勢へつなげる。

### 低評価

1. 不快感や不安への受け止めを短く書く。
2. 公開で断定できない事実は説明しすぎない。
3. 個別確認が必要な内容は、電話、メール、問い合わせフォームのうち1つだけへ誘導する。

### 星だけ

1. 評価への感謝だけを短く書く。
2. 利用内容、来店内容、症状、担当者を推測しない。

## AI返信候補との差別化

- GBP管理画面にAI返信候補が表示される場合も、汎用AI文も、そのまま採用せず、本文固有点、業種リスク、直近返信との重複を確認する。
- 感謝、褒め言葉、再来訪依頼だけの定型3文に固定せず、口コミの情報量に応じて焦点を変える。
- 医療、福祉、士業、低評価では、自然さより先に個人情報、効果保証、事実確認の境界を確認する。

## 返信タイミングの扱い

- Google公式の「適時に返信する」という推奨を、高評価・中立評価は数日以内という運用目安へ落とす。
- 低評価はP5の確認優先を踏まえ、感情的な即返しを避け、事業主の事実確認後24〜72時間以内を目安にする。
- 重大な個人情報・医療・法務リスクがある場合は、時間目安より確認を優先する。

## 確認方法

- 返信案が、ユーザー提供の口コミ本文と事業者情報だけで成立している。
- SEO語・差別化ポイント入り版で、未確認の地域名、サービス名、看板商品、こだわりを足していない。
- 低評価で、公開反論よりも受け止めと非公開導線が優先されている。
- 医療・福祉系で、本文にない利用歴、症状、治療、効果、家族事情を認めていない。本文に明記された事実へ触れる場合も、詳細を広げず、効果保証や将来保証にしていない。
- 飲食系で、来店日時、注文内容、同伴者、支払内容を断定していない。
- 公開運用記事の例文をコピーしていない。

## 不合格時の対応

- 口コミ本文にない事実が入った場合は、その文を削る。
- 反論や責任転嫁に見える場合は、受け止めと確認導線だけに戻す。
- 医療・福祉系で個別事情を認めている場合は、運営姿勢と窓口案内へ置き換える。
- 規約違反や法務判断が必要な場合は、返信本文と別メモに分け、最新の公式情報確認を促す。

## 除外した材料

- 出典が広告色の強いツール販売記事だけで、根拠が確認できない数値。
- 公開記事内のコピー用テンプレート本文。
- Redditなど匿名投稿の個別成功談。運用仮説としては参考になるが、スキルの根拠にはしない。
