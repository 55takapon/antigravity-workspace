# 公開根拠台帳

このファイルは外部根拠の所在と適用限界を管理する。通常生成の文章規則は`reply-rules.md`と確認済み全文例に置き、この台帳で重複定義しない。高リスク判断、規約確認、根拠監査が必要な時だけ該当カードを読む。

## 出典階層

| 階層 | 使用範囲 | 使用しない範囲 |
|:---|:---|:---|
| 公式・行政 | 公開性、簡潔さ、非販促、privacy、規約、法規 | 固定日本語、固定文数、全文例の自動承認 |
| 専門職・査読研究 | 守秘、感謝、謝罪、第三者反応の限定的補助 | GBP全般への一般化、定型文の義務化 |
| 運用記事・テンプレ集 | ケース在庫、検査観点 | 原文コピー、公式根拠扱い、approved自動昇格 |
| ユーザー確認済み境界 | この運用内の日本語・全文例 | 外部一般論としての提示 |

## 材料の扱い

- 外部記事の元返信を確認済み全文例へコピーしない。
- ユーザーが明示承認・修正確定した新規全文だけを`confirmed-good`へ進める。
- client profileと最終返信logを優先し、knowledgeはprofileが許可した節だけ読む。
- 規約違反報告、医療広告、法務判断など返信文作成を超える判断では、作業時点の最新公式情報を確認する。
- phrase-levelの過去確定事項は`examples/quality-boundaries.md`に監査証跡として保持するが、通常生成の必読資料にしない。
