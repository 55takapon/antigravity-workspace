# 出力形式と再審査済み実例

通常は投稿可能な最終返信文だけを出す。内部整理、判断ラベル、調整意図、自己チェック、記録テンプレは表示しない。複数件は番号だけを付け、口コミとの対応を明確にする。事実確認・公開前確認・規約報告が必要な時だけ、返信本文の後へ短い注意メモを分けて記載する。

このファイルで完成文として示すのは、client原資料で確定状態を確認し、匿名化後に現行ルールで再審査した2件だけである。別口コミへ本文をコピーせず、適用条件と削除判断を参照する。作成者が考えた完成文を品質例として追加しない。

## 実例A: 詳細な高評価から2点へ絞った返信

| 項目 | 内容 |
|:---|:---|
| 出典種別 | client原資料のユーザー修正確定稿 |
| record ID | client-record-35 |
| 原資料上の状態 | ユーザー修正・確定 |
| skill内状態 | active-conditional |
| 投稿済み | 未確認。postedとみなさない |
| 匿名化 | 投稿者名を収録しない。本文・最終文に店名・地域名なし |
| 再審査結果 | 口コミの3要素を全列挙せず、雰囲気と接客の2点へ絞っており、事実追加・評価強度の水増しなし |

**入力となった口コミ**

> おいしかったです。お店の雰囲気が落ち着いていてゆっくり食事できました。丁寧に接客していただきありがとうございました。

**ユーザー修正後の最終文**

> 温かい口コミをありがとうございます。落ち着いた雰囲気の中でゆっくりお過ごしいただけたようで、また接客も丁寧とお褒めくださり、嬉しく思います。またのご来店をお待ちしております。

適用条件:

- 本文のある高評価で、profileがこの敬語・事業者側の感情表現に合い、接客上の歓迎締めが文脈に適する。
- 口コミが「ゆっくりできた」「接客が丁寧」と明記している。
- 詳細の全列挙を避け、主要テーマを最大2つに絞る必要がある。

不適用条件:

- 事業者側の感情表現を使わないprofile、星だけ、低評価、医療・法務等で再訪・再相談の歓迎が不適切な高リスク内容。
- 「過ごしていたようだ」という内心推測になる入力。元口コミに同等の記載がなければこの受け方を使わない。

## 実例B: 明確な低評価を受け止めた返信

| 項目 | 内容 |
|:---|:---|
| 出典種別 | client原資料の確定・返信済み稿 |
| record ID | client-record-36 |
| 原資料上の状態 | 確定・返信済み |
| skill内状態 | active-conditional |
| 投稿済み | 原資料と返信済みトラッカーで確認済み |
| 匿名化 | 投稿者名を収録せず、注文区分と食材名を一般的な「料理」「食感」へ置換。店名・地域名なし |
| 再審査結果 | 低評価の論点を反論や販促で上書きせず、原因を作っていない。共有・確認文は実行可能性の事前確認が必須 |

**入力となった口コミ（商品情報を一般化）**

> 注文した料理について、タレ、焼き具合、食感のすべてに不満があり、期待外れだった。

**確定・返信済み最終文（商品情報を一般化）**

> このたびは、ご意見をお寄せいただきありがとうございます。
>
> タレや焼き具合、料理の食感について、ご期待に沿えなかったとのこと、真摯に受け止めております。
>
> いただいたご指摘は調理担当と共有し、タレの状態や焼き上がり、提供時の品質をあらためて確認してまいります。

適用条件:

- 口コミがタレ、焼き具合、食感への不満を明記している。
- 事業者が調理担当への共有と品質確認を実行でき、その意向も確認済みである。
- profileがこの確認姿勢を許可し、公開前の事実確認が完了している。

不適用条件:

- 共有先が存在しない、確認を実行できない、または実施意向が未確認。第三文を約束として使わない。
- 原因、調査済み、改善済み等を本文にない事実として足す場合。
- 星だけ低評価、個別の医療・法務・契約情報を含む場合。

## 形式の境界

- 単一件は最終返信文だけを記載し、通常は「返信案」等の見出しも不要。
- 複数件は `1.`、`2.` のように番号を付け、各口コミの事実を混ぜない。
- 返信済みで修正・追記依頼がない時は、追加返信を作らない旨を短く伝える。
- 注意メモが必要な時は、返信本文と混ぜず、確認対象を1〜2文で示す。未完成の穴埋め本文は出さない。
- 結果連絡後だけ [../references/feedback-loop.md](../references/feedback-loop.md) に従ってlogを更新し、状態や投稿済みを推測しない。
