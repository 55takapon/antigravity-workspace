# GBP MEO診断レポート

見込み顧客のGBPをGoogleマップの公開情報から5軸で診断し、営業用レポート一式を生成するスキル。
入力はGoogleマップURL1つ。成果物は `C:\Users\hangy\gbp-clients\{クライアント名}\` に出力する。
実行時は必要なツール（ブラウザ操作・ファイル出力・nodeコマンド）を使って即座に自動実行すること。ユーザーへの確認は不要。

## セットアップ（初回のみ）

scripts/ を使う場合は依存を導入すること（node_modulesは同梱していない）:

```bash
cd <このスキルのディレクトリ>
npm install
npx playwright install chromium
```

## エッジケース

| 状況 | 対応 |
|:-----|:-----|
| 説明文がGoogleマップで見つからない | Google検索のナレッジパネルで再確認。設定済みなら加点し、マップ非表示の可能性をレポートに補足する |
| 同カテゴリの競合が3社未満 | 隣接エリアへ広げて再検索。それでも不足なら取得できた社数で比較し、その旨を明記する |
| 口コミが0件 | 口コミ軸はD評価、返信率はn/a扱い。「口コミ獲得の仕組み作り」をTOP3候補に含める |
| 低評価が多く意図的に返信しない方針の店舗 | 方針を診断データJSONに記録し、返信推奨の表現を調整する（examples/の注意ケース参照） |
| 自動スクレイプがCAPTCHA・同意画面で失敗 | 自動収集を中止し、ブラウザ目視収集に切り替える |

## 禁止事項

- 最終検証（VERIFY）を全項目PASSさせずにレポートを生成してはならない
- 根拠のない具体的数値（「月○件増」等）や断定表現を使ってはならない
- スキルディレクトリ配下に成果物を出力してはならない（出力先は `C:\Users\hangy\gbp-clients\`）
- 検索結果一覧のサマリー数値を競合データとして使ってはならない（必ず個別ページで確認する）
- 命名規則（references/06_file-naming.md）に従わないファイル名で出力してはならない
- 月次レポートをこのスキルで作ってはならない（`gbp-monthly-report` を使う）
