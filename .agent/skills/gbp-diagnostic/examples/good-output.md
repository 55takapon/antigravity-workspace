# 診断の入力→出力例（実データ）

実際に納品した診断2件からの抜粋。成果物ファイルは `C:\Users\hangy\gbp-clients\{クライアント名}\` に保管されている。

---

## 例1: 正常系 — ハレノヒカフェ（カフェ / 総合C）

**出典**:
- 入力: `C:\Users\hangy\gbp-clients\harenohi_cafe\diagnostic_data_harenohi_cafe_20260402.json`
- 出力: 同フォルダの `diagnostic_report_harenohi_cafe_20260402.html` / `_notebook.txt` / `diagnostic_sales_pitch_harenohi_cafe_20260402.txt`

### 入力（収集データの要点）

| 項目 | 値 |
|---|---|
| 口コミ | 77件 / 平均4.2 / 返信0件（サンプル・参考値） |
| 写真 | 25枚 |
| 投稿 | 0件（投稿機能未活用） |
| 説明文 | 未設定 |
| 属性 | 3個 |
| 競合 | cafe lien 4.5/100件, Blanket 4.0/147件, kinsendo 4.1/92件, Tokiaprofumo 4.3/53件 |

### 出力（NotebookLMテキストの抜粋）

```
## スライド2: 総合スコア
総合評価: C（改善が必要）
スコア: 49/100点

5軸の評価:
  B 基本情報の完全度: 50点
  A 写真・動画の充実度: 75点
  B 口コミの力: 55点
  D 投稿の活用度: 0点
  B 競争力: 50点

## スライド4: 伸びしろ 🥇 第1位
テーマ: 投稿の定期更新
現在のランク: D
現状の課題:
  - 投稿機能が活用されていません
改善の方向性: 最新情報・写真・イベント情報を定期的に投稿することで、
  GBPの活性度を高める効果が期待できます
想定工数: 投稿企画・写真撮影・文案作成: 1投稿あたり30〜60分、月4回程度
```

**この例で見るべき点**:
- Dランクの軸（投稿）が優先度1としてTOP1に選定されている
- 返信率がサンプル算出のため「参考値」注釈が付いている
- 効果は「期待できます」の定性表現で、断定数値がない

## 例2: 注意ケース — ミート歯科（歯科医院 / 低評価・返信しない方針）

**出典**:
- 入力: `C:\Users\hangy\gbp-clients\meet_dental\diagnostic_data_meet_dental_20260329.json`
- 出力: 同フォルダの `diagnostic_report_meet_dental_20260329.html` / `_notebook.txt`

### 入力（収集データの要点）

| 項目 | 値 |
|---|---|
| 口コミ | 21件 / 平均3.5 / 低評価（★1）が直近に集中 |
| 特記事項 | `replyRateNote`: 全21件中返信0件。ネガティブ口コミに意図的に返信しない方針 |
| 写真 | 106枚（充実） |
| 投稿 | 直近3ヶ月で6件（活用中） |
| 競合 | 岩田歯科 4.0/50件, 山本歯科 4.3/41件, おおきデンタル 4.0/27件 |

### 出力（NotebookLMテキストの抜粋）

```
## スライド2: 総合スコア
総合評価: B（平均的）
スコア: 66/100点

5軸の評価:
  S 基本情報の完全度: 90点
  A 写真・動画の充実度: 85点
  C 口コミの力: 45点
  B 投稿の活用度: 70点
  D 競争力: 25点

## スライド4: 伸びしろ 🥇 第1位
テーマ: 競合との差別化
現在のランク: D
現状の課題:
  - 口コミ件数が競合に比べて少ない（21件）
  - 平均評価が競合平均(4.1)を下回り(3.5)
改善の方向性: 口コミ・写真・投稿の各項目で競合を上回ることで、
  ローカルパックでの上位表示の可能性が高まります
```

**この例で見るべき点**:
- 基本情報S・写真Aでも、競争力Dが最優先課題としてTOP1になる（優先度ルールどおり）
- 「意図的に返信しない方針」を診断データJSONの特記事項に記録している
- 投稿が活用中（6件/3ヶ月）のため「投稿機能が活用されていません」の定型文を使っていない
  （事実と矛盾する定型文の禁止ルールが機能しているケース）
