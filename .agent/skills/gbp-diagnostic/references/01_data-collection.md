# データ収集手順と注意事項

診断の入力となるGBP公開情報の収集ルール。データ収集はブラウザ（browser_subagent）での目視確認を正とする。

## 全体フロー

```
【入力】GoogleマップURL（例: https://maps.google.com/maps?cid=XXXXX）
   ↓
【収集】基本情報 / 口コミ / 写真 / 投稿 / 属性 / 競合
   ↓
【出力】診断データJSON（後続のスコアリング・レポート生成の唯一の入力）
```

## ブラウザでの収集手順

1. GoogleマップURLを開く
2. ビジネス名・カテゴリ・住所・電話・URL・営業時間を取得
3. 説明文を取得（下記「説明文の表示場所による違い」を必ず参照）
4. 口コミセクションで件数・平均評価を取得
5. **口コミを「新しい順」にソートしてから**最大20件分スクロール取得（テキスト・評価・日付・オーナー返信有無）
   - 絶対ルール: サンプリングは必ず最新の口コミから開始する
   - 返信の有無は各口コミの直下に「オーナーからの返信」があるかを1件ずつ確認する
6. 写真タブで写真枚数を取得し、以下4カテゴリの有無を個別確認する:
   - 外観写真（オーナー提供）
   - 内観/店内写真（オーナー提供）
   - 商品/メニュー写真
   - スタッフ/施術者写真
7. 投稿を全件確認する:
   - 概要タブの「最新情報」セクションを確認
   - 「すべての最新情報を表示」をクリックして投稿一覧を開く
   - 直近3ヶ月分の投稿日と件数を正確にカウントする
   - 投稿の種類（最新情報/イベント/特典）を確認する
8. 「基本情報」タブを**最下部まで必ずスクロール**し、全カテゴリの属性を1個ずつ取得する
   - バリアフリー、サービスオプション、健康と安全、決済方法など全カテゴリ
   - 表示されている属性の総数が2個以下の場合、スクロール不足を疑って再確認する
9. 競合検索を行う（下記「競合検索の正確性」を必ず参照）

## 説明文の表示場所による違い

- **Google検索結果（ブラウザ）** → 説明文は表示される
- **Googleマップ（ブラウザ版）** → 投稿（最新情報）が存在する場合、説明文が非表示になることがある
- **Googleマップ（アプリ版）** → 説明文は表示される
- 取得手順: ①まずGoogleマップで確認 → ②見つからなければGoogle検索（`ビジネス名 地域名`）でナレッジパネルを確認
- 設定済みだがマップ非表示の場合: スコア上は「設定済み」として加点し、レポートには「Googleマップのブラウザ版では投稿が優先表示されるため、説明文がPC検索ユーザーに直接見えない可能性があります」と補足する

## 投稿の正確なカウント

- 概要タブのトップに表示される投稿は最新の1件のみの場合がある
- 必ず「すべての最新情報を表示」で全投稿一覧を確認する
- 「○週間前」等の相対表示ではなく、表示される**具体的な日付**を記録する

## 競合検索の正確性（最重要）

- **検索クエリ**: GBPに表示されている**メインカテゴリ名そのもの**＋エリア名で検索する
  - NG例: 「飲食店 加古川」（広すぎてカフェや中華も含まれる）
  - OK例: 「居酒屋 加古川」（カテゴリ名と完全一致）
- **カテゴリフィルタ**: 各店舗のカテゴリが対象店舗と同一または類似であることを確認し、異なるカテゴリは除外する
- **個別ページ確認必須**: 検索結果一覧のサマリー数値は不正確な場合がある。必ず各競合の個別ビジネスページを開き、以下を目視確認する:
  - 店舗名の正式表記 / カテゴリ名 / 平均評価（小数点第1位まで） / 口コミ件数（正確な数値）
- スコアリングには取得した全社（3〜5社）を使い、レポート表示は口コミ数上位3社に限定する
- 不正確な競合データは絶対に記載しない。データの信頼性がレポート全体の信用を左右する

## 収集データJSONの構造

```json
{
  "basic": {
    "name": "ビジネス名",
    "category": "メインカテゴリ",
    "subCategories": ["サブカテゴリ1"],
    "address": "住所",
    "phone": "電話番号",
    "website": "URL",
    "hours": { "月": "11:00-23:00" },
    "description": "説明文（あれば）",
    "attributes": ["Wi-Fi", "個室", "駐車場"]
  },
  "reviews": {
    "totalCount": 45,
    "averageRating": 4.2,
    "items": [
      { "rating": 5, "text": "口コミ本文", "date": "2026-03-15", "hasOwnerReply": true }
    ]
  },
  "photos": {
    "totalCount": 23,
    "hasExterior": true,
    "hasInterior": true,
    "hasFood": true,
    "hasStaff": false
  },
  "posts": {
    "latestPostDate": "2026-03-15",
    "recentCount": 3,
    "hasOffer": false,
    "hasEvent": false
  },
  "competitors": [
    { "name": "競合A", "rating": 4.5, "reviewCount": 120, "photoCount": 45 }
  ]
}
```

特記事項（例: 低評価口コミに意図的に返信しない方針）がある場合は、JSONに `replyRateNote` 等のメモとして必ず記録し、後続の表現調整に使う。
