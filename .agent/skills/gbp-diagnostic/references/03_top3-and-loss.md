# 伸びしろTOP3の選定ロジックと機会損失の表現

## TOP3の選定基準

5軸のスコアから、以下の優先度で改善インパクトが大きい項目を3つ選定する:

```
優先度1: スコアがD（0-29）の軸 → 「深刻な問題」として最優先
優先度2: スコアがC（30-49）の軸 → 「改善が必要」として次点
優先度3: 同ランクの場合は重み順
         （口コミ30% > 基本情報25% > 写真20% > 投稿15% > 競争力10%）
```

## 伸びしろの表現テンプレート

各項目は「現状 → 伸びしろ → 推奨アクション → 想定工数」の4要素で構成する。

```
【投稿がDランクの場合】
  現状: 投稿が{最新投稿からの日数}日間更新されていません
  伸びしろ: 定期的な投稿でGBPの「活性度」が高まり、
    検索表示回数の改善が見込まれます
  推奨アクション: 週1回の投稿（最新情報・写真・イベント情報）
  想定工数: 投稿テーマの企画・写真撮影・文案作成で1投稿あたり約30〜60分

【口コミ返信率がCランクの場合】
  現状: {返信率}%の口コミに未返信です
  伸びしろ: 口コミへの丁寧な返信は、他の閲覧者の来店意欲を
    高める効果が期待できます
  推奨アクション: 全口コミへの個別対応（過去分＋今後の即時返信体制構築）
  想定工数: 過去の未返信{件数}件の対応に約{時間}時間＋今後は1件5〜10分

【写真がCランクの場合】
  現状: 写真{枚数}枚（業種平均{業種平均}枚に対して不足）
  伸びしろ: 写真の充実は第一印象を高め、来店検討者の
    興味を引く重要な要素です
  推奨アクション: 外観・内観・商品/メニュー・スタッフ等の
    カテゴリ別に計{推奨枚数}枚以上の掲載を推奨
  想定工数: プロカメラマン撮影 or 自社撮影＋編集で半日〜1日
```

## 表現ルール（必須）

- 数値の断定を避ける: 「〜倍になります」→「〜倍に改善が見込まれます」「〜の可能性があります」
- 投稿頻度の推奨は最大「週1回」を上限とする
- 根拠のない数値を使わない: 「問い合わせ○件増」→「問い合わせ増加が期待できます」
- レポート最終段階で全文の断定表現チェックを必ず実施する
- 対象店舗の事実と矛盾する定型文を使わない
  （例: 返信率100%の店舗に「返信がありません」、週1投稿中の店舗に「投稿機能が活用されていません」）
- 低評価口コミに意図的に返信しない方針の店舗では、「100%返信を推奨」の定型表現を方針に合わせて調整する

## 推定機会損失の表現（定性表現のみ）

具体的な「月○件」等の数値は使用しない。総合ランク別の定性表現で危機感を喚起する。

| 総合ランク | 表現例 |
|-----------|--------|
| S | 現時点で非常に高い水準です。さらなる最適化で持続的な成長が期待できます |
| A | 改善ポイントを押さえることで、さらなる集客効果が期待できます |
| B | いくつかの改善により、現在取りこぼしている可能性のある顧客層にアプローチできます |
| C | 複数の重要項目に改善余地があり、相当数の集客機会を逃している可能性があります |
| D | 基本的な設定から見直しが必要で、本来の集客力を大きく下回っている状態です |
