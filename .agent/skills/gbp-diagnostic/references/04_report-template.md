# レポートテンプレート（成果物4形式）

成果物は以下の4形式＋診断データJSONの計5点。CTA・連絡先は必ず `knowledge/company-profile.md` の内容を使うこと。

## 1. HTMLレポート（PDF化用）

印刷時にA4で美しく出力されるCSS設計とし、以下の構成で生成する。

```html
<header>
  GBP MEO 無料診断レポート
  {ビジネス名} 様 / 診断日: {日付}
  ※本レポートはGoogleマップ上の公開情報に基づく簡易診断です
</header>

<section id="summary">
  <!-- 総合スコア（大きく表示） / 5軸のスコアバー（視覚的） / 一言コメント -->
</section>

<section id="opportunity">
  <!-- 推定される機会損失（定性表現。references/03参照） -->
</section>

<section id="top3">
  <!-- 伸びしろTOP3（🥇🥈🥉） -->
  <!-- 各項目: 現状 → 伸びしろ → 推奨アクション → 想定工数 -->
</section>

<section id="axis-detail">
  <!-- 5軸それぞれの詳細分析: スコア + 現状データ + 課題 + 改善の方向性 -->
</section>

<section id="competitor">
  <!-- 競合比較（表形式）: 御社 vs 上位3社の口コミ数・評価・写真数 -->
</section>

<section id="action-list">
  <!-- 改善アクション一覧（優先度順）: 内容 + 難易度(★) + 想定工数 -->
</section>

<footer>
  <!-- まとめ + CTA（knowledge/company-profile.md の文言・連絡先を使用） -->
  <!-- 免責: 「※本レポートの評価基準は一般的な業種ベンチマークに基づくものであり、
       個別の状況により最適な施策は異なる場合があります」 -->
</footer>
```

## 2. NotebookLM用テキスト

NotebookLMに読み込ませてスライド化するための構造化テキスト（9スライド構成）。

```
# {ビジネス名} 様 GBP MEO診断結果

## スライド1: 表紙
タイトル: Googleビジネスプロフィール診断レポート
サブタイトル: {ビジネス名} 様 / 日付: {診断日} / 業種: {業種}
※Googleマップ上の公開情報に基づく簡易診断です

## スライド2: 総合スコア
総合評価: {ランク}（{ランクの意味}） / スコア: {点数}/100点
5軸の評価を一覧表示

## スライド3: 推定される状況
{機会損失の定性表現}

## スライド4〜6: 伸びしろ 🥇🥈🥉
各: テーマ / 現在のランク / 現状の課題 / 改善の方向性 / 想定工数

## スライド7: 競合との比較
{競合比較テーブル}

## スライド8: 改善アクション一覧
{優先度順のアクション + 難易度 + 工数}

## スライド9: まとめ・ご提案
{CTAメッセージ（knowledge/company-profile.md準拠）}
```

## 3. 営業トーク稿（diagnostic_sales_pitch）

商談・電話で読み上げる想定のテキスト。実績のある以下の3部構成で生成する
（実例: 過去納品分 `diagnostic_sales_pitch_harenohi_cafe_20260402.txt` に基づく構成）。

```
■ 現状と機会損失について
  - 「検討段階の見込み客がマップの口コミ・更新状況で最終確認する」という行動事実の提示
  - 対象店舗で機会損失が起きている客観的事実の指摘（断定数値は使わない）

■ 主なボトルネック（現状の課題点）
  - 伸びしろTOP3を箇条書きで要約
  - 各項目に診断の実数値（口コミ件数・返信率・属性数等）を添える
  - サンプル算出の返信率には「参考値」を必ず付記

■ MEOの資産化とご提案
  - 「プロ運用でアカウントを集客資産として育てる」提案
  - オーナー側の協力（口コミ獲得等）が必要である旨を正直に伝える
  - 「前向きに改善したい場合は運用パートナーとして伴走可能」のクロージング
```

トーンのルール:
- 危機感の喚起は事実ベースで行い、煽り表現・断定的な効果数値は使わない
- 「我々だけでは達成できない。オーナー様の協力が必要」という誠実さを必ず含める

## 4. PDF

HTMLレポートを `node scripts/generate_pdf.js <HTMLパス>` でPDF化する。手動で印刷ダイアログを使わない。
