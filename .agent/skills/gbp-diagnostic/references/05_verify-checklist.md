# 最終検証チェック（データ照合）

> このチェックを全項目PASSしなければ、レポート生成・ユーザー報告に進んではならない。

データ収集完了後、レポート生成前に以下の全項目をブラウザで目視照合する。
browser_subagentで対象ページを開き直し、各項目をスクリーンショット付きで確認する。

## VERIFY-1: 基本情報照合

```
□ ビジネス名が正確か（公式表記と一致）
□ カテゴリが正確か（メインカテゴリのテキスト一致）
□ 住所が正確か（番地・ビル名まで）
□ 電話番号が正確か
□ ウェブサイトURLが正確か（リンク先が存在するか）
□ 営業時間が全曜日取得できているか
```

## VERIFY-2: 説明文照合

```
□ 説明文の有無を以下の3箇所で確認したか:
  ├─ Googleマップ概要タブ → あり/なし
  ├─ Googleマップ基本情報タブ → あり/なし
  └─ Google検索ナレッジパネル → あり/なし
□ 説明文がある場合、文字数は正確にカウントしたか
□ マップでは非表示だが検索では表示される場合、その旨を記録したか
```

## VERIFY-3: 属性・サービス照合

```
□ 「基本情報」タブを最下部までスクロールしたか
□ カテゴリごとの項目数を記録したか
  （サービスオプション/サービス/特徴/食事/設備/雰囲気/その他）
□ 属性+サービスの総数が収集データと一致するか
```

## VERIFY-4: 口コミ返信率照合

```
□ 口コミ総件数が収集データと一致するか
□ 平均評価が収集データと一致するか
□ 返信率の算出根拠を記録したか:
  ├─ 全件確認の場合 → 「X/Y件確認」
  └─ サンプルの場合 → 「X/Y件のサンプル（全Z件中）・参考値」
□ サンプルベースの場合、レポートに「参考値」注釈が含まれるか
```

## VERIFY-5: 投稿照合

```
□ 「すべての最新情報を表示」をクリックして全投稿一覧を確認したか
□ 直近3ヶ月の投稿日を全て記録したか（具体的な日付で）
□ 投稿件数・最新投稿日が収集データと一致するか
```

## VERIFY-6: 写真照合

```
□ 写真タブで総枚数を確認したか
□ 写真カテゴリ（外観/内観/商品/スタッフ）の有無が正確か
```

## VERIFY-7: 競合照合（最重要）

```
□ 検索クエリが「GBPメインカテゴリ名 × エリア名」で正確か
□ 各競合のカテゴリが対象店舗と同一または類似か（異カテゴリを除外したか）
□ 各競合の個別ビジネスページを開き、以下を目視確認したか:
  - 店舗名の正式表記 / カテゴリ名 / 平均評価（小数点第1位） / 口コミ件数
□ 検索結果一覧のサマリー数値ではなく、個別ページの数値を使用しているか
□ 不正確なデータが含まれていないか（信用に直結する）
```

## VERIFY-8: レポート出力検証（レポート生成後に実施）

```
□ HTML内のスコアが期待値と一致するか（grep/Select-Stringで確認）
  - 口コミ返信率が「0/XX件」のままになっていないか
  - 投稿スコアが極端に低くないか（投稿がある場合）
  - 写真スコアが実態と乖離していないか（写真ありの場合）
□ 「改善アクション」に事実と矛盾する記述がないか
  例: 返信率100%なのに「返信がありません」
  例: 週1投稿しているのに「投稿機能が活用されていません」
□ 競合テーブルの数値がVERIFY-7のスクリーンショットと一致するか
```

## チェック実行方法

```
1. 対象GBPページをbrowser_subagentで開き直す
2. 各VERIFYセクションについて:
   a. 該当セクションに移動（タブ切替・スクロール）
   b. スクリーンショットを取得
   c. 収集データと照合
   d. 不一致があれば修正
3. 全項目PASSしたら「✅ 最終検証完了」を記録
4. 1つでもFAILがあれば: データ修正 → 再スコアリング → 再VERIFY
```

## チェック結果報告フォーマット

```markdown
## 最終検証結果

| # | チェック項目 | 結果 | 備考 |
|---|-----------|------|------|
| V1 | 基本情報照合 | ✅/❌ | {不一致があれば詳細} |
| V2 | 説明文照合 | ✅/❌ | {取得元: マップ/検索} |
| V3 | 属性・サービス照合 | ✅/❌ | {項目数: XX個} |
| V4 | 口コミ返信率照合 | ✅/❌ | {X/Y件, 参考値/全件} |
| V5 | 投稿照合 | ✅/❌ | {直近3ヶ月: X件} |
| V6 | 写真照合 | ✅/❌ | {総枚数: XX枚} |
| V7 | 競合照合 | ✅/❌ | {X社取得} |

判定: 全項目PASS → レポート生成に進む
```

（V8はレポート生成後に同表へ追記する）

## スクリーンショットの後始末

検証で取得したスクリーンショット（1診断あたり約20-40枚）は蓄積するため、
レポート納品後に `node scripts/cleanup_screenshots.js` で定期削除する（使い方はスクリプト冒頭のUsage参照）。
