# GBP MEO運用スキル｜施術院（整体院）

> **対象**: 整体院・整骨院（接骨院）・鍼灸院・カイロプラクティック・リラクゼーションサロン
> **フォーカス**: 整体院（民間資格、保険適用外の手技療法）
> **前提**: コアスキル（`gbp-meo-core/SKILL.md`）の知識を前提とする
> **分類方針**: 医療広告ガイドライン適用のクリニック（`gbp-meo-medical`）とは独立。法的資格要件・広告規制・GBPカテゴリが根本的に異なるため別スキルとして体系化
> **最終更新**: 2026-03-28

## 1. 施術院のMEO市場環境（2025-2026）

### 1.1 施術院×ローカル検索の現状

- **施術院の市場規模**: 整体院・整骨院・鍼灸院・リラクゼーション店を合わせると全国約14万件超。コンビニの2倍以上の超激戦市場
- **「症状名＋地域名」検索の主戦場**: 「肩こり 整体 ○○駅」「腰痛 整骨院 ○○区」等の症状ベースの検索がMEOの主戦場
- **予約サイト経由 vs Googleマップ直接**: ホットペッパービューティー等の予約サイト経由に加え、Googleマップからの直接予約・電話が急増
- **AI検索の影響**: 「肩こりに整体と整骨院どちらがいい？」のような比較クエリにAI Overviewsが回答。業態の違いを明確に情報発信するクリニックが引用される
- **口コミの質が決定的**: 「施術の効果」「先生の技術力」「体の変化」等の具体的な口コミが来院を左右

### 1.2 整体院・整骨院・鍼灸院の違い（MEO観点で最重要）

> **⚠️ この違いの理解がMEO戦略の出発点**。カテゴリ設定・広告規制・口コミ戦略のすべてに影響する。

| 項目 | 整体院 | 整骨院（接骨院） | 鍼灸院 |
|------|--------|----------------|--------|
| **国家資格** | **不要**（民間資格） | **必要**（柔道整復師） | **必要**（はり師/きゅう師） |
| **保険適用** | **なし** | **あり**（急性外傷） | **あり**（慢性疾患6症） |
| **GBPメインカテゴリ** | 「整体」 | 「整骨院・接骨院」 | 「鍼灸院」 |
| **Schema @type** | `HealthAndBeautyBusiness` | `MedicalBusiness` | `MedicalBusiness` |
| **適用法規** | 景品表示法のみ | **柔整師法** + 景表法 | **あはき法** + 景表法 |
| **広告制限** | 比較的緩い | **中程度**（施術内容の広告制限あり） | **中程度**（施術内容の広告制限あり） |
| **「治る」表現** | ❌ 使用不可 | ❌ 使用不可 | ❌ 使用不可 |
| **競合密度** | 非常に高い | 高い | 中程度 |

### 1.3 施術院MEOの難易度と特徴

| 項目 | 施術院の特徴 |
|------|------------|
| 競合密度 | **極めて高い**（整体+整骨+鍼灸で都市部半径1km内に30〜80院） |
| 口コミ優先度 | **最重要**（施術効果・先生の技術への評価が直結） |
| 写真の影響度 | **高い**（清潔感・施術風景・スタッフの信頼感） |
| リピート率 | **高い業種**（定期メンテナンスの来院サイクル） |
| 広告規制 | 業態により異なる（整体<整骨≒鍼灸） |
| 季節変動 | 中程度（冬の肩こり・梅雨の体調不良等） |

→ コアスキル セクション1（MEO全体像・ランキング要因）を前提知識として参照

## 2. カテゴリ・属性の最適設定

### 2.1 GBPカテゴリ設定

#### メインカテゴリ（業態別に1択で厳選）

| 業態 | 推奨メインカテゴリ | 注意点 |
|------|------------------|--------|
| 整体院 | **「整体」** | 「マッサージ」とは別カテゴリ |
| 整骨院/接骨院 | **「整骨院・接骨院」** | 柔道整復師の国家資格が必要 |
| 鍼灸院 | **「鍼灸院」** | はり師/きゅう師の国家資格が必要 |
| 鍼灸整骨院 | **「鍼灸院」**または**「整骨院・接骨院」** | 主力サービスに合わせて選択 |
| カイロプラクティック | **「カイロプラクティック」** | 日本では民間資格 |
| リラクゼーション | **「マッサージ」** | 「あん摩マッサージ指圧師」資格なしの場合 |

> **⚠️ カテゴリの誤登録は最も多いMEO失敗原因**: 整体院が「整骨院・接骨院」カテゴリを設定すると、Googleのポリシー違反リスク＋信頼性低下。資格に基づいた正確なカテゴリ選択が必須。

#### サブカテゴリ（推奨2〜4個）

**整体院の場合:**
1. 「マッサージ」
2. 「カイロプラクティック」（カイロ施術を行う場合）
3. 「リフレクソロジー」（足つぼ等を行う場合）
4. 「理学療法クリニック」（理学療法に近い手技を行う場合）※慎重に

**整骨院の場合:**
1. 「整体」（整体メニューもある場合）
2. 「鍼灸院」（鍼灸も行う場合）
3. 「理学療法クリニック」（リハビリ要素がある場合）
4. 「スポーツ医学クリニック」（スポーツ障害対応の場合）※慎重に

**鍼灸院の場合:**
1. 「整体」（手技療法も行う場合）
2. 「整骨院・接骨院」（柔整師も在籍する場合）
3. 「マッサージ」（マッサージも提供する場合）
4. 「東洋医学クリニック」（漢方相談も行う場合）

### 2.2 属性設定チェックリスト（施術院固有）

#### 必須属性
- [ ] **バリアフリー**: 車椅子対応入口 / エレベーター
- [ ] **駐車場**: あり/なし/台数（郊外型は特に重要）
- [ ] **支払い方法**: 現金 / クレジットカード / 電子マネー / 保険適用（整骨院）
- [ ] **予約**: 予約制 / 予約優先 / 当日受付可
- [ ] **性別**: 女性施術者在籍（女性患者に最重要の属性）

#### 施術院重要属性
- [ ] **個室**: 個室施術あり/なし（プライバシー配慮）
- [ ] **着替え**: 施術着の用意あり/なし
- [ ] **子連れ**: お子様連れOK / キッズスペースあり
- [ ] **深夜・早朝営業**: 21時以降/朝8時前の営業（差別化ポイント）
- [ ] **日曜・祝日営業**: 日祝対応は限られるため大きな差別化
- [ ] **急患/予約なし**: 当日来院可（「今すぐ行きたい」検索に対応）
- [ ] **初回限定特典**: ※GBP属性ではなく投稿で訴求（景表法注意）

> **「女性施術者在籍」「個室」属性は超重要**: 女性患者の約40%が女性施術者を指名検索する。個室は「整体 個室 ○○」の高CVRキーワードに直結。

## 3. 写真・動画コンテンツ戦略

### 3.1 施術院の必須写真カテゴリ

施術院は**清潔感・安心感・施術者の信頼感**が来院決定の鍵。最低20枚、理想40枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **外観** | 3〜5枚 | 昼/夜・看板・入口（初来院でもわかるカット） |
| **受付・待合スペース** | 2〜3枚 | 清潔感・リラックスできる空間 |
| **施術室** | 3〜5枚 | ベッド・タオルセッティング済みのきれいな状態 |
| **個室** | 2〜3枚 | プライバシーが保たれる空間（あれば） |
| **施術風景** | 5〜8枚 | 施術中のイメージカット（顔はモザイク/背面撮影） |
| **施術者ポートレート** | 3〜5枚 | 笑顔のポートレート＋施術中の真剣な表情 |
| **資格証書・認定証** | 1〜2枚 | 壁に掲げた資格証書（信頼性の視覚的証明） |
| **施術前後の姿勢比較** | 2〜3枚 | 姿勢写真のビフォーアフター（顔は映さない） |
| **院内の衛生管理** | 1〜2枚 | タオル交換・消毒・換気の様子 |

### 3.2 施術写真の撮影テクニック

```
【施術風景写真のコツ】
  ✓ 患者の顔は「映さない」のが鉄則（背面/横顔/モザイク）
  ✓ 施術者の手元にフォーカス（技術力のアピール）
  ✓ 温かみのある照明（リラックス感の演出）
  ✓ 清潔なタオル・シーツが映るように
  ✓ 施術着を着た状態で（Tシャツ等のカジュアルすぎる服装はNG）

【姿勢比較写真のコツ】
  ✓ 同じ場所・同じ服装・同じ角度で撮影
  ✓ 顔は映さない（後頭部or全身シルエット）
  ✓ 施術前後の差がわかる姿勢写真（横からの全身ショット）
  ✓ 「整体で治る」等の表現は添えない（広告規制）

【ファイル最適化】
  ✓ ファイル名: 「新宿_整体_骨盤矯正_施術.jpg」
  ✓ 解像度: 1200x900px以上
  ✓ ジオタグ: 院内で位置情報ONにして撮影
```

### 3.3 動画コンテンツ案（75秒フル活用）

| 動画テーマ | 尺 | 内容 |
|-----------|-----|------|
| **院内ツアー** | 45〜75秒 | 外観→受付→施術室→設備の一連 |
| **施術の流れ紹介** | 60〜75秒 | カウンセリング→検査→施術→施術後説明 |
| **セルフケア指導** | 30〜60秒 | 肩こり改善ストレッチ・腰痛予防体操 |

| **アクセス案内** | 30〜45秒 | 最寄り駅→院までの道順 |

> **セルフケア動画は最強コンテンツ**: 「肩こり ストレッチ」等で検索→動画視聴→「この先生に見てもらいたい」の来院導線を作る。YouTube/Instagramとの相互連携が効果的。

## 4. 口コミ獲得・管理（施術院特化）

### 4.1 施術院の口コミ獲得タイミング

施術院は**「体の変化を実感した瞬間」**に依頼するのが鉄則。

#### 最適タイミング
1. **施術直後（効果実感時）**: 「肩が軽くなった！」等の実感を述べた直後に依頼
2. **3〜5回目の来院時**: リピーターとして効果を実感している段階（質の高い口コミ）
3. **症状改善完了時**: 「もう大丈夫ですね」と卒業タイミング（最も具体的な口コミ）
4. **産後骨盤矯正完了時**: 結果に満足した母親からの口コミは影響力大
5. **メンテナンス継続中**: 定期来院の常連に自然な形で依頼

#### 口コミ依頼の声がけ例（施術院向け）
```
【施術後（効果実感時）】
「肩の動きが楽になったようですね！
 もし良ければ、同じ症状でお悩みの方の参考になりますので、
 Googleマップに感想をいただけると嬉しいです。
 こちらのQRコードから簡単に投稿できます」

【3〜5回目の来院時】
「最初の頃と比べて体の調子はいかがですか？
 ○○さんのように改善されていく過程を
 共有していただけると、悩んでいる方の励みになります」

【症状改善完了時】
「ここまで頑張って通っていただきありがとうございました！
 もし今後同じ症状で悩んでいる方のお役に立てれば嬉しいので、
 よろしければ体験談をGoogleに書いていただけませんか？」
```

### 4.3 ABSA属性（Googleが施術院口コミから抽出するキーワード）

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **施術の効果** | 楽になった、改善した、変化を感じた、軽くなった |
| **技術力** | 上手、ゴッドハンド、的確、原因を見つけてくれた |
| **カウンセリング** | 丁寧な説明、しっかり聞いてくれる、原因を教えてくれた |
| **痛み** | 痛くない、心地よい、適度な力加減、ボキボキしない |
| **雰囲気** | リラックスできる、清潔、落ち着く、居心地が良い |
| **スタッフ** | 親切、話しやすい、笑顔、気さく |
| **予約のしやすさ** | 予約が取りやすい、待ち時間がない、LINEで予約 |
| **価格** | コスパが良い、妥当、値段以上の効果 |

### 4.4 施術院固有のリスク・注意点

- **施術事故の口コミ**: 「施術後に悪化した」等のクレームは即座に個別対応へ誘導。公開の場での反論は避ける
- **「治る」表現の口コミ**: 患者が「治りました！」と書くのは自由だが、**返信文では「治る」は使わない**
- **無資格施術への指摘**: 整体院が「治療」「接骨」等の用語を使用すると、柔整師法違反の指摘リスク
- **他院との比較口コミ**: 「○○院より良い」等の比較は自社有利でもスルー（助長すると不正競争防止法リスク）

### 5.2 ローカルリンクビルディング機会（施術院向け）

## 9. 施術院の広告規制・ガイドライン

### 9.1 業態別の適用法規

| 法規制 | 整体院 | 整骨院 | 鍼灸院 |
|--------|--------|--------|--------|
| **景品表示法** | ✓ 適用 | ✓ 適用 | ✓ 適用 |
| **柔道整復師法** | — | ✓ 適用 | — |
| **あはき法**（あん摩マッサージ指圧師、はり師、きゅう師法） | — | — | ✓ 適用 |
| **医療広告ガイドライン** | — | **限定的に適用** | **限定的に適用** |
| **不正競争防止法** | ✓ 適用 | ✓ 適用 | ✓ 適用 |

### 9.2 GBP投稿・説明文での禁止事項

#### 全業態共通の禁止事項
1. ❌ **「治る」「治療します」「治した」**: 整体院は医療機関ではないため医療行為を示唆する表現は禁止
2. ❌ **「必ず改善」「100%効果あり」**: 効果の保証は景品表示法違反
3. ❌ **「医師推薦」等の虚偽の権威表現**: 実在しない推薦は不正競争防止法違反
4. ❌ **「他院では治らなかった症状も改善」**: 比較優良広告は禁止
5. ❌ **「○○症候群に効く」等の医学的効能**: 整体院が特定の疾患名への効果を謳うことは不可

#### 整骨院固有の禁止事項
- ❌ 保険適用外の施術を保険適用と謳うこと
- ❌ 肩こり・腰痛等の慢性症状に保険適用を示唆すること（保険は急性外傷のみ）
- ❌ 保険請求の不正（いわゆる「肩こりを捻挫として申請」等の不正請求は法律違反）

#### 鍼灸院固有の注意事項
- 保険適用は「医師の同意書」が必要な6疾患（神経痛・リウマチ・五十肩・頸腕症候群・腰痛症・頸椎捻挫後遺症）のみ
- 施術内容の広告はあはき法で制限されている
