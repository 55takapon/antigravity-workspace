# blog-writing-qa

> ブログ記事の報告前品質検査スキル。7軸で採点し、合否と改善箇所を明示する。

## 実行フロー

```
STEP 1: 記事と対応するコンテンツブリーフを受け取る
  ↓
STEP 2: 7軸チェックリストを全項目実行
  ↓
STEP 3: 各軸をスコアリング（各軸100点満点）
  ↓
STEP 4: 不合格項目の改善指示を出力
  ↓
STEP 5: 総合判定（PASS / CONDITIONAL PASS / FAIL）を出力
  ↓
STEP 6: PASSのみ報告へ進む。それ以外は修正後に再検査
```

---

## 軸1：SEOキーワード配置チェック（100点）

**目的**: 計画通りのキーワードが正しい場所に自然に入っているか確認する。

```
【必須配置チェック】（各5点 × 8項目 = 40点）
□ メインKWがタイトル（H1）に含まれているか
□ メインKWが記事冒頭100文字以内に含まれているか
□ メインKWが少なくとも1つのH2見出しに含まれているか
□ メインKWがメタディスクリプションに含まれているか
□ サブKWが本文中に自然に3回以上登場しているか
□ 共起語（関連語）が本文中に含まれているか
□ パーマリンクにメインKWが含まれているか（英語推奨）
□ 画像のaltタグにKWが含まれているか

【過剰・不自然チェック】（各-10点）
□ キーワードを不自然に詰め込んでいないか（キーワードスタッフィング）
□ 同じキーワードが連続して2回以上出現していないか

【KW配置スコア: ___/40点】
```

---

## 軸2：構成フレームワーク適合チェック（100点）

**目的**: コンテンツブリーフで選択したフレームワーク（PREP/PAS/AIDA）通りに書かれているか確認する。

```
【共通構成チェック】（各10点）
□ H2/H3の階層構造が論理的で、見出しだけで記事の流れが理解できるか
□ FAQセクション（最低3問）が含まれているか
□ まとめセクションで要点を3点以内で再提示しているか
□ CTAが記事末尾に自然な流れで設置されているか

【フレームワーク適合チェック】（各15点）
PREP法の場合:
  □ 冒頭または早期に結論（Point）が提示されているか
  □ その理由（Reason）が説明されているか
  □ 具体的な手順・例（Example）があるか
  □ まとめで結論（Point）に戻っているか

PAS法の場合:
  □ 読者の問題（Problem）を具体的に言語化しているか
  □ 放置するリスク（Agitation）を提示しているか
  □ 解決策（Solution）を具体的に提示しているか

AIDA法の場合:
  □ 成果・興味を引く要素（Attention）で始まっているか
  □ 背景と課題（Interest）を説明しているか
  □ 施策と結果（Desire）が明確か
  □ 次の行動（Action）につながるCTAがあるか

【構成スコア: ___/100点】
```

## 軸3：ライティング品質チェック（100点）

**目的**: 読者が実際に読み続けられる文章になっているか確認する。

```
【文章の質チェック】（各10点）
□ 一文が60文字以内に収まっているか（長文が5行以上連続していないか）
□ 「あなた」に語りかける文体で書かれているか
□ 各セクションに「なぜそうするのか」の理由が添えられているか
□ セクション間に「次への誘導」（つなぎの一言）があるか
□ 具体的なアクション（「○○の画面を開いて〜」）まで書かれているか

【禁止表現チェック】（違反1件につき-20点）
□ 「〜という方は多いです」（他人事表現）がないか
□ 「いかがでしたか？」（記事末尾定型文）がないか
□ 「〜はずです」「〜かもしれません」（断言回避）がないか
□ 「GBP」「CTR」「E-E-A-T」（読者に使わない略語）がないか
□ 「〜を解説します」だけで終わる締まりのない導入がないか

【用語ルールチェック】（各5点）
□ Googleビジネスプロフィールを初出で説明し、以降「マップ情報」に統一しているか
□ MEO対策を初出で説明し、以降「マップ集客」「マップ対策」に統一しているか
□ 同一記事内で表記ゆれ（ひらがな/カタカナ等）がないか

【ライティングスコア: ___/100点】
```

---

## 軸4：冒頭キャッチー度チェック（100点）

**目的**: 冒頭3〜5行で読者が「続きを読みたい」状態になっているか確認する。

```
【導入の4ステップ確認】（各20点）
□ 「問いかけ」から始まっているか（読者の状況・悩みを質問形で言語化）
□ 「共感」が示されているか（「その気持ちわかります」と寄り添う表現）
□ 「ベネフィット」が示されているか（この記事で何がわかるか）
□ 「結論の予告」があるか（答えを1〜2行でチラ見せ）

【プロの冒頭テクニック確認】（各10点）
□ クリフハンガーがあるか（「実は〜なんです」「結論から言うと〜」と続きを予告）
□ スマホ画面に収まる分量か（冒頭は400文字以内が目安）
□ 冒頭だけで「この記事が自分向けだ」と判断できるか

【NG確認】（違反1件につき-15点）
□ 疑問形を連発していないか（2回以上の「〜ですか？」連続）
□ テンプレート丸写し感のある導入になっていないか

【冒頭スコア: ___/100点】
```

## 軸5：法令・ガイドライン遵守チェック（100点）

**目的**: Googleのウェブマスターガイドライン・景品表示法・薬機法に抵触する表現がないか確認する。

```
【Googleガイドラインチェック】（各20点）
□ 根拠のない最上級・No.1表現がないか
  NG例:「業界No.1」「日本一の集客力」「最強の集客方法」
□ 誇大表現・過度な断定がないか
  NG例:「必ずうまくいく」「確実に集客できる」「100%効果がある」
□ 競合他社の名指し批判がないか
□ 著作権・肖像権に問題のある素材を使っていないか

【景品表示法チェック】（20点）
□ 根拠なく優良・有利と誤認させる表現がないか
  NG例:「他社より絶対安い」「誰でも月100万円稼げる」

【薬機法チェック】（20点）
□ 医療・健康効果を断定する表現がないか（医療クリニック・整体記事で注意）
  NG例:「〇〇が治る」「完全に改善する」「効果が保証される」

【遵守スコア: ___/100点】
```

## 軸6：ジェットプロデュースらしさチェック（100点）

**目的**: ジェットプロデュースのブランドボイスと差別化要素が表現されているか確認する。

```
【書き手ペルソナの確認】（各15点）
□ 「伴走者・相談相手」の立場で書かれているか（上から教えていないか）
□ 「あなたのお店では」「あなたの場合は」と語りかけているか
□ 実際にオーナーと日常的にやり取りしているプロ感が伝わるか

【ミッションとの整合性】（各10点）
□ 「良いサービスが、正しく見つけられる世の中に」というミッションと記事の方向性が一致しているか
□ 読者が記事を読んで「自分でも動ける」状態になるか（自立支援の精神）

【差別化要素の活用】（各10点）
□ タイトル・内容に「加古川・姫路・明石・神戸」などのローカル要素が活用されているか（該当記事のみ）
□ 「作業代行ではなくプロデュース」という独自ポジションが感じられるか

【CTAの自然さ】（20点）
□ CTAが押し売りでなく、「自然な流れで読者が動きたくなる」形になっているか
□ 「30分無料診断」への誘導が唐突でなく、記事の内容と連動しているか

【ブランドスコア: ___/100点】
```

---

## 軸7：テクニカルSEO・公開設定チェック（100点）

**目的**: WordPress/SWELLへの公開前に必要な技術設定が整っているか確認する。

```
【メタ情報】（各15点）
□ タイトルタグが30〜35文字に収まっているか
□ メタディスクリプションが80〜120文字で書かれているか
□ パーマリンクが英語で設定されているか（日本語URLは避ける）

【AI検索最適化】（各10点）
□ 記事の早い段階（冒頭付近）に「結論・直接回答」があるか
□ FAQ構造がH2/H3形式で整理されているか
□ 手順・定義が明確な見出しと箇条書きで構成されているか

【内部リンク・画像】（各10点）
□ 関連記事への内部リンクが2〜3本設置されているか（アンカーテキストが具体的か）
□ アイキャッチ画像が設定されているか
□ 画像にaltタグが設定されているか

【テクニカルスコア: ___/100点】
```

## 総合判定基準

| 判定 | 条件 | 対応 |
|------|------|------|
| **PASS** ✅ | 全軸70点以上 かつ 軸5（法令）が100点 | 報告へ進む |
| **CONDITIONAL PASS** ⚠️ | 軸5が100点 かつ 他軸に60〜69点あり | 指摘箇所を修正後に報告（軽微な修正のみ） |
| **FAIL** ❌ | 軸5に違反あり、または任意の軸が60点未満 | 修正後に再検査。報告禁止 |

## NGパターン

- 軸5（法令遵守）に違反があるにもかかわらずPASSにしない
- コンテンツブリーフなしで検査を実施しない（ブリーフとの照合が必須）
- スコアを算出せずに主観的な合否判定をする
