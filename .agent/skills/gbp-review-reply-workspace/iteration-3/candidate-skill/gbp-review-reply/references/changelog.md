# gbp-review-reply 変更履歴

- 2026-07-19 iteration-3候補版（本番未適用）: iteration-2の5工程を維持し、自然な日本語と低評価の責任対応を増分設計。
  - 自然語: 標準的な歓迎締めの自然な反復を許容し、「機会」「日」を使う作文調の4締めをconfirmed-ng化。冷淡な受領報告だけの終止も不採用。
  - 低評価: 星数だけでなく本文、確認状況、業種リスクでL1〜L4を判断。謝罪は自動挿入せず、主観・未確認は具体的論点の受け止めと確認、明確で必要な不備だけ対象を示すお詫びとした。「真摯」の定型必須化をやめ、論点に合う複数の姿勢patternと実行可能な確認・改善を使う。
  - 感謝: 「貴重なご意見」を標準候補、「率直なご意見」を文脈依存、「具体的な状況」を追加経緯提供時だけのlimited-useとした。「時間」「勇気」は内部背景から公開文へ出さない。
  - 公開性: 安心・誠実を自己宣伝せず、反論しないこと、改善対象、実行可能な行動そのもので第三者の不安を減らす。
  - 状態管理: 22理由タグと7つのphrase-level状態を分離。Excel候補30件は監査したが全文資産として不採用とし、runtime参照外にした。
  - 例: A35を維持し、A36は本文とposted事実を保持したhistorical候補とした。会話でユーザー確定したU-R04・U-R05だけを未投稿のactive品質例として追加し、削除された推測・余分な店側感情を不適用条件に記録した。phrase-level境界は新規candidateの `quality-boundaries.md` へ分離。

注記: 以下の2026-07-18追補にある「評価へ時間を割いた」という説明と、同日履歴内の星だけ1文・CTA条件は、後続の追補でsupersededとなった。履歴本文は当時の記録として保持し、現役生成ルールには使わない。

- 2026-07-18 追補: 口コミ返信を「事実を短く受領する文」ではなく、評価へ時間を割いた投稿者へ感謝を返す接客として再定義。
  - 締め: 一般的な接客上の歓迎締めを販促CTAから分離。★5肯定本文では原則使用し、再来店意思には圧をかけず応答する。地域文脈付き締めはprofileで検証・許可された場合だけ使う。
  - 星だけ: ★5本文なしは誠実な評価感謝＋自然な歓迎、★4本文なしは誠実な評価感謝＋節度ある改善姿勢の各2文へ変更。体験・満足・原因は補わない。
  - 販促: 他商品、予約、割引、キャンペーン、同伴者指定等の販促CTAは原則禁止。医療・法務等の高リスク業種は再訪・再相談でなく感謝＋サービス向上姿勢を使う。
  - 重複: 同時バッチと直近finalを横断し、同一感情文と同じ感謝→感情→締め骨格の連続を不合格化。標準的な歓迎締めの自然な重複は許容し、強制類語置換はしない。
  - 根拠: Google公式の会話的・非販促的な返信原則と、Hot Pepperグルメ公式マニュアルの飲食店向け「来店への感謝＋再来店を促す一言」を区別して記録。外部公開例を承認済み実例にはしない。

- 2026-07-18: 口コミの長さ・温度へ装飾的な型名を割り当てる判定を、現行の生成ロジック、通常出力、ログ項目、フィードバック条件から廃止。
  - 理由: ラベルが文章を先に規定し、口コミにない解説、ブランド表現、評価強度、定型的な外部説明を足す原因になっていたため。
  - 代替: 本文有無、評価帯、明記事実、項目別評価、強さ、禁止推測、公開リスク、返信済み状態、profile制約だけを内部整理する。
  - 情報量: 最低文字数と固定3段構成を廃止。星だけ高評価は原則感謝1文とし、感謝・固有点・締めを全件必須にしない。
  - CTA / SEO: 既定OFF。ユーザーの明示希望とprofileの許可が両方ある場合だけ検討し、星だけ・低評価・高リスク内容では原則使用しない。
  - 重複: `posted` / `final_approved` の最終返信だけを分析対象とし、使用率による強制的な類語変更を廃止。単語より機能構造の反復を見る。
  - フィードバック: 理由タグを実際の失敗原因へ変更し、適用範囲E/C/I/Uを新設。単一クライアントの件数や採用率だけでは共通ルールを変更しない。
  - 出力: 通常は投稿可能な最終返信案だけを表示し、内部整理、調整意図、自己チェック、記録テンプレを外した。修正時は元の口コミ、profile、確定指摘から全文再構成する。
  - 例: 既存の承認実績は削除せず、匿名化したうえで `active` / `historical` / `deprecated` に分類し、現行ルールに反する旧例を模倣元から除外。
