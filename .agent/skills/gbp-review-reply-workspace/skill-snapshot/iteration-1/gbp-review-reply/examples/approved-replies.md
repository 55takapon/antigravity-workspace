# 承認済み返信例

このファイルは、ユーザー提供の実クライアント合格返信を品質境界として保存する。返信本文を別口コミへそのまま流用せず、採用理由、拾い方、避けたことを参照する。

採用理由と差分境界は仮説メモです。実運用の意図と違う場合は、ユーザー修正を正とする。

採用理由を確定へ昇格する時は、ユーザーへ該当実例と採用理由を示し、「この理由で承認した」と明示確認を取る。返信本文が採用された事実だけでは、理由まで確認済みとみなさない。明示確認を得た項目は見出しを「採用理由（確認済み）」へ変更し、確認日と確認方法を1行で記録する。確認できない項目は「採用理由（仮説）」のまま残す。

このファイルの扱い:

- 実例には実在クライアントの名称・地域が含まれる。業種ごとの品質境界（どこまで拾ってよいか）の学習にだけ使い、名称・地域・言い回しを他クライアントの返信本文へ持ち込まない。
- 現在の収集状況は星5中心（医療4・飲食5・士業3）と星だけ（星5・星1が各1件）。本文あり低評価、星3、事実誤認、攻撃的口コミの実例は未収集。これらはユーザー修正で確定した返信から [../references/feedback-loop.md](../references/feedback-loop.md) の昇格手順で追加する。
- クライアント固有のボイス（そのクライアントにしか通用しない言い回し）は、ここではなく各クライアントの profile.md に記録する。

### 医療 M1 星5 長期通院・家族利用・インプラント

**口コミ内容**

7〜8年前から家族でお世話になっています。  
私自身、昔から歯医者はあちこち通いましたが苦手でした。こちらにかかってからは治療は痛みも無く、説明もわかりやすく丁寧にしていただき、歯医者嫌いが解消されました。  
インプラントを入れて6年になりますが、まったく問題ありません。  
先生をはじめスタッフの皆さん、明るく親切な方ばかりで、今後も通い続けたいと思います。

**承認済み返信**

長年にわたりご家族でお通いいただき、本当にありがとうございます。

「痛みがなく、説明がわかりやすかった」とおっしゃっていただけたこと、私たちが大切にしていることをしっかり受け取っていただけたようで、とてもうれしく思います。インプラントも6年間ずっと問題なくお使いいただけているとのこと、改めて安心いたしました。これからも一人ひとりの患者さまに寄り添いながら、丁寧な診療を続けてまいります。

高砂市でいつでも気軽に相談できるかかりつけ歯医者として、今後ともどうぞよろしくお願いいたします。

**採用理由（仮説）**

- 長期通院、説明のわかりやすさ、痛みへの配慮、スタッフの雰囲気という口コミ内の強い評価軸を拾っている。
- 「高砂市」「かかりつけ歯医者」を末尾に入れ、SEO語と差別化を自然な範囲で入れている。
- 口コミ本文にあるインプラントの経過に触れつつ、過度な効果保証には寄せていない。

**差分境界**

- 「インプラントが問題ない」は口コミ主の記載を受ける範囲に留める。将来も問題ない、成功している、必ず長持ちするとは書かない。
- 医療系でも、口コミ本文に明記された治療内容は拾える。ただし広告的に強調しない。

- 具体的な相談内容を公開していない。

**差分境界**

- 短文口コミでは無理にSEO語や長い説明を足さない。
- 士業は相談内容の秘匿性があるため、公開返信では抽象度を保つ。

## 横断ルール仮説

- 口コミ本文の情報量に応じて具体点を1〜4個拾ってよい。具体点が多い場合は「細やかにお書きいただき」のように束ねる。
- SEO語・差別化ポイントは、最後の一文に自然に置くと広告感が弱い。地域名と業種語・事業所種別が一まとまりなら1セットとして扱う。
- 医療は口コミ本文に治療内容があっても、将来保証や一般化を避ける。患者本人の感想を医院の運営姿勢へ変換する。
- 飲食は料理名、食感、味変、接客などを比較的具体的に拾える。コメントなしでは料理体験を作らない。
- 士業は相談内容の詳細を広げず、安心感、分かりやすさ、伴走姿勢を中心にする。
- コメントなしの星だけレビューは、本文がないため推測しない。星5なら感謝と再来店導線、星1なら受け止めと確認導線に絞る。
