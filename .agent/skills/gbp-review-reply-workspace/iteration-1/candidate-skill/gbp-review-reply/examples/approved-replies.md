# 実承認返信の状態台帳

このファイルは、ユーザー提供の実クライアント承認返信を履歴として保持する。作成者が新しく考えた文は追加しない。実例は固有名を匿名化し、現行ルールでの状態、適用条件、不適用条件を付ける。返信本文を別口コミへコピーせず、境界だけを参照する。

承認された事実と、今後も模倣できる事実は別である。採用理由は、ユーザーが理由まで確認したものだけ「確認済み」とし、それ以外は仮説のまま扱う。

状態:

- `active`: 現行ルールで再審査済み。条件内で品質境界として参照できるが、本文はコピーしない。
- `historical`: 実承認の履歴。現在は一部要素がprofile依存または過剰なため、全体を模倣しない。
- `deprecated`: 現行のハードエラーまたは既定方針と衝突するため、生成の模倣元にしない。

## 現行運用での参照境界

- `active` でも返信本文や固有の語彙をコピーせず、口コミの情報量と安全な焦点の選び方だけを参照する。
- `historical` は承認履歴として保持するが、CTA、SEO、ブランド表現、姿勢文、個人情報の扱いを現行ルールの根拠にしない。
- `deprecated` は廃止理由を確認するためだけに使い、生成案やprofileの現役例へ流用しない。
- 星だけは高評価・低評価とも体験を補充しない。高評価は原則感謝1文、低評価は原因を推測しない短い受け止めを基本にする。
- CTAとSEOは既定OFF。承認済み旧例に含まれていても、ユーザーの明示希望とprofileの許可がなければ使わない。
- 医療・法務等では、投稿者が書いたセンシティブ情報も事業者側から反復・確認しない。
