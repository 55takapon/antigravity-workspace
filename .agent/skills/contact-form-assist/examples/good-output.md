# 入力→出力の例

実ツールの出力形式に基づく型。文面サンプルは実データ（config/profiles/ のプロファイル）を使うため、ここでは出力の型だけを示す。

## 例1: 正常系（送信完了）

### 入力

- Sheets行: C列「株式会社サンプル工務店」/ D列「山田太郎」/ F列「https://sample-koumuten.jp/contact/」/ G列・I列 空
- プロファイル: web-production

### 出力

UI表示:

```
[入力済み 6件] [必須未入力 1件]
入力済み: お名前 / 会社名 / メールアドレス / メールアドレス（確認） / 電話番号 / お問い合わせ内容
必須未入力: ご希望の連絡方法（赤ハイライト・人間が選択して送信）
```

送信後の記録:

| 記録先 | 内容 |
|---|---|
| Sheets G列 | 2026/07/17 |
| Sheets H列 | 〇 |
| DB status | submitted_by_human |

## 例2: 異常系（営業NG検出で自動スキップ）

### 入力

- Sheets行: C列「株式会社サンプル商事」/ F列「https://sample-shoji.co.jp/inquiry/」
- ページ本文に「営業目的のお問い合わせはお断りいたします」の記載あり

### 出力

```
⏭  スキップ: 株式会社サンプル商事 (sales_ng_detected)
```

| 記録先 | 内容 |
|---|---|
| Sheets G列 | （空のまま） |
| Sheets H列 | × |
| Sheets I列 | 営業NG |
| DB status / notes | skipped / 営業お断りページ（検出語: 営業目的のお問い合わせ） |

ブラウザは自動で閉じ、人間の操作なしで次の1件に進める。
