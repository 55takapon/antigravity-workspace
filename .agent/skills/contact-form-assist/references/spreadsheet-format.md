# 送信リストの列仕様とスキップ判定

## 目的

Google Sheets / CSV の送信リストを正しく読み込み、送信対象行を誤りなく判定する。

## 使う材料

- Google Sheets のスプレッドシートID（URLの `/d/` と `/edit` の間）とシート名
- または CSVファイル（同じ列順）

## 列仕様（固定・変更禁止）

| 列 | ヘッダー名 | 用途 |
|---|---|---|
| A | № | 連番 |
| B | エリア | 都道府県・地域 |
| C | 企業名 | 送信先企業名（本文パーソナライズに使用） |
| D | 代表者名 | 宛名（`{{rep_salutation}}` の展開に使用） |
| E | URL | 企業ホームページURL |
| F | 問い合わせフォームURL | **送信先URL（必須）** |
| G | 送信日 | 送信完了日（ツールが自動書込） |
| H | 送信○× | 送信結果: 〇/×（ツールが自動書込） |
| I | 送信不可理由 | スキップ理由・エラー内容（ツールが自動書込） |
| J〜N | リサーチデータ | 従業員数・資本金・キーワードHIT等（送信処理では未使用） |
| O | Web3分類 | `web_marketing` ならCLIモードで web-marketing プロファイルを自動選択 |

## スキップ判定ルール（読み込み時に自動適用）

| 優先順 | 判定列 | 条件 | 理由 |
|---|---|---|---|
| 1 | F列 | 空 | 送信先URLなし |
| 2 | G列 | 値あり | 送信済み |
| 3 | I列 | 「営業NG」「NG」「スキップ」「リンク切れ」を含む | 送信不可 |

## 宛名の展開ルール

- D列が「ご担当者」「担当者」「代表者」等の汎用表記 → `{{rep_salutation}}` は「ご担当者様」
- D列が実名 → 「代表取締役 ○○様」（役職を勝手に省略してはならない）

## 確認方法

- 読み込み後にUI/CLIへ表示される件数が、シート上の「G列空 かつ I列空 かつ F列あり」の行数と一致すること

## 不一致の場合

- 件数が合わない場合は、行範囲オプション（`--rows`）と上記スキップ判定を突き合わせ、原因をユーザーに報告してから進める
