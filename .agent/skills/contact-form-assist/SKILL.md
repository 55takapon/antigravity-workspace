# contact-form-assist

企業のお問い合わせフォームに営業文面を半自動で入力し、人間の確認・送信操作を経て結果を記録するスキル。送信の最終判断は必ず人間が行う。

## 実行環境と依存

- 実行コードの正本置き場: `C:\Users\hangy\.cursor\test\contact-form-assist`（git管理・自動バックアップ対象）
- 依存パッケージ: better-sqlite3 / express / googleapis / playwright / ws（`npm install` 済み環境で実行）
- Google認証鍵: `%USERPROFILE%\.gcp\contact-form-assist\google_credentials.json`（リポジトリ外に隔離。環境変数 `CONTACT_ASSIST_CREDENTIALS` で上書き可）
- 結果記録先: `data/contact-assist.sqlite`（二重送信防止の正本）+ Google Sheets（G/H/I列）

## ステップ1: 送信リストの確認

- [ ] 送信リスト（Google SheetsまたはCSV）の場所とシート名を必ず確認した
- [ ] 列構造とスキップ判定ルールを [references/spreadsheet-format.md](references/spreadsheet-format.md) で必ず確認した
- [ ] 送信日（G列）が空で、送信不可理由（I列）に記載がない行だけが対象であることを確認した

#### 完了条件
- 対象リストと処理行範囲が確定していること
- この完了条件を満たすまで、次のステップに進んではならない

## ステップ2: サーバー起動

- [ ] 起動コマンドとオプションを [references/operations.md](references/operations.md) で必ず確認した
- [ ] `npm run ui -- --sheets <ID> --sheet-name <シート名>` 形式でサーバーを起動した

#### 完了条件
- UIに送信対象一覧が表示されていること（0件の場合は理由をユーザーに報告して終了）
- この完了条件を満たすまで、次のステップに進んではならない

---

## ステップ3: 1件ずつ入力・確認・送信

- [ ] 1件ずつ「ブラウザを開く」→ 自動入力 → 人間が内容確認 → 人間が送信ボタンを押す、の順で処理した
- [ ] 必須未入力（赤ハイライト）がある場合は、人間がブラウザ上で補完してから送信した
- [ ] 営業NGワード検出・フォーム不在は自動スキップされることを確認した（スキップ理由はDBとSheetsに自動記録される）
- [ ] 送信ボタンをスクリプトやAIが押していないことを必ず確認した

#### 完了条件
- 対象行がすべて「送信完了」「スキップ」「エラー」のいずれかで記録されていること
- この完了条件を満たすまで、次のステップに進んではならない

---

## ステップ4: 結果確認と報告

- [ ] UIのサマリー（またはDB累計）で送信完了・スキップ・エラーの件数を必ず確認した
- [ ] SheetsのG/H/I列に結果が反映されていることを必ず確認した
- [ ] 件数・スキップ理由の内訳・エラー内容をユーザーに必ず報告した

#### 完了条件
- 報告が事実確認済みの件数だけで構成されていること
- この完了条件を満たすまで、作業を完了してはならない

## エッジケース

| 状況 | 対応 |
|:-----|:-----|
| フォームが見つからない | 自動でスキップ記録される。ページを目視確認し、別URLにフォームがあればSheetsのF列を修正して再実行 |
| 営業NGワードが検出された | 自動スキップ・I列に「営業NG」記録。無効化・回避してはならない |
| CAPTCHA付きフォーム | 人間がCAPTCHAを解いてから送信する（スクリプトは触らない） |
| 入力エラーが表示された | UIの警告とDBのnotesにエラー内容が残る。ブラウザ上で人間が直接入力して送信 |
| Sheets書き込みエラー | DBには記録済み。[references/operations.md](references/operations.md) のトラブル対応に従い、鍵と共有設定を確認 |
| ブラウザを強制終了したい | UIの強制キャンセルを使う（スキップとして記録される）。プロセスキルは使わない |

---

## 禁止事項

- 送信ボタンをスクリプト・AIが押す改造をしてはならない（半自動設計が本スキルの前提）
- 営業NGワード検出（`config/ng-keywords.json`）を無効化・削除してはならない
- Google認証鍵をリポジトリ内（`.cursor\test` 配下）に置いてはならない
- I列（送信不可理由）に記載がある行へ送信してはならない
- 手順・ルールを実行コード側のポインタSKILL.mdに書き足してはならない（正本はこのファイル）
- DBファイル（`data/contact-assist.sqlite`）を直接編集・削除してはならない
