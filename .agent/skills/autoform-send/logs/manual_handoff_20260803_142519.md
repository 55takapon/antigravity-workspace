## 1. 株式会社カラフルクローバー
- フォーム: https://www.colorful-clover.co.jp/contact/
- 本文（下のブロックをコピペ）:

```
株式会社カラフルクローバー
ご担当者様

突然のご連絡の中、ご覧いただき誠にありがとうございます。
わたくし、ジェットプロデュース の 田中 と申します。

EC制作から始まりながら、
『作るだけ』では売上は変わらないと捉え直した歩みに、
顧客成果への誠実さを感じました。

構築、移行、商品ページ、集客、運用をつなぎ、
共に考え、実行し、検証し、改善することで、
お客様のチームに近い支援をされているのですね。

外から答えを渡すだけでなく、
現場で成果まで一緒に追う仕事のあり方に、
深く共感しました。

サイト制作後も、できれば継続してクライアントを支援したい。
  
けれど、日々の制作案件を進めながら、
新たに担当者を採用・育成し、
毎月の運用や顧客対応まで担うのは簡単ではない。
  
そうしたお悩みはございませんか。
  
  
今回、制作後のGoogleマップ集客
（Googleビジネスプロフィール運用）を担う外部パートナーとして、
お力になれればと思い、ご連絡いたしました。
  

私は現在、クリニック、飲食店、士業事務所、学習塾など、
10社以上のGoogleビジネスプロフィール運用を
継続してご支援しています。
  
もともとは製造業で会社員としてシステム開発に携わり、
独立後は、制作会社のコーディング業務を
年単位で継続して受託しておりました。
  
外部の運用担当として、
主に以下の業務をお引き受けしています。
  
・ご提案資料の作成、商談への同席・ご説明
・投稿、口コミ返信、店舗情報の整備・改善
・月次レポートの作成とご報告
・事業者様からのご質問、ご相談への対応
  
ご提案の段階から、運用開始後の事業者様とのやり取りまで、
私が責任を持って対応いたします。
  

御社で専任担当者を新たに採用・育成したり、
日々の細かなディレクションを増やしたりすることなく、
店舗型クライアント向けの継続支援メニューを
追加していただくことができます。
  
御社とクライアント様との関係を大切にし、
窓口や商流を尊重したうえで、
あくまで御社の案件として携わります。
  

また、運用を続けていると、
サービスページの追加やキャンペーン用LP、
LINEへの導線づくりなど、
制作に関するご相談が生まれることもあります。

そうしたご相談は、すべて御社へお戻しします。
  

私がGoogleビジネスプロフィールの運用に
力を入れるようになったきっかけは、
かかりつけの歯科医院から、
  
「低評価の口コミに、どう対応すればよいのか」
  
と相談を受けたことでした。
  
私自身、それまでは歯科医院に苦手意識があり、
かかりつけもありませんでした。
  
しかし、その医院で丁寧に診ていただき、
安心して相談できる専門家がいる心強さを実感しました。
  
患者さんの負担を少しでも減らそうと、
設備を整え、診療の改善を続けておられる姿も知っていたため、
その医院が口コミ対応で困っていると聞き、
何とかお役に立ちたいと思ったことが、この仕事の原点です。
  

支援を続ける中で、良い仕事をしていても、
その価値が必要な方に届いていない事業者様は
少なくないと感じています。
  
探している方と、その力になれる事業者様をつなぐこと。
Googleマップを通じて、その接点を増やすことが、
私の役割だと考えています。
  
「問い合わせが増えた」「予約につながった」と
事業者様から直接お声をいただき、
一緒に変化を喜べる距離で支援できることに、
大きなやりがいを感じています。
  

実績の一例として、関西の飲食店では、
2026年5月からGoogleビジネスプロフィールの
運用支援を開始しました。
  
支援前の4月と運用3か月目の7月を比較すると、
  
・ルート検索数　　　月68回から444回（約6.5倍）
・サイトへの遷移数　月78回から560回（約7.2倍）
・電話発信数　　　　月10回から46回（4.6倍）
  
となりました。
  
口コミ数も8件から49件へ増加し、
評価点は3.8から4.3まで改善しています。
  
口コミ面と、来店・問い合わせにつながる
ユーザー行動の両方で伸びが見られた事例です。
  
※4月と7月の単月比較です。期間中にGoogle検索広告を
一部実施しており、間接的な影響は切り分けていません。
広告クリック自体は、上記数値に含まれていません。
  
その他の事例、具体的な対応内容、価格については、
以下のページにまとめています。
  
https://jet-produce.com/lp/partner01/
  

御社の方針とクライアント様との関係を大切にしながら、
困ったときにすぐ相談していただける距離で、
長くご一緒できればと考えています。
  
制作後の継続支援の選択肢として
ご関心をお持ちいただけましたら、
ご連絡いただけますと幸いです。
  
必要に応じて、Zoomでも詳しくご説明いたします。
  
ご多用のところ、最後までお読みいただき
ありがとうございました。
  
どうぞよろしくお願いいたします。
```
