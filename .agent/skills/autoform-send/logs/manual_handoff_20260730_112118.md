# 手動送信リスト（10 社）— ご自分のブラウザで開いてください

## 1. BIRTHDAY SUIT
- フォーム: https://birthdaysuit.info/contact/
- 本文（下のブロックをコピペ）:

```
BIRTHDAY SUIT
ご担当者様

突然のご連絡の中、ご覧いただき誠にありがとうございます。
わたくし、ジェットプロデュース の 田中 と申します。

『適切』なWeb制作を届けるという考え方と、
できること、できないことを率直に示す姿勢に、
思わず手が止まりました。

『万能ではございません』と明言しながら、
起業やスタートアップの予算に合わせて提案する姿に、
誇大な言葉に頼らない誠実さを感じます。

事業の第一歩を預かる相手として、
約束できる範囲で丁寧に力を尽くす仕事観に、
同じ制作者として強く惹かれました。

サイト制作後も、
できれば継続してご支援を続けていきたい。
  
けれど今の社内リソースでは正直むずかしい。
そうしたお悩みはございませんでしょうか。
  
  
先に、この連絡の目的だけ申し上げます。
制作後の運用を担う外部パートナーとして、
一度ご検討いただけないかというご相談です。
  
お読みいただいたうえで、ご興味があれば
ご連絡いただけますと幸いです。
ピンとこなければ、そのまま閉じていただいて構いません。
  
  
私は制作後のGoogleマップ集客
（Googleビジネスプロフィール運用）を
専門にしております。
  
クリニックや飲食店、士業事務所など10社以上を、
継続してご支援させていただいております。
  
  
元システムエンジニアで、以前は制作会社様から年単位で
コーディングなどを受託させていただいておりました。
そのため制作現場の進め方も一通り分かるつもりです。
  
サイトが公開されてからの長いお付き合いを前提とした支援に、
現在は力を入れています。
  
  
制作会社様の「運用担当」として、実際にお引き受けしているのは以下です。
  
・ご提案資料の作成と、商談への同席・ご説明
・Googleビジネスプロフィールの日々の運用
　（投稿・口コミ対応・店舗情報の最適化）
・月次レポートの作成とご報告
・事業者さんからのご質問・ご相談への対応
  
  
ご提案の段階から同席し、運用が始まってからの
事業者さんとのやり取りも、責任を持って対応いたします。
  
必ずしも御社で専任の担当を立てていただかなくても、
進めていくこともできます。
  
あくまでも御社のご案件として、私が携わらせていただく形です。
  
  
また、運用を続けていると
「このページを追加したい」
「キャンペーン用のLPがほしい」
「LINEへの導線をつくりたい」といった
制作のご相談が実際に出てきます。
  
そうしたご相談も、すべて御社にお戻しします。
日々のやり取りの延長で、自然と生まれてくるご依頼です。
  
  
▼ ご支援先の事例
  
【歯科クリニック／関西】
オーナー確認がされておらず、低評価の口コミが入ったことをきっかけに
ご相談をいただきました。情報の最適化と口コミへの対応を進め、
最寄り駅＋業種の検索で上位表示を獲得しています。
  
・電話でのお問い合わせ　月71回 → 100回
・検索での表示回数　　　月384回 → 554回
・サイトへの遷移　　　　月49回 → 80回
（対策3ヶ月／前年同月比）
  
口コミ数と評価点も上がり、現在は予約が取りづらい状態が続いています。
  
  
【士業事務所／関西】
マップ上に「閉業」と表示されたままの状態からのご相談でした。
Googleへの修正申請と設定の最適化、定期的な情報更新を行っています。
  
・プロフィールの閲覧　月97回 → 142回
・ルート検索　　　　　月30回 → 70回
（対策2ヶ月）
  
  
その他の事例、対応内容、価格について、以下にてご確認いただけます。
https://jet-produce.com/lp/partner01/
  
  
ここまでお読みいただき、少しでもご興味をお持ちいただけましたら、
ご連絡いただけますと幸いです。
メッセージでも、Zoomでも、ご都合の良い方で対応いたします。
  
ご多用のところ、最後までお読みいただきありがとうございました。
何卒よろしくお願いいたします。
```
