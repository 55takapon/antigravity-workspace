# sales-copywriting-qa

> 提案文を送る前に必ずここを通す。作った人間が見落とすものを、辛口で指摘する。

## 使い方

```
1. 検査対象の提案文（件名 + 本文）を貼り付ける
2. このスキルの8軸チェックリストで評価する
3. 合否判定 + 改善指摘を出力する
4. 合格するまで改善 → 再検査を繰り返す
```

---

## 8軸チェックリスト

### 軸1: 信頼セットアップ（Block 1）

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 1-1 | 冒頭2〜3行で「何者か」が明確に伝わるか | ✅/❌ |
| 1-2 | 権威性が「安心装置」として機能しているか（自慢になっていないか） | ✅/❌ |
| 1-3 | Block 1 が4行以上に膨らんでいないか | ✅/❌ |
| 1-4 | 「突然のご連絡失礼いたします」等の定型文で開始していないか | ✅/❌ |
| 1-5 | 実績は事実のみか（水増し・誇張がないか） | ✅/❌ |

**判定基準**: 1-1, 1-2 は必須。他は1項目以上NG で要改善。

---

### 軸2: パーソナライズ・フック（Block 2）

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 2-1 | 相手の業種 or 事業への具体的言及があるか | ✅/❌ |
| 2-2 | 「このテンプレートはうちだけに送られた」と感じさせる要素があるか | ✅/❌ |
| 2-3 | ヨイショ・根拠のない持ち上げが含まれていないか | ✅/❌ |

**判定基準**: 2-1 は必須。全項目クリアで合格。

---

### 軸3: 課題共感（Block 3）

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 3-1 | 「同業種でよく聞く声」として事実共有できているか | ✅/❌ |
| 3-2 | 煽り表現（「今すぐ」「このままでは」等）が含まれていないか | ✅/❌ |
| 3-3 | 課題の共感が「脅し」ではなく「寄り添い」のトーンか | ✅/❌ |
| 3-4 | 相手が「そうそう、それ課題だ」と感じられる具体性があるか | ✅/❌ |

**判定基準**: 3-2 は必須。3-1, 3-3, 3-4 は2項目以上クリアで合格。

---

### 軸4: ベネフィット（Block 5）

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 4-1 | ベネフィットの主語が「貴社（相手）」になっているか | ✅/❌ |
| 4-2 | 「変化後の世界」で描写されているか（状態変化が見えるか） | ✅/❌ |
| 4-3 | ①②③の記号で視覚的に区切られているか | ✅/❌ |
| 4-4 | 「弊社が〜します」の自社主語になっていないか | ✅/❌ |

**判定基準**: 4-1, 4-4 は必須。全項目クリアで合格。

---

### 軸5: CTA・クロージング

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 5-1 | CTAが1つだけに絞られているか | ✅/❌ |
| 5-2 | 「15分」等の低ハードルで「カジュアルでOK」の温度感があるか | ✅/❌ |
| 5-3 | 「ぜひご導入を」「ぜひ一度お話を」等の押し付け表現がないか | ✅/❌ |
| 5-4 | 選択権が相手にあることが伝わるか | ✅/❌ |

**判定基準**: 5-1, 5-3 は必須。全項目クリアで合格。

---

### 軸6: セールス臭・営業臭

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 6-1 | 読み返して「営業メールだ」と即判断されないか | ✅/❌ |
| 6-2 | 過剰な敬語・よそよそしい文体になっていないか | ✅/❌ |
| 6-3 | 人間味・温度感があるか（伴走者の文体か） | ✅/❌ |
| 6-4 | 「御社にピッタリ」等のセールス臭MAX表現がないか | ✅/❌ |
| 6-5 | 煽りではなく事実の共有になっているか | ✅/❌ |

**判定基準**: 6-1, 6-4, 6-5 は必須。3項目以上クリアで合格。

---

### 軸7: 文字数・読みやすさ

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 7-1 | 全体が1000文字未満か（必須制約） | ✅/❌ |
| 7-2 | 理想の600〜800文字に収まっているか | ✅/❌ |
| 7-3 | 件名が20文字以内か | ✅/❌ |
| 7-4 | 段落が詰め込まれていないか（2〜3行で区切られているか） | ✅/❌ |
| 7-5 | すっと読めるか（読み手のエネルギーを奪っていないか） | ✅/❌ |

**判定基準**: 7-1, 7-3 は必須。3項目以上クリアで合格。

---

### 軸8: リスク・誤解チェック

| 項目 | チェック内容 | 合否 |
|------|------------|------|
| 8-1 | 誇張・盛った表現がないか（事実のみで構成されているか） | ✅/❌ |
| 8-2 | 読み方によって別の意味に取られるあいまい表現がないか | ✅/❌ |
| 8-3 | サービス内容について誤解を生む可能性がないか | ✅/❌ |
| 8-4 | 「何をしてくれる人か」が最後まで読めば分かるか | ✅/❌ |
| 8-5 | 返信した場合に次に何が起きるか相手が想像できるか | ✅/❌ |

**判定基準**: 8-1, 8-2, 8-3 は必須。全項目クリアで合格。

---

## 合否判定ルール

| ランク | 条件 | 対応 |
|--------|------|------|
| **✅ 合格** | 必須項目全クリア + 各軸の基準を満たす | そのまま送信可 |
| **🔧 要修正** | 必須項目は全クリアだが軸基準に未達あり | 指摘箇所を修正して再検査 |
| **❌ 不合格** | 必須項目に1つ以上NG | 大幅修正が必要。再検査必須 |

|----|----|------|------|

## NGパターン速攻チェック（実施前の事前確認）

送信前にこれだけ確認すれば最悪のケースは防げる。

- [ ] 「突然のご連絡失礼いたします」で始まっていないか
- [ ] Block 1（冒頭）で権威性・実績が最低1つ入っているか
- [ ] 1000文字を超えていないか
- [ ] 件名が20文字を超えていないか
- [ ] 「今すぐ」「限定」「ぜひご導入を」が含まれていないか
- [ ] CTAが2つ以上になっていないか
- [ ] 「御社にピッタリ」等のセールス臭MAX表現がないか
- [ ] ベネフィットの主語が「貴社（相手）」になっているか
