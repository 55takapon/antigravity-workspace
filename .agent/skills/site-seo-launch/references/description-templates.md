# ディスクリプション記入例テンプレート集

> `site-seo-launch` SKILL.md STEP 2 の詳細資料

---

## 汎用テンプレート

```
{地域名}の{事務所名/店舗名}です。{主要サービス}に対応。
{差別化要素1}・{差別化要素2}。{CTA文}。
```

**作成ルール:**
- PC表示：100〜120文字 / スマホ表示：先頭50文字が勝負
- 冒頭50文字以内に「地域名」「事務所名」「主要キーワード」を入れる
- 末尾にベネフィットと行動促進を入れる
- 各ページで必ずユニークな文章にする（コピー流用NG）

---

## 司法書士事務所の記入例

### トップページ
**タイトル（〜35文字）:**
```
柴本司法書士事務所｜加古川の相続・登記・債務整理
```

**ディスクリプション（〜120文字）:**
```
加古川市の柴本司法書士事務所です。相続登記の義務化に対応。
相続・遺言・会社設立・債務整理まで幅広くご相談いただけます。
初回相談無料・土日対応可。お気軽にお電話ください。
```

### サービスページ（相続）
**タイトル:**
```
相続登記・相続手続き｜柴本司法書士事務所（加古川）
```
**ディスクリプション:**
```
加古川・姫路・明石の相続登記はお任せください。義務化に対応。
遺産分割協議書作成から登記申請まで一括サポート。初回相談無料。
```

### 料金ページ
**タイトル:**
```
料金・費用一覧｜柴本司法書士事務所
```
**ディスクリプション:**
```
相続登記・会社設立・債務整理などの費用を明確にご案内。
加古川の柴本司法書士事務所は料金の透明性を重視。お気軽にご相談ください。
```

### 事務所概要
**タイトル:**
```
事務所概要・アクセス｜柴本司法書士事務所（加古川市）
```
**ディスクリプション:**
```
柴本司法書士事務所の所在地・アクセス・代表プロフィール。
加古川市に位置し、相続・登記・債務整理を専門とする地域密着型事務所です。
```

### お問い合わせ
**タイトル:**
```
お問い合わせ｜柴本司法書士事務所
```
**ディスクリプション:**
```
柴本司法書士事務所へのご相談はこちら。電話・メールフォームから
ご連絡可能。初回相談無料・土日対応。加古川・姫路・明石エリア対応。
```

## 他業種への応用パターン

### 税理士事務所
```
タイトル: {事務所名}｜{地域名}の確定申告・法人税・相続税
ディスクリプション: {地域名}の{事務所名}です。確定申告・法人設立・
相続税申告に対応。{差別化}。初回相談無料。お気軽にご相談ください。
```

### 整体院・治療院
```
タイトル: {店舗名}｜{地域名}の{施術特化}
ディスクリプション: {地域名}の{店舗名}。{主訴（腰痛・肩こり等）}でお悩みの方へ。
{差別化（国家資格・実績数等）}。{CTA（ご予約はお電話で）}。
```

### 飲食店
```
タイトル: {店舗名}｜{地域名}の{料理ジャンル}
ディスクリプション: {地域名}の{料理ジャンル}{店舗名}。{特徴（個室あり・宴会対応等）}。
{差別化}。ご予約・お問い合わせはお気軽にどうぞ。
```
