# site-seo-launch

> WordPress/SWELLサイトの本番公開時に行うSEO設定を、抜け漏れなく順番に実行するためのスキル。
> 士業（司法書士等）サイトを主ユースケースとして設計。他業種にも応用可能。

**位置づけ**: `website-production` Phase 8（公開・SEO）の**詳細実行スキル**。
制作フルフローの場合は `website-production` → Phase 8 から本スキルに遷移して使う。

**詳細資料**: `references/` フォルダにディスクリプション文例テンプレート・構造化データサンプルを格納。

## STEP 1：WordPress 基本設定

| 設定場所 | 設定項目 | 設定内容 |
|---------|---------|---------|
| 設定 > 一般 | サイトのタイトル | 事務所名 |
| 設定 > 一般 | キャッチフレーズ | サービス概要 |
| 設定 > 一般 | WordPress/サイトアドレス | `https://`（SSL確認） |
| 設定 > パーマリンク | 構造 | **投稿名**を選択（公開後の変更は禁止） |

### 表示設定（最重要）

| タイミング | 「検索エンジンにインデックスしないようにする」 |
|-----------|------------------------------------------|
| 制作中 | ✅ チェックあり |
| **公開時** | ❌ **チェックを外す ← 絶対に忘れない** |

## STEP 2：SEO SIMPLE PACK 設定

### 2-1. トップページ設定
**設定場所：** SEO PACK > 一般設定 > 基本設定タブ

| 設定項目 | 文字数目安 |
|---------|-----------|
| タイトル | 30〜35文字 |
| ディスクリプション | 100〜120文字（冒頭50文字にKW集中） |

**ディスクリプション テンプレート（汎用）**
```
{地域名}の{事務所名/店舗名}です。{主要サービス}に対応。
{差別化要素1}・{差別化要素2}。{CTA文}。
```

**記入例（司法書士事務所）**
```
加古川市の柴本司法書士事務所です。相続登記の義務化に対応。
相続・遺言・会社設立・債務整理まで幅広くご相談いただけます。
初回相談無料・土日対応可。お気軽にお電話ください。
```

**ディスクリプション作成の鉄則**
1. 最重要KWを**冒頭50文字以内**に（スマホの表示限界）
2. ベネフィットを明記（初回無料・土日対応など）
3. 行動促進で締める
4. **各ページで必ずユニークな文章**（コピー流用NG）

> 各ページの具体的な記入例は `references/description-templates.md` を参照。

### 2-2. ウェブマスターツールタブ

| 設定項目 | 入力内容 |
|---------|---------|
| Google Search Console 認証コード | HTMLタグのcontent値 |
| Google Analytics 測定ID | `G-XXXXXXXXXX` |

### 2-3. OGP設定タブ

| 設定項目 | 入力内容 |
|---------|---------|
| デフォルトOGP画像 | 1200×630px推奨 |
| Twitter: カードタイプ | `summary_large_image` 推奨 |

### 2-4. Canonical 設定
SEO SIMPLE PACK はデフォルトで全ページに自己参照 canonical を自動出力する。以下を確認：
- www有/無 の統一が WordPress アドレス設定と一致しているか
- 末尾スラッシュの有/無がサイト全体で統一されているか
- カスタムcanonicalが必要なページ（LP等）は個別に設定

### 2-5. タクソノミーアーカイブの noindex 設定
**設定場所：** SEO PACK > 一般設定 > タクソノミーアーカイブ

| 対象 | 記事数が少ない初期 | 記事が充実してきたら |
|------|------------------|-------------------|
| カテゴリアーカイブ | **noindex** に設定 | index に切り替え |
| タグアーカイブ | **noindex** に設定 | 厳選して index |

> 記事数が10本未満のカテゴリ/タグはインデックスさせても薄いページ扱いになりサイト全体の評価を下げるリスクがある。

### 2-6. 各固定ページの個別設定
**設定場所：** 固定ページ編集画面下部「SEO SIMPLE PACK設定」エリア

各ページごとにタイトル・ディスクリプション・canonicalを設定。
具体的な記入例は `references/description-templates.md` を参照。

## STEP 3：SWELL テーマ SEO設定

### 3-1. 構造化データ
**設定場所：** SWELL設定 > 構造化データ

| 設定項目 | 入力内容 |
|---------|---------|
| サイトのロゴ画像 | ロゴ画像URL |
| サイト名（組織名） | 事務所名/店舗名 |
| SNSプロフィールURL | LINE公式・Instagram等 |

### 3-2. サイト基本情報（ファビコン等）
**設定場所：** SWELL カスタマイズ > サイト基本情報

| 設定項目 | 入力内容 |
|---------|---------|
| ファビコン | 32×32px PNG |
| スマホ用アイコン | 180×180px PNG |

### 3-3. LocalBusiness 構造化データ（JSON-LD）
**設定場所：** 「Insert Headers and Footers」等プラグインの `<head>` 内

> 完全なJSON-LDサンプルは `references/structured-data-samples.md` を参照。

**必須プロパティ一覧（LegalService/LocalBusiness）**

| プロパティ | 用途 |
|-----------|------|
| `name` | 事務所名 |
| `description` | 事業概要（50〜100文字） |
| `address` | 所在地（PostalAddress） |
| `telephone` | 電話番号 |
| `openingHours` | 営業時間 |
| `url` | サイトURL |
| `image` | ロゴ/外観写真 |
| `areaServed` | 対応地域（ローカルSEOで重要） |
| `sameAs` | SNS・GBPプロフィールURL（E-A-T紐付け） |
| `founder` / `employee` | 代表者情報（E-E-A-T強化） |

**追加スキーマ（該当ページがある場合）**
- `FAQPage` — Q&Aページ
- `BreadcrumbList` — パンくずリスト（SWELL自動出力だが確認推奨）

> 設置後、[Googleリッチリザルトテスト](https://search.google.com/test/rich-results) でエラーがないか**必ず**確認する。

## STEP 4：Google アナリティクス（GA4）設定

### 4-1. GA4プロパティ作成
1. [Google Analytics](https://analytics.google.com/) > 管理 > プロパティを作成
2. タイムゾーン：日本 / 通貨：日本円
3. データストリーム > ウェブ > URLを入力
4. **測定ID（G-XXXXXXXXXX）をコピー**

### 4-2. SWELLへの測定ID設置
SEO SIMPLE PACK > 一般設定 > ウェブマスターツール > Google Analytics に測定IDを貼り付け

### 4-3. 内部トラフィック除外（必須）

| 手順 | 操作 |
|------|------|
| ① | GA4 管理 > データストリーム > 対象ストリーム > Googleタグ > タグ設定 |
| ② | 「すべて表示」> 「内部トラフィックの定義」> 「作成」 |
| ③ | ルール名：`社内アクセス` / IPアドレス：自社IPを入力して保存 |
| ④ | GA4 管理 > データフィルタ > 「Internal Traffic」を「テスト」→「有効」に変更 |

> ⚠️ まず「テスト」状態でリアルタイムレポートを確認し、除外が効いてから「有効」にする。
> クライアントの事務所IPも追加すること（アクセス数が少ない士業サイトでは汚染の影響が大きい）。

### 4-4. キーイベント（コンバージョン）設定

**最低限計測すべき2つのCV:**

| CVポイント | 計測方法 |
|-----------|---------|
| お問い合わせフォーム送信 | サンクスページの `page_view` をカスタムイベントとして検出し、キーイベントに設定 |
| 電話番号タップ | GTMで `tel:` リンクのクリックを検出し、GA4イベント `phone_click` として送信 → キーイベントに設定 |

**サンクスページ型（GTM不要・最低限）:**
1. GA4 管理 > イベント > 「イベントを作成」
2. イベント名：`generate_lead`
3. 条件：`event_name` = `page_view` AND `page_location` に `/thanks/` を含む
4. 保存 → キーイベント > 新しいキーイベントとして `generate_lead` を登録

### 4-5. GA4 動作確認
- リアルタイムレポートで自分のアクセスが計測されているか確認
- 内部トラフィックフィルタがテスト状態で正しく除外されているか確認
- テスト送信でキーイベントが発火しているか確認

## STEP 5：Google サーチコンソール登録

### 5-1. プロパティ登録

| 方式 | 推奨度 | 特徴 |
|------|-------|------|
| **URLプレフィックス** | ★★★ | 設定が簡単。HTMLタグで認証可能 |
| ドメインプロパティ | ★★☆ | www有/無・http/httpsを包括管理可能（DNS認証が必要） |

**URLプレフィックス方式の手順（推奨）：**
1. Search Console > プロパティを追加 > URLプレフィックス
2. 所有権の確認：**HTMLタグ** を選択
3. content値をコピー → SEO SIMPLE PACK > ウェブマスターツール に貼り付けて保存
4. Search Console で「確認」をクリック

### 5-2. XMLサイトマップ送信

| 手順 | 操作 |
|------|------|
| ① | 左メニュー「サイトマップ」を選択 |
| ② | サイトマップURL入力（例：`sitemap.xml`） |
| ③ | 「送信」をクリック → ステータス「成功しました」を確認 |

**サイトマップに含める/除外する基準：**
- ✅ 含める：公開中の固定ページ・投稿ページ・カテゴリアーカイブ（indexのもの）
- ❌ 除外：noindexページ・404ページ・リダイレクトページ・下書き

### 5-3. 個別インデックス登録リクエスト
公開直後の重要ページ（トップ・サービス等）は個別にリクエスト：
1. Search Console 上部の検索窓にURLを入力（URL検査）
2. 「インデックス登録をリクエスト」をクリック

> ⚠️ インデックス反映は数日〜数週間かかる。即時ではない。

## STEP 6：公開前チェックリスト（Pre-flight）

### 🔴 CRITICAL（1つでも未完了なら公開禁止）
```
□ 「設定 > 表示設定」でインデックス設定を解除した
□ SEO SIMPLE PACK: 全固定ページの「インデックスさせない」がOFFか確認した
□ URL が https:// になっている
□ robots.txt に Disallow: / が残っていないか確認した
□ お問い合わせフォーム送信テスト完了（管理者・ユーザー両方にメール届く）
□ GA4 キーイベント（フォーム送信・電話タップ）が発火するか確認した
```

### 🟡 SEO設定チェック
```
□ トップページのタイトルタグ・ディスクリプション入力済み
□ 各固定ページのタイトル・ディスクリプション入力済み（ユニークな文章）
□ OGP画像（デフォルト）設定済み
□ GA4 測定ID（G-XXXXXXXXXX）設定済み
□ GA4 内部トラフィック除外フィルタ有効化済み
□ Search Console 認証コード設定・認証済み
□ XMLサイトマップ送信済み
□ Canonical タグが全ページで正しく出力されているか確認
□ 構造化データ（LegalService等）設置済み・リッチリザルトテスト合格
□ パーマリンク設定が「投稿名」になっている
□ カテゴリ/タグアーカイブの noindex が適切に設定されている
```

### 🟡 SWELLテーマ設定チェック
```
□ サイトロゴ設定済み
□ ファビコン設定済み（ブラウザタブで表示確認）
□ ヘッダー・フッターのNAP情報（名称・住所・電話）が正確
□ パンくずリスト有効化済み
```

### 🟡 コンテンツ品質チェック
```
□ NAP情報がサイト全体・GBP・構造化データで完全統一
□ 代表者の顔写真・プロフィール・登録番号掲載済み
□ 料金ページの金額が現状と一致
□ プライバシーポリシーページが存在する
□ 全画像にalt属性が設定されている
□ リンク切れがないか確認済み
```

### 🟡 表示・パフォーマンスチェック
```
□ スマホ・タブレットでの表示崩れなし
□ PageSpeed Insights モバイルスコア 70点以上（目標 90点以上）
□ 画像をWebP形式または圧縮済み
```

### 🟡 セキュリティチェック
```
□ 管理者ユーザー名が「admin」でない
□ SiteGuard等でログインURL変更済み（推奨）
□ テスト用の投稿・ページを削除済み
```

## 【補足：運用編】公開後の継続改善

> 以下は納品後にクライアントと保守契約がある場合、または自社運用の場合に参照する。

### 公開後1週間チェック
```
□ Search Console: カバレッジに大量エラーがないか確認
□ Search Console: 主要ページがインデックス済みになっているか確認
□ Googleで「事務所名」を検索し、表示されるか確認
□ GBP: 「サイトリニューアル」告知を投稿
```

### 公開後1ヶ月チェック
```
□ Search Console: 検索クエリ上位10件を確認（狙ったKWで表示されているか）
□ GA4: 流入数・滞在時間・直帰率を確認
□ GA4: キーイベント（CV）が計測されているか確認
□ リッチリザルトテストで構造化データにエラーがないか再確認
□ 「事務所名 ＋ 地域名」指名検索で1位になっているか確認
```

### 継続改善サイクル（月次）

```
確認 → 分析 → 改善 → 確認 ...

【毎月確認する3つの指標】
1. Search Console: 検索クエリの表示回数・クリック数の推移
2. GA4: 主要ページの流入数・直帰率・CV数
3. PageSpeed Insights: モバイルスコアの推移

【改善アクション例】
- 検索クエリに出ているがCTRが低い → タイトル・ディスクリプションを改善
- 特定ページの直帰率が高い → コンテンツ・導線を見直し
- 新しい法改正情報 → コラム記事を投稿（E-E-A-T強化）
- GBPの投稿を月1回以上更新（ローカルSEO強化）
- 口コミへの返信を継続（信頼性向上）
```

## NGパターン

- 全ページで同じディスクリプションを使い回す
- インデックス設定を「サイト全体」だけ見てページ単位の noindex を見逃す
- robots.txt の Disallow: / を残したまま公開する
- SEO SIMPLE PACK 以外のSEOプラグインを併用する（不具合の原因）
- canonical の www/非www・スラッシュ有無が不統一のまま公開する
- GA4で内部トラフィック除外せずにデータを汚す
- コンバージョン計測なしで「アクセスは取れています」と納品する
- 構造化データ設置後にリッチリザルトテストで確認しない
- カテゴリ/タグが少ない状態でインデックスさせ薄いページを量産する
