## PART 1: 感動のメカニズム

### 1-1 感動の3層構造

| 層 | 脳の部位 | 刺激方法 |
|---|---|---|
| **理解（ロジック）** | 大脳新皮質 | 明確な構成・PREP法・データ |
| **共感（エモーション）** | 大脳辺縁系 | エピソード・セリフ・失敗談 |
| **行動変容（インスピレーション）** | 脳幹 | WHY・使命・ビジョン |

> **鉄則：感動はロジックではなくエモーションから起動する。しかし行動変容にはロジックとWHYの両方が必要。**

### 1-2 神経化学の活用

- **オキシトシン（信頼）**：自己開示・弱さの告白・真摯なアイコンタクト
- **ドーパミン（集中）**：意外性・フック・ストーリーのハラハラ感
- **コルチゾール（緊張）**：問いかけ・課題提示で適度に高めると前のめりになる

### 1-3 ゴールデンサークル（Simon Sinek）

```
WHY（信念・使命）← ここから始める
 ↓
HOW（方法・プロセス）
 ↓
WHAT（結果・成果物）
```

### 1-4 新田祐士式：フィルター書き換えの原理

- **事実は変えられないが、意味づけ（解釈）は変えられる**
- 「あの失敗があったからこそ、今の自分がある」→ 過去の再定義が聴衆の認知を変える
- **日常→非日常（新世界）→日常への帰還** — 帰ってきた時に世界の見え方が変わっている構造がカタルシスを生む
- 五感描写で**変性意識状態（没入感）**を作り、その状態でメッセージを届ける

### 1-5 Nancy Duarte「What Is vs What Could Be」

聴衆を動かすには「現状（What Is）」と「理想の未来（What Could Be）」を**交互に繰り返す**。このコントラストが変化への渇望を生む。聴衆はヒーロー、話し手はメンター。

## PART 2: 構成設計

### 2-1 鴨頭嘉人式 エピソードトーク4ステップ

> スピーチの**5〜7割をエピソードトーク（シーン再現）**で構成する。

1. **シーン設定**：「あれは○年前の○月のことでした。場所は…」
2. **セリフ再現**：「そのとき私は言いました。『…』」← レポートではなくドラマ化
3. **内面の開示**：「正直、このとき私の心の中は…でした」← 弱さ・葛藤を見せる
4. **転換点（気づき）**：「しかしそのとき、あることに気づいたんです」

**❌ NG（レポート型）：**
> 「お客様からクレームがあり、私は謝罪しました。関係が改善されました。」

**✅ GREAT（ドラマ型）：**
> 「あれは3年前の夏の朝でした。スマホが鳴り、画面には『田中様』と。正直、手が震えていた。電話を取ると、低い声で『あなたのせいで…』と。7分間、ただ黙って聴くしかなかった。——その7分間が、私の人生を変えました。」

### 2-2 倫理法人会モーニングセミナー 40分講話テンプレート

| 時間 | パート | 内容 | 演出ポイント |
|------|--------|------|-------------|
| 0:00-1:00 | **フック** | 最もドラマチックな瞬間/衝撃的な問い | 「こんにちは」で始めない。心臓を掴む |
| 1:00-3:00 | **導入** | WHYの提示＋聴衆との接点作り | 「今日持ち帰ってほしいもの」を1文で |
| 3:00-12:00 | **Before（苦境）** | 倫理を知る前の自分・悩み・失敗 | セリフ・五感描写で没入させる |
| 12:00-22:00 | **Practice（実践）** | 倫理との出会い＋具体的な行動 | 「万人幸福の栞」との紐付け必須 |
| 22:00-32:00 | **After（変化）** | 実践後の具体的変化（数字・事実） | S.T.A.R.モーメントをここに配置 |
| 32:00-37:00 | **Learning（決意）** | 学び＋これからの自分の決意 | 「あなたへの問いかけ」で聴衆を巻き込む |
| 37:00-40:00 | **クロージング** | 最も力強い1文で締める | 余韻を残す。「以上です」で終わらない |

> **40分の黄金比率：エピソード60%・教訓20%・導入&締め20%**

### 2-3 感情曲線の設計（ローラーコースター構成）

```
感情の高さ
  高 ──┐     ┌────── S.T.A.R.（感動のピーク）
       │     │
  中 ──┘     │   ┌── 決意・クロージング
             │   │
  低     ────┘   │
  （苦境・どん底）  └── 余韻
```

**重要：平坦なスピーチは退屈。笑いの直後に深い話を持ってくると落差の効果で倍刺さる。**

## PART 3: 10の技術

| # | 技術名 | 核心 |
|---|--------|------|
| 1 | **間（ま）の魔法** | 重要メッセージの前後に1〜3秒の無音。「えー」の代わりに沈黙を使う |
| 2 | **声の3次元** | 音量×スピード×ピッチの変化。強調ワードは30%ゆっくり（Jobs式） |
| 3 | **アイコンタクト3点法** | 会場を左/中央/右に分け、各エリアの1人と3〜5秒「会話」する |
| 4 | **S.T.A.R.モーメント** | 聴衆が永遠に覚える瞬間を意図的に設計する（Nancy Duarte） |
| 5 | **「うまく話そうとしない」** | 完璧さより真心。噛んでも詰まっても人間らしさ（鴨頭式） |
| 6 | **自己開示の深度** | Lv1事実→Lv2意見→Lv3感情→Lv4弱さ・恥→Lv5存在の揺らぎ |
| 7 | **3の法則** | メッセージは3つ以内。人間の脳は3グループで最適処理 |
| 8 | **Logline** | スピーチ全体を1文に圧縮。これが刺さらなければ全体を見直す |
| 9 | **非言語の設計** | 姿勢・手の動き・表情・移動を言葉に連動させる |
| 10 | **没入描写** | 五感（視覚・聴覚・触覚・嗅覚・味覚）で場面を再現し変性意識を作る（新田式） |

> 📖 各技術の詳細・具体例は [references/techniques-detail.md](./references/techniques-detail.md) を参照

## PART 4: 絶対NGな構成・演出

### 致命的NG（1つでもあれば即修正）

1. **「こんにちは、◯◯と申します」で始める** → フック不在。聴衆の好奇心ゼロ
2. **「今日は○○についてお話します」宣言型** → ネタバレ。好奇心を殺す
3. **「時間が来ましたのでまとめます」で終わる** → 流れを壊す。準備不足の証明
4. **「以上です」「ありがとうございました」だけで終わる** → 余韻ゼロ。最後の1文が全体の印象
5. **教訓・メッセージが4つ以上** → 何も残らない。1〜3つに絞る勇気
6. **成功自慢で終始する** → 倫理の場では「失敗と気づき」が価値
7. **抽象的な結論（「大切だと分かりました」）** → 具体的な行動・変化で締める
8. **他人のせい・被害者目線** → 自責・感謝・決意に変換

### 要改善NG

9. **「頑張りました」「うれしかったです」形容詞だけの感情描写** → 具体シーンに変換
10. **「〜と思います」の多用** → 断言力の欠如。確信のない人は信頼されない
11. **「えー」「あのー」の多用** → 「間」に置き換える
12. **長すぎる前置き・自己紹介** → 最初の1分が命
13. **データ羅列だけの箇所** → 必ず人間のストーリーで肉付け
14. **平坦な音量・スピードのまま続く** → 必ず変化点を設計
15. **比喩・例えが過多または陳腐** → 1〜2つの際立った比喩に絞る

### 倫理法人会 追加NG

16. **特定の政党・宗教への言及/他者批判・中傷/商品の宣伝**
17. **倫理以外の思想を倫理実践として紹介する**
18. **「万人幸福の栞」との紐付けがない**
19. **時間オーバー（40分厳守）**

## PART 5: 企画〜台本作成フロー

### STEP 1: ヒアリング（必ず最初に確認）

1. **場所・状況**：どこで話すか（MS/講演会/朝礼等）
2. **時間制限**：何分か（MSなら40分）
3. **対象聴衆**：年齢層・職種・関係性
4. **目的**：聴衆にどう変わってほしいか
5. **自己課題**：自分で感じている弱点

### STEP 2: 素材マイニング

- `personal_story_bank.md` から関連エピソードを検索
- 感情の振れ幅が最も大きいエピソードを核に選ぶ
- 「この瞬間だけで一本のスピーチが作れる」シーンを特定

### STEP 3: WHYの蒸留＋Logline作成

- 「なぜこの話を今・ここで・この聴衆に話すのか」を1文で
- 例：「逃げることをやめたとき、初めて人生が動き出した」

### STEP 4: 構成設計

- 2-2のテンプレートに素材を配置
- 感情曲線（2-3）を設計
- S.T.A.R.モーメントの位置を決定

### STEP 5: エピソードのドラマ化

- レポート型→ドラマ型に変換（2-1の4ステップ）
- 五感描写を追加（新田式没入描写）
- セリフを入れる

### STEP 6: クロージングの磨き上げ

- 最後の1文が全体の印象を決める
- 「あなたへのプレゼント」として持ち帰れる一言を設計

### STEP 7: 台本出力


## PART 6: 添削スコアリング（100点満点）

| # | 評価項目 | 配点 |
|---|---------|------|
| 1 | WHY（存在意義）の明確さ | 15点 |
| 2 | フック（掴みの強さ） | 10点 |
| 3 | エピソードの具体性（セリフ・場面・感情） | 15点 |
| 4 | 自己開示の深さ（弱さ・失敗・葛藤） | 10点 |
| 5 | 感情の振れ幅（波の設計） | 10点 |
| 6 | 聴衆ファースト度 | 10点 |
| 7 | メッセージの一本軸（Logline） | 10点 |
| 8 | クロージングの力 | 10点 |
| 9 | 時間・テンポ設計 | 5点 |
| 10 | 言語の鮮度（独自の表現） | 5点 |

**90〜100点：グレートプレゼンター水準 / 75〜89点：微調整で化ける / 60〜74点：構成見直し / 60点未満：WHY・エピソードの再設計**
