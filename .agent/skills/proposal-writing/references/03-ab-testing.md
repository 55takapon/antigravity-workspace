# 一変数A/B案

## 目的

Web制作会社向けGBP協業提案文で、本文の一部だけを変えて比較できるA/B案を作る。

## 基本ルール

- 一度に変更する変数は必ず1つだけにする
- 指定変数以外の本文、Web制作会社向けという対象範囲、文字数帯、固定CTAは同一にする
- CTAは第1弾では変数にしない
- 個社別文面にしない
- 送信結果や企業別ログをスキル内へ保存しない

## 第1弾で扱える主な変数

- 「連絡理由」と「外注営業ではない」の提示順序
- 中核ベネフィットの表現
- 担当範囲を提示する位置
- 約1,000字版と約2,000字版の長さ比較

## 指標の扱い

主な指標は肯定的返信率にする。返信率だけでなく、協業可能性のある返信かどうかを見る。

小標本で勝者を断定しない。数件の反応差は仮説として扱い、次の1変数テスト候補にする。

## 実験カード形式

A/B案では、本文の前か後に短い実験カードを付ける。

| 項目 | 内容 |
|:---|:---|
| 変更する1変数 | 今回変える要素 |
| 固定する範囲 | Web制作会社向けという対象範囲、本文の大部分、文字数帯、固定CTA |
| 主な指標 | 肯定的返信率 |
| 判定時の注意 | 小標本で勝者を断定しない |

## 確認方法

1. A案とB案の差分を確認する。
2. 指定変数以外の文が変わっていれば、同一になるよう戻す。
3. 固定CTAが完全に同一であることを確認する。
4. CTA変更を求められている場合は、第1弾では扱わないと伝える。
