# proposal-writing 変更履歴

- 2026-07-25: `proposal-writing` を新規作成。旧 `sales-copywriting` 系スキルとは互換性を持たない。第1弾はWeb制作会社向けGBP協業提案のみを対象にし、個社カスタマイズなし、固定CTA、独立QAなし、ランタイム品質ゲートなしで設計した。客観確認は事実、文字数、A/B差分のみ。Webマーケティング会社、広告代理店は未実装。
- 2026-07-25: 適用対象から「店舗型事業者の制作実績を確認済みのWeb制作会社だけ」という絞り込みを外した。第1弾の対象はWeb制作会社向けのまま維持し、実績掲載の有無で送信機会を狭めない方針へ変更。GBP運用やサービス拡充に興味がある会社だけが読み進める前提とし、企業検索、個社閲覧表現、個別称賛、Webマーケティング会社・広告代理店向けは引き続き対象外。
