# 入力と出力の型

ユーザー承認済みの完成提案文はまだ存在しないため、ここに完成提案文の良い例は置かない。以下はコピー用の完成文ではなく、出力の型を示す例である。

## 例1: 構成設計

### 入力

Web制作会社向けのGBP協業提案文について、本文を書く前に構成と理由を整理して。

### 出力

**中心メッセージ**

制作会社側の採用・育成・運用管理の負担を増やさず、Googleビジネスプロフィール運用を制作後の継続支援・サービス拡充の一つとして提案する。関心があるWeb制作会社だけが読み進めやすいよう、提案の正体と協業価値を冒頭で明確にする。

**固定情報順序**

1. Web制作会社へ、GBP運用を制作後支援・サービス拡充の協業案として連絡した理由
2. 制作・コーディング外注営業ではないこと
3. 採用・育成・運用管理を増やさない中核ベネフィット
4. 商談同席、運用、改善、クライアント対応、報告までの担当範囲
5. 制作後の継続接点と、制作領域の相談を制作会社へ共有する流れ
6. 常時10店舗以上の実績と、具体的な顧客保護ルール
7. 固定CTA

**各部分の役割**

冒頭はWeb制作会社へ連絡した理由と提案の正体を示す。個別サイトを見たような未確認表現は避ける。GBP運用やサービス拡充に興味がある会社だけが読み進めればよいので、相手全員を説得する長い業界論は入れない。外注営業ではないことを早く伝え、誤解による離脱を減らす。中盤で基準表現を置き、協業の価値を「サービス追加」だけに弱めない。後半で顧客保護と案件共有を示し、制作会社側の不安を具体的に下げる。

**基準表現を置く位置**

外注営業ではないことを伝えた直後に置く。提案の主役をGBP運用代行ではなく、負担を増やさない継続支援の外部パートナーに固定するため。

**固定CTA**

末尾は固定CTAを使う。第1弾では資料送付、15分面談、電話、日程候補返信などへ分岐させない。

**最初に検証する1変数**

「連絡理由」と「外注営業ではない」の提示順序。CTAは変数にしない。

## 例2: ブラッシュアップ

### 入力

AI時代に制作だけでは厳しくなる中、御社も人手不足でお困りではないでしょうか。弊社のMEOサービスをぜひ導入ください。必ず追加案件が発生し、売上が増えます。今すぐお問い合わせください。

### 出力

**辛口診断**

このまま送信するのは不可。AI時代の危機感は相手社長への市場講釈になりやすく、今回の固定戦略から外れる。「人手不足でお困り」は相手の経営課題の断定であり、未確認事実にあたる。「必ず追加案件が発生」「売上が増えます」は成果保証で使えない。「ぜひ導入」「今すぐ」は押し付けが強い。

**削除・再構成する理由**

危機感や課題断定で押すのではなく、制作会社側の負担を増やさずに継続支援の選択肢を増やせることを中心に置く。MEOサービスの導入営業ではなく、制作後の接点づくりと制作領域の相談共有を提案する。

**修正断片**

採用・育成・運用管理の負担を増やさず、店舗型クライアント向けの継続支援メニューを追加できます。商談同席から運用、クライアント対応、報告までこちらで担当します。

**固定CTAの扱い**

末尾は固定CTAへ置き換える。これは完成提案文の承認例ではなく、ブラッシュアップ時の診断と修正方向の例である。
