## 🚀 はじめ方（3ステップ）

### STEP 1: アカウントプロフィールを作成する

1. `account_profiles/ACCOUNT_PROFILE_TEMPLATE.md` をコピー
2. コピーしたファイルに自分のアカウント名をつける（例: `my_account.md`）
3. すべてのセクションを記入する

> 💡 **ポイント:** Section 4（一次情報の源泉）を最も丁寧に書くこと。ここの質が投稿の差別化を決める。

---

### STEP 2: ネタを考える（週1回 15分）

1. `02_TOPIC_RESEARCH_SKILL.md` を開く
2. **ネタ収集チャンネル一覧**から今週ネタを集める
3. **QSSスコアリングシート**で各ネタを採点（15点以上に絞る）
4. **週次ネタストックシート**に記録する

> 💡 **ポイント:** 「AI ネタ収集プロンプト」（`03_AI_EXECUTION_PROMPTS.md > TOPIC RESEARCH PROMPT`）を使えばAIが10本提案してくれる。

---

### STEP 3: 投稿を生成する（ネタごと 5分）

1. `03_AI_EXECUTION_PROMPTS.md` を開く
2. **MASTER PROMPT** をコピーしてAIに貼り付ける
3. `[ ]` の部分を自分の情報に置き換える
4. AIが生成した投稿を `output/` フォルダに保存する

> 💡 **ポイント:** 一次情報（自分の体験・数字・失敗談）を入れるほど投稿の価値が上がる。
> 掘り起こしが難しければ「FIRST INFORMATION EXTRACTION PROMPT」を使う。

## 📊 各プラットフォームの役割分担（2026年最新版）

| プラットフォーム | 主役割 | KPI指標 | 投稿頻度 |
|----------------|--------|---------|---------|
| **IG リール** | 新規発見・リーチ拡大 | 視聴完了率・送信数 | 週3〜4本 |
| **IG フィード** | 信頼構築・専門性表現 | 保存数・滞在時間 | 週2〜3本 |
| **IG ストーリーズ** | 関係性維持・コミュニティ | インタラクション率 | 毎日〜週5 |
| **Threads** | 対話・コミュニティ形成 | 返信数・滞在時間 | 毎日1〜3本 |
| **Facebook** | 権威付け・信頼のハブ | シェア数・コメント | 週3〜4本 |
| **X（旧Twitter）** | 即時会話・権威構築・収益化 | リプライ率・ブックマーク・プロフクリック率 | 毎日1〜3本 + 長文/スレッド週1本 |

## 🔁 PDCAサイクル運用スケジュール

```
【週次ルーティン（推奨）】
月：ネタ収集 & QSSスコアリング（15分）
火〜木：投稿生成（AIに依頼）& 投稿
金：今週の投稿インサイトをチェック
土：翌週カレンダー骨格作成（AIに依頼）
日：オフ or コミュニティ返信対応

【月次ルーティン（推奨）】
月末：PDCA REVIEW PROMPT で月次振り返り
翌月初：コンテンツカレンダー完成 & 承認
```

## 🎯 重要KPI（2026年プロマーケタースタンダード）

```
【インスタグラム】
  送信率（Sends/Reach）: 目標 3%以上 → 良好は 5%以上
  保存率（Save/Reach）: 目標 2%以上 → 良好は 4%以上
  視聴完了率（Reels）: 目標 30%以上 → 良好は 50%以上
  フォロワー転換率: インプレッション → フォロワー 0.5%以上

【Threads】
  返信率（Reply/View）: 目標 1%以上
  引用スレッズ数: 週5件以上
  他者リプライからの流入: 週10件以上

【Facebook】
  シェア率（Share/Reach）: 0.5%以上
  コメント率: 1%以上
  グループインタラクション: 週3回以上
```

## ⚠️ やってはいけないこと（2026年版NGリスト）

❌ TikTokウォーターマーク付き動画のInstagram転用（ペナルティ）  
❌ ハッシュタグ10個以上（逆効果）  
❌ 「いいね・保存してください」の露骨な懇願（アルゴリズム評価が下がる可能性）  
❌ 他プラットフォームからの単純コピペ投稿  
❌ 毎日低品質投稿（品質 > 数量）  
❌ コメントへの無返信（関係密度の機会損失）  
❌ 外部リンクのみの投稿（各プラットフォームのエコシステムを出る行為は評価が下がる）
