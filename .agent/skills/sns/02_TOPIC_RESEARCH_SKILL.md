# 🔍 ネタ収集スキル（Topic Research Skill）
**バージョン:** v1.0 (2026-04-11)  
**用途:** アカウントの属性・ジャンルに合わせたネタを発掘・品質スコアリング→投稿ネタに変換

---

## 🎯 このスキルの目的

ネタ切れを永遠になくす。  
「なにを投稿すればいい？」という問いに、常にデータと戦略の根拠を持って答える。

## 🧲 ネタ品質スコアリングシステム（QSS: Quality Score System）

> ネタを思いついたら以下の6軸でスコアリング。合計15点以上が「投稿に値するネタ」。

```
【ネタ品質スコアシート】

ネタ名：
　

採点（各0〜5点）:

① シェア衝動スコア
  「このネタを見た人が誰かにDMで送りたくなるか？」
  0=全くない / 3=まあまあ / 5=絶対送る
  スコア: /5

② 共感スコア
  「ターゲットペルソナが『あ、自分のことだ』と感じるか？」
  0=全くない / 3=まあまあ / 5=強く刺さる
  スコア: /5

③ 独自性スコア
  「このネタ・切り口は他で見ない独自のものか？」
  0=よく見る / 3=少し独自 / 5=唯一無二
  スコア: /5

④ 一次情報含有スコア
  「自分の体験・実績・失敗・数字が入れられるか？」
  0=全く入らない / 3=少し入る / 5=リッチに入れられる
  スコア: /5

⑤ 行動誘発スコア
  「このネタを読んだ後、フォロワーに何か行動させられるか？」
  0=行動なし / 3=自然に思う / 5=即アクション
  スコア: /5

⑥ SEO・発見性スコア
  「このトピックで検索されているか？ハッシュタグ・キーワードで見つかるか？」
  0=需要なし / 3=そこそこ / 5=高需要キーワード
  スコア: /5

──────────────────
合計: /30点

判定:
  24〜30点 → ⭐⭐⭐⭐⭐ A級ネタ（最優先で投稿）
  18〜23点 → ⭐⭐⭐⭐ B級ネタ（良ネタ・積極投稿）
  12〜17点 → ⭐⭐⭐ C級ネタ（加工次第で使える）
  0〜11点  → ⭐⭐ D級ネタ（ストック・没にする）
```

## 💡 ネタ発想フレームワーク（ネタ切れ防止8パターン）

### パターン1：悩み逆算型
```
ターゲットの悩み → その解決策 → 「〇〇で悩む人がやっていないこと」
例: 「フォロワーが増えない → 投稿前の戦略設計 → 『フォロワーが増えない人のたった1つの共通点』」
```

### パターン2：Before→After型
```
「昔の自分」の状態 → 「今の自分」の状態 → 変化のきっかけ
例: 「売上0円の個人事業主 → 月100万円 → インスタ戦略を変えた話」
```

### パターン3：常識破壊型
```
業界の「普通」 → 「でも実は...」という反論 → 根拠（一次情報）
例: 「毎日投稿した方がいい → でも週3本の方が伸びた → 私の実験結果」
```

### パターン4：数字・データ型
```
驚きのデータ → 「なぜそうなるのか」解説 → 読者への示唆
例: 「Instagram DMシェア数が1000%増えた投稿の3つの共通点」
```

### パターン5：ランキング型
```
「〇〇TOP10」「最強の〇〇5選」→ 各アイテムの解説 → まとめの洞察
例: 「2026年最も使えるインスタハッシュタグ戦略TOP5」
```

### パターン6：タイムライン型
```
「〇〇日間/週間/ヶ月でやってみた」→ 経過レポート → 結果と学び
例: 「Threadsを30日間毎日投稿した結果がヤバかった件」
```

### パターン7：比較型
```
「AとBどっちが良いか？」→ 各メリデメ → 私のオススメ（一次情報付き）
例: 「リールとカルーセル、どちらが2026年フォロワーが増えやすいか検証してみた」
```

### パターン8：トレンド便乗型
```
最新ニュース/トレンド → 「これが〇〇にとってどういう意味か」解説 → 今すぐ行動
例: 「Meta AI新機能がリリース→あなたのインスタ運用をどう変えるべきか」
```
