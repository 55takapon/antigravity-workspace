## 🧠 PART 1：2026年 X アルゴリズム完全解説

### ■ 核心思想：Xは「会話の深度」でコンテンツを評価する

> 2026年のXアルゴリズム（コードネーム「Phoenix」）は、Grok AIを統合した**予測型レコメンデーションエンジン**。  
> 「どれだけバズったか」ではなく「どれだけ価値ある会話を生み出したか」を基準に配信を決定する。

### ■ エンゲージメント重み付け（公式データ換算）

| アクション | アルゴリズム重み | 従来との違い |
|-----------|---------------|------------|
| **リプライ（返信）** | ✕13（いいね換算） | 最重要。会話の深度シグナル |
| **リポスト（再投稿）** | ✕20（いいね換算） | 拡散シグナルとして依然高評価 |
| **ブックマーク** | ✕10（いいね換算） | 「沈黙のいいね」。保存価値の証明 |
| **プロフィールクリック** | ✕5（いいね換算） | フォロワー転換の前段階 |
| **いいね** | ✕1（基準） | 単体では弱い。補助シグナルに過ぎない |
| **外部リンクへの誘導** | **マイナス50〜90%** | プラットフォーム外への離脱＝大幅ペナルティ |

### ■ 配信判断の「ゴールデン30分」

```
【投稿後の拡散メカニズム】

投稿 → 【0〜30分】AIが少数ユーザーにテスト配信
         ↓
    エンゲージメント速度を計測
    （特にリプライ率・リポスト率）
         ↓
    高速度 → より広いネットワークへ拡散
    低速度 → 配信を絞り込む（露出減）
         ↓
【決定的分岐点：最初の30〜60分が全て】
```

> **プロの鉄則**：投稿後は「ポスト＆ゴースト」厳禁。  
> 投稿後30分は必ずリプライ対応に充てる。これが配信量を2〜4倍変える。

### ■ アルゴリズムが評価するアカウントスコアリング（3軸）

| 軸 | 評価内容 | 改善アクション |
|----|---------|--------------|
| **Reputation（信頼性）** | ブロック・ミュート・報告の少なさ。質の高いエンゲージメント履歴 | 価値ある投稿の継続。炎上・スパム的行動の回避 |
| **Relevance（関連性）** | アカウントが特定ニッチに特化しているか。「Vector Consistency（トピック一貫性）」 | 投稿テーマをジャンルに絞る。迷走しない |
| **Reach（リーチ力）** | フォロワーの質。プレミアムユーザー比率 | 収益化対象層（課金ユーザー）を惹きつける内容を発信 |

## 📝 PART 3：投稿フォーマット別攻略法

### 3-1. 単発ツイート（Single Post）
> **目的：** 瞬発的なリーチ / 会話の起点 / 権威づけ  
> **文字数目安：** 100〜200文字（短く・密度高く）

**黄金構造：**
```
[フック1行]（スクロールを止める）
↓
[核心（本文）1〜3行]（価値 or 驚き or 共感）
↓
[問いかけCTA]（リプライを誘発する）
```

**効果的なフック10パターン：**
```
① 数字フック：「○○を△年間続けた結果、□□が〇倍になった話。」
② 逆説フック：「毎日投稿しても伸びない人の共通点は『○○しすぎ』です。」
③ 問いかけフック：「○○で悩んでいる人、この方法試しましたか？」
④ 告白フック：「恥ずかしい話をします。以前は○○でした。」
⑤ データフック：「○○を分析した。9割の人が知らないパターンがある。」
⑥ 速報フック：「【重要】○○が変わります。今すぐ知るべき理由。」
⑦ リスト予告：「○○を劇的に改善する7つのこと。①から始めます→」
⑧ 体験フック：「○年前の私に教えたかった△つのこと。」
⑨ ユニーク視点：「みんなが○○に注目している。でも私は△△の方が重要だと思う。」
⑩ 共感フック：「○○してても全然伸びない…そう感じたことがある人、います?」
```

### 3-2. スレッド（Thread）
> **目的：** 滞在時間の最大化 / 権威構築 / フォロワー転換  
> **理想の本数：** 8〜12ツイート  
> **最強の投稿フォーマット（Xで他を圧倒する型）**

**スレッド黄金構造：**
```
【ツイート1】フック（最重要。10〜15の案から1つ選ぶ）
  → 結論・驚き・強い約束で「続きを読む」を引き出す

【ツイート2】問題提起 / 共感
  → ターゲットの悩みをそのまま言語化する

【ツイート3〜4】背景・なぜ重要か
  → 「なぜこの話をするのか」の文脈を語る

【ツイート5〜8】核心コンテンツ（1ツイート1ポイント）
  → 具体的なノウハウ・一次情報・データを展開
  → 各ツイートは250文字以内。改行・スペースで視認性UP

【ツイート9】まとめ・洞察
  → 全体から得られる「1つの真実」を語る

【ツイート10】問いかけ（会話誘発）
  → 「あなたはどう思いますか？」でリプライ促進

【ツイート11】CTA（最終）
  → 「フォローして毎日○○の情報を受け取る」
  → 外部リンクはここにのみ置く（本文には絶対入れない）
```

**スレッドの視覚設計ルール：**
```
✅ 1ツイート＝1メッセージ（複数の情報を詰め込まない）
✅ 3〜4ツイートごとに画像・図解・スクリーンショットを挟む
✅ 改行を積極的に使い「壁のようなテキスト」を避ける
✅ 数字・箇条書きで視認性を高める
✅ 最初のツイートに「(ツイート数/総数)」の番号は付けない（古い手法）
```

