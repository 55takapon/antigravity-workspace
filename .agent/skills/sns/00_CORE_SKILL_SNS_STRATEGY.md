## 🧠 PART 1：2026年 アルゴリズム完全解説

### ■ 共通原則：3プラットフォーム横断

> 2026年現在、メタ（Instagram/Threads/Facebook）はすべて**「ユーザーが誰かに教えたくなる価値のある投稿」**を最重要指標として評価している。
> いいね・フォロワー数より「送信数・滞在時間・返信深度」が新たな真北。

| 指標 | 重要度 | 解説 |
|------|--------|------|
| **送信数（DM share）** | ★★★★★ | 最強の拡散シグナル。「誰かに教えたい」を引き出せた証拠 |
| **滞在時間（Watch Time）** | ★★★★★ | 動画・カルーセル問わず「見続けた時間」で価値を評価 |
| **保存数（Save）** | ★★★★☆ | 「後で見返したい」＝長期的価値のある情報 |
| **返信・コメント深度** | ★★★★☆ | 一言より対話。会話が続くコンテンツを優遇 |
| **いいね数** | ★★☆☆☆ | 参考指標にとどまる（単体では弱いシグナル） |
| **フォロワー数** | ★★☆☆☆ | フォロワー数そのものは非評価。関係密度が重要 |

## 📸 PART 2：Instagram（インスタグラム）

### 2-1. フォーマット別アルゴリズム解説（2026年最新）

#### 🎞️ リール（Reels）— 新規リーチ・発見の主軸
- **最重要KPI：最初の2秒の離脱率 / 視聴完了率 / ループ再生数**
- アルゴリズムは冒頭2秒で「続きを見るか」を判断する
- 理想尺：**7〜30秒**（ループしやすい短尺が最も有利）
- 他SNS（TikTok等）のウォーターマーク付きは**ペナルティ対象**
- トレンドBGMは活用すべきだが、ジャンルに合わないものは逆効果
- 「送信テスト」：投稿前に「これをDMで友達に送りたくなるか？」を自問

#### 🖼️ フィード投稿（Feed）— 信頼構築・ブランディング
- **カルーセル**（複数枚）は**保存率と滞在時間**の両方を高められる最強フォーマット
- 単体画像：ビジュアルインパクトで瞬時に止める力が必要
- ハッシュタグ：3〜5タグに絞る（多用は2026年時点で逆効果）
- **インスタSEO**が必須：キャプションとプロフィールへのキーワード埋め込み
- 投稿後1時間以内のエンゲージメント速度が非常に重要

#### 📱 ストーリーズ（Stories）— 関係性維持・コミュニティ深化
- フォロワーとの**「関係密度」**を高める場
- アンケート・質問箱・クイズ・スライダーを積極活用
- インタラクティブスタンプは「関係の深さ」シグナルとしてアルゴリズムが評価
- トップパフォーマーのフィード投稿をリポストして既存フォロワーにも届ける

### 2-2. 2026年 Instagram 投稿の黄金律

1. **Quality over Quantity**：週3〜4リール＋週2〜3カルーセルが理想
2. **オリジナリティ最優先**：インスタネイティブのコンテンツを作る
3. **「送りたくなる」設計**：保存でなくシェアを誘発する構造を意識
4. **コメント返信は必須**：投稿後1時間以内に返信→アルゴリズムへの「活発」シグナル
5. **インサイト活用**：送信数・滞在時間を軸に勝ちパターンを見つけてダブルダウン

## 🧵 PART 3：Threads（スレッズ）

### 3-1. アルゴリズム解説（2026年最新）

| ランキング要素 | 重要度 | 解説 |
|---------------|--------|------|
| **エンゲージメント速度** | ★★★★★ | 投稿後30〜60分の反応量が拡散の分岐点 |
| **返信の深度・質** | ★★★★★ | いいねより返信。「対話が続く投稿」が最優遇 |
| **滞在時間** | ★★★★☆ | 読み終わるまで離脱しないコンテンツが評価される |
| **ネットワーク関連性** | ★★★★☆ | 同ジャンルのユーザーにリーチする精度 |
| **投稿の新しさ** | ★★★☆☆ | For Youフィードでは鮮度も評価 |

### 3-2. 2026年 Threads 成長戦略

**「3-2-5エンゲージメントルール」**
- 3：毎日3本のオリジナルスレッズ（自分の考え・洞察・問い）
- 2：自分の投稿に2回返信（コメント欄を盛り上げる）
- 5：同ジャンルの他クリエイターへ5回コミュニティ交流

**投稿の本質：「会話ファースト」**
- 一方的な発信＝NG。問いかけ、対話、反論を歓迎する空気感
- ビジュアル（画像付き）投稿はテキストのみより好パフォーマンス傾向
- トレンドタグに乗るが、価値ある独自のコメントがある場合のみ

**Threadsの特性：信頼の資産化プラットフォーム**
- 1万フォロワー未満のアカウントが現在最も有機的リーチを得やすい
- 他の大型アカウントへの「質の高いリプライ」が発見の近道
- 目的地（LINE・HP）への導線設計を忘れずに

## 📘 PART 4：Facebook（フェイスブック）

### 4-1. アルゴリズム解説（2026年最新）

- フィードの**最大50%が非フォローアカウントのコンテンツ**（レコメンデーション化）
- ランキング原則：**Inventory（在庫）→ Signals（シグナル）→ Predictions（予測）→ Relevance（関連性）**
- 短尺縦型動画（リール）がすべての動画として全面移行済み

### 4-2. 2026年 Facebook コンテンツ戦略

**コンテンツ力学の公式：80／20ルール**
- **80%：価値提供**（教育・娛楽・共感・インスピレーション）
- **20%：プロモーション**（商品・サービス・お知らせ）

**優先フォーマット：**
1. **リール**（Reels）：発見・新規リーチのメインエンジン
2. **カルーセル・写真**：既存フォロワーへのエンゲージメント強化
3. **ストーリーズ**：日常感・温度感でトップオブマインドを維持
4. **グループ投稿**：ページ投稿より高いリーチが期待できる場

**Facebookの特性（日本市場）：**
- 30〜50代のビジネス層がメイン（実名制、信頼性が高い）
- BtoB向けの権威付け・業界情報発信に最適
- インスタとのクロスポストは「ネイティブコンテンツ」として常にリメイクを徹底
