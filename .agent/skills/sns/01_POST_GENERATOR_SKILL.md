## 🏗️ 投稿の型ライブラリ（Post Template Library）

### ■ TYPE 1：ノウハウ系カルーセル（Howto型）
> **目的：保存数・送信数最大化 / 信頼構築**
> **最適媒体：Instagram フィード（カルーセル）**

```
【構成テンプレート】

[スライド1：フック]
タイトル：「〇〇で失敗する人が絶対やっていないこと」
サブ：「これを知っているだけで〇〇が変わる」

[スライド2：問題提起]
あなたはこんな悩みを抱えていませんか？
・悩み1
・悩み2
・悩み3

[スライド3〜7：核心コンテンツ]
ポイント①：〇〇
詳細説明（2〜3行）
具体例またはデータ

（ポイントを3〜5個）

[スライド8：まとめ]
今日から使える3つのアクション
①②③

[スライド9：CTA]
「保存して後で見返してね」
「他にも〇〇の情報発信中→プロフから✔️」
```

**キャプション構造：**
```
冒頭フック1行（止まらせる問い or 宣言）

本文（3〜5行のリード文）
〇〇について詳しく解説しました。

▼ 特にこの投稿が刺さる人
・[ペルソナ特徴1]
・[ペルソナ特徴2]

💾 後で見返せるよう「保存」がおすすめ！

#[キーワード1] #[キーワード2] #[キーワード3]
```

### ■ TYPE 2：体験談・一次情報型（Story型）
> **目的：共感・フォロワー転換 / ブランディング**
> **最適媒体：Instagram Reels / Threads / Facebook**

```
【構成テンプレート：STAR法×Before→After】

[Hook - 衝撃の結論から始める]
「〇〇で△△した結果、××が変わりました」
「これをやるまで私は〇〇で悩み続けていました」

[Situation - 状況設定]
「あの頃の私は〇〇でした...」
（具体的な時期・状況・数字）

[Trouble - 問題・葛藤]
「〇〇が原因で△△という問題が起きていました」
（共感ポイントを丁寧に描写）

[Action - 行動・転換点]
「そんな時に〇〇を試しました」
（具体的な行動、なぜそれをしたか）

[Result - 結果]
「結果、〇〇が△△になりました」
（数字や具体的な変化）

[Learning - 読者への洞察]
「この経験で気づいたのは〇〇です」
（一次情報から得た独自の洞察）

[CTA]
「あなたにも当てはまる部分がありましたか？
コメントで教えてください👇」
```

### ■ TYPE 3：議論喚起型（Opinion型）
> **目的：コメント・返信エンゲージメント最大化**
> **最適媒体：Threads / Facebook**

```
【構成テンプレート：反論から入る型】

[対立軸の提示]
「〇〇の常識は、実は間違っているかもしれません。」

[一般的な認識]
「多くの人は〇〇だと思っています。」

[自分の見解（一次情報付き）]
「でも私が〇〇年間〇〇をやってきた中で気づいたのは...」

[根拠・データ]
「実際に〇〇したところ、○%が△△でした」

[読者への問いかけ]
「あなたはどう思いますか？
→〇〇派はいいね♡
→△△派はコメント欄で教えてください」
```

### ■ TYPE 4：リスト・まとめ型（List型）
> **目的：保存数・送信数・リーチ最大化**
> **最適媒体：Threads / Instagram フィード**

```
【構成テンプレート：数字タイトル型】

[タイトル]
「〇〇を知っているだけで△△できる7つのこと」
「絶対やってはいけない〇〇の失敗5選」

[リード]
「〇〇で悩む人がこれを知らないのは損です。」

[リスト本体]
①〇〇：△△（理由を1行）
②〇〇：△△
③〇〇：△△
（5〜10個）

[まとめ・洞察]
「共通点は〇〇です。」

[CTA]
「どれが1番刺さりましたか？→コメントで！」
「保存して今すぐ実践してみてください」
```

### ■ TYPE 5：最新情報・トレンド型（News型）
> **目的：シェア（送信）最大化 / 権威構築**
> **最適媒体：Facebook / Threads / Instagram Story**

```
【構成テンプレート：速報→解説→自分の見解型】

[速報ライン（フック）]
「⚡ 〇〇に大きな変化が！」
「【速報】〇〇が〇〇年から変わります」

[事実・情報]
「〇〇年〇月〇日、〇〇により△△が発表されました。
具体的には...（要点を簡潔に）」

[プロの解説]
「これが何を意味するかというと...」

[あなたへの影響]
「〇〇をしているあなたに直接影響するのは...」

[今すぐできるアクション]
「今からやることは1つ：〇〇」

[シェア促進]
「まだ知らない人にシェアしてあげてください🔁」
```

## 🔁 一次情報の活かし方ガイド（価値を10倍にする技術）

### 一次情報の入れ方レベル表

| レベル | 説明 | 例 |
|--------|------|----|
| Lv.1 基礎 | 「〇〇の経験がある」と言及する | 「実際に試してみて」 |
| Lv.2 中級 | 具体的な数字・期間・結果を入れる | 「3ヶ月で〇〇が△△%改善」 |
| Lv.3 上級 | 失敗・葛藤・転換点を詳細に語る | 「あの時〇〇したことで...」 |
| Lv.4 プロ | 業界の常識への反論を一次情報で語る | 「一般的には〇〇と言われるが私の経験では△△」 |

### 一次情報を引き出す質問リスト
```
□ この体験を通じて「最初に思っていたことと違った」ことは何ですか？
□ 失敗したことはありますか？その失敗から何を学びましたか？
□ この体験で「〇〇を信じなくなった」ことはありますか？
□ 他の人にはない「あなただけ」の視点は何ですか？
□ この体験で数字として変わったこと（KPI・売上・時間）は何ですか？
□ 「あの時こうすれば良かった」と今なら言えることは何ですか？
```
