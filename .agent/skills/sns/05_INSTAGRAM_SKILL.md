## 🧠 PART 1：2026年 Instagram アルゴリズム完全解説

### ■ 核心：Instagramは「1つのアルゴリズム」ではない

2026年のInstagramは **Feed / Reels / Stories / Explore** の4面でそれぞれ独立したAIランキングシステムを運用。共通するのは **「ユーザーが誰かに教えたくなるコンテンツ」** を最優遇するという設計思想。

### ■ 最重要ランキングシグナル（2026年4月確定版）

| シグナル | 重要度 | 解説 |
|---------|--------|------|
| **DM送信（シェア）** | ★★★★★ | **最強指標**。「友達に教えたい」＝最高の評価 |
| **視聴完了率（動画）** | ★★★★★ | 最後まで見られた＝価値あるコンテンツ |
| **ループ再生** | ★★★★★ | 「もう一度見たい」は極めて高評価 |
| **保存（Save）** | ★★★★☆ | 「後で見返したい」＝長期的価値の証明 |
| **キャプション滞在時間** | ★★★★☆ | 長文キャプションを読み込む行為もシグナル |
| **コメント（深い対話）** | ★★★★☆ | 短い絵文字より長い会話が高評価 |
| **いいね** | ★★☆☆☆ | 補助指標。単体では弱い |

### ■ 4面体制の各ランキングロジック

#### 🎬 Reels（発見・新規リーチ）
- 完視聴率 → DM送信数 → オリジナリティ
- TikTokロゴ付き動画は **おすすめ枠から除外**
- フォロワー0人でもバズる可能性がある唯一のフォーマット

#### 🖼️ Feed（信頼構築・ブランディング）
- フォロー中のアカウント + AIレコメンドの混合
- 過去の交流履歴（いいね・コメント・DM）が表示順を決定
- カルーセルは「セカンドチャンス表示」あり（スワイプしなかったユーザーに再表示）

#### 📱 Stories（関係性維持）
- 視聴頻度・リアクション・DM履歴で「親密度」を算出
- インタラクティブスタンプ（アンケート・スライダー）使用で親密度UP
- 既存フォロワーとの関係深化が目的

#### 🔍 Explore（新規発見）
- 類似ユーザーの行動パターンから推薦
- ニッチ特化していると正確にカテゴリ分類される
- 「Your Algorithm」機能でユーザーが自らジャンルを選択可能に（2026年新機能）

## 👤 PART 2：プロフィール最適化（ランディングページ設計）

### ■ プロフィールは「LP（ランディングページ）」と同じ

```
【名前フィールド（SEO最重要）】
  → 「本名 | 専門キーワード」（検索で発見される）
  → 例：「田中太郎｜認知科学コーチ×Web集客」

【bio（4行で完結）】
  1行目：誰を助けるか（Who I help）
  2行目：何を達成させるか（Transformation）
  3行目：実績・権威（Proof）
  4行目：CTA（1つだけ）
  
  例：
  コンフォートゾーンの外側にゴールを設定する方法を発信
  200社以上のWeb集客を支援した元広告代理店マーケター
  認知科学ベースのコーチングで「本当にやりたいこと」を実現
  ↓ 無料相談はこちら

【リンク】
  → Linktreeよりも直接的な1つのURL（LP・LINE）が推奨
```

### ■ ピン留め投稿（3本＝ファネルの入口）
```
1本目：自己紹介 / ブランドストーリー（「この人は何者？」に答える）
2本目：最もバズった投稿 or 最高の教育コンテンツ
3本目：高価値リソース / 無料オファー / サービス紹介
```

### ■ ハイライト設計（プロフィールのメニュー）
```
推奨5〜7カテゴリ：
📌 自己紹介 / About
📌 サービス内容 / Offers
📌 お客様の声 / Reviews
📌 よくある質問 / FAQ
📌 裏側・日常 / Behind the Scenes
📌 無料コンテンツ / Free Resources
```

### ■ アカウント設定チェックリスト
- [ ] ビジネスアカウント or クリエイターアカウントに切替
- [ ] 名前フィールドにニッチキーワード含む
- [ ] bioに変革の約束（Transformation Promise）
- [ ] CTAは1つだけ（迷わせない）
- [ ] プロフィール写真はブランド統一の高解像度
- [ ] ピン留め3本設定済み
- [ ] ハイライト5カテゴリ以上整備

## 🎬 PART 3：リール完全攻略

### ■ 冒頭2秒のルール

```
最初の2秒で視聴者の指を止めなければ、中身に到達しない。

【テクニック】
① 「2カットの法則」：冒頭2秒以内にカットを2回（視覚変化で強制停止）
② テキストオーバーレイで結論を先出し（音なしでも伝わる）
③ ズーム・アップなどの強い視覚インパクト
④ 「これを知れば解決する」とベネフィットを即提示
```

### ■ 伸びるリールの3層構成

```
【層1】フック（0〜2秒）
  → 視聴者の興味を掴む（上記テクニック）

【層2】本編（滞在時間確保）
  → テンポよく展開。無駄な間を省く
  → 1スライド＝1メッセージ

【層3】アクション誘導
  → 「参考になったら保存してね」
  → 「友達に教えてあげて」（DM送信誘発＝最強シグナル）
```

### ■ 推奨尺
| 尺 | 用途 |
|----|------|
| 7〜15秒 | ループ再生狙い（バズ最大化） |
| 15〜30秒 | ノウハウ・Tips系 |
| 30〜60秒 | 体験談・ストーリー系 |
| 60〜90秒 | 深い解説（ただし離脱率注意） |

### ■ トレンド音源の活用
- IG音楽ライブラリのトレンド音源はリーチ拡大に有効
- ただし**ジャンルに合わない音源は逆効果**
- 音源横の「↗️」マークがトレンド指標

## 🖼️ PART 4：カルーセル完全攻略

### ■ なぜカルーセルが最強か
- スワイプ行動 → **滞在時間が自動的に伸びる**
- 「セカンドチャンス表示」：スワイプしなかったユーザーに再表示
- 保存率・DM送信率が他フォーマットより高い

### ■ 構成（8〜10枚推奨）

```
【スライド1】フック（表紙）
  → 大きなタイトル + 高コントラスト
  → 「○○する人が知らない△つのこと」

【スライド2〜8】本編
  → 1枚1メッセージ（詰め込みすぎない）
  → 3〜5枚目にショート動画を挟むとdwell time UP（ハイブリッドメディア）

【スライド9】まとめ
  → 全体の要約を1枚で

【スライド10】CTA
  → 「保存して後で見返してね 📌」
  → 「友達にシェアしてあげて 📩」（DM送信誘発）
  → 「フォローで毎日○○の情報をお届け」
```

### ■ デザインルール
```
✅ 統一フォント・カラーパレット（ブランド認知）
✅ 読みやすいフォントサイズ（スマホ最適化）
✅ 重要テキストは中央配置（端はUI要素で隠れる）
✅ Canva / Figma でテンプレート化して効率化
```

## 🔍 PART 5：キャプションSEO vs ハッシュタグ（2026年決定版）

### ■ 2026年の事実：キーワードSEOがハッシュタグを完全に上回った

| 要素 | 役割 | 重要度 |
|------|------|--------|
| **キャプション内キーワード** | メインの発見エンジン | ★★★★★ |
| **名前フィールドのキーワード** | プロフィール検索で発見 | ★★★★★ |
| **画面内テキスト（オンスクリーン）** | AIが読み取りSEO対象 | ★★★★☆ |
| **ALTテキスト** | AIが読み取りSEO対象 | ★★★★☆ |
| **ハッシュタグ** | カテゴリ分類の補助のみ | ★★☆☆☆ |

### ■ キャプションの書き方
```
【構成】
1行目：フック（読ませる導入）
2〜5行目：本文（価値提供・体験談・解説）
最後：CTA + ハッシュタグ3〜5個

【キーワード戦略】
→ 自然な文脈でターゲットキーワードを含める
→ 「認知科学コーチング」「MEO対策」「Web集客」など
→ 不自然な羅列は逆効果（人間が読んで自然であること）
```

### ■ ハッシュタグ運用ルール（2026年版）
```
数量：3〜5個（これ以上は逆効果）
選び方：ニッチ特化（#認知科学コーチング > #コーチング）
配置：キャプション末尾 or 1コメ目
NG：30個のタグ羅列（2020年代の手法、現在はスパム判定リスク）
```
