## タイトル × キャッチコピー キーワード戦略（最重要）

### 核心ルール：キーワードを重複させるな

タイトルとキャッチコピーは**SEOが効く2つの枠**。
ここに同じキーワードを入れるのは文字数の無駄遣い。
**タイトルで取るキーワード × キャッチコピーで取るキーワード** をセットで設計する。

> ococona라内検索にもサイト外（Google等）検索にも影響する。文字数が限られている分、1字1字の重みが大きい。

### 設計手順

1. **狙うキーワードを書き出す**
   - 例: GBP投稿文、Googleビジネスプロフィール、MEO、集客、投稿代行、口コミ 等

2. **検索ボリューム・競合を考えてAとBに振り分ける**
   - タイトル枠（23字）: コアキーワード（最も検索される語）
   - キャッチコピー枠（15〜30字）: サブキーワード・差別化語・実績

3. **重複ゼロで組む**

```
【NG例】キーワードが重複している
タイトル:    GBP投稿文4本｜MEO集客強化し
キャッチコピー: MEO実績あり｜GBP投稿文作成
→「GBP投稿文」「MEO」が両方に入っていて文字数の無駄

【OK例】キーワードを分散させている
タイトル:    GBP投稿文4本｜集客に繋がる文章作成し
キャッチコピー: MEO実績10社以上｜歯科・士業・飲食対応
→「GBP投稿文・集客・文章作成」と「MEO・実績・業種」で分散
```

## タイトル設計のルール

### 絶対ルール
- タイトル末尾は「**ます**」固定（画面に「※「ます」は必須のため削除できません」と明記）
- 「ます」の2文字は25字のカウントに**含まれる**（画面カウンターが「23」と表示）
- 出品者が入力できるのは実質 **23字以内**

### 優先順序
1. 最も検索される主キーワードを先頭
2. サービスの核心を端的に言い切る
3. 末尾「ます」に自然につながる語尾で終わる

---

## キャッチコピー設計のルール

- **15〜30字の範囲内に必ず収める（必須項目・範囲外はエラー）**
- タイトルで使ったキーワードは使わない（分散戦略）
- 実績数・資格・対応業種など、タイトルに入らなかった差別化要素を入れる

```
例: MEO実績10社以上｜歯科・士業・飲食対応（22字）✅
例: 公式認定3資格｜Googleマップ集客を強化（21字）✅
```

## サービス内容（1,000字以内）の構成設計

### 構成の基本順序（CVR最大化）

1. **共感（悩みの言語化）** — 〜150字
2. **解決提示** — 〜100字
3. **納品物（箇条書き）** — 〜150字
4. **制作の流れ** — 〜150字
5. **対応業種** — 〜100字
6. **アップセル導線** — 〜80字
- **合計目安: 700〜800字**（残りはポートフォリオ画像・Q&Aで補完）

## NGパターン（禁止事項）

| NG | 理由 |
|---|---|
| ━━━ などの装飾区切り線 | 1本20〜25字消費。情報ゼロ |
| 絵文字を見出しに多用 | 文字数消費。全体3個以内に抑える |
| 「競合店のURL・GBPリンクを教えてください」 | 一般ユーザーは回答不能。「参考にしたいお店があれば」に変える |
| 注意書きの多重化 | 500字制限の「お願い」欄で繰り返さない |
| 効果・順位の保証表現 | 必ず「保証はできません」を1箇所明記 |
| 「まずはお気軽に〜」の多用 | 1回のみ |
| 「〜させていただきます」 | 冗長。「〜します」に統一 |

---

## ユーザーリテラシーの前提

- 一般ユーザーは「GBP」「MEO」「CTA」を知らない前提
- 専門用語は使う場合、直後に括弧で補足（例: GBP（Googleビジネスプロフィール））
- ヒアリングで聞くのは「業種・強み・ターゲット客層」の3点まで
- 購入者に調査・リサーチ作業を求めない

---

## 購入にあたってのお願い（500字以内）の構成

1. 必要情報（3項目以内） — 購入後ヒアリングで聞くことを予告
2. 納期 — 通常日数＋急ぎオプション
3. 注意事項（箇条書き3〜4点） — 含まないもの・保証できないこと
4. 複数店舗ルールなど個別条件
