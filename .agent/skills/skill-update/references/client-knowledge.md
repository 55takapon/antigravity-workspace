# クライアントナレッジの読み込み方

## 目的

クライアント案件に関係するスキル改善では、実際の店舗情報、過去投稿、制作物、業種メモを確認し、机上の一般論だけで改善しない。

## 既定の参照先

クライアントフォルダの既定パスは `C:\Users\hangy\.gemini\antigravity\.agent\clients` とする。
環境変数 `ANTIGRAVITY_CLIENTS_ROOT` がある場合は、その値を優先する。

## 使う材料

| 種類 | 扱い |
|:---|:---|
| クライアント別フォルダ | 店舗名、業種、サービス、過去施策、制作物の確認に使う |
| 過去投稿・原稿 | GBP投稿、口コミ返信、LP、広告文の改善評価に使う |
| ナレッジファイル | 事実確認、トーン、禁止事項、サービス範囲の確認に使う |
| 未確認メモ | 確認済み材料として扱わず、質問候補にする |

## 作業手順

1. ユーザー依頼にクライアント名、店舗名、フォルダ名、業種、案件名が含まれるか確認する。
2. 該当しそうなクライアントフォルダだけを探す。全クライアントを一括で読み込んではならない。
3. `rg` で、店舗名、サービス名、投稿テーマ、過去投稿、NG表現、実績、料金、営業時間などを検索する。
4. 改善対象スキルに使う材料と、今回だけの案件固有情報を分ける。
5. スキルへ入れるのは、複数案件で再利用できるルールだけにする。クライアント固有の本文や機密情報をスキル本文へ直接入れてはならない。

## 出力形式

| 区分 | 内容 | 参照元 | スキル改善での扱い |
|:---|:---|:---|:---|
| 再利用ルール | 複数クライアントで使える判断基準 | ファイル名またはフォルダ名 | referencesへ反映候補 |
| 案件固有情報 | 特定クライアントだけの情報 | ファイル名またはフォルダ名 | 評価ケースや材料に限定 |
| 未確認情報 | 出典が不足している内容 | 不明 | 質問または除外 |

## 確認方法

- 対象クライアント以外の情報を混ぜていない。
- クライアント固有情報を、汎用スキル本文へ直接書いていない。
- 参照元を示せない事実を、確認済み材料として扱っていない。
- 既存のクライアントデータを削除、移動、上書きしていない。

## 不合格時の対応

- 対象クライアントが特定できない場合は、候補フォルダを提示して確認する。
- 複数クライアントの情報が混ざった場合は、材料を分け直す。
- 機密性が高い本文は、スキル本文ではなく評価ケースまたは作業メモに限定する。
