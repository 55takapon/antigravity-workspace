## 1. クリニック（歯科）のMEO市場環境（2025-2026）

### 1.1 歯科×ローカル検索の現状

- **歯科医院はコンビニより多い**: 全国約68,000院（2025年時点）。コンビニ（約56,000店）を大きく上回る激戦市場
- **患者の受診行動の変化**: 「地域名＋歯医者」「近くの歯科」でのGoogle検索→マップ確認→口コミ読了→電話/ネット予約の流れが定着
- **口コミの決定力**: 歯科は「痛み」「不安」を伴う受診が多く、口コミの質（「痛くなかった」「丁寧に説明してくれた」等）が来院決定に**最も強く影響**する業種の1つ
- **AI検索の影響**: 「虫歯の治療費用はいくら？」「矯正歯科の選び方」等の情報クエリにAI Overviewsが回答。E-E-A-T（経験・専門性・権威性・信頼性）の高いクリニックがAI引用される
- **YMYL（Your Money or Your Life）領域**: 健康に直結するため、Googleは通常業種よりも高い信頼性基準を適用

### 1.2 歯科MEOの難易度と特徴

| 項目 | 歯科の特徴 |
|------|----------|
| 競合密度 | **非常に高い**（都市部では半径1km内に20〜50院） |
| 口コミ優先度 | **最重要**（「先生の対応」「痛み」「待ち時間」が来院決定に直結） |
| 写真の影響度 | **高い**（清潔感・最新設備が信頼感に直結） |
| E-E-A-T要件 | **極めて高い**（YMYL領域。資格・学会所属の明示が必須） |
| 広告規制 | **非常に厳しい**（医療広告ガイドライン適用） |
| 電話アクション比率 | **高い**（プロフィール閲覧→電話発信率が6〜10%） |
| 季節変動 | 中程度（学校歯科検診後・長期休暇前に増加） |

→ コアスキル セクション1（MEO全体像・ランキング要因）を前提知識として参照

## 2. カテゴリ・属性の最適設定

### 2.1 GBPカテゴリ設定

#### メインカテゴリ（1択で厳選）

| 診療形態 | 推奨メインカテゴリ |
|---------|------------------|
| 一般歯科（保険診療中心） | **「歯科医院」** |
| 矯正専門 | 「矯正歯科」 |
| 小児専門 | 「小児歯科」 |
| 口腔外科中心 | 「歯科口腔外科」 |
| インプラント専門 | 「歯科医院」（※「インプラント」はサブカテゴリ/説明文） |

> **⚠️ 注意**: メインカテゴリは**1つのみ**。最も来院数が多い主要診療に合わせる。一般歯科を主体に矯正も行う場合は「歯科医院」をメインに。

#### サブカテゴリ（推奨2〜5個）

一般歯科クリニックの場合の推奨例：
1. 「矯正歯科」（矯正対応の場合）
2. 「小児歯科」（小児対応の場合）
3. 「審美歯科」（ホワイトニング・セラミック等対応の場合）
4. 「歯科口腔外科」（抜歯・口腔外科対応の場合）
5. 「歯科技工所」（院内ラボがある場合）

> **サブカテゴリの設定ミスは致命的**: 適切なサブカテゴリを設定しないと、間接検索（「矯正歯科 渋谷」等）での表示機会を**30〜50%失う**可能性がある。

### 2.2 属性設定チェックリスト（歯科固有）

#### 必須属性
- [ ] **バリアフリー**: 車椅子対応入口 / エレベーター / 車椅子対応トイレ
- [ ] **駐車場**: あり/なし/台数
- [ ] **支払い方法**: 保険証 / 現金 / クレジットカード / 電子マネー
- [ ] **予約**: 予約制 / 予約優先 / 当日受付可
- [ ] **性別**: 女性医師在籍（「女性歯科医師」で検索するユーザー多数）

#### 歯科重要属性
- [ ] **キッズスペース**: あり/なし（保護者にとって重要な判断基準）
- [ ] **個室診療室**: あり/なし（プライバシー重視の患者に訴求）
- [ ] **衛生対策**: 感染対策の徹底（コロナ以降の重要属性）
- [ ] **急患対応**: 急患受付可（「歯が痛い 今すぐ」検索に対応）
- [ ] **土日診療**: 土曜/日曜/祝日の診療有無（検索フィルターに直結）
- [ ] **夜間診療**: 19時以降の診療（「夜間 歯科」検索に対応）
- [ ] **訪問診療**: 対応可否（高齢者向けの重要属性）

> **「土日診療」「夜間診療」属性は超重要**: 「土曜日 歯医者 ○○駅」は高CVRキーワード。土日診療の歯科は限られるため、設定するだけで差別化になる。

## 3. 写真・動画コンテンツ戦略

### 3.1 歯科の必須写真カテゴリ

歯科は**清潔感・安心感・最新設備**が来院決定の鍵。最低20枚、理想50枚以上。

| カテゴリ | 推奨枚数 | 撮影ポイント |
|----------|---------|-------------|
| **外観** | 3〜5枚 | 昼/夜・看板・入口（初来院でもわかるカット） |
| **受付・待合室** | 3〜5枚 | 清潔感・明るさ・リラックスできる雰囲気 |
| **診療室** | 3〜5枚 | チェア・モニター・最新設備が映るカット |
| **個室診療室** | 2〜3枚 | プライバシー配慮の空間（あれば） |
| **医療設備** | 3〜5枚 | CT / マイクロスコープ / レーザー等の最新機器 |
| **院長・スタッフ** | 3〜5枚 | 白衣姿の笑顔のポートレート・集合写真 |
| **キッズスペース** | 2〜3枚 | 子供が安心できる空間（あれば） |
| **カウンセリングルーム** | 1〜2枚 | 説明・相談の場（あれば） |
| **衛生管理** | 2〜3枚 | 滅菌器・オートクレーブ・個包装の器具 |

### 3.2 歯科写真の撮影テクニック

```
【照明】
  ✓ 明るく清潔感のある白色照明（暖色系は非推奨）
  ✓ 蛍光灯のちらつきが出ない設定（シャッタースピード調整）
  ✓ 設備写真は照明をフルに点灯して撮影

【注意点】
  ✗ 治療中の口腔内写真は原則NG（患者の不安を煽る）
  ✗ 血液・手術器具が露出した写真は禁止
  ✓ 患者の同意なしの顔写真は厳禁（肖像権）
  ✓ ビフォーアフター写真は医療広告ガイドラインの制約あり（後述）

【ファイル最適化】
  ✓ ファイル名: 「渋谷_歯科_診療室.jpg」（地域名+業種+内容）
  ✓ 解像度: 1200x900px以上（4:3推奨）
  ✓ ジオタグ: 院内で位置情報ONにして撮影
```

## 4. 口コミ獲得・管理（歯科特化）

### 4.1 歯科の口コミ獲得タイミング

歯科は**「治療の安心感を得た瞬間」**に依頼するのが鉄則。

#### 最適タイミング
1. **治療完了後の会計時**: 「本日の治療はいかがでしたか？」→満足の確認後に依頼
2. **定期検診終了後**: 「異常なし」の安心感が最も高い瞬間
3. **矯正治療完了時**: 結果に最も満足しているタイミング（質の高い口コミが得やすい）
4. **お子様の治療後（保護者へ）**: 「お子様が嫌がらずに治療できましたね」→保護者の感謝が口コミに
5. **ホワイトニング後**: 目に見える効果に感動した直後

#### 口コミ依頼の声がけ例（歯科向け）
```
【治療完了時】
「今日の治療お疲れさまでした。痛みはいかがですか？
 もしよろしければ、Googleマップに感想をいただけると
 同じ症状でお悩みの方の参考になりますし、
 私たちの励みにもなります」

【定期検診後】
「検診の結果、特に問題ありませんでした。
 引き続き良い状態を維持しましょう！
 もしよければGoogleで当院の感想をお聞かせいただけると嬉しいです」

【矯正完了時】
「矯正治療の完了、おめでとうございます！
 長い期間がんばりましたね。
 もしよろしければ、これから矯正を検討されている方のために
 Googleに体験談を書いていただけると大変ありがたいです」
```

#### 口コミ獲得ツール
```
【院内設置型】
  ┣ 受付前にQRコードスタンド
  ┣ 会計時に渡す「感想カード」にQRコード印刷
  ┣ 診察券ケースにQRコードシール
  ┗ 待合室のポスター・デジタルサイネージ

【デジタル施策】
  ┣ 予約確認メール/SMSに口コミリンク
  ┣ LINE公式の治療後フォローメッセージにリンク
  ┗ 公式サイトの「患者様の声」ページからGoogleマップ誘導
```

### 4.3 ABSA属性（Googleが歯科口コミから抽出するキーワード）

GoogleのNLPが歯科レビューから自動抽出し、「ハイライト」タグとして表示する属性：

| 属性カテゴリ | 具体的なキーワード例 |
|-------------|-------------------|
| **痛みへの配慮** | 痛くない、無痛治療、麻酔が上手、怖くなかった |
| **医師の専門性** | 丁寧な説明、わかりやすい、信頼できる先生 |
| **待ち時間** | 予約通り、待たずに済む、待ち時間が短い |
| **スタッフの対応** | 親切、優しい、笑顔、受付の対応が良い |
| **清潔感** | きれい、清潔、衛生的、設備が新しい |
| **治療技術** | 腕が良い、丁寧な治療、仕上がりがきれい |
| **子供対応** | 子供に優しい、キッズスペース、子供が嫌がらない |
| **設備** | 最新の機器、CT完備、モニターで説明 |
| **アクセス** | 駅近、通いやすい、駐車場あり |

> **口コミ誘導テクニック**: 「治療の感想や当院の雰囲気について書いていただけると嬉しいです」と伝えると、上記属性ワードが含まれやすくなる。

### 4.4 歯科固有のリスク・注意点

- **治療トラブルの口コミ**: 医療行為に対するクレームは慎重に対応。事実関係確認後、個別対応に誘導（具体的な反論は公開の場で行わない）
- **守秘義務との両立**: レビュー返信で患者の具体的な症状・治療内容に触れない
- **競合医院からの悪質レビュー**: 不自然なパターンの場合はGoogleに報告＋証拠保存
- **スタッフ退職に伴う口コミ**: 「○○先生がいるから通っている」→退職後のフォロー策を準備
- **匿名レビュー制度（2025年〜）**: 匿名（ペンネーム）レビューが増加。スパム監視がより重要に

## 9. 医療広告ガイドライン遵守（最重要）

### 9.1 歯科クリニックに適用される法規制

| 法規制 | 対象 | 主な制限 |
|--------|------|---------|
| **医療法（医療広告ガイドライン）** | Webサイト・GBP投稿・SNS | 虚偽広告禁止・誇大広告禁止・比較優良広告禁止 |
| **医薬品医療機器等法（薬機法）** | 医療機器・材料の広告 | 未承認機器の効能表示制限 |
| **景品表示法** | すべての広告表現 | 優良誤認・有利誤認の禁止 |
| **不正競争防止法** | 競合との比較 | 虚偽事実の告知禁止 |

### 9.2 GBP投稿・説明文での禁止事項

#### 絶対にやってはいけないこと
1. ❌ **ビフォーアフター写真の無条件掲載**: 症例写真は「治療内容・費用・リスク・副作用」の4点セットを併記しなければ掲載不可
2. ❌ **「地域No.1」「最高の治療」等の比較優良広告**: 根拠のない最上級表現は禁止
3. ❌ **体験談を広告として使用**: 患者の体験談・感想を事業者が選定して掲載することは制限対象
4. ❌ **「絶対に痛くない」「100%成功」等の誇大表現**: 医療に絶対はない
5. ❌ **未承認医薬品・機器の効能効果の広告**: インビザライン等は薬機法上の注意が必要
6. ❌ **費用の虚偽表示**: 「○○円〜」の最低価格のみの表示で実際には高額になるケース

#### ビフォーアフター写真の正しい掲載方法
```
【症例写真掲載時の必須記載事項（4点セット）】

① 治療内容: セラミッククラウン（e.max）3本
② 費用: 1本 80,000円（税込）× 3本 = 240,000円
③ 治療期間: 約2ヶ月（3回の通院）
④ リスク・副作用: まれに知覚過敏が生じる場合があります。
   噛み合わせの調整が必要になることがあります。

※ この4点が併記されていれば、GBP投稿やWebサイトでの
   症例写真掲載は可能（2018年医療広告ガイドライン改正後）
```

### 9.3 GBP投稿で使える表現 / 使えない表現

| 分類 | ○ 使える表現 | ✗ 使えない表現 |
|------|------------|---------------|
| 治療の特徴 | 「痛みに配慮した治療を心がけています」 | 「無痛治療」「絶対痛くない」 |
| 設備 | 「歯科用CT完備」「マイクロスコープ導入」 | 「最新鋭の設備で日本一の治療」 |
| 実績 | 「開院20年、年間○○件の治療実績」 | 「地域No.1の実績」「最高の腕を持つ」 |
| 矯正 | 「マウスピース矯正に対応しています」 | 「マウスピースで必ず綺麗になれる」 |
| 料金 | 「ホワイトニング 15,000円（税込）〜」 | 「激安」「業界最安値」 |
| 院長 | 「日本口腔インプラント学会認定医」 | 「ゴッドハンド」「名医」 |

### 9.4 インビザライン等の薬機法上の注意

- インビザラインは**薬機法上の医療機器としての承認を受けていない**（個人輸入の形で使用）
- GBP投稿やWebサイトでインビザラインの効果を謳う場合、以下の注意事項の明記が推奨される：

```
【インビザライン掲載時の推奨注記】
・入手経路等の明示: 「個人輸入にて入手」
・国内承認の有無: 「薬機法上の承認を得ていない」
・同等品の国内承認: 「国内にも薬機法承認のマウスピース矯正あり」
・リスクと副作用: 適応外ケースでは効果不十分の可能性
```
