# クライアント情報：札幌市・噛み合わせ（顎変位症治療）専門歯科

## ⚠️【投稿作成時の絶対ルール（最重要）】⚠️
* **医療広告ガイドライン遵守・断言表現の禁止**: 医療・健康に関する情報発信であるため、「絶対に治る」「〜の原因は100%これだ」といった断言口調や誇大表現は厳禁です。「〜の可能性があります」「〜と言われています」「〜を改善するケースがあります」といった慎重で客観的な表現（Softening）を徹底してください。
* **マウスピース治療（装置等の詳細を含む）という言葉は投稿に出さないこと。**
* **ホワイトニング（FAP等）や審美歯科・インプラント等の話題も投稿に出さないこと。**
* 投稿の目的は「あくまでも【噛み合わせ・あごズレ】の重要性を啓蒙すること」。日常の話題（新生活の疲れ、デスクワーク、スマホ首、スポーツ、日々の原因不明の不調など）から自然に『噛み合わせ（あごのズレ）』の話題へ繋げ、読者に「もしかして治らない不調の根本原因はこれかもしれない」という可能性を体感ベースで伝える構成に徹すること。

## 【クリニックの特徴・強み（会話に自然に織り交ぜるナレッジ）】
* 単なる虫歯治療ではなく、「あごずれ・噛み合わせ（顎変位症治療・顎矯正治療）」に特化した専門集団。
* 慢性的な身体の不調（頭痛、首こり、肩こり、腰痛、顎関節症など）は、実は「あごのズレ」が原因であると着目している。
* 独自のアプローチとして、「あごの位置を整えた際の身体機能の変化を確認する検査」を実施しており、患者様に体感で納得してもらってから根本治療を行う。
* マッサージや薬で治らない痛みの「最後の駆け込み寺」としての役割を担っている。

- 【長文投稿の構成目安（約1000字）】導入部・約150字（季節の話題から自然に噛み合わせへ誘導）→ 問題提起・約200字（季節特有のリスク）→ 専門知識の提供・約400字（検査手法・治療哲学のナレッジを自然に織り交ぜる）→ まとめ・約150字（優しく締めくくる）。末尾に固定フッター。
- 【改行ルール】段落間の空白行には必ず全角スペース「　」を1つ入れる（GBPでの視覚的な空白確保のため）。
- 投稿タイトルは【】で囲む。
- 【オーナー報告】納品時は各記事に目的文を2案付ける。構文「〇〇することで、〇〇を狙っています。」・30〜40字・専門的かつ簡潔。
