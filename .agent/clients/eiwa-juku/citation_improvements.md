### NAP不一致の根本原因まとめ

| 種別 | 内容 | 対象校舎 | 深刻度 |
| :--- | :--- | :--- | :---: |
| **ビジネス名の表記ゆれ** | 「平岡北校」と「平岡**駅**北校」が混在。GBP・マイベストプロ・tsuku2は「駅」あり、公式サイト2つ・塾ナビ・塾ログは「駅」なし | 北校のみ | 🔴 高 |
| **エキテン北校：名称不一致** | 北校の住所（新在家1140-1）でエキテン登録はあるが、ページ名が「英和塾」のみ。「平岡北校」「平岡駅北校」の名称がなく、Googleが北校のサイテーションとして正しく認識できない | 北校 | 🔴 高 |
| **エキテン南校：完全未登録** | 「英和塾 平岡南校」「西谷206-2」での掲載ページがまったく存在しない | 南校 | 🟡 中 |
| **公式ドメインが2つ存在** | `eiwajuku.jp` と `eiwajuku.com` が並立。Googleが正規ドメインを判断しにくい | 両校 | 🟡 中 |

---



1. **エキテンは本校（新在家）のみ掲載** → 北校・南校の個別掲載がないため、各校舎のNAPが不統一
2. **複数の公式サイト（eiwajuku.jp / eiwajuku.com）が存在** → GoogleがどちらのURLを正規URLとして認識すべきか迷う可能性がある。どちらか1本に統一または正規URLを明示するのが理想
3. **Apple Maps / Navitimeへの掲載なし** → iPhone・カーナビ系からの検索流入ゼロ
4. **校舎ごとのNAP統一状況が不明** → 各ポータルで「北校の電話番号・住所」が正確かどうかの確認が必要

## 【改善】追加推奨サイテーション（5件以上）

### 優先度：最高（学習塾特化・SEO効果大）

- [ ] **じゅく探し / スタスタ（studysupli.com）**
  - **目的:** 学習塾に特化した大手比較サイト。「加古川市 個別指導」の検索で上位表示されやすい高権威ドメイン。
  - **作業:** 無料掲載申請フォームから各校舎の情報を登録。

- [ ] **塾シル（jukukashiru.com）**
  - **目的:** 「個別指導 加古川」「フォニックス英語 加古川」などのロングテールキーワードで検索ヒットしやすい学習塾ポータル。
  - **作業:** 無料掲載申請から登録。北校・南校を別々に登録。

### 優先度：高（汎用ディレクトリ・ローカルSEO効果）

- [ ] **Apple Maps Connect**
  - **目的:** iPhoneの純正マップ・Safari検索からの流入強化。スマホ検索で「近くの塾」を探す保護者・生徒へのリーチ。
  - **作業:** Apple IDでログインし北校・南校それぞれ登録。

- [ ] **Yahoo!プレイス（Yahoo!マップ）**
  - **目的:** Yahoo!検索での露出強化。保護者世代（30〜40代）のYahoo!利用率は依然として高い。
  - **作業:** Yahoo!ビジネスIDで両校舎を無料登録（未登録の場合）。

- [ ] **エキテン（北校・南校の個別登録）**
  - **目的:** 現状は本校のみ掲載。北校・南校を個別ページとして登録することで、各校舎のNAP統一とサイテーション強化。
  - **作業:** 既存の本校アカウントに追加、または別途各校舎を個別登録。

### 優先度：中（地域特化・認知拡大）

- [ ] **ナビタイム（Navitime）**
  - **目的:** 交通系アプリ・カーナビ経由の「近くの塾」検索に対応。
  - **作業:** Navitimeの店舗情報登録ページから申請。

- [ ] **Googleビジネスプロフィール属性の活用（既存GBPの強化）**
  - **目的:** 現在のGBPに「幼児向け」「英語教育」「個別指導」などの属性タグをすべて設定することで、フィルタ検索での表示機会を拡大。
  - **作業:** GBP管理画面 → 「その他の情報」→ 属性を確認・追加。
