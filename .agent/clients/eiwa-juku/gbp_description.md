■ こんなお子様・ご家族に選ばれています

■ 英和塾の3つの特徴

勉強を通じて、将来の道を自分で切り拓く力を育てます。「自分が親なら通わせたい塾」であり続けるために、私たちは日々真剣に子どもたちと向き合っています。

JR東加古川駅から徒歩でも通いやすく安心です。無料体験授業を随時受付中ですので、まずはお気軽にお問い合わせください。
