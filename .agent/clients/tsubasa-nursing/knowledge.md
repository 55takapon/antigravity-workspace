## 3. サービス分野（4分野）

### 3-A. 小児訪問看護

#### 概要
- お子様だけでなくご家族様の状況にも合わせた看護
- 発達成長を促すリハビリ・生活をしやすくしていくリハビリ
- 身体運動・言葉・認知・情緒・知能・社会性の6領域をカバー
- 看護師・理学療法士・作業療法士等が対応
- キャッチコピー：「お子様とご家族に、安心と笑顔を」

#### 対応可能な対象（3カテゴリ）

**① 発達障害・知的障害のあるお子様**
- 自閉症スペクトラム障害（ASD）
- 注意欠陥・多動性障害（ADHD）
- 学習障害（LD）
- 発達性協調運動障害（DCD）
- 境界性知能
- 不登校

**② 医療的ケア児**
- 遺伝性疾患
- 神経・筋疾患
- 消化器系疾患
- 血液・免疫疾患
- 呼吸器・心疾患
- その他小児疾患

**③ 脳性麻痺・遺伝子疾患・低緊張のお子様**
- 脳性麻痺
- ミオパチー
- ダウン症
- 早産・低出生体重児
- 発達遅滞

#### 具体的な支援内容
- 重症心身障害児・障害者の看護
- NICU退院後のお子さんの育児相談・アドバイス、状態観察、医療的処置
- 酸素療法・気管切開・人工呼吸器使用児の症状観察、吸引、気切部交換、回路交換、入浴介助
- 自閉症を中心とした発達障害のリハビリを生涯通して実施
- レスパイトケア（ご家族の休息支援・介護負担軽減）

#### 小児訪問看護の特徴（3ポイント）
1. **発達障害・知的障害のあるお子さんへのリハビリ・看護（個別療育）** ─ 一人ひとりの特性に合わせた支援
2. **レスパイトケア** ─ ご家族の休息を支援し、介護負担を軽減
3. **重度身体障害者の訪問看護・リハビリ** ─ 医療的ケアが必要なお子様に対応

#### 大人の発達障害にも対応
- ASD、ADHD、LD
- 「子どもとの関わり方がわからない」「コミュニケーションがうまく取れない」等のお悩みに対応
- 生活・仕事・家庭での困りごとに看護とリハビリの視点から具体的サポート

#### お困りごとの例（投稿ネタとして活用可能）
- いつもひとりでいて、周囲と馴染めない
- すぐに手が出てしまう
- 思い通りにならないと泣いてしまう
- 2歳になっても立てない・歩けない
- 1語文・2語文が出てこない
- 自分の体や手先をうまく使えない
- レスパイトケアで自分の時間を確保したい
- 病院で教わった手技が合っているか不安

#### 料金
- 医療証をお持ちの方は、大体の方が自己負担なし
- 小児慢性特定疾病医療費助成制度あり（18歳未満、月額上限0円〜数千円）
- 重度心身障害者医療費助成制度
- 自立支援医療（育成医療）
- 各自治体の医療費助成制度
- **制度の申請もサポート**

### 3-B. 精神科訪問看護

#### 概要
- うつ病・統合失調症・双極性障害・不安障害・発達障害・認知症などの精神疾患をお持ちの方が対象
- 住み慣れたご自宅や地域で安心して生活を続けられるよう支援
- キャッチコピー：「ご本人のペースを大切にしながら、安心して暮らせるよう支援します」

#### 対応疾患（18種類）
- 統合失調症
- 双極性障害
- うつ病
- アルコール依存
- 薬物依存
- 解離性障害
- 強迫性障害
- 睡眠障害
- 摂食障害
- 適応障害
- 認知症
- パーソナリティー障害
- 発達障害
- パニック障害
- 不安障害
- 高次脳機能障害
- てんかん
- その他（上記以外も相談可）

#### 提供するケア（4カテゴリ）
1. **服薬管理・健康観察** ─ 服薬状況の確認・服薬管理／気分や睡眠、体調の変化の観察
2. **精神的サポート** ─ 不安や悩みの傾聴／精神的サポート
3. **生活支援** ─ 再発・悪化予防のための生活支援／自立支援
4. **連携** ─ 主治医や関係機関との連携

#### その他のサポート
- 日常生活のリズムづくり
- 社会復帰に向けた支援
- ご家族への相談・支援
- 緊急時の対応

#### 精神訪問看護の特徴（6ポイント）
1. **在宅精神看護経験者・精神科経験豊富な看護師が対応**
2. **土曜日・祝日対応** ─ ご都合に合わせて柔軟に対応
3. **産後うつや小児（児童、思春期）にも対応** ─ 幅広い年代をサポート
4. **自立支援医療申請手続きサポート** ─ 複雑な手続きも安心
5. **ご家族様へのお悩みにも親身に寄り添う**
6. **24時間365日連絡体制** ─ 緊急時いつでも連絡可能

#### お悩みの例（投稿ネタとして活用可能）

**ご本人様の悩み：**
- 通院するのがつらい
- 薬をきちんと飲めているか不安
- 調子の波があり、生活リズムが崩れがち
- 一人で悩みを抱え込んでしまう
- 家から出るのが怖い
- 誰かに話を聞いてほしい

**ご家族様の悩み：**
- 家族がどう接したらいいかわからない
- 本人が通院を拒否してしまう
- 再発・悪化が心配
- 家族の負担が大きい
- 専門家に相談したい
- 在宅での療養を支えたい

#### 料金
- 医療保険適用
- 自立支援医療（精神通院医療）制度で自己負担を大幅軽減
- 自己負担額：原則1割負担、所得に応じて月額上限あり（0円〜20,000円）
- 自立支援医療の申請サポートあり（制度説明、必要書類案内、記入サポート、主治医への診断書依頼）

| 事業姿勢（全投稿で使用可） | 「できない」ではなく「どうすればできるか」を一緒に考える |
| 小児リハビリ | 「その子らしい成長」を大切にしながら、ご家族と一緒にリハビリを進める |
| 精神理念 | 「通院がつらい」「一人で抱え込んでしまう」方のペースを大切に |

**GBP投稿での最優先コピー:**
- 「あなたらしい暮らしのそばに」── 冒頭または締めくくりに必ず組み込む
- 「できない」ではなく「どうすればできるか」── 事業姿勢を示す場面で使う

## 11. 法令遵守メモ（投稿時の注意事項）

- 医療広告ガイドライン準拠必須（YMYL領域）
- 「治る」「改善する」等の効果保証表現は禁止
- 「No.1」「最高」等の比較優良表現は禁止
- 患者体験談・口コミの引用は禁止
- 柔道整復師の資格記載は「保有資格」としてのみ（施術効果の広告不可）
- 「無料体験」の条件注記をウェブサイト側で常に最新に保つこと
- 自立支援医療の自己負担額は「所得に応じて異なる」旨を必ず記載
