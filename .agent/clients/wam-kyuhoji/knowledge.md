# クライアント情報：個別指導WAM 久宝寺校

## 【教室の特徴・強み（会話に自然に織り交ぜるナレッジ）】
* エリア：大阪府八尾市太子堂（JR久宝寺駅周辺からの通塾に便利）。
* メソッド：AIシステムを活用して過去の単元までさかのぼる「もどり学習」で、苦手の根本原因を特定して解消する。
* 小学生向け：「勉強の習慣づけ」を重視し、楽しく分かりやすい指導で基礎を固める。中学受験の対策も可能。
* 中学生向け：学校の定期テスト（内申点）対策を中心に、高校受験に向けた志望校別の対策を実施。対話型指導で思考力も養う。
* 高校生向け：一般選抜から総合型選抜まで大学受験をカバー。自学自習のやり方から指導し、成績が伸びる自習室も完備。
* サポート体制：相性ピッタリの講師によるマンツーマンベースの指導と、定期的な面談カウンセリング。自信があるからの「返金保証」制度を導入。
