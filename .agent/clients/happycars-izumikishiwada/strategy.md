## 2. GBP設定方針

### ビジネス名

**推奨**: ハッピーカーズ 和泉岸和田店

不可例:

- ハッピーカーズ 和泉岸和田店 車買取 出張査定
- ハッピーカーズ 和泉岸和田店 高価買取
- ハッピーカーズ 和泉岸和田店 免許返納 車売却

Googleはビジネス名に営業時間、電話番号、URL、サービス名、所在地情報、マーケティング文言を追加することを制限しているため、正式名称を維持する。

### 住所表示

公式ページに「店舗を構えず」と明記があるため、実際に営業時間中に顧客対応できる看板付き拠点でない場合は、**住所非表示のサービス提供地域型**が安全。

所在地は「旭町14-14-202」とマンションの部屋番号を含む住所であり、看板付きの来店拠点でない場合は、住所公開がプライバシーリスクにもなる。クライアントには「GBP登録・認証用に住所入力は必要だが、顧客向けの表示はオフにする」という違いを明確に説明する。

確認質問:

- 旭町14-14-202に常設看板はあるか。
- 営業時間中に顧客が来店できるか。
- 来店査定を受け付ける実態があるか。

上記がない場合:

- 住所は管理者確認用として保持。
- 公開表示はオフ。
- サービス提供地域を登録。

### カテゴリ

カテゴリは管理画面の候補で最終判断する。Google公式では、カテゴリは「事業に何が含まれるか」ではなく「事業が何であるか」で選ぶ。

推奨候補:

| 優先 | カテゴリ候補 | 判断 |
|---|---|---|
| 1 | 中古車販売業者 | 現在の業種分類として最も近い候補。販売実態が薄い場合も、車買取カテゴリ候補がない場合は現実的 |
| 2 | 自動車販売店 | 管理画面に出る場合のみ検討 |
| 3 | 自動車仲介業者/車両買取系カテゴリ | 候補が出る場合のみ検討 |

カテゴリは増やしすぎない。軽トラ、免許返納、無料査定などはカテゴリではなくサービス・投稿・説明で拾う。  
「廃車サービス」は実際に廃車・事故車・不動車を主要サービスとして扱うことが確認できるまで追加しない。対応可否が確認できた場合でも、カテゴリ追加よりサービス登録・投稿で拾う方を優先する。

## 5. 投稿設計

### 月4本の基本ローテーション

| 週 | テーマ | 目的 |
|---|---|---|
| 第1週 | はじめての車出張買取 | 不安解消、流れ理解 |
| 第2週 | 免許返納・家族の車売却 | 高齢者/家族ニーズ獲得 |
| 第3週 | 軽自動車・軽トラ・商用車 | 車種/状態KW獲得 |
| 第4週 | 手続き無料・減額なし・支払い | 信頼性と比較検討対策 |

### 投稿内で自然に入れる要素

- 対応エリア名は1投稿あたり2-4個程度。
- サービス名は「出張査定」「引取り」「名義変更」「一時抹消」からテーマに合わせる。
- 車種名は実績写真がある場合に入れる。
- CTAは「今すぐ電話」ボタンまたはWEB査定。
- 電話番号は本文に入れない。
- GBPの「最新情報」投稿にはタイトルフィールドがない。投稿案で見出しを作る場合は「本文冒頭1行目」として扱う。イベント/オファー形式を使う場合のみタイトル欄がある。
- 「減額なし」「即日現金」は適用条件を確認してから使う。未確認時は「最終金額やお支払い方法も事前に丁寧に説明します」に弱める。
- 投稿本文の電話番号は不承認リスクがあるため入れない。連絡導線はGBPの「今すぐ電話」ボタンを使う。

### 投稿テンプレ

```text
【導入】
同じ状況の人が検索しそうな悩みを1つだけ書く。

【当店の対応】
尾木さん本人対応、出張査定無料、手続き無料など、テーマに合う根拠を説明。

【安心材料】
減額なし、支払い方法、書類の説明、免許返納相談などを具体化。ただし「減額なし」「即日現金」は適用条件確認後のみ断定。

【対象エリア】
泉大津市・岸和田市・和泉市など、自然に2-4地域。

【CTA】
査定だけでも相談可。GBPの電話ボタンまたはWEB査定へ。
```

## 8. Q&A初期設定候補

GBPのQ&Aは、初期の不安解消と検索面の補助に使える。原則は、実際に顧客・見込み客から受けた質問をもとに整備し、オーナーとして回答する。関係者アカウントで質問を作る運用は自作自演と見られるリスクがあるため、実施する場合も実際の問い合わせ内容に基づき、過度な宣伝文にしない。

| 質問案 | 回答案 |
|---|---|
| 査定だけでも大丈夫ですか？ | はい、査定だけのご相談も可能です。売却を急がず、金額や流れを確認してからご判断いただけます。 |
| 出張査定に費用はかかりますか？ | 泉州エリアの出張査定は無料です。対応地域外の場合は事前にご相談ください。 |
| 名義変更や一時抹消の手続きもお願いできますか？ | はい、名義変更や一時抹消の手続きも無料で対応しています。必要書類は事前にご案内します。 |
| 免許返納に伴う車の売却も相談できますか？ | はい、ご本人様だけでなくご家族からの相談も可能です。引取りや書類手続きまで丁寧に説明します。 |
| 車検切れの車も相談できますか？ | 対応可否と引取り方法を確認したうえでご案内します。公道走行ができないため、状態や保管場所を事前にお知らせください。 |
| ローンが残っている車も売れますか？ | 対応可否は残債や所有者名義によって変わります。査定額より残ローンが多い場合の差額負担なども含め、事前に確認します。 |

| 質問案 | 回答案 |

## 10. クライアント確認事項

### すぐ確認したいこと

- 住所は公開してよい実店舗か、それとも住所非表示にすべきか。
- 堺市は全域対応か。泉北方面・堺市北部まで対応するか。
- GBP、公式サイト、エキテンで店名表記が一致しているか。「ハッピーカーズ 和泉岸和田店」のスペース有無も確認する。
- 廃車、事故車、不動車、車検切れ車の対応可否。
- ローン中、所有権解除、相続車両の対応可否。
- ハッピーカーズFC側で表示可能な許可証・資格情報・第三者認証があるか。JPUC等の加盟がある場合は、一次情報確認後にのみ使用する。
- 「金額提示後の減額なし」は、現車確認前の電話/WEB概算提示後にも適用されるのか、現車確認後の最終金額提示後から適用されるのか。
- 支払いは公式記載どおり即日現金/翌日振込で常時対応できるか。即日現金に上限額があるか、高額車両は翌日振込などの条件があるか。
- 残ローンが査定額を上回る場合の方針。差額自己負担の説明、対応不可条件、所有権解除の流れを確認する。
- 出張対応の時間帯や当日対応可否。
- 写真撮影可能な車両実績があるか。
- 口コミ依頼に使えるLINE/SMS導線があるか。

### 投稿前に毎回確認すること

- 車種名、年式、走行距離、地域名を出してよいか。
- 買取金額を出してよいか。原則は出さない。
- 車両写真のナンバー・個人情報が完全に隠れているか。
- 「対応可」と書くサービスが本当に対応可能か。

## 11. ココナラ返信に使える方針メモ

