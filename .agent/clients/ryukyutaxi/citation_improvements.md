## 【改善】追加のサイテーション構築アクション（プロ厳選）

現状、古いタイプのディレクトリには網羅されていますが、**「現代のユーザーが実際にサービスを探す・予約する」プラットフォーム**への露出が決定的に欠けています。MEO効果（強いドメインからの被リンク）と実際の送客効果を兼ね備えた、プロ視点での厳選ターゲットは以下の通りです。

### 0. 【最優先】既存媒体のNAP修正・名寄せ（Phase 0）

すべてのサイテーション構築の前提として、現在発生している致命的なエラーを解消します。

- [ ] **GBPの住所修正:** 「介護タクシー沖縄」を削除し、「朝日荘202」を追記。
- [ ] **既存ポータルへの修正依頼:** Yahoo!マップ、介護タクシー案内所などの住所を「朝日荘202」まで正確に統一。

### 1. マッチング・予約型プラットフォームへの登録（優先度：最高）

非常に高いドメインパワーを持ち、かつ「今すぐ介護タクシーを呼びたい」ユーザーが直接検索する現代の必須プラットフォームです。

- [ ] **くらしのマーケット（介護タクシー部門）**
  - **目的:** 強力なサイテーション獲得に加え、料金や口コミを比較検討する層からの直接予約を獲得。
  - **作業:** 事業者として無料登録し、出店ページを作成（NAPを完全に一致させること）。
- [ ] **のれるんです / Tasuke Xi（タスケシー）**
  - **目的:** 近年台頭している介護タクシー専用の配車アプリ・ポータルへの網羅。
  - **作業:** 事業者向けページから無料登録・掲載申請。

### 2. 沖縄特化型・観光系プラットフォームへの露出（優先度：高）

「介護タクシー琉球」様の最大の強みである「沖縄観光」「空港送迎」を活かすための、極めて権威性の高いサイテーション獲得先です。

- [ ] **「おきなわ物語」（沖縄観光コンベンションビューロー）**

  - **作業:** バリアフリー観光サポート事業者として掲載条件を確認し、登録申請または情報提供。
- [ ] **TripAdvisor（トリップアドバイザー）**
  - **目的:** 「車いす 沖縄観光」などの検索に対して、世界最大の旅行プラットフォームからのサイテーションを獲得。
