# クライアント情報：iami（アイアムアイ加古川）

## 【店舗基本情報】
* 店名：iami加古川（アイアムアイ加古川）
* 業態：居酒屋・もつ鍋・小料理・ダイニングバー
* 住所：兵庫県加古川市加古川町木村65 やかたビル東3C（駐車場向かって右側階段）
* 最寄り駅・アクセス：JR加古川駅から南へ徒歩約15分
* 駐車場：店舗前に1台分あり。徒歩5分圏内にコインパーキング複数あり。
* 定休日：毎週水曜日
* 電話番号：079-490-4425

## 【コンセプト・特徴】
* 国産のぷりぷりもつと味が染み込んだキャベツを使ったあっさり系「もつ鍋」が看板。〆のチーズリゾット、夏期の冷房対策・夏バテ対策としても提案。
* 「震度5でも崩れないぷるぷるだし巻きたまご」、特製マヨソースの「エビマヨ」、赤ワインソースが決め手の「手作りハンバーグ」、外とろとろ・中ぷりぷりの「母の絶品たこ焼き」など、ストーリー性のある一品料理が充実。
* 日本酒を中心に厳選したお酒が豊富。特に加古川の地酒「盛典 純米吟醸」を推奨。限定銘柄（田酒など）のスポット入荷もある。
* **【口コミ高評価ポイント】ビールが美味しいと評価するお客様が多い。キンキンに冷えた温度管理と、きめ細かいクリーミーな泡が特徴で、ビールそのものの旨さに言及する口コミが頻出。ビール好きには特に刺さるコンテンツとして投稿に積極的に組み込む。**
* アルコールが苦手な方にも配慮し、ノンアルコールのソフトドリンクが充実。スペシャルティコーヒー「モカへレフ」を使用した本格コーヒーや大人のデザートドリンク「アイリッシュコーヒー」も楽しめる。
* 店内はカウンター席中心のこじんまりとした隠れ家的空間。バックバーにボトルが並び、アットホームで温かみのある雰囲気。

## 【利用シーン・強み】
* 仕事帰りの一人飲みから、歓送迎会、記念日、友人や家族との鍋を囲む食事など、幅広い用途に対応。
* 少人数〜中規模の宴会に対応し、貸し切り相談も可能。
* 予算・要望に応じたオードブル注文が可能で、テイクアウトやホームパーティー需要にも対応。
* 雨の日限定「雨の恵 ファーストドリンク半額クーポン」を実施中（提示条件あり）。
