## T1: 構成設計

### 入力

Web制作会社向けのGBP協業提案文について、本文を書く前に構成と理由を整理して。

### 実出力

**中心メッセージ**

制作会社側の採用・育成・運用管理の負担を増やさず、店舗型クライアント向けの継続支援メニューを追加できる外部パートナーとして提案します。Googleビジネスプロフィール運用は主役ではなく、制作後の継続接点を作る入口として扱います。

**固定情報順序**

1. 店舗型事業者の制作実績がある会社へ連絡した理由
2. 制作・コーディング外注営業ではないこと
3. 採用・育成・運用管理を増やさない中核ベネフィット
4. 商談同席、運用、改善、クライアント対応、報告までの担当範囲
5. 制作後の継続接点と、制作領域の相談を制作会社へ共有する流れ
6. 常時10店舗以上の実績と、具体的な顧客保護ルール
7. 固定CTA

**各部分の役割**

冒頭は、同一文面が適合する送信対象を選んでいることを示します。外注営業ではないことを早く伝え、制作案件の下請け提案と誤解される離脱を減らします。中盤では、採用・育成・運用管理の負担を増やさずに継続支援メニューを追加できる価値を置きます。後半では、制作領域の相談共有と顧客保護を具体化し、パートナー先として検討しやすくします。

**順序の理由**

相手の課題を断定する前に、なぜ連絡したか、何の提案ではないか、何を代わりに提案するのかを順に示すことで、押し付け感を抑えます。

**離脱・誤解リスク**

GBP運用代行の売り込みに見えると、制作会社側のメリットが弱くなります。追加案件や売上増加を保証すると、根拠のない成果保証になります。顧客保護が抽象的だと、エンドクライアントへの直接営業を警戒されます。

**最初に検証する1変数**

「連絡理由」と「外注営業ではない」の提示順序を比較します。CTAは変数にしません。

### 判定

pass。完成本文を作らず、固定情報順序と各部分の役割を説明した。

### 実出力

**送信可否**

不可。このまま送ると、上から目線の業界講釈、相手課題の断定、成果保証が重なり、協業提案としての信頼を落とします。

**最重要問題**

「AI時代に制作だけでは厳しくなる」は市場環境の講釈で、相手に不要な危機感を押し付けています。「御社も人手不足でお困り」は未確認の経営課題断定です。「必ず追加案件が発生し、売上が増えます」は確認済み事実ではなく、成果保証として使えません。

**改善優先順位**

1. AI時代や制作業界の不安を削除する
2. 人手不足など相手の事情を断定しない
3. MEOサービス導入の売り込みではなく、制作後の継続接点を作る外部パートナー提案へ戻す
4. 追加案件、売上増加、成約率、順位改善の保証を削除する
5. 固定CTAに合わせ、相手に選択権が残る表現へ変える

**リスク**

未確認の課題断定により、フォーム営業のテンプレ感が強くなります。成果保証は期待値を不適切に上げます。顧客保護や制作領域の案件共有がないため、エンドクライアントを取られる不安も残ります。

### 判定

pass。送信可否、最重要問題、改善優先順位、リスクを示し、全文修正版は出していない。
