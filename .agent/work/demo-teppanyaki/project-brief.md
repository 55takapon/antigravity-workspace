# デザイン方針

- トーン: 温かい、静か、気取らない、少し上質
- 色: 墨黒、鉄板グレー、生成り、焦がし茶、銅色。赤とオレンジの多用は禁止
- 書体: 見出しは上品な明朝、本文は読みやすいゴシック
- 角丸: 原則0〜4px
- 影: 写真浮遊要素のみに限定
- 固有モチーフ:
  1. 鉄板の水平な縁を思わせる細い横罫線
  2. 立ちのぼる湯気の曲線
  3. カウンター越しの近い距離感
- 避ける方向:
  - 高級ステーキハウスの黒金・大理石・威圧感
  - 大衆居酒屋の赤提灯・筆文字・情報過多
  - 炎を過剰に見せる派手な演出
  - 均等な角丸3カード
