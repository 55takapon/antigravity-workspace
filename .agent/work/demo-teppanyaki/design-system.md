# 鉄板小料理 ふた葉 — Design System

## ロック状態

- 状態: **承認済み案A「大判写真フルブリード型」をデザインロック**
- 適用元: `project-brief.md` / `content-plan.md` / `fv-variants/fv-a.html`
- 以後のセクションは本書を正とし、色・書体・角丸・影・モチーフを無断で追加・変更しない。
- 中心印象: 夫婦とカウンターの近い距離、鉄板の湯気、静かで気取らない少し上質な時間。
- 禁止方向: 黒金の高級ステーキハウス、赤提灯の大衆居酒屋、炎の過剰演出、均等な角丸カード。

## 固定コピー

以下は変更しない。

- h1: `鉄板の向こうに、` / `いつもの笑顔。`
- 補足: `夫婦ふたりで営む、小さな鉄板焼き店。焼ける音と湯気を囲んで、肩の力を抜ける時間を。`
- FV CTA: `LINEで席について相談する`
- ロゴ: `鉄板小料理 ふた葉`
- 補助表記: `FUTABA TEPPAN`

## カラートークン

| 役割 | 値 | 用途 |
|:---|:---|:---|
| 墨黒 / base | `#151311` | ページ背景、暗部の基準 |
| 生成り / text | `#F7F0E3` | 見出し、主要文字 |
| 淡い生成り / text-muted | `#DDD2C2` | 英字補助表記、補足 |
| 銅色 / accent | `#B7794D` | 鉄板の水平線、縦罫線、限定的な強調 |

- 赤・明るいオレンジを面として使わない。
- LINEの緑はCTAだけに使い、背景や装飾へ広げない。
- 写真上では黒の多層グラデーションを使い、文字の可読性と人物の見え方を両立する。

## タイポグラフィ

- 見出し: `"Yu Mincho", "Hiragino Mincho ProN", "Hiragino Mincho Pro", "Noto Serif JP", serif`
- 本文・ナビ・CTA: `"Yu Gothic", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif`
- h1: `clamp(42px, 4.3vw, 64px)`、行高 `1.42`、字間 `.075em`。599px以下は `clamp(31px, 8.9vw, 35px)`、字間 `.04em`。
- h1は指定された2行を固定し、行中で折り返さない。
- 本文: `14–16px`、行高 `2`、字間 `.075em`。スマホは `13px`、行高 `1.8`。
- CTA: `13–14px`、太字、字間 `.04em`。
- 補助英字: `9px`、字間 `.28em`。装飾ではなく店名補助としてのみ使う。

## スペーシング

- 基本スケール: `4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 112px`
- PC左右余白: `40px`以上、最大コンテンツ幅 `1360px`
- 960px以下左右余白: `32px`
- 599px以下左右余白: `16px`
- ヘッダー高: PC `88px`、960px以下 `78px`、599px以下 `70px`
- h1→補足: PC `28px`、スマホ `18px`
- 補足→CTA: PC `36px`、スマホ `24px`
- 重要要素ほど余白を広くし、同じ余白量の連続を避ける。

## 角丸・罫線・影

- 角丸: 原則 `0`。操作要素でも最大 `4px`。カードのための大きな角丸は禁止。
- 湯気曲線のみ `border-radius: 50%` を許可する。
- 罫線: 基本 `1px`。鉄板の水平な縁を表す長い線と、コピー脇の細い銅色縦線を使う。
- 水平線は `銅色 14% + 明線 86%` の比率を基準とする。
- 影: 原則なし。承認FVでは主CTAの写真上での分離に限り `0 12px 28px rgba(0, 0, 0, .25)` を使う。
- 面を浮かせる汎用カード影は禁止。

## 固有モチーフ

### 鉄板の水平線

- セクション境界、編集リスト、写真の下端など横方向の構造として使う。
- すべての要素へ付けず、1画面につき主線1本を目安にする。
- 銅色を短く、生成りの細線を長く使い、派手な装飾にしない。

### 湯気の曲線

- `1px`の半透明生成り線を大きな楕円弧として置く。
- 写真の湯気や余白から自然に立ち上がる位置に限定し、アイコン化・反復しない。
- 不透明度は `.24`前後、写真や文字より必ず弱くする。

## 写真トーン

- 主役は50代夫婦、鉄板、湯気、カウンター越しの近い距離。
- 暖色寄りでも赤・オレンジを強くせず、墨黒、焦がし茶、銅の質感を残す。
- 光は店内のやわらかな実景光。高級ホテル風の硬いスポット光や、炎の派手な演出は禁止。
- PCのFVは `object-position: center center`。左側の暗い余白へコピーを置く。
- 599px以下のFVは `object-position: 56% center`。夫婦双方の顔と上半身を半分以上見せる。
- 画像上の黒グラデーションは、人物を塗りつぶさずコピー側を中心に濃くする。
- 生成画像を実店舗写真・実績写真として扱わない。

## CTA階層

- 主CTA: LINE。背景 `#08783D`、白文字、1pxの`#0B8244`境界。最小タップ領域 `44px`。
- FV CTA: 高さ `58px`、最小幅 `280px`。599px以下は幅100%、高さ `54px`。
- PCヘッダーCTA: 高さ `48px`、文言 `LINEで相談`。
- モバイルのLINE CTAはナビパネル内に置き、文言 `LINEで席を相談する`。
- CTA以外のリンクは透明背景＋文字と細線で表現し、緑を使わない。
- LINEは相談導線であり、予約確定を意味する文言を使わない。

## レスポンシブ原則

- 主ブレイクポイント: `960px`。`959px`以下でモバイルナビへ切り替える。
- 補助ブレイクポイント: `600px`。`599px`以下でスマホ余白・文字サイズ・画像焦点へ切り替える。
- FVは `100svh`を基準にし、PC `min-height: 720px / max-height: 980px`、スマホ `min-height: 690px / max-height: 860px`。
- 375pxで人物、h1固定2行、補足、CTAが横方向にはみ出さない。
- 960pxではデスクトップナビへ切り替わり、ロゴ・ナビ・CTAが重ならない。
- 最大幅では写真を拡大しすぎず、コンテンツ幅を `1360px`で止める。
- タップ領域は44px以上、フォーカスリングを常に可視にする。
- モバイルナビはEscapeで閉じ、開閉時にフォーカスを適切に移し、開いている間はパネル内でTab移動を循環させる。

## 下層展開時の守ること

- セクションは2つずつ追加し、各バッチでレビューする。
- 同じ白背景・中央見出し・角丸カードを繰り返さない。
- 大判写真、横罫線の編集リスト、ワイド写真、LINE CTA帯を役割ごとに使い分ける。
- 未確認の料理名、価格、住所、営業時間、席数、実績、口コミを追加しない。
