# サイト概要

- 案件種別: デモ
- 納品形態: A. 静的サイト
- 目的: 初めての利用者の不安を減らし、LINE相談につなげる
- 対象: 肩・腰・姿勢などの不調が気になるが、自分に合う相談先か判断できずにいる人
- 中心メッセージ: 不調の理由を、いっしょに整理する整体院
- 初見3秒で伝える内容: 整体院 / 話を聞いてから進める / LINEで相談できる

# デザイン方針

- トーン: 清潔、静けさ、親しみ、説明の明快さ
- 色: warm ivory / pale sage / charcoal / muted clay（CTAのみ）
- 固有モチーフ: 身体の流れを思わせる細い曲線「コンディションライン」。FV、悩み、考え方、FAQへ展開
- 造形: 大判写真、編集的な罫線リスト、縦型ステップ、濃色CTA帯を使い分ける
- 避ける: 均等3カラムカード、過度な角丸、青白い医療感、派手な効果訴求

# 実装条件

- HTML / CSS / 最小限のJavaScriptのみ
- 960px / 600pxを主要ブレイクポイントにする
- すべてのCTAをLINE導線へ統一する
- ヒーロー以外の画像は遅延読み込みし、width / heightを指定する
- h1は1つ。キーボードフォーカスを可視化し、操作領域は44px以上にする
- PC、タブレット、スマホで横スクロールを出さない

# 確認方法
