## 💥 やらかしたこと・つまずいたこと（INCIDENT）

### ① chrome_profile/ が全件バックアップ対象になってGitに混入

- **発生**: 5/4にgit add .（全ファイル対象）に変更した副作用で、翌日にGitHubのSecret Scanningが反応
- **影響**: アラート1件。ただし漏洩キーがGoogle自身のキーであり自社への実被害なし
- **対処**: .gitignoreに `**/chrome_profile/` を追加して恒久的に除外
- **スキル反映**: .gitignoreのコメントに設計意図を明記（E-01/E-02ルール準拠）
- **教訓**: `git add .` へ切替直後に「除外すべきフォルダのチェックリスト確認」が必要だった

### ② your-subject リテラル `[your-subject]` が全件のメール件名に届いた

- **発生**: 260325testシート2-10行（9件）を送信後、全件のメール件名が「題名: [your-subject]」のリテラルのまま届いた。「以前修正したはず」だったが、修正が不完全だった
- **根本原因**: `cf7_http_submitter.js` の補完コードが `detectedFieldNames.has('your-subject')` の条件付きで、**フォームHTMLに `your-subject` フィールドが存在しない場合は補完が走らなかった**。CF7のメールテンプレートは `[your-subject]` を参照しているため、フィールド未定義でもリテラルが届く仕様
- **影響**: 全9件のメール件名に `[your-subject]` リテラルが露出。先方への印象が悪化
- **対処**: `your-subject` の `detectedFieldNames` チェックを完全除去 → 常時空文字で先にペイロードに追加。行11で修正を検証（Rank S・ログに「C-04適用」確認）→ 2-10行を再送信
- **スキル反映**: C-04をNG_RULES.mdに登録。「NGにいれるのはいいけど、送信してからでは遅い」という指摘を受け、**コードで構造的に防止**することを優先（ルールよりコード）
- **教訓**: 「修正済み」の認識は実際のコードで確認してから「済み」とすること

### ③ 世界へボカン株式会社のフォームで海外事業向け選択肢が選ばれた

- **発生**: セレクトボックスのフォールバック（先頭選択）で「越境EC/海外BtoB展開」が選択された
- **影響**: 海外事業向け企業への不適切な問い合わせカテゴリで送信
- **対処**: `SELECT_PREFERENCES` に「それ以外」「その他のお問い合わせ」を最優先候補として追加。フォールバック除外リストに BtoB・EC・越境・海外系キーワードを追加

### ④ playwright_submitter.js が `SELECT_PREFERENCES` 二重定義で破損

- **発生**: multi_replace中にファイルが破損（`SELECT_PREFERENCES` が二重定義の状態になった）
- **対処**: `git checkout 4d9a0a3 -- scratch/contact-auto/core/playwright_submitter.js` でGitから正常版に戻し、その後Node.jsスクリプトで安全にパッチ適用
- **教訓**: 大規模ファイル編集では multi_replace の代わりにNodeスクリプトで書き換えるほうが安全

### ⑤ cf7_http_submitter.jsの除外ロジック漏れ（実装同期忘れ）

- **発生**: playwright_submitter.jsには除外キーワードロジックが実装されていたが、CF7 HTTP直接送信側のセレクトボックスフォールバック処理には未実装だった
- **対処**: 同一ロジックをcf7_http_submitter.jsに移植完了
