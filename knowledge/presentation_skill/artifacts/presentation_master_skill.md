## 🧠 PART 1: 感動のメカニズム ─ なぜ人の心は動くのか

### 1-1 感動の3層構造
感動は「情報」だけでは生まれない。**脳の3層への同時アプローチ**が必要。

| 層 | 脳の部位 | 刺激方法 |
|---|---|---|
| **理解（ロジック）** | 大脳新皮質 | 明確な構成・PREP法・データ |
| **共感（エモーション）** | 大脳辺縁系 | エピソード・セリフ・失敗談 |
| **行動変容（インスピレーション）** | 脳幹 | WHY・使命・ビジョン |

> **鉄則：感動はロジックではなくエモーションから起動する。しかし行動変容にはロジックとWHYの両方が必要。**

### 1-2 オキシトシン＆ドーパミンの活用
- **オキシトシン（信頼・絆ホルモン）**：自己開示・弱さの告白・真摯なアイコンタクトで分泌
- **ドーパミン（報酬・集中ホルモン）**：意外性・フック・ストーリーのハラハラ感で分泌
- **コルチゾール（緊張ホルモン）**：問いかけ・課題提示で適度に高めると聴衆が前のめりになる

### 1-3 サイモン・シネック「ゴールデンサークル」の法則
```
    [WHY] ← ここから話し始める！
      ↓
    [HOW]
      ↓
    [WHAT]
```
- **NG（外から内）**：「私はこれをやっています（WHAT）→ なぜなら〜（WHY）」
- **GREAT（内から外）**：「私はこの世界を変えたいと思っています（WHY）→ だからこう動いています（HOW）→ その結果がこれです（WHAT）」

> **倫理法人会への応用：「なぜ倫理を学んだのか」というWHYから始め、「何が変わったか」というWHATは最後に語る。**

## 🏗️ PART 2: 構成設計の鉄板フレームワーク

### 2-1 鴨頭嘉人式 エピソードトーク構造
> スピーチ原稿の**5〜7割をエピソードトーク（シーン再現）**で構成する。

**エピソードトークの4ステップ：**
1. **シーンの設定**：「あれは○年前の○月のことでした。場所は…」
2. **会話（セリフ）の再現**：「そのとき私は言いました。『…』」← **レポートではなくドラマ化**
3. **内面の開示**：「正直、このとき私の心の中は…でした」← **弱さ・葛藤・迷いを見せる**
4. **転換点（気づき）**：「しかしそのとき、あることに気づいたんです」

**❌ NG例（レポート型）：**
> 「その日、お客様からクレームがあり、私は謝罪しました。その結果、関係が改善されました。」

**✅ GREAT例（ドラマ型）：**
> 「あれは3年前の夏の朝でした。私のスマホが鳴りました。画面には『田中様』と表示されていた。正直、その瞬間、手が震えていたんです。電話を取ると、低い声で『あなたのせいで…』と。私はただ、黙って聴くしかなかった。7分間。ずっと黙って。——その7分間が、私の人生を変えました。」

### 2-2 スピーチ黄金構成テンプレート（15分版）

```
[最初の15秒] ← 聴衆を引き込む「フック」
  - 衝撃的な事実 / 問いかけ / 意外なエピソードの冒頭
  - 「こんにちは、◯◯です」から始めない！

[0:15〜2:00] オープニング・ストーリー
  - 聴衆が共感できる普遍的な場面からスタート
  - 「この話を聴いてあなたに持ち帰ってほしいもの」を1文で提示

[2:00〜10:00] 本編（コアメッセージ×3）
  - メッセージ①：エピソード→気づき→教訓
  - メッセージ②：エピソード→気づき→教訓（最も感情的な部分）
  - メッセージ③：エピソード→気づき→教訓（解決・希望）

[10:00〜13:00] 行動変容への橋渡し
  - 「だから私はこう決意した」
  - 「あなたにもこの問いを持ち帰ってほしい」

[13:00〜15:00] クロージング ← 最も記憶に残る瞬間
  - 最も力強いメッセージを最後に
  - スティーブ・ジョブズ式「One more thing」感覚で締める
  - 問いかけで終えると余韻が残る
```

### 2-3 倫理法人会 講話専用フレーム（ビフォー・アフター法）

| ステップ | 内容 | 分数目安 |
|---|---|---|
| **Before（苦境）** | 倫理を知る前の自分・悩み・失敗・限界点 | 3〜4分 |
| **Practice（実践）** | どの倫理実践を行ったか（具体的行動） | 3〜4分 |
| **After（変化）** | 実践後に起きた具体的な変化（数字・事実） | 3〜4分 |
| **Learning（決意）** | そこから学んだこと・これからの自分の決意 | 1〜2分 |

> **要注意：「After」は抽象的に語らない！**
> ❌「人間関係が良くなりました」
> ✅「翌朝、妻が初めて私に『今日も頑張ってね』と言ってくれました。その一言で私は泣きそうになりました。」

## 🎯 PART 3: グレートプレゼンターの10の技術

### 技術①「間（ま）の魔法」
- 重要なメッセージの**前後に1〜3秒の無音**を置く
- 沈黙は弱さではなく**権威と自信の証明**
- 「えー」「あのー」は聴衆の集中を奪う最大の敵
- **黄金の間：「今から一番大事なことを言います。（2秒）実は——」**

### 技術②「声の3次元設計」
| 次元 | テクニック |
|---|---|
| **音量** | 静かにして聞かせる部分 ⇔ 感情が高まる部分で音量UP |
| **スピード** | 重要な部分は必ずゆっくり・丁寧に。エピソードは会話のテンポで |
| **ピッチ（高低）** | 感情を込める時に変化をつける。単調を防ぐ |

> **スティーブ・ジョブズの法則：強調したいキーワードは「前後の言葉より30%ゆっくり」話す。**

### 技術③「アイコンタクト・3点法」
- 大勢の前では会場を左・中央・右の3エリアに分ける
- 各エリアの**特定の1人**と3〜5秒「会話」する
- 全体に向かって話すのをやめ、**「一騎打ちの会話」を積み重ねる**

### 技術④「S.T.A.R.モーメントの設計」
> **Something They'll Always Remember（彼らが永遠に覚えていること）**

聴衆が帰宅後も思い出す「あの瞬間」を意図的に設計する：
- 予想外の数字や事実の告白
- 突然の感情的な告白（涙・怒り・喜び）
- 小道具や実物の提示
- 意外な言葉の逆転（「実は逆でした」型）

### 技術⑤「鴨頭式：うまく話そうとしない」
- **「上手に話そう」という自意識が壁を作る**
- 聴衆は「完璧なスピーチ」ではなく**「本物の人間」**に心を動かされる
- 噛んでも、詰まっても、それが人間らしさ
- 目標は「完成度」ではなく**「心への届き方」**

### 技術⑥「自己開示の深度コントロール」
```
レベル1：事実の共有（役職・経歴）
レベル2：考えや意見の共有
レベル3：感情・感覚の共有（プレゼンの大半はここ止まり）
レベル4：弱さ・失敗・恥の共有 ← グレートプレゼンターはここまで行く
レベル5：存在の揺らぎ（価値観の崩壊と再生） ← 伝説のスピーチはここ
```

### 技術⑦「3の法則（Rule of Three）」
- 人間の脳は**3つのグループ**で情報を最も処理しやすい
- 「今日お伝えしたいことは、3つあります」
- ジョブズも「iPhone、iPod、そしてインターネット端末——この3つを持ち歩けます」
- 倫理講話では：「Before・Practice・After」が自然に3の法則に合致する

### 技術⑧「一行の核心メッセージ（Logline）」
- スピーチ全体を**1文に圧縮できるか**を必ず確認する
- 例：「逃げることをやめたとき、初めて人生が動き出した」
- この1文が聴衆の心に刺さるものでなければ、内容全体を見直す必要がある

### 技術⑨「非言語コミュニケーションの設計」
| 要素 | 実践ポイント |
|---|---|
| **姿勢** | 重心を低く、足を肩幅に。前のめりが「熱量」を示す |
| **手の動き** | 言葉に連動させる。「3つ」と言いながら指3本立てる |
| **表情** | 語る内容の感情を顔に乗せる。喜びの場面で笑顔 |
| **移動** | ステージを活用。新しい話題で位置を変えることで「転換」を示す |

### 技術⑩「感情の曲線設計（ローラーコースター構成）」
```
高揚 ─────┐        ┌──── 感動のピーク
           │        │
通常 ──────┘        │
                    │
不安             ───┘
（問題提起）    （解決・決意）
```
- 平坦なスピーチは退屈。**感情の振れ幅**が大きいほど記憶に残る
- 笑いの直後に深い話を持ってくると**落差の効果**で倍以上刺さる

## 🔍 PART 4: 辛口添削フレームワーク ─ プロの視点で台本を解剖する

### 4-1 添削スコアリング（100点満点）

台本・原稿の添削依頼が来たら、以下の10項目で採点した上でフィードバックを行う。

| # | 評価項目 | 配点 | 評価基準 |
|---|---|---|---|
| 1 | **WHY（存在意義）の明確さ** | 15点 | この話を通じて「なぜこれを語るのか」が伝わるか |
| 2 | **フック（掴みの強さ）** | 10点 | 最初の30秒で聴衆を引き込めるか |
| 3 | **エピソードの具体性** | 15点 | セリフ・場面・感情が再現されているか |
| 4 | **自己開示の深さ** | 10点 | 弱さ・失敗・葛藤が正直に語られているか |
| 5 | **感情の振れ幅（波）** | 10点 | 笑い・緊張・感動の曲線が設計されているか |
| 6 | **聴衆ファースト度** | 10点 | 「自分語り」ではなく「聴衆へのプレゼント」か |
| 7 | **メッセージの一本の軸** | 10点 | 1文に圧縮できるコアメッセージがあるか |
| 8 | **クロージングの力** | 10点 | 余韻が残る締め言葉があるか |
| 9 | **時間・テンポ設計** | 5点 | 情報量は適切か。冗長な部分がないか |
| 10 | **言語の鮮度（表現力）** | 5点 | 使い古された表現を脱し、独自の言葉があるか |

**評価基準：**
- 90〜100点：グレートプレゼンター水準
- 75〜89点：良質。微調整で化ける
- 60〜74点：構成の見直しが必要
- 60点未満：核心（WHY・エピソード）の再設計が必要

---

### 4-2 添削で必ず指摘する15のNG

1. **「こんにちは、◯◯と申します」から始まるスピーチ** → フック不在
2. **「今日は○○についてお話します」という宣言型オープニング** → 聴衆の好奇心を殺す
3. **「頑張りました」「うれしかったです」という形容詞のみの感情描写** → 具体的シーンに変換せよ
4. **長すぎる前置き・自己紹介** → 最初の1分が命
5. **「〜と思います」の多用** → 断言力の欠如。聴衆は確信のない人を信頼しない
6. **データ・数字の羅列だけの箇所** → 必ず「人間のストーリー」で肉付けする
7. **「えー」「あのー」の多用** → 代わりに「間」を使う
8. **抽象的な結論（「大切だと分かりました」）** → 具体的な行動・変化で締める
9. **平坦な音量・スピードのまま続く箇所** → 必ず変化点を設計する
10. **聴衆が「自分事」として受け取れない話** → 「あなたも同じ経験があるはず」な普遍化を
11. **「時間が来ましたのでまとめます」型クロージング** → 流れを壊す。クロージングは1発でキメる
12. **他人のせいにする・被害者目線の多い話** → 自責・感謝・決意に変換する
13. **教訓・メッセージが3つ以上ある** → 1つに絞り込む勇気を持て
14. **比喩・例えが陳腐または過多** → 1〜2つの際立った比喩に絞る
15. **最後の言葉が弱い（「以上で終わります」）** → 最後の1文が全体の印象を決める

### 4-3 倫理法人会 講話特有の追加チェック

- [ ] NG：特定の政党・宗教への言及／他者批判・中傷／商品の宣伝

- [ ] MUST：制限時間を厳守できる分量か（基本は10〜15分以内）

## 📚 PART 6: 参照プレゼンターの教え ─ 巨人の肩に立つ

### 🎤 鴨頭嘉人（かもがしら・よしひと）氏の哲学
- **「スピーチは技術。学べば誰でも変われる」**
- 「うまく話そうとしない」——完璧主義より真心を
- エピソードトーク：日常の気づきこそが最強のコンテンツ
- 振り返り（動画撮影・文字起こし）による「スピーチ脳」の育成
- 緊張は「パフォーマンスを上げようとする体の本能」——恐れるな
- **日常そのものを変える**：良い情報を撒き、自己イメージを高める生き方が説得力に直結

### 🍎 スティーブ・ジョブズの哲学
- **「シンプルさは究極の洗練である」**
- スライドは1枚1メッセージ、箇条書き禁止
- 「魔法の言葉」を作る：「1,000曲をポケットに」
- ルール・オブ・スリー（3の法則）を徹底
- プレゼンはリハーサルの積み重ね（本番同様を100回以上）
- **「敵（Problem）→ 英雄（Solution）」の物語構造**

### 🌐 サイモン・シネックの哲学
- **「人々はあなたが何をするかを買うのではない。なぜそれをするかを買う」**
- WHY→HOW→WHATの順で伝える（ゴールデンサークル）
- WHYは論理ではなく感情・信念・使命
- リーダーシップとはビジョンへの感情的共鳴を生むこと

### 🎭 TED Talksの知見
- **A.B.C（Audience Before Content）：コンテンツより聴衆を先に考える**
- Throughline（一本の糸）：全てのエピソードがひとつのテーマに収束する
- 18分ルール：集中力の限界に合わせた時間設計
- 脆弱性（Vulnerability）の力：完璧でない人間への信頼
- S.T.A.R.モーメントを意図的に設計する

## 🚀 PART 8: 台本添削の依頼プロトコル

ユーザーが台本・原稿を提供したら、以下の手順で添削を行う：

### ステップ1：ヒアリング（情報収集）
添削する前に必ず確認する：
1. **場所・状況**：どこで話すか（倫理法人会モーニングセミナー、講演会、朝礼など）
2. **時間制限**：何分でスピーチするか
3. **対象聴衆**：誰に話すか（年齢層・職種・関係性）
4. **目的・ゴール**：この話を聴いた後、聴衆にどう変わってほしいか
5. **自己課題**：自分で感じている弱点（「話が長い」「感情が伝わらない」など）

### ステップ2：スコアリング（10項目採点）
PART 4-1の採点表で採点し、点数と各項目のコメントを提示する。

### ステップ3：辛口フィードバック
- 良い点（必ず具体的に、1〜3点）

### 9-1 入力の受け付け方（どんな形でも受け付ける）

### 9-2 ストーリー整形の7ステップ

素材を受け取ったら、以下の順番で整形する。各ステップの結果はユーザーに提示し、修正の余地を残す。

#### ステップ① 素材マイニング（宝石の発掘）
- 渡された素材から**感情的なピーク**（怒り・悲しみ・喜び・驚き）を持つ瞬間を特定する
- **「この瞬間だけで一本のスピーチが作れる」**と思える核となるシーンを見つける
- 個人ナレッジファイル（`personal_story_bank.md`）が参照可能なら、関連するエピソードを引き当てる

#### ステップ② WHYの蒸留
- 「なぜこの話を今・ここで・この聴衆に話すのか」を1文で設定する
- 例：「逃げることをやめた日から、私の人生は動き始めた」← これがスピーチ全体を貫く軸

#### ステップ③ フックの設計（最初の15秒）
- 核となるシーンの「最もドラマチックな瞬間」から始める（冒頭に時系列を無視して配置するのが効果的）
- フックパターン：
  - **問いかけ型**：「あなたは、逃げたことを後悔している瞬間はありますか？」
  - **シーン投入型**：「私が社長の前で泣いたのは、あの木曜日の朝でした。」
  - **逆説型**：「人前で話すのが大嫌いだった私が、今日こうして皆さんの前に立っています。」

#### ステップ④ エピソードのドラマ化
- 単なる事実の説明を、**鴨頭式エピソードトーク**でドラマ化する
- 変換の公式：
  ```
  [情報]          → [シーン描写]
  「〜があった」   → 「あれは〇年前の〇月でした...」
  「〜と言われた」 → 「そのとき彼は静かに言いました。『...』」
  「〜と感じた」   → 「正直、手が震えていました。」
  ```

#### ステップ⑤ 感情曲線の設計
- エピソードを「緊張→解放」の波で並べ替える
- 笑いのポイント（緊張緩和）を適切に配置する
- S.T.A.R.モーメントの位置を決定する

#### ステップ⑥ クロージングの磨き上げ
- 最後の1分で**Logline**を力強く語る
- 「あなたへのプレゼント」として聴衆が持ち帰れる一言を設計する
- 絶対に「以上です」「ありがとうございました」で終わらない

#### ステップ⑦ 台本の仕上げ出力
以下の形式で台本を出力する：

