# ブログ記事タイトルリサーチ マスタースキル v1.0

> **対象事業**: ジェットプロデュース（https://jet-produce.com/）
> **最終更新**: 2026年5月｜SEO/AI検索最新トレンド反映済み
> **ターゲット**: 店舗・クリニック・士業事務所・整体院のオーナー/経営者

---

## PART 1：スキル概要

### このスキルの目的
検索ユーザーの意図を正確に捉え、**クリックされ、読まれ、行動を促す**記事タイトルを設計するための体系的フロー。

### 基本方針
1. **SEOファースト**: 検索エンジンに正しく評価されるタイトル構造
2. **CTR最大化**: 検索結果の中で「選ばれる」表現技法
3. **AI検索対応**: AI Overviews / Gemini に引用される設計
4. **新田祐士式**: フィルター書き換えで読者の「当たり前」を壊すタイトル

## PART 2：タイトルリサーチ 5ステップフロー

### Step 1：ペルソナの悩みを抽出する

**情報源（優先度順）**:
1. クライアントとの日常会話・問い合わせ内容（最高の一次情報）
2. Googleビジネスプロフィールの口コミ・質問
3. Yahoo!知恵袋 / 教えて!goo の質問
4. SNS（Instagram/X）のコメント・DM
5. 競合サイトのFAQ・ブログコメント欄

**抽出テンプレート**:
```
【悩み抽出シート】
- ペルソナ: （例）加古川市で整体院を経営する40代男性
- 具体的な悩み: （例）ホットペッパーに頼らず自力で集客したい
- 悩みの裏にある本音: （例）広告費を下げて利益率を上げたい
- 検索しそうな言葉: （例）「整体院 集客 ホットペッパー以外」
- 解決した先の理想: （例）指名検索で来る患者だけで予約が埋まる
```

### Step 2：キーワード調査

**使用ツール**:
- Google検索（サジェスト・関連キーワード）
- ラッコキーワード（無料で十分使える）
- Googleキーワードプランナー（検索ボリューム確認）
- Google Search Console（既存流入KWの確認）

**調査手順**:
1. メインKWを入力してサジェストを全取得
2. 関連KWの検索ボリュームを確認（月間100〜1,000がスイートスポット）
3. KWの検索意図を分類:
   - **Know（知りたい）**: 「MEO対策とは」
   - **Do（やりたい）**: 「GBP 設定方法」
   - **Go（行きたい）**: 「加古川 整体院」
   - **Buy（買いたい/依頼したい）**: 「MEO対策 代行 料金」

### Step 3：検索上位10件の競合分析

**分析項目**:
```
【競合分析シート】
- 検索KW: ___
- 上位10件のタイトル一覧:
  1. ___
  2. ___（以下略）
- 共通する訴求ポイント: ___
- 不足している切り口: ___（← ここが差別化チャンス）
- 記事の形式: （リスト型/ガイド型/Q&A型/事例型）
- 文字数の平均: ___文字
- 構造化データの有無: ___
```

### Step 4：AI Overviewsの表示確認

**確認手順**:
1. 対策KWでGoogle検索
2. AI Overviewsが表示されるか確認
3. 表示される場合:
   - AIが引用しているサイトを特定
   - AIの回答パターンを分析（定義型/手順型/比較型/リスト型）
   - 回答に含まれていない情報を特定（← 差別化ポイント）
4. 表示されない場合:
   - 従来型SEO（検索順位勝負）で攻める

### Step 5：タイトル案を3パターン生成

**必ず以下の3パターンを作成**:
1. **王道パターン**: 検索意図に直球で応えるタイトル
2. **差別化パターン**: 競合にない切り口を入れたタイトル
3. **新田祐士式パターン**: フィルター書き換え型のタイトル（PART 5参照）

## PART 3：SEOタイトル設計ルール

### 絶対ルール（違反厳禁）

| # | ルール | 理由 |
|---|--------|------|
| 1 | **文字数は30〜35文字** | 検索結果で省略されない範囲で最大限情報を入れる |
| 2 | **狙うKWは左寄せ（文頭に近づける）** | 検索エンジンの評価＋ユーザーの目に入りやすい |
| 3 | **タイトルと記事内容の完全一致** | 乖離は離脱率上昇→SEO評価低下を招く |
| 4 | **1記事1メインKW** | 複数KWを詰め込むとどちらも中途半端になる |
| 5 | **同一KWのカニバリ（食い合い）禁止** | サイト内で同じKWを複数記事で狙わない |

### 推奨ルール

- **数字を入れる**: 「5つ」「3ステップ」「10選」→ 具体性でCTR向上
- **記号を活用**: 【 】｜！を使って視認性を高める
- **ターゲットを明記**: 「店舗オーナー向け」「クリニック院長必見」
- **ベネフィットを提示**: 「〜で問い合わせが増える」「〜で予約につながる」
- **年号を入れる（時事記事のみ）**: 「【2026年最新】」

## PART 4：CTR向上テクニック（クリック率を爆上げする型）

### テンプレート集

#### 【Type 1】網羅型（完全ガイド系）
```
[KW]の完全ガイド｜初心者でも失敗しない〇つのステップ
[KW]まとめ｜プロが教える〇〇から〇〇まで全解説
```
**使い所**: ピラー記事（カテゴリの柱記事）に最適

#### 【Type 2】課題解決型（お悩み系）
```
[KW]で悩んでいませんか？プロが教える最短の解決法
「〇〇できない…」を解決する｜[KW]の改善チェックリスト
```
**使い所**: ターゲットの具体的な悩みに対応する記事

#### 【Type 3】リスト・ランキング型
```
[KW]おすすめ〇選｜徹底比較で失敗しない選び方
〇〇が選ぶ[KW]ランキング｜プロ視点で厳選
```
**使い所**: 比較検討フェーズの読者を獲得する記事

#### 【Type 4】ノウハウ・裏技型
```
〇〇（対象）必見！[KW]を効率化する驚きのテクニック
プロだけが知っている[KW]のコツ｜〇〇で差がつく方法
```
**使い所**: 中級者向け・差別化ポイントを打ち出す記事

#### 【Type 5】警告・注意喚起型
```
【要注意】[KW]でやってはいけない〇つのNG行動
知らないと損する[KW]の落とし穴｜失敗する人の共通点
```
**使い所**: 損失回避心理を活用し、高CTRを狙う記事

#### 【Type 6】事例・実績型
```
[施策]で[成果]｜[業種]の集客改善レポート
「[悩み]」から[成果]へ｜[業種]オーナーの〇ヶ月の記録
```
**使い所**: 信頼獲得→問い合わせ促進に直結する記事

## PART 5：新田祐士式 フィルター書き換え型タイトル設計

### 概要
読者が持っている「当たり前」「常識」「思い込み」（= フィルター）を壊し、**「えっ、そうだったの？」**という知的好奇心を刺激するタイトル設計。

### 原則
1. **「常識」を特定する**: ターゲットが信じている業界の常識は何か？
2. **「逆」を提示する**: その常識の反対、もしくは一段深い真実を見せる
3. **「希望」につなげる**: 新しい視点が読者にとってプラスになることを暗示する

### テンプレート

#### 【書き換えパターン A】常識破壊型
```
[常識]は間違い？[真実]が[成果]につながる本当の理由
[常識]を信じている[ターゲット]が見落としている決定的なこと
```
**例**:
- 「SEO対策 = キーワードを入れること」は間違い？AI時代に検索される記事の本質
- 「口コミは自然に増える」を信じている店舗オーナーが見落としていること

#### 【書き換えパターン B】視点転換型
```
[ターゲット]が本当にやるべきなのは[意外な施策]だった
[悩み]の原因は[一般的な理由]ではなく[本質的な理由]にある
```
**例**:
- 集客に悩む店舗オーナーが本当にやるべきなのは「Googleマップの写真整理」だった
- 問い合わせが来ない原因は「SEO」ではなく「導線設計」にある

#### 【書き換えパターン C】自発的行動促進型
```
[成果]を出した[ターゲット]が、最初の1週間でやったたった1つのこと
なぜ[成功事例]は[意外な方法]から始めたのか
```
**例**:
- 予約数2倍を達成したクリニックが、最初の1週間でやったたった1つのこと
- なぜ繁盛店は「広告」ではなく「口コミ返信」から始めたのか

## PART 6：タイトル品質チェックリスト

タイトル確定前に必ず以下を確認:

```
□ メインKWが含まれているか
□ KWが文頭に近い位置にあるか
□ 30〜35文字以内に収まっているか
□ 記事の内容とタイトルが一致しているか
□ ターゲット読者が明確か
□ 読者のベネフィットが伝わるか
□ 競合タイトルと差別化できているか
□ 感情を動かす要素が入っているか（新田式チェック）
□ 同サイト内でKWカニバリしていないか
□ AI Overviewsの回答と差別化できているか
```

## PART 7：ジェットプロデュース固有の強み（タイトルに活かすポイント）

記事タイトルに織り込むべきジェットプロデュースの差別化要素:

4. **加古川・姫路・明石・神戸**: 地域名をローカルSEO記事に活用
5. **プロデュース視点**: 作業代行ではなく「プロデュース」という独自ポジション
