## PART 1：ブランドボイス定義

### ジェットプロデュースのポジショニング

```
【Who】  誰が書いているか
→ Googleマップ×Web戦略で店舗の集客を改善するプロデューサー

【What】 何を伝えるか
→ 店舗・クリニック・士業が「見つけてもらえる仕組み」を作る具体的な方法

【Why】  なぜ伝えるか
→ 「良いサービスが、正しく見つけられる世の中に」というミッション

【How】  どう伝えるか
→ プロの知見を惜しみなく公開し、読者が自分で行動できる状態を作る
  （新田祐士式：教育×エンターテイメント）
```

### トーン＆マナー

| 項目 | 方針 |
|------|------|
| **文体** | です・ます調（親しみやすさ重視） |
| **専門用語** | 使う場合は必ず平易な説明を併記 |
| **スタンス** | 上から目線の「教える」ではなく「一緒に考える」伴走型 |
| **感情表現** | 共感を軸に、読者の不安を受け止めてから解決策を提示 |
| **CTA** | 押し売りしない。読者が自発的に動きたくなる導線設計 |
| **禁止事項** | 誇大表現・競合の名指し批判・根拠なき断定 |

## PART 5：新田祐士式「教育×エンターテイメント」戦略

### コンテンツの2軸設計

全ての記事を以下の2軸で評価し、バランスを取る:

```
        教育（価値提供）
           ↑
     ③    │    ①
   知識偏重  │  理想のコンテンツ
           │  （学びがあり面白い）
    ───────┼───────→ エンターテイメント
           │        （面白さ・引き込み）
     ④    │    ②
    無価値  │  面白いだけ
           │  （学びがない）
```

**目指すべきは①の象限**: 読んで学びになり、かつストーリーや切り口が面白い記事。

### カテゴリ別の「教育×エンタメ」配分

| カテゴリ | 教育:エンタメ | 理由 |
|---------|-------------|------|
| A: GBP/MEO | 7:3 | 実践ノウハウ重視だが事例ストーリーで引き込む |
| B: SEO/AI検索 | 6:4 | 難しいテーマなので物語で噛み砕く比率を上げる |
| C: SNS集客 | 5:5 | SNSとの親和性が高いためエンタメ要素を強めに |
| D: HP活用 | 7:3 | 具体的な改善ポイント重視 |
| E: 集客戦略 | 4:6 | 思考法・マインドセット系はストーリー重視 |
| F: 事例 | 3:7 | ストーリーそのものがコンテンツ |

### フィルター書き換えの戦略的活用

**四半期ごとに「常識破壊テーマ」を1つ設定し、読者の価値観を段階的に更新する**:

```
Q1（1-3月）: 「集客 = 広告」というフィルターを書き換える
  → 広告に頼らない集客の本質を伝える記事群

Q2（4-6月）: 「HP = 名刺代わり」というフィルターを書き換える
  → HPを集客装置として再定義する記事群

Q3（7-9月）: 「SNS = 若者向け」というフィルターを書き換える
  → 店舗ビジネスにおけるSNSの本質的な役割を伝える記事群

Q4（10-12月）: 「Googleマップ = 地図」というフィルターを書き換える
  → GBPを「デジタル資産」として再定義する記事群
```

## PART 7：コンテンツ運用の鉄則

### やるべきこと
1. **週2本ペースの安定更新**（量より頻度の安定性が重要）
2. **月1回のリライト**（上位記事の情報更新＋下位記事の改善）
3. **GBP投稿との連動**（ブログ→GBP投稿で相乗効果）
4. **SNSでの記事シェア**（Instagram/LINE公式での告知）
5. **Search Consoleの定期確認**（流入KWの発見→新記事ネタ）

### やってはいけないこと
1. **AIで丸投げ量産**（品質低下→サイト評価下落）
2. **検索ボリュームだけで記事テーマを決める**（ペルソナ不在の記事は成果が出ない）
3. **公開して放置**（古い情報は信頼性を損なう）
4. **競合の丸パクリ**（独自性ゼロの記事はAIにも評価されない）
5. **全カテゴリを同時に攻める**（まずGBP/MEO→SEOの順で集中）
