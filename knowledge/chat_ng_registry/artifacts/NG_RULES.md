## ⚙️ チャットNG学習・登録フロー（Stop → Think → Log → Resume）

ユーザーからチャットで品質NG（トリガーワード: `NG:` / `NG！` / `やり直し` / `違う` / `それダメ`）を受けた場合：

1. **Stop**: 現在の作業を即座に中断する。
2. **Think**: 何がNGだったか分析する。
3. **Log**: 下記の表に**3条件（When/What/How to verify）を満たす形で**追記する。関連スキルのSKILL.mdにも同時追記する。
4. **Resume**: 書き込み完了をユーザーに宣言してから修正作業を再開する。

### 登録品質ゲート（3条件を満たさないルールは登録禁止）

| 条件 | 説明 | NG例 |
|---|---|---|
| **When（いつ発動するか）** | 具体的なトリガー条件 | ❌「レポート作成時」→ ⭕「GBP月次レポートのグラフ描画時」 |
| **What（何をする/しないか）** | 具体的な行動制約 | ❌「気をつける」→ ⭕「数値カラムのカンマを stripInt() で除去してから渡す」 |
| **How to verify（どう検証するか）** | ルールが守られたことの確認方法 | ❌「目視確認」→ ⭕「生成されたHTMLをブラウザで開き、グラフの値が元データと一致するか照合する」 |
