# GBP口コミ分析マスタースキル

本スキルは、Googleビジネスプロフィール（GBP）の口コミを全件取得し、自然言語処理により店舗の強み・弱み・評価の推移を可視化する自動化パイプラインである。

## システムアーキテクチャ
1. **抽出 (Scraping)**: `scrape_reviews.js`
   - テキストの有無に関わらず、すべての口コミ（星評価のみも含む）を抽出する。
   - オーナーからの返信の有無と内容を正確に取得する。
   - Googleマップの公式メタデータ（総件数、平均評価、業種カテゴリ）を取得する。
2. **分析 (Analysis)**: `analyze_reviews.js`
   - 全件データを用いた統計解析（評価分布、オーナー返信率、時系列推移）。
   - テキスト付きデータを用いた自然言語解析（テーマ分類、感情分析、キーワード、重複排除済みの強み・弱み抽出）。
3. **可視化 (Reporting)**: `render_review_report.js`
   - 分析結果をクライアント向けの洗練されたHTMLレポートとして出力する。
4. **【必須】品質保証 (QA)**: `validate_report.js`
   - レポート出力後、提出前に必ず実行される自動バリデーション工程。

## 作業フロー（Pre-flight to Post-flight）
1. コマンドラインから `scrape_reviews.js` に対象URLと正確なクライアント名（日本語可）を渡して実行する。
2. 生成されたJSONを入力として `analyze_reviews.js` を実行する。
3. 分析結果を入力として `render_review_report.js` を実行し、HTMLを生成する。
4. **【厳守】** 上記完了後、直ちに `gbp_review_qa_skill` に定義されたQAプロセスを `validate_report.js` で実行する。このテストを通過しない限り、作業完了を報告してはならない。
