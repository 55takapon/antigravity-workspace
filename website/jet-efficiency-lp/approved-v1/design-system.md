# Jet Produce AI導入診断LP デザインシステム

## 制作方針

- 目的: 自社のどの業務にAIを使えるかを整理する「30分無料診断」への申込み
- 主な対象: 加古川・姫路近郊の中小企業経営者、事業責任者
- 初見3秒: AI導入を大きな計画にせず、最初の1業務から相談できる
- 固有モチーフ: 生成りの紙、業務書類、濃緑の机上面、判断をつなぐ朱赤の一本線
- 実装形態: 静的HTML / Vanilla CSS / Vanilla JavaScript。SWELLへ移植しない

## セクション構成

1. First View: 自社のどの仕事にAIが使えるか。30分無料診断への最短導線
2. Repetitive Work: 同文作成、重複入力、資料検索の3業務だけを自分ごと化
3. Diagnostic Outcome: 30分で最初に試す1業務まで絞る。中間CTA
4. Consultant & Conditions: 実在担当者と、時間・方法・地域・診断後の選択肢
5. Final CTA: 見出し、補足1文、CTAの3要素だけ

## 実装条件

- `body.jet-ai-preview` と `.jet-ai-lp`、固有の `.ja-*` 名前空間以外へスタイルを出さない
- 本人写真は公開済みの実画像を直接配置し、生成画像へ差し替えない
- CTAリンク先はすべて `https://forms.gle/6wRaUhvpwhWAK2jz7`
- スマホ固定CTAは、本文内CTAが表示されたら非表示にして二重表示を防ぐ
- 重要テキストを画像へ焼き込まない
- 375 / 390 / 599 / 600 / 768 / 959 / 960 / 1100 / 1279 / 1280 / 1366 / 1440 / 1920pxで表示確認する
