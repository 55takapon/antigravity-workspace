# 💡 Ideas Inbox

クリエイティブの源泉置き場。daily-reportとは完全分離。

## ルール

- **アイデアは実施前提ではない** — 忘れないために置く場所
- **daily-reportに混ぜない** — 実施済みタスクとは別管理
- **呼んだときに出す** — 必要なときに「アイデア出して」と声かけ
- **メモのたびに通知しない** — ✅だけ返す（ノイズ防止）

## フォルダ構造

```
ideas/
├── inbox/       ← 生のアイデア（Discord から随時投入・承認不要）
├── digest/      ← 毎日22:00の自動まとめ
└── README.md    ← このファイル
```

## 入力方法（Discord from AntiCrow）

### サイレントモード（デフォルト）
メモをそのまま送る → `✅` だけ返ってくる。通知ノイズなし。

```
メモ: [内容]
idea: [内容]
アイデア: [内容]
思いついた：[内容]
```

### 応答モード（「応答して」を付ける）
詳細を返してほしいときだけ付ける。

```
メモ: [内容] 応答して
アイデア: [内容] 応答して
```

### まとめ・一覧表示

```
アイデアまとめ       → digest を手動生成して返却
アイデア出して       → inbox + digest の一覧を表示
idea-review         → 同上（英語トリガー）
```

## 承認不要の理由

`ideas/inbox/` はワークスペース内（`c:\Users\hangy\.gemini\antigravity\ideas\`）に存在するため、
`write_to_file` が承認プロンプトなしで即座に実行される。

## まとめタイミング

毎日 22:00 JST に自動実行（cron 登録済み）
→ `digest/YYYYMMDD_digest.md` に生成
