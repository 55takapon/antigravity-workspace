# Jet Produce Contact Form Dark Plan

添付セクションの方向性に寄せた追加案です。既存案のファイルは変更せず、別ファイルとして追加しています。

## 使うファイル

- `contact-form-7-form-dark-plan.txt`  
  Contact Form 7 の「フォーム」タブに貼り付けます。

- `additional-dark-plan.css`  
  WordPress 管理画面の「外観 > カスタマイズ > 追加CSS」に貼り付けます。

- `preview-dark-plan.html`  
  見た目確認用の静的HTMLです。

## デザイン意図

- 添付セクションに合わせ、深いネイビーから青緑への面グラデーションを採用。
- 左の青緑ライン、右奥の円形ラインで、暗い面に奥行きを出しています。
- 入力欄は半透明カード風、ラジオボタンは3つの選択カードとして構成。
- 選択中の項目はゴールド枠で強調し、添付の中央カードに近い見え方にしています。
- 送信ボタンは白いピル型で、添付セクションのCTAに寄せています。

## メール設定

メール設定は既存の `mail-settings.txt` をそのまま使えます。
